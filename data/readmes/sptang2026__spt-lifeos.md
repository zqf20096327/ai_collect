# LifeOS — 会自我进化的 AI 第二大脑操作系统（Multi-Agent Second Brain & PKM）

> **开源、下载即用的多 Agent 个人知识管理与内容创作操作系统（支持 Claude Code / Antigravity / Codex / Cursor / WorkBuddy / Trae / Obsidian）**
>
> **版本**：v1.1 · **协议**：MIT · **核心结构**：五层架构 · 10 个协同 Agent · 输入 → 加工 → 输出 → 进化完整闭环

---

## TL;DR（30 秒看懂 LifeOS）

**LifeOS** 是一套开源的 **AI 原生个人第二大脑（AI Second Brain / PKM）操作系统**。通过「核心身份层 + 进化层 + 输入层 + 加工层 + 输出层」五层架构与 10 个分工明确的 Agent，它把你的读书笔记、文章收藏、灵感碎片自动拆解为可复用的 **Wiki 内容单元库（QST / CON / OPI / CAS / SOL）**，按需装配成选题骨架与成稿，并把每一次思考与创作规律沉淀回个人身份与记忆文件——**用得越久，AI 越懂你的思维方式与表达风格**。

**适用工具**：Obsidian、Claude Code、Google Antigravity、OpenAI Codex、Cursor、WorkBuddy、Trae、Cline 等任意支持读取本地 Markdown 文件夹的 AI Agent。

## 与传统笔记软件 / 静态知识库的区别

| 对比维度 | 传统静态知识库（普通笔记/收藏夹） | **LifeOS（五层多 Agent 第二大脑）** |
| :--- | :--- | :--- |
| **输入处理** | 收藏即吃灰，文章和金句长期沉底 | 4 个输入 Agent（读书/金句/Web/碎片）自动提纯入库 |
| **知识复用** | 每次写文章或做视频从空白页憋起 | 拆解为 5 类原子单元（QST/CON/OPI/CAS/SOL），新选题直接装配骨架 |
| **AI 理解度** | 每次新开对话都要重复解释“我是谁” | `00-LifeOS/IDENTITY` 自动加载使命、现状与个人风格画像 |
| **长期复利** | 知识越积越乱，难以检索 | `01-进化系统` 持续沉淀洞见与表达模式，反哺全部 10 个 Agent |
| **部署门槛** | 需配置复杂数据库或插件 | 纯 Markdown 文件夹，下载即用，发给任意本地 Agent 一键初始化 |

```text
输入（素材）→ 加工（提纯）→ 输出（创作）→ 进化（沉淀）→ 反哺核心
```

## 快速开始（5 分钟跑起来）

### 方式一：交给任意本地 AI Agent 一键搭建（推荐）

下载或克隆本仓库到本地后，用 **Claude Code / Antigravity / Codex / Cursor / WorkBuddy / Trae** 打开仓库目录，直接发送下面这段话：

```text
请先读取当前仓库的 README.md、AGENTS.md 和 AGENT_LINKS.md，理解这套 LifeOS 五层架构。
然后通过 5 个简洁问题采访我，帮我生成 🥷 00-LifeOS/IDENTITY/ 下的 TELOS.md、CONTEXT.md 和 PROFILE.md，完成我的个人 LifeOS 初始化。
```

### 方式二：手动配置使用

1. **配置个人身份层（IDENTITY）**：编辑 `🥷 00-LifeOS/IDENTITY/` 下的三个核心文件：
   - **TELOS.md**：你的使命与长期目标
   - **CONTEXT.md**：你当前的工作与生活状态
   - **PROFILE.md**：你的思维偏好、特质与表达风格
2. **接入日常输入与创作**：
   - 深度读书时在 `🟡 02-阅读palace` 创建阅读笔记
   - 有灵感时往 `🟡 02-碎片Agent/fragments/` 记录碎片
   - 看到好文章丢进 `🟡 02-X`
   - 需要打磨观点或写稿时在 `♻️ 03-思考系统` 与 `🔵 04-内容创作` 启动协作

## 三大核心机制

### 1. Wiki 内容单元库（QST / CON / OPI / CAS / SOL）
把旧文章、读书笔记和对话记录拆解为五类可复用原子单元：**问题（QST）、概念（CON）、观点（OPI）、案例（CAS）、方案（SOL）**，并维护关系索引。新选题来临时直接从单元库按主题调取，彻底告别“收藏吃灰”。

### 2. 选题装配稿（scripts）
告别每次从零憋稿。AI 从 `♻️ 03-Wiki` 拉取关联单元，自动拼出高密度的选题论证骨架，创作者只需把精力集中在核心判断、亲身经历补充与语言润色上。

### 3. 内容处理状态追踪
通过 `🥷 00-LifeOS/WORKING/content-processor.md` 持续记录历史素材拆解进度，防止重复加工与遗漏。

## 常见问题（FAQ）

### 什么是 AI 驱动的 LifeOS（个人第二大脑操作系统）？
LifeOS 是基于本地 Markdown 文件夹与多 Agent 协作规范构建的个人知识操作系统。它用清晰的目录协议把“信息输入、知识提纯、内容输出、经验进化”串成自动化流水线，让 AI 长期记住你的目标、知识资产与语言习惯。

### LifeOS 支持哪些 AI Agent 和笔记软件？
因为底层 100% 基于纯文本 Markdown 文件，本仓库天然兼容 **Obsidian**（作为可视化浏览与双链管理界面），并可直接搭配 **Claude Code、Google Antigravity、OpenAI Codex、Cursor、WorkBuddy、Trae、Cline** 等所有能读写本地文件的 AI Agent。

### 完全不懂代码的小白可以用吗？
完全可以。整个系统没有任何复杂数据库或编译依赖，只需点击右上角 `Code → Download ZIP` 解压到本地，用任意支持读文件夹的 AI 软件打开目录，发一句「按 `AGENTS.md` 帮我初始化 LifeOS」即可开始使用。

### 如何把旧文章、旧视频稿导入这套系统？
把已有稿件放入对应输入目录（或 `♻️ 03-Wiki/_归档-参考文章`），让 Agent 按 `AGENT_LINKS.md` 中的“旧内容回流路径”批量拆解为 QST/CON/OPI/CAS/SOL 单元，并同步更新 `WORKING/content-processor.md`。
