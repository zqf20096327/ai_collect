## 1. Overview

**WebAgent 2.0** is an enterprise-grade, privacy-first Chromium browser extension designed to turn web-based Large Language Models (LLMs) into fully autonomous local engineering agents. 

By creating a secure, low-latency bridge between browser-based AI chats and your local system (via standard Model Context Protocol - MCP and the Nexus execution core), WebAgent allows web models to safely inspect files, run shell commands, edit code, call local tools, and orchestrate complex development tasks—without requiring paid API keys or exposing proprietary code to untrusted cloud intermediaries.

---

## 2. What's New in WebAgent 2.0 (vs v1.3.4)

WebAgent 2.0 is a complete architectural overhaul delivering unmatched stability, zero-error execution, and a refined modern user experience:

- **New 3D Brand Identity & Visual Upgrade**:
  - Custom 3D glossy visual brand, rounded app icon, and a distraction-free main action drawer.
- **Zero-Error Resilient Parser Engine**:
  - Automatically strips web-injected code block artifacts (such as `nexusCopyDownload` buttons generated by DeepSeek/ChatGPT).
  - Four-tier self-healing parser for Windows single backslashes, unescaped quotes, and complex PowerShell hash tables (`$b=@{...}`).
  - Completely eliminates red "Errors" warnings in `chrome://extensions/`.
- **Dual-Isolated Control Panels (Nexus Exclusive MCP + Skills Center)**:
  - Separate dropdown panels on the main drawer for Exclusive MCP tools and Skill capabilities.
  - Dedicated local directory path inputs with one-click trash can (`🗑️`) clearing buttons.
  - Independent scrollable list containers (`max-height: 140px; overflow-y: auto`) with row-level instant delete controls.
- **Full Accordion Settings Center**:
  - Converted monolithic settings into 5 independent collapsible accordion cards:
    1. *Card 0: Official Guide & Blog Tutorial* (integrated circular author avatar and direct blog link).
    2. *Card 1: Interface Language & Local Paths* (4-language grid switch, default workspace, exclusive MCP, skills path).
    3. *Card 2: Execution & Rate-Limiting Policies* (privacy desensitization, auto-execute, safe review mode, delay and quota sliders).
    4. *Card 3: Extensions & Advanced Options* (registered MCP tools, custom system prompts, token/port).
    5. *Card 4: Developer & Community Matrix* (GitHub repo, official Telegram channel, QQ group, feedback email).
- **100% Pure Multilingual Internationalization (Zero-Leakage i18n)**:
  - Full native translations for English (`en-US`), Simplified Chinese (`zh-CN`), Japanese (`ja-JP`), and German (`de-DE`).
  - All UI elements, toasts, placeholders, and injected model protocols dynamically re-render with zero language contamination.
- **Cross-Session Auto-Handover & State Preservation**:
  - Monitors web platforms for session context length limits. Automatically packages project path, active goals, and recent execution checkpoints, opens a fresh chat, and resumes execution seamlessly.

## 5. Quick Installation (5 Minutes)

### Step 1: Clone or Download
Clone this repository to your local computer:
```bash
git clone https://github.com/ysunyang4/webagent.git
```

### Step 2: Load into Chromium Browser
1. Open any Chromium-based browser (Google Chrome, Microsoft Edge, Brave, etc.):
   - Chrome: Navigate to `chrome://extensions/`
   - Edge: Navigate to `edge://extensions/`
2. Toggle on **Developer Mode** in the top-right corner.
3. Click **Load unpacked** in the top-left corner and select the cloned `webagent` directory (ensure it contains `manifest.json`, `content.js`, etc.).

### Step 3: Configure & Run
1. Navigate to any supported AI website (e.g. [DeepSeek](https://chat.deepseek.com/) or [ChatGPT](https://chatgpt.com/)).
2. The **WebAgent 2.0 floating control pill** will appear automatically at the top of the chat page.
3. Click the gear icon to open the **Settings Center** and set your default workspace directory following the [Official Blog Guide](https://blog.ycu.de5.net/).
4. Click **Inject Protocol** to start letting the web AI collaborate with your local system!

## 6. Privacy & Security Architecture

- **Strict Local Loopback**: All inter-process communication is locked to `127.0.0.1` (localhost). Zero code or command telemetry is uploaded to external servers.
- **Automatic Data Desensitization**: In-flight regex filters mask API keys, private tokens, passwords, and absolute user paths before sending tool outputs back into the web chat.
- **Execution Rate-Limiting & Quota**: Built-in delay buffers (0.5s – 10s) and configurable loop limits (1 – 50 steps) prevent unintended runaway loops.
