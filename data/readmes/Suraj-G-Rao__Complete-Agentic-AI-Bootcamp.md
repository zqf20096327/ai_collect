## 📖 About This Bootcamp

This repository is a **complete, structured curriculum** for mastering Agentic AI — from writing your first Python script to building autonomous multi-agent systems powered by **LangChain**, **LangGraph**, and cutting-edge LLMs.

Every module is self-contained with Jupyter notebooks, real-world projects, and production-grade code. Whether you're a beginner or a seasoned developer looking to level up with AI agents, this bootcamp has you covered.

## ⚡ Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Suraj-G-Rao/Complete-Agentic-AI-Bootcamp.git
cd Complete-Agentic-AI-Bootcamp
```

### 2. Set Up a Virtual Environment

```bash
# Using venv
python -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows

# Or using uv (recommended for newer modules)
pip install uv
uv venv && source .venv/bin/activate
```

### 3. Install Dependencies

Each module has its own `requirements.txt`. Navigate to the module you want:

```bash
cd "03-Langchain Basics"
pip install -r requirements.txt
```

### 4. Configure API Keys

Create a `.env` file in the relevant module folder:

```env
OPENAI_API_KEY=your_openai_api_key
GROQ_API_KEY=your_groq_api_key
LANGCHAIN_API_KEY=your_langsmith_api_key
LANGCHAIN_TRACING_V2=true
LANGCHAIN_PROJECT=your_project_name
```

> ⚠️ **Never commit your `.env` file!** It's already covered by `.gitignore`.

### 5. Start Learning!

```bash
# Launch Jupyter for notebook-based modules
jupyter notebook

# Or run a Streamlit project
cd "17-AI Chatbot using langgraph"
streamlit run app.py
```
