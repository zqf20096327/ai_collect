# GitHub 大白话解读

一个 Chrome / Edge 扩展：粘贴一个 GitHub 仓库链接，还你一份**中文大白话说明**——它是干嘛的、靠不靠谱、怎么上手、有哪些坑。

不用懂英文，也不用懂代码。

---

## 它解决什么问题

GitHub 上很多好项目，README 是英文的，术语一个接一个：RPC、序列化、依赖注入、幂等……看得懂每个字，但不知道这东西到底是干嘛用的、跟我有没有关系。

这个扩展干的事很简单：把仓库的客观数据（星标、更新频率、许可证、文件结构、README）抓下来，交给 AI 翻译成一段**给外行看的话**，然后按固定结构排出来。

## 出来的东西长这样

固定五段，从上往下读就行：

1. **一句话 + 一个比喻** —— 它是什么，用生活里的事打个比方
2. **体检表** —— 活跃度、星标、许可证、体积，每项配一句人话解释
3. **它解决什么痛点** —— 「以前你得……现在它能……」，以及谁会用得上
4. **怎么用起来** —— 分几步，每步在哪做、大概花多久
5. **实在话** —— 有坑就说坑，不适合你就直说不适合
6. **术语小抄** —— 报告里出现的黑话，一句话解释

最后给个结论：推荐 / 看情况 / 不推荐，以及为什么。

## 装（约 1 分钟，只需一次）

1. 下载这个项目（右上角 Code → Download ZIP，解压）
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车（Edge 是 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选中解压出来的 **`插件`** 文件夹（里面能看到 `manifest.json`）

看到一张写着「GitHub 大白话解读」的卡片就装好了。建议点浏览器右上角的拼图图标，把它固定到工具栏。

详细版说明见 [安装说明.txt](安装说明.txt)。

## 第一次用：填一个 AI 接口的 Key

扩展本身不带你任何 Key，得自己填一个。推荐 DeepSeek，便宜：

1. 去 <https://platform.deepseek.com> 注册，创建一个 API Key
2. 点扩展图标 → 「设置」→ 把 Key 粘进去 → 保存

一次解读大概几分钱。接口地址默认就是 DeepSeek，也支持任何 OpenAI 格式的兼容接口（填 base url + 模型名即可）。

> Key 只存在你本机的浏览器存储里，请求从你的浏览器直接发到 AI 服务商，不经过任何中间服务器。

## 用

**方式一（最省事）**：打开任意 GitHub 仓库页面，右下角有个绿色的「大白话解读」按钮，点一下，新标签页直接出结果。

**方式二**：点扩展图标，粘链接，点解读。

## 看完还能接着问

报告下面有个对话区，它记得上面这份报告，不用重复解释。重点不是复述，是给**能照着做的方案**：分几步、每步在哪做、花多久、会卡在哪。

- 想就某句话问：直接选中报告里的文字，会浮出一个按钮
- 答完它会给两三个「接着问」的建议，点一下就行

## 转交给别的 AI 接着做

对话区右下角有个「转交给 XXX →」，点开可以选：

- **桌面应用**：WorkBuddy、Claude、ChatGPT、Cursor、豆包、通义千问（装了才跳得过去）
- **网页版**：ChatGPT、Claude、Kimi、豆包、DeepSeek、通义千问、腾讯元宝、Gemini

选哪个都会先把「仓库信息 + 完整报告 + 聊过的内容 + 你最后问的问题」整理成一段话复制到剪贴板，再跳过去，粘一下就能接着干。

菜单最下面还能填自定义地址，网址里写 `{q}` 会被替换成这次要转交的内容。

## 关于 GitHub 限流

查一个仓库要调 3～4 次 GitHub 接口。不登录的话每小时只有 60 次，约合 15 份解读，点多了会被拦。

在设置里填一个 GitHub 令牌（[github.com/settings/tokens/new](https://github.com/settings/tokens/new)，勾选框一个都不用选，公开仓库不需要任何权限）就变成每小时 5000 次。同一个仓库反复点「重新生成」不会重复消耗额度。

## 目录结构

```
插件/                 扩展本体，装的就是这个文件夹
  manifest.json       扩展清单（MV3）
  background.js       所有网络请求都在这儿（绕过跨域限制）
  app.html / app.js   主界面：报告渲染 + 追问对话 + 转交
  popup.html/js       点图标弹出的小窗
  content.js          在 GitHub 页面右下角注入按钮
  icons/              图标
index.html            早期的单文件网页版，留作降级，双击就能用
启动.cmd              Windows 下用浏览器打开网页版
安装说明.txt          给人看的安装步骤
```

## 几个实现上的选择

- **报告分段并行生成**。一开始是一次性让 AI 吐一个大 JSON，经常因为撞 max_tokens 被截断，表现就是「第一次失败、第二次成功」「内容总是不完整」。现在拆成三段（开头 / 步骤痛点 / 结论术语）并行要，每段单独做 JSON 抢救和加额度重试，单段失败不影响其余。
- **所有请求走 background**。MV3 的扩展页里 fetch 会受 CORS 和 CSP 限制，交给 service worker 加 host_permissions 最稳。
- **报告可导出**。能打印成 PDF、复制成 Markdown、下载成单文件网页（发微信里别人双击就能看）。

## 已知限制

- 桌面应用那一栏走的是各家自己的协议（`workbuddy://`、`claude://` 等），没装对应 App 点了不会有反应，换网页版即可（内容已经在剪贴板里了）
- 转交只能把内容送到对面输入框的剪贴板，没法替你按回车——这是浏览器的限制
- 私有仓库需要给令牌勾 `repo` 权限才能读
