# 🍼 超级奶爸 AI 育儿助手（Super Dad）

> 0-6 岁婴幼儿一站式科学养娃 AI Skill，基于 WHO、AAP、中国营养学会等权威机构指南。

## ✨ 简介

**Super Dad** 是一个为 AI Agent 设计的育儿领域 Skill，让 AI 变身专业的育儿顾问。它涵盖了从喂养管理到早教互动的全方位育儿场景，提供 **12 大功能模块**，帮助新手爸妈科学、从容地养育宝宝。

所有健康建议均基于权威医学机构的最新指南，所有输出均为**纯静态文件**（Excel / HTML），无需服务器支持。

| # | 模块 | 类型 | 说明 |

| 12 | 🧒 发育里程碑 | 内置知识 | 大运动/精细动作/语言/社交认知四大域分月龄参考 |

## 🚀 快速使用

### 安装依赖

```bash
pip install -r requirements.txt
```

### 脚本工具示例

#### 1. 生成喂养计划

```bash
# 生成 8 月龄混合喂养计划
python scripts/feeding_planner.py --age 8 --method 混合

# 指定过敏原
python scripts/feeding_planner.py --age 12 --method 奶粉 --allergens 牛奶,鸡蛋

# 自定义输出目录
python scripts/feeding_planner.py --age 6 --method 母乳 --output ./output
```

输出：`喂养计划_8个月.xlsx`（含奶量计划、辅食食谱、营养建议三个 Sheet）

#### 2. 分析生长曲线

```bash
# 需要准备 CSV 数据文件
python scripts/growth_tracker.py --gender 男 --data growth.csv
```

CSV 格式要求：
```csv
月龄,体重kg,身高cm,头围cm
0,3.3,50.0,34.5
1,4.5,54.0,37.0
3,6.2,61.0,40.5
```

输出：`生长曲线报告.html`（交互式图表，含 WHO P3/P15/P50/P85/P97 百分位线）

#### 3. 生成宝宝成长主页

```bash
# 基础用法
python scripts/baby_website_generator.py --name 小明 --birthday 2025-06-15

# 完整用法
python scripts/baby_website_generator.py \
  --name 小明 \
  --birthday 2025-06-15 \
  --gender 男 \
  --photos ./photos \
  --milestones milestones.json
```

里程碑 JSON 格式：
```json
[
  {"date": "2025-07-01", "title": "第一次微笑", "description": "宝宝对妈妈露出了第一个微笑"},
  {"date": "2025-09-15", "title": "会翻身了", "description": "从仰卧翻到俯卧"}
]
```

输出：`小明的成长主页.html`（纯静态，直接浏览器打开）

#### 4. 获取育儿资讯报告

```bash
# 按主题获取
python scripts/news_report_generator.py --topic 营养

# 限定年龄段
python scripts/news_report_generator.py --topic 健康 --age-range 0-1岁
```

可选主题：`营养` | `健康` | `教育` | `安全` | `综合`

输出：`育儿资讯报告_营养.html`
