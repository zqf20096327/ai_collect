# 💻 Development

## GitHub.dev

https://www.github.dev/

Open any GitHub repository instantly in a lightweight VS Code editor.

Example:

```
https://github.dev/owner/repository
```

---

## VSCode.dev

https://vscode.dev/github.com/owner/repository

Open GitHub repositories directly inside VS Code for the web.

---

## Bolt + GitHub

https://bolt.new/github.com/owner/repository

Import a GitHub repository directly into Bolt for AI-powered development.

---

## CodeSandBox + GitHub

https://githubbox.com/owner/repository

Import a GitHub repository directly into CodeSandbox where you can setup and run the project!

---

## GitMCP

https://gitmcp.io/owner/repository

Connect GitHub repositories to MCP-compatible AI agents.

---

## GhGrab

https://github.com/abhixdd/ghgrab

CLI utility that lets you quickly grab files or folders from a repository directly from your terminal.
