# AI Operator

一个 Windows 桌面小程序：读取你指定窗口的画面，交给你自己配置的模型接口判断，然后模拟键盘和鼠标执行动作，主要用途是替人完成游戏里的重复操作

它适合节奏不快的游戏：回合制、RPG、卡牌、策略、开放世界探索，不适合需要毫秒级反应的射击游戏，原因见「已知限制」

> 本软件会模拟真实的键鼠输入，可能违反游戏条款并导致账号被封，首次运行必须阅读并逐项确认《免责声明》与《用户使用协议》，请先判断自己能否接受这些风险

## 运行要求

- Windows 10 / 11，64 位系统
- .NET Framework 4.8（Windows 10 2004 之后的版本默认自带，老系统需要单独安装）
- 一个支持图像输入的模型接口，默认指向 DeepSeek 官方接口，需要自备 API Key
- API 调用费用由你自己承担，本软件本身免费

## 下载与运行

1. 在仓库的 **Releases** 页面下载 `AI-Operator-v1.4-win64.exe`（约 388 KB）
2. 双击运行，程序没有代码签名，Windows 可能提示「已保护你的电脑」：点「更多信息」→「仍要运行」
3. 第一次运行会弹出协议窗口，勾选三项确认后才能进入主界面，确认之前主界面被磨砂遮罩盖住，这个窗口也关不掉，只能选择同意或退出
4. 免安装，删掉 exe 就是卸载，本机残留的配置见「数据与隐私」

## 第一次使用

1. **连接**：粘贴 API Key（`sk-` 开头），点「测试连接」，返回「通了」说明接口可用
   密钥使用 Windows 账户的 DPAPI 加密后保存在本机，不会发送给开发者
2. **游戏**：把游戏切换到无边框窗口模式，点「刷新列表」选中它，再点「抓一帧」确认预览不是黑屏
3. **说明**：在「AI」页写清游戏名称、界面布局、当前目标，这段文字每一轮都会发给模型，写得越具体，执行结果越接近预期
4. 按 **F8** 开始，第一次使用建议先盯着看几轮，确认动作表里的按键和游戏的实际键位一致

## 热键

全局生效，游戏在前台时也能用

| 键 | 作用 |
|---|---|
| F8 | 开始 / 暂停 |
| F9 | 接管 / 交还（接管期间程序不动键鼠） |
| F10 | 紧急停止，立即松开所有按键与鼠标 |
| F11 | 让模型立刻重新读取画面 |
| F12 | 叠加层开关 |
| F7 | 按住不放，叠加层变成可拖动，松手记住位置 |

热键可在「热键」页修改，改完立即生效，如果某个键被游戏占用，换一个即可

## 动作是怎么执行的

模型每轮返回的不是「按一下 W」，而是带时长的动作序列：

```json
{"thought":"前方有箱子，先走过去","actions":[
  {"do":"walk","dir":"forward","meters":1.0},
  {"do":"click","x":0.52,"y":0.61}
]}
```

- `walk` 按「动作」页的标定值换算成按住时长，默认 620ms 对应 1 米
- `act` 按动作名执行，键和按住时长取「动作」表里那一行，模型不需要知道具体键值
- `turn` / `look` 按鼠标灵敏度换算成横向位移，转之前先把光标拉回窗口中心
- 一轮可以输出多个动作，本地按毫秒精确执行，同一批里连续的移动会合并成一次长按
- 每轮之间要等模型回复 1 到 2 秒，这期间角色是静止的，「移动滑行」会把最后一段移动多按一会儿来补这个空档
- 下一轮模型会看到上一轮的动作和结果，走得不够可以自己补

标定方法：把「走 1 米需要多少毫秒」调到合适值，或者点「试走 1 秒」看角色走了多远再反推

## 安全机制

- **白名单**：只有「动作」表里启用的键会被按下，表外的键会触发暂停
- **危险动作**：标记为「危险」的动作默认拦截，可在「AI」页关闭拦截
- **预算**：每日预算到顶后自动暂停
- **急停**：F10 任何时候都能用，会释放所有按下的键和鼠标

这些机制只能降低风险，不能消除风险，不要让程序在无人监督的情况下长时间运行

## 方案与 Beta 功能

左侧「方案」页可以保存多套配置：动作表、走位标定、游戏说明各存一份，换游戏时切换方案即可，不会覆盖其它方案，也不会动你的键位

托盘右键也能切方案

「AI」页最下面有三个 Beta 开关，默认关闭，每次打开都会弹出条款，勾选三项并同意才生效，关掉窗口或取消都不会打开：

| 功能 | 作用 | 代价 |
|---|---|---|
| 连续控制 | 移动结束不松键，一直按到下一轮结论出来，缓解走走停停 | 会走过头，运动中的画面判断没那么准 |
| 键盘转向 | 用左右转身键代替鼠标，适用于鼠标注入被游戏过滤的情况 | 占用两个键，角度靠标定，部分游戏转身有惯性 |
| 允许购买 | 放开危险动作拦截，允许在单笔上限内买道具 | 真的会花钱，价格靠模型看画面读，可能读错 |
| 不限金额购买 | 连单笔上限也去掉，看到能买就买 | 余额可能被花光，不可撤回 |
| 自由按键 | 允许 AI 试动作表以外的键 | 白名单失效，可能误触删除、退出、付费入口 |

## 峰谷提示

标题栏右侧常驻一个小指示，不做成胶囊：红色圆点加「峰」表示现在按双倍价计费，绿色「谷」表示半价，后面的数字是距价格切换的倒计时，每秒刷新，鼠标停上去能看到完整规则

规则以北京时间为准：工作日 09:00-12:00、14:00-18:00 为高峰，其余时段（含午休、夜间、周末、中国法定节假日全天）为空闲，空闲价是高峰价的一半

## 版本检查与更新

启动后程序会在后台向仓库的 `version.json` 请求一次版本号，每天最多一次，结果缓存在本机，它只有三种表现：

| 情况 | 表现 |
|---|---|
| 有比当前新的版本 | 右上角出现一条可关闭的「v1.1 已发布」轻提示，不挡操作，25 秒后自动消失 |
| 发布者把最低支持版本抬到了你之上 | 界面被磨砂遮罩盖住，弹出无法关闭的更新窗口，只能下载新版或退出 |
| 请求失败、断网、仓库不存在 | 什么都不弹，照常使用 |

这个检查可以关掉：启动加 `--skip-update-check` 参数即可，它只读取一个公开的版本号文件，不发送任何本机信息

## 数据与隐私

程序不设服务器，不做统计和埋点，除了一次版本号请求之外不主动联网，所有数据都在本机：

```
%APPDATA%\AIOperator\
├─ config.json  配置（模型、Key 地址、动作表、窗口句柄等）
├─ key.bin      API Key，用当前 Windows 账户加密，换账户无法解密
├─ cost.txt     当日估算花费
├─ legal.json   协议确认记录（含版本与时间）
└─ operator.log 运行日志
```

运行过程中，目标窗口的截图会连同你填写的说明文字一起发送到**你自己配置**的接口，是否保存、保存多久由该服务商决定，程序不主动上传这些内容到其他地方

删除 `%APPDATA%\AIOperator\` 这个文件夹等于重置软件，下次启动会重新弹出协议窗口

## 常见问题

**预览是黑屏**
游戏的独占全屏模式截不到画面，改成无边框窗口模式，把游戏窗口置前再抓一帧，少数带反作弊的游戏会直接拒绝截图，这种情况只能放弃

**按 F8 没有反应**
先看左侧状态是否变成「运行中」，没有变化通常是游戏抢占了热键，去「热键」页换一个键，缺少 API Key 或没有选择窗口时，程序会跳回对应页面并在右上角提示

**界面文字太小或太大**
程序按系统缩放比例绘制，如果系统缩放设置在 125% 以上觉得偏小，可以在「设置 → 系统 → 显示」里调整，或在 exe 的「属性 → 兼容性 → 更改高 DPI 设置」里选择「系统（增强）」

**角色走起来一顿一顿**
每一轮之间要等模型回复，这 1 到 2 秒里程序不按任何键，所以原生就是走走停停，现在有三层缓解：同一批里连续的移动会合并成一次长按，单次按住上限 8 秒，最后一段移动会多按「移动滑行」那么多毫秒，如果还觉得碎，把「AI」页的「移动滑行」往上调到 800 甚至 1200，代价是停下时会稍微走过头

**AI 转不动视角**
先确认「鼠标灵敏度」不是 0，程序每次转视角前会把光标拉回游戏窗口中央，避免光标贴住屏幕边缘后位移被吞掉，如果这个游戏必须按住鼠标右键拖才能转镜头，去「AI」页打开「转视角时按住右键」，还不行的话在「日志」页看每轮有没有「转动视角」这条，完全没有就是模型没发这个动作，有但画面不动就是游戏过滤了注入的鼠标

**杀毒软件报毒**
程序没有数字签名，且会模拟键鼠输入、截取窗口画面，容易被启发式引擎误判，可以把它加入信任列表，或者从源码自行编译（见下）

**费用比预期高**
「图片精度」调低、「每轮间隔」调大、打开「画面没有变化时跳过请求」，都能明显降低成本

## 已知限制

- 云端视觉每轮耗时 0.5 到 2 秒，做不到射击游戏级别的跟枪与压枪
- 独占全屏、HDR、多显示器缩放异常时，截图可能偏黑或变形
- 部分游戏的反作弊会拒绝截图或注入输入，这类情况无解
- 只提供 64 位版本，32 位系统无法运行
- 尚未实现：多套配置方案切换、日志导出、弹幕互动

## 从源码构建

只需要 .NET Framework 自带的 C# 编译器，不需要 Visual Studio 或 .NET SDK

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物在 `dist\AI-Operator-v1.4-win64.exe`，脚本会同时打印文件大小和 SHA256

```
src\            源码（WPF，C# 5 语法，兼容 .NET Framework 4.x）
assets\         图标与资源
tools\          开发期使用的测试脚本，运行程序不依赖它们
docs\           《免责声明》《用户使用协议》全文
version.json    版本清单，决定新版提示与强制更新
build.ps1       构建脚本
```
