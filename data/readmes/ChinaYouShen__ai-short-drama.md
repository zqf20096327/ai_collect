# AI 生成短剧技能包（ai-short-drama）

一套面向 AI 智能体的**中文短剧 / 漫剧 / 视频提示词创作技能包**。按阶段产出选题、大纲、人物卡、场景与道具资产、剧本、分镜、图片提示词、漫剧分镜，以及 MiniMax H3 的文戏 / 武戏视频提示词。武戏按体系分六大类（武侠、神话、修真、异能、原创等），逐层选到门派与招式，随时可退回上一层；东方武侠一类已收全金庸十五部作品带特效的武功。

- 许可证：**GPL-3.0** —— 可自由商用，但修改后分发必须同样以 GPL-3.0 开源
- 语言：简体中文
- 适配：Codex / Cursor / DeepSeek Harness / 豆包 / 文心一言 / WorkBuddy

> 本技能只负责**内容整理与提示词生产**，不负责上传素材、调用 API、实际生成图片或视频、剪辑与成片验收，这部分交给外部工作流。

## 快速开始

保留 `ai-short-drama` 文件夹的**完整目录结构**，入口 `SKILL.md`、`references/` 和所选平台的 `adapters/` 文件需同时可访问，否则按需模块无法加载。

| 智能体 | 接入文件 |
| --- | --- |
| Codex | `SKILL.md`、`agents/openai.yaml`（可用 `$ai-short-drama` 触发） |
| Cursor | `adapters/cursor.mdc` |
| DeepSeek Harness | `adapters/deepseek-harness.md` |
| 豆包 | `adapters/doubao.md` |
| 文心一言 | `adapters/wenxin.md` |
| WorkBuddy | `adapters/workbuddy.md` |

接入时让智能体读取对应入口文件与根目录 `SKILL.md`，并确保入口文件内的相对路径仍指向同一技能目录。

## 触发词

总触发 `/AI生成短剧`，或直接进入独立阶段：

| 触发 | 产物 |
| --- | --- |
| `/选题` `/大纲` | 题材方向、故事大纲 |
| `/人物` `/场景` `/道具` `/站位` | 人物卡、场景卡、道具卡、站位卡 |
| `/剧本` `/分镜` | 分集剧本、镜头分镜 |
| `/图片` `/漫剧` | 图片提示词、漫剧分镜 |
| `/文戏` `/武戏` | H3 视频提示词（对白/表演 或 对抗/格斗） |
| `/必杀技` `/武戏体系` | 带招名与法相的大招；或是先查武戏分哪几类、怎么单选 |
| `/H3` | 直接生成 H3 提示词 |

触发词后的全部文字即本阶段输入，只加载对应模块。例如：

```
/AI生成短剧 分镜 写第3集的连续镜头
/武戏 两人徒手交锋
/图片 角色三视图
```

## 核心设计

- **阶段可独立调用**：选题、大纲、人物、资产、剧本、分镜、图片提示词、H3 提示词互不强制前置，可随时「跳过 / 直接做 X / 只做检查 / 回到上一步」。
- **按需加载**：只读取当前任务需要的那一个模块，避免整包灌进上下文。
- **事实优先**：用户给定的对白、人物、招式顺序、素材用途、结局逐字保留；未授权不新增剧情、角色与台词。假设必须显式标注。
- **文武分治**：同一段同时含文戏与武戏时按转折拆段，各套各的规则，不混写。
- **体系先行**：武戏先定「哪一套武学」再谈招式。能量设定决定法相、光形与色板，技术参数（范式、时长、镜数）跨体系共用，所以换题材不必重写规则，只换体系卡。
- **路线严格分离**：T2VA / I2VA（首帧）/ L2VA（尾帧）/ FL2VA（首尾帧）/ Ref2VA（多参考）字段不混用，参考标签数量与素材清单一一对应。
- **景别约束**：画面中有人物时不用远景或大全景，中景仅在必须读清关系与位置时短暂使用。
- **输出前自检**：交付前逐条核对工作方式、戏型、路线、编号稳定性、时长可行性、声音分层，并明确「文本自检不等于成片验证」。

## 使用示例

```
/文戏 新建，文生视频，严格改写，中文。两个人在茶馆谈判，保留我提供的对白，重点表现克制和试探。
```

```
/武戏 优化，首帧图生，兵器交锋，多镜连续，中文。保留现有招式顺序，补足接触点、受力和镜头衔接。
```

```
/武戏 武侠，丐帮对少林，两人徒手，8 秒。
```

```
/必杀技 神话，青铜天马，天马流星拳，12 秒。背后要有青蓝色带翼天马法相，出拳按原作那种流光轨迹。
```

```
/武戏 天龙八部，段誉对鸠摩智，六脉神剑对火焰刀，10 秒。
```

```
/武戏体系 金庸，天龙八部，想看全部带特效的武功
```
