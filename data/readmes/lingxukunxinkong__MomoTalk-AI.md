## 项目简介

MomoTalk-AI 是一款基于 Web 技术的智能聊天应用，集成了 AI 大模型对话功能，支持多种角色设定和个性化对话体验。应用采用Blue Archive（蔚蓝档案）游戏角色主题色设计，提供直观友好的用户界面。主打简约，轻量，开箱即用。

## 主要特性

- **多角色对话**：内置 11 个 Blue Archive 游戏角色，每个角色拥有独特的性格和对话风格
- **智能 AI 对话**：集成多种 AI 大模型，支持自然语言处理和上下文理解
- **聊天记录管理**：本地存储对话历史，支持聊天记录清除功能
- **响应式设计**：适配各类设备屏幕尺寸，提供一致的用户体验
- **Markdown 支持**：完整支持 Markdown 语法渲染，包括代码高亮和特殊格式
- **深度思考展示**：特殊设计的思考容器，直观展示 AI 推理过程（由社区版贡献）

## 技术架构

### 前端技术
- 原生 HTML5、CSS3 和 JavaScript
- 响应式 CSS Grid 和 Flexbox 布局
- 自定义 CSS 动画和过渡效果
- 本地存储 API 及聊天记录用于数据持久化

### API 集成
- 支持多种 AI 大模型接口
- 可配置的 API 端点和密钥设置
- 标准化的聊天补全接口
- 自带公益API接口，开箱即用（由商汤科技日日新提供）

## 安装与使用

### 环境要求
- 现代浏览器（Chrome、Firefox、Safari、Edge 等）
- 稳定的网络连接
- 支持 JavaScript 和本地存储功能
- 一个能运行浏览器的设备（不建议使用三星note7以防爆炸）

### 部署方式
1. 下载项目文件
2. 将文件部署到 Web 服务器
3. 在设置中配置 API 端点和密钥（可使用自带的公共API）
4. 开始与 AI 角色对话
#
安卓部署:

1.只下载项目文件中的MomoTalkAiv2.1.apk

2.安装在您的受支持的安卓设备上

3.直接使用默认API端点和密钥进行使用

## 配置说明

### API 设置
- **API 地址**：可自定义的 AI 服务端点
- **模型选择**：支持多种 AI 模型，包括 DeepSeek、Gemini、Qwen 等，以及自定义api模型
- **API 密钥**：用于身份验证的访问密钥

### 角色设置
应用内置 11 个预设角色，每个角色包含：
- 个性化头像
- 专属欢迎语
- 定制化系统提示词
- 独特的对话风格
