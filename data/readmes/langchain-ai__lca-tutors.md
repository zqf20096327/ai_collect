# LCA Tutors

Skill-based tutors for LangChain Academy courses. Each course lives in its own
subdirectory as a self-contained Claude Code skill.

## Courses

| Directory | Course |
|---|---|
| [`lca-deepagents`](./lca-deepagents) | Deep Agents |

## Quickstart

1. Install [Node.js](https://nodejs.org).
2. Install a course's skill:

   ```bash
   npx skills add langchain-ai/lca-tutors/<directory-name>
   ```

   For example, to install the Deep Agents tutor:

   ```bash
   npx skills add langchain-ai/lca-tutors/lca-deepagents
   ```
