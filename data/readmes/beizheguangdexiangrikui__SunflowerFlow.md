# sunflower. FLOW

**一个跑在自己电脑上的 AI 社交机器人。**

不是套壳的聊天框。它有自己的性格、自己的记忆、自己的社交账号：
在群里像正常人一样接话，被点名时答，觉得不该说话时就闭嘴。

接 QQ / 微信 / 抖音 / B站；能画图、能生视频、能发语音；
所有数据留在本机，模型走你自己的通道，不经过任何第三方服务器。

## 它和「机器人框架」不一样在哪

|  | 常见做法 | sunflower. FLOW |
|---|---|---|
| 人格 | 一段 prompt 应付所有场景 | 一份全局人格 + 每个群、每个私聊单独覆写 |
| 什么时候说话 | 要么全回，要么只回 @ | 五种触发模式，可按群设，还有概率项细调 |
| 模型 | 绑死一家，挂了就哑 | 多供应商 + 备用链 + 全局兜底，被拒答自动降级 |
| 数据 | 传上云 | 全在本机 `data/`，卸载保留人格与配置 |
| 管理 | 改配置文件、重启 | 浏览器控制台里点，改完即生效 |

## 它不是「关键词机器人」

规则型机器人只认那几种说法：说了「画」才画，说了「图」才看图，换个说法就听不懂。
这一版把判断权交给模型自己——它拿到的是一张真实的「现在是什么情况」，而不是一串关键词。

**什么时候该画**
你说「这个不行换个别的」「图啊」，它知道你在说上一张，会重画；
说「太丑了删了吧」它也不会自作多情去画。
出图是一个它真的能调用的工具，改图时会拿上一张当图生图的底图，不是照着文字重新画。

**什么时候该看图**
你先发一张截图，再单独 @ 它说「评价一下」，它会去回看上一条的图，而不是回你「图呢」。
腾讯的图片外链经常过期，这时它会按图里的 md5 去 QQ 本地缓存把原图捞回来；
真捞不到就老实说「我这边看不到这张图，你单独发我或者把文字贴过来」，不会编一个画面出来。

**现在几点**
每次回话都带着当前时间与时段语感。下午三点不会再说「这大半夜的还有人不怕」，也不会张口就报「15:27」像机器播报。

**上次说过什么**
主动找你说话时会避开刚说过的话，隔一段时间换一个方向；也不会催没做完的事（「那张图到底改哪儿了」这种）。

## 功能清单

### 1. 此刻 · PULSE

- 实时事件流：消息、推理、媒体按时间流入，不打断你
- 运行体检：一键扫端口、依赖、服务真实状态，**不报假绿**
- 唤醒全部：把协议端、语音、ComfyUI 等后台服务一起拉起来
- 响应节奏：最近 14 分钟每分钟响应量，看它有没有在干活；没数据时直接说「暂无事件」而不是画一排矮柱
- 护栏看板：出站保护、发送审核是否生效，一眼看得见
- 推理用量：本月 token 与调用次数

### 2. 流式日志 · STREAM

- 全量事件按对话 / 推理 / 媒体分栏筛选
- Trace 检索：按消息、来源或 Trace ID 定位一次完整链路
- 单条轨迹：点任意事件展开它的完整调用与推理过程
- 导出片段：把一段时间的事件导成文件

### 3. 对话管理 · CONVERSATIONS

- 跨渠道会话：QQ 群、私聊、抖音、B 站收在同一张列表
- 上下文查看：每条会话最近若干轮原文，点开即看；列表直接显示「40 条 · 2 分钟前」
- 图片回溯：上一条是图，这条没带图，也会把那张图找出来一起读
- 单独清空：只清这个会话，不牵连别处
- 静音 / 归档：不想理的群直接静音，旧会话收起来（悬停这一行才出现，不占版面）
- 批量归档：一次性处理一批不再活跃的会话
- 导出记录：会话原文导出留档

### 4. 群与私聊 · SCOPES

- **三层覆盖**：全局 → 群 / 私聊，越具体越优先，没配的自动继承
- 独立触发：每个群单独设 @ / 关键词 / 都回 / 静音
- 独立模型：不同群走不同模型，闲聊群用便宜的那个
- 独立概率：抢话、表情包、语音概率按群单独调
- 批量管理：勾多个群，一次套用同一套策略（没勾选时这块不出现）
- NSFW 开关：群级 > 私聊级 > 私聊默认 > 全局，四级各自可控
- 每项都能看到「当前生效：X（来源）」，不会出现显示和实际不一致

### 5. 社媒中心 · CHANNELS

- 四平台入口：QQ / 微信 / 抖音 / B 站各一张卡，不再散落
- 单渠开关：启停某个平台不影响其他平台
- 凭据管理：webhook、AppID、SESSDATA 填进去就存，回显打码
- 真实测试：测试连接走真探测，不通就如实说不通
- 能力清单：文本 / 图片 / 语音 / 群聊 / 私聊逐项标注
- 聊天样式：分段、延迟、表情、引用，按平台分别调
- 手机连接：USB / ADB 连真机，协议端二维码在线出码

### 6. 账号连接 · IDENTITY

- 扫码登录：协议端二维码在线出码、刷新、重置，**不用重启进程**
- 登录态：设备信息、在线状态、掉线原因都在这
- 账号绑定：各平台账号与机器人的对应关系
- 身份隔离：一个机器人接多平台，会话互不串号

### 7. 模型管理 · MODELS

- 多供应商：一家一个 Key，别名映射到具体模型，支持 OpenAI 兼容接口
- 主模型 + 备用链：被拒答自动降到下一个，不会突然哑巴
- 全局兜底：所有模型都挂了，还有最后一层可用
- 客户端桥：借本机已登录客户端的额度，省一份 Key
- 健康探测：延迟、可用性、真实返回，测得出就显示得出
- 用量统计：按客户端 / 按天 / 按模型 / 最近调用四个维度
- 思考档位：低 / 中 / 高三档，决定它想多深再开口
- 上下文长度：按模型能力设，避免爆窗截断

### 8. 创作工坊 · STUDIO

- 生图：ComfyUI 本机出图，或走云端图像 API
- 生视频：文生 / 图生视频，接 MiniMax 等通道
- 语音合成：Breeze / Edge TTS，音色可试听、可克隆
- 工作流：选 ComfyUI 工作流并注入参数
- 自动找素材：要参考图时先搜再画，不是凭空硬画
- 任务队列：进度、成图、失败原因都留在队列里
- 通道自测：图像 / 视频 / 语音三类各有测试连接

### 9. 表情素材 · COLLECTION

- 自动收藏：群里别人发的图自动入库，越用越多
- 自动去重：同一张图只留一份
- 审核分类：脏图错图删掉，剩下的打标签
- 手动上传：自己的表情包也能加进来
- 发送频率：发多少、什么场合发，在功能策略里统一调

### 10. 人格编辑 · PERSONA

- 一份全局人格：所有平台默认都用它，改一处全线生效
- 渠道覆写：QQ 一个性格、B 站一个性格，互不干扰
- 提示词编辑：在线改 system prompt，保存即生效
- 实时预览：改完一句话就能看它怎么回，不用去群里试
- 形象库：角色立绘与头像，按场景换
- 梗知识：自定义词条，让它听懂你们的黑话
- 固定话术：打招呼、排队、等待占位等十五组
- 可塑性记忆：跨群恒有效的事实与偏好，不随上下文丢

### 11. 数据记忆 · MEMORY

- 长期记忆：事实、偏好、关系都能增删改
- 语义检索：按意思搜历史对话，不是关键词硬匹配
- 挤掉回捞：十二轮之前被压缩掉的内容还能找回来
- 自我学习：它自己总结的结论，可一键采纳为记忆
- 用量统计：token、调用次数、会话规模

### 12. 功能策略 · POLICY

- 触发模式：智能判断 / 只回 @ 与点名 / 触发关键词 / 全局都回 / 完全静音
- 触发关键词：自己定，多个词用逗号隔开
- 概率项：抢话、冷场攀谈、表情包、语音各自的概率
- 回复长度与延迟：按字符数和秒数控制说话节奏
- 安全护栏：NSFW 过滤（含「私聊默认」一档）与出站白名单
- 主动找话题：冷场多久开口、两次至少隔多久、每天上限，各自独立设置；**最低 1 分钟**
- 改动即时保存：没有「保存」按钮，改完就生效；调乱了有「恢复推荐值」
- 官方群号：介绍弹窗里展示的那个群
- 跟随全局：单项没配就继承全局，不写死也不藏起来

### 13. 偏好设置 · PREFERENCES

- 外观：主题、背景图、动效开关
- 看门狗：进程掉了自动拉起，带限流防风控
- 服务重启：每个后台服务单独重启，不用整机重启
- 插件扩展：MCP 服务接入、Skill 技能包上传
- 配置体检：检查冲突与缺失项，能一键修复
- 备份还原：改之前自动备份，随时回滚
- 计划任务：定时任务列表与最近一次执行结果
- 开机自启：随系统启动，关机不影响已存配置

## 快速开始

1. **下载安装** —— 双击 `SunflowerFlow-Setup-20261106.exe`，选盘符，勾桌面图标
2. **打开** —— 双击桌面「Sunflower Flow」，首次等 10~20 秒（后台服务在启动）
3. **接模型** —— 模型管理页填一个模型通道，或直接借本机已登录的客户端
4. **接 QQ** —— 账号连接页出二维码，手机 QQ 扫码，登录后群里就能说话了

**不用装 Python，不用 pip install。** 安装包自带运行时（`runtime\`，Python 3.12 + 全部核心依赖），
装完双击就能用。万一环境有问题，窗口会换成一张说明页告诉你下一步怎么做，不会卡在启动动画里干等。

第一次启动会自动生成配置文件和随机网关口令，不需要手写 JSON。

## 模型怎么接

三条路，任选一条能跑，也可以叠着用：

1. **本机客户端桥** —— 电脑上已登录的 AI 客户端可以直接借来用，不需要再买 Key
2. **云 API** —— 任何 OpenAI 兼容接口：填 base url、Key、模型 ID 即可
3. **本地模型** —— Ollama / LM Studio / vLLM 暴露的兼容端口，填 `127.0.0.1:端口`

配好主模型后，建议把「备用链」也填上两三个。主模型被拒答或超时，会自动降级，不会让群里的对话卡在那里。

## 群聊策略怎么调

**五种触发模式**，全局设一个，每个群可单独改：

| 模式 | 行为 | 适合 |
|---|---|---|
| 智能判断 | 看语境决定回不回 | 默认，大群 |
| 只回 @ 与点名 | 被叫到才回 | 不想被打扰的群 |
| 触发关键词 | 命中词才回 | 有明确用途的群 |
| 全局都回 | 每条都接 | 人少的小群、测试 |
| 完全静音 | 不说话 | 暂时关掉某个群 |

**三个层级的覆盖**：全局 → 单个群 / 单个私聊。在群页改过的项，只影响那个群；没改的沿用全局。

**主动行为默认全关**：不主动凑热闹、不冷场插话、不乱发表情包。想开再开，每个都有独立的概率滑杆。

打开「主动找话题」时是这样运作的：

- **冷场多久才开口**、**两次之间至少隔多久**、**每天最多几条**，三个值共同决定节奏，群聊和私聊各一套
- 阈值最低可设 **1 分钟**；巡检频率会自动跟着最短阈值走（设 1 分钟 → 20 秒看一次），不会「设了 1 分钟结果五分钟才开口」
- 每轮只在**一个**会话里开口，不会同时往几个群发
- 会先看「上次说了什么」，同一件事换个说法也算重复，会被拦下来重写或跳过
- 找话题的方向会轮换：对方提过但没聊完的小事 / 完全新的话题 / 它自己刚做的事 / 跟聊天记录无关的小事，不会永远绕着同一段对话
- 上次说了没人接，就停在那，不追问

**NSFW 四层开关**：群级 > 私聊级 > 私聊默认 > 全局。
常见组合是「群里拦住（防平台审核）、私聊放行」：关掉「私聊默认」这一档即可，不用给每个私聊单独设。

## 数据与隐私

- 记忆、人格、表情、日志全部在你自己的机器上，路径是安装目录下的 `data/`
- 模型请求直接发往你配置的通道，不经过作者或任何中转服务器

- 卸载时清掉日志与缓存，**保留人格与配置**，重装能接着用

## 常见问题

**Q：装完打开，看到的是别人机器上的数据？**

不会。每个安装目录的数据完全独立，人格、配置、记忆都在自己的 `data/` 下。

**Q：需要自己配模型吗？**

需要。模型管理页接一条通道（支持 OpenAI 兼容接口），或者直接用本机客户端桥。

**Q：它会不会在群里乱说话？**

默认「智能判断」：被 @、被点名、被回复、命中关键词才回。主动行为（凑热闹、冷场插话、发表情包）默认全关，开关和概率都在「功能策略」页。

**Q：它会不会老重复同一句话？**

不会。主动找话题时会带上「上次说过什么」，并且有一个相似度闸门：新句子和上一句太像就重写，还像就这一轮不说。

**Q：我发张图再 @ 它「评价一下」，它能看见吗？**

能。它会把上一条图找出来读。腾讯的图片外链过期也不影响——会按 md5 去 QQ 本地缓存捞原图。真找不到时会直说「我这边看不到」，不会编画面。

**Q：不想让它回某个群怎么办？**

群与私聊页找到那个群，触发模式选「完全静音」，或者直接把整个群静音归档。不影响别的群。

**Q：能同时接多个平台吗？**

能。四个平台各自独立开关、独立模型、独立人格，会话互不串号。

**Q：画图必须装 ComfyUI 吗？**

不必须。可以走云端图像接口；ComfyUI 只是本机免费出图的路子。没装就用不了本机出图，其他功能不受影响。

**Q：语音是怎么发出来的？**

文字转语音后作为语音消息发出，音色可选、可克隆，也能自己上传参考音。没有 TTS 服务时会退化成纯文字。

**Q：数据会上传吗？**

不会。记忆、人格、表情库都在本机 `data/` 目录。

**Q：换电脑怎么迁移？**

把安装目录整个拷过去，依赖重装一遍即可，`data/` 里的东西都在。

**Q：更新会不会覆盖我的配置？**

不会。安装器只更新程序文件，`data/` 里的配置、人格、记忆不动。
