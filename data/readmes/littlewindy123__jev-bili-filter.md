# B站降噪 · JEV

中文 | [English](README.en.md)

**弹幕照开，噪音别来。**

四个开关：**剧透 / 反串黑 / 广告 / 基本盘**。还想屏蔽什么，写一句话，点「添加」。在 B 站原页面过滤评论和普通文字弹幕。

不用整理屏蔽词，不用写提示词。选中不想看的内容，把讨论区留给自己想看的。

**[下载安装包](https://github.com/littlewindy123/jev-bili-filter/releases) · [安装指南](docs/INSTALL.md) · [反馈问题](https://github.com/littlewindy123/jev-bili-filter/issues)**

## 怎么用

| 你想做什么 | 操作 |
| --- | --- |
| 看剧时少点剧透 | 打开「剧透」 |
| 不想看捧杀和反讽招黑 | 打开「反串黑」 |
| 不想被推广打扰 | 打开「广告」 |
| 不想看无条件站队和口号复读 | 打开「基本盘」 |
| 还有自己的偏好 | 输入「屏蔽提前报比赛结果」等一句话，点「添加」 |

选好后继续看视频。命中的评论和弹幕自动隐藏，关闭总开关即可恢复。

## 安装

1. 从 [Releases](https://github.com/littlewindy123/jev-bili-filter/releases) 下载 `jev-bili-filter.zip`，解压并保留文件夹。
2. Chrome 地址栏输入 `chrome://extensions/`，打开右上角「开发者模式」。
3. 点击「加载未打包的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**。
4. 打开「B站降噪」面板，首次粘贴自己的 [TypeSafe API Key](https://console.typesafe.ai/)，点击「保存并连接」。
5. 刷新已经打开的 B 站视频页面。之后选择想屏蔽的规则即可，规则变化不需要刷新。

开启后，页面左下角显示已判断及屏蔽条数。所有默认规则初始开启，可分别关闭；关闭顶部总开关会恢复原内容。自定义规则添加后立即启用，也可以关闭或删除。

## 当前支持

- B 站桌面普通视频页面、新版 Shadow DOM 评论区、常见旧版评论节点。
- 当前普通播放器的 DOM 文字弹幕；监听播放器已获取的弹幕分段，预判即将出现的文字。
- 滚动加载、评论回复、弹幕节点复用、页面内切换视频。
- 相同规则、视频上下文和文字的判断缓存，不重复请求；关闭或更换规则自动重判。

先判断，再放行文字。网络异常时未判定内容继续隐藏，页面会显示原因；关闭总开关可恢复。视频播放不会等待模型。

## 声明

过滤是模型对文字的判断，可能误判或漏判。防剧透侧重明显透露、结局和暗示性表达，不读取视频画面、不建立完整剧情知识库。“基本盘”预设指无条件站队、口号复读、压制事实讨论的表达，不对作者身份作判断。

仅支持已适配的文字内容。图片评论、视频里的文字、直播、特殊/高级弹幕不在本版支持范围。若播放器切换到 Canvas 弹幕模式，会暂时隐藏该弹幕层并给出提示，评论继续过滤。番剧路径已配置，但尚未完成番剧实站回归。

扩展不收订阅费，JEV 调用使用你自己的 TypeSafe 额度。启用时，待判断文字、相关回复上文及视频标题/简介发送至固定官方接口。不会发送 Cookie、用户名、账号 ID、私信或整页 HTML。API Key 只保存于浏览器扩展本机存储，不写入安装包；缓存只存摘要键和判断结果，最多 3,000 项、有效期 24 小时。

## 验证

运行扩展无第三方依赖，无需安装 Node.js。开发测试使用 Node.js 22+：

```sh
npm test

# 浏览器回归：响应使用测试夹具，不消耗 JEV 额度
npm install
npx playwright install chromium
npm run test:browser

# 打包可直接加载的扩展 ZIP，需要 Python 3
python scripts/package.py
```

当前验证范围及真实 API 小样本结果见 [测试记录](docs/TESTING.md)。这不等于所有 B 站页面和所有表达均识别正确。
