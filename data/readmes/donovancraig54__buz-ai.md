## Features

- AI customer service assistant
- Live chat inbox
- Customer management
- Staff / team management
- Analytics dashboard
- Multi-business accounts
- SaaS pricing + custom development CTA

## Stack

- **MongoDB** (Mongoose) with in-memory fallback for local demos
- **Express** REST API
- **React** (Vite) marketing site + app dashboard
- **Node.js**

## Quick start

```bash
cd buz-ai
npm install
npm run install:all
npm run dev
```

- Marketing + app: http://localhost:5173
- API: http://localhost:5000/api
