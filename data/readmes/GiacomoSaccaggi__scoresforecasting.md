# Score Forecasting

Sports score prediction using statistical models and machine learning.

## Methods

- Poisson regression for goal modeling
- Time series analysis of team performance
- Elo rating system implementation
- Ensemble methods for match outcome prediction
- Monte Carlo simulation for tournament brackets

## Tech Stack

- Python
- statsmodels (Poisson regression)
- scikit-learn
- pandas / NumPy
- Matplotlib / Plotly
