### 🔍 实战干货：自动化研发团队管好工具账单的 4 个实用技巧

1. **区分“个人日常订阅卡”和“自动化流水线卡”**  
   日常写代码用的 Claude Pro、Cursor 或 GitHub Copilot 月付订阅，和后台 CI/CD 自动调用的 API 算力池一定要分开开卡。月付卡固定金额稳稳续费，流水线卡按周或按迭代充值，互不干扰。
2. **用单卡余额充当硬性预算上限**  
   很多开发平台的“消费预警邮件”存在延迟。在 **CoreGold** 后台 **「卡片管理」** 中，你可以随时查看卡片的可用余额与状态，按迭代周期精准充值。一旦余额用尽，超额扣款直接在银行清算层被拦截，避免半夜自动审 PR 触发死循环把主账户刷穿。
3. **团队计划集中管控研发成员用卡**  
   研发小组或初创公司在 **CoreGold「申请开卡」** 时可以选择 **团队计划**，管理员统一在后台分配卡片，避免成员各自拿个人卡垫付、月底报销发票和账单对不上的尴尬。
4. **AVS 账单地址照抄详情页，减少开发工具绑卡拒付**  
   海外开发者平台普遍校验结账地址（Billing Address）。在 **CoreGold** 开卡时勾选 **「自动生成账单信息」** 或手动填写规范北美地址后，结账时原封不动照抄即可轻松过检。

> **开卡小技巧**：开卡充值时，建议在套餐标价基础上多留 **$2~$5 缓冲余额**，用来应对海外网关首绑时的 $1 预授权测试或部分地区的数字服务税。

#### 第一步：注册 CoreGold 账号

#### 第二步：使用 USDT（TRC20）充值钱包
1. 登录后点击左侧菜单 **「我的钱包」** -> **「充值」**。
2. 输入需要充值的金额，系统会显示 USDT 收款地址与二维码。
3. 打开你的数字货币钱包或交易平台（如 OKX、币安；若还没有 USDT 可先在平台购买），选择 USDT 提币/转账，**选择 TRON（TRC20）网络**。
4. 核对地址、网络及金额后确认转账。转账后自动到账（若 10 分钟未到账请直接联系客服）。

#### 第三步：选择套餐、卡段与账单信息
1. 钱包充值成功后，点击左侧 **「申请开卡」**，按需选择 **个人计划**（如 Diamond Plan、AI Subscription 等）或 **团队计划**（不同套餐价格、支持场景及费用以页面实时显示为准）。
2. 选择适配 **AI 工具 / 云服务** 的美国发行卡 BIN，填写初始充值金额。
3. 勾选 **「自动生成账单信息」** 或取消勾选手动填写姓名、州、城市、街道地址及邮编，注意后续付款保持账单地址一致。

#### 第四步：查看虚拟卡信息并绑定 Apple Pay / Google Pay
1. 开卡成功后进入 **「卡片管理」** 选择对应卡片，查看卡号、有效期、CVV、可用余额、账单地址及状态，支持充值、提现与冻结（请妥善保管敏感信息，勿向他人泄露）。
2. 绑定 **Apple Pay / Google Pay**（全卡段支持）：
   - 打开 iPhone 的 **Apple Wallet** 或安卓的 **Google Wallet**，选择「添加支付卡」，手动输入卡号、有效期及 CVV。
   - 根据提示选择**邮箱验证**方式发送验证码。
   - 返回 CoreGold 后台 **「卡片管理」**，找到正在绑定的虚拟卡，点击卡片详情页下方的 **「添加到数字钱包」** 按钮查看验证码。
   - 返回手机钱包输入验证码，验证通过即可完成绑定。
