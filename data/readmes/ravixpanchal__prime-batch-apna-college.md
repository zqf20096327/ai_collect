## 🚀 Run the Code Locally

```bash
# Step 1: Clone the repository
git clone https://github.com/ravixpanchal/AI-ML-Prime-Batch.git

# Step 2: Move into the folder
cd AI-ML-Prime-Batch

# Step 3: Install required packages
pip install -r requirements.txt
```

```bash
# Step 4: Open any topic, for example the SVM notebook
cd Machine_Learning/SVM
jupyter notebook SVM_Complete.ipynb
```

> 💡 **Recommended:** Use [Google Colab](https://colab.research.google.com/) or [VS Code](https://code.visualstudio.com/) with the Jupyter extension.
