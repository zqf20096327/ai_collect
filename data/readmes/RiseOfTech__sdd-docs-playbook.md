# sdd-docs-playbook

**[English](en/README.md)** | **[Русский](ru/README.md)**

## English

Specifications are hard to read. Documentation drifts away from the code. A new person does not know where to start.

This library helps you bring order to the documentation of a project with SDD (spec-driven development). You copy templates, prompts, and AI agent skills into your project. You do not install anything.

What your project gets:

- **Project map:** which areas exist, where their code is, and which guides to read.
- **Glossary:** one term = one meaning.
- **Guides:** for the analyst (what and why) and for the developer (how and where).
- **Single set of rules:** how to write and update documentation.
- **AI agent skills:** they update and check guides after code changes.

Version 0.1. For changes between versions, see `CHANGELOG.md`.

## Русский

Спецификации трудно читать. Документация расходится с кодом. Новый человек не знает, с чего начать.

Эта библиотека помогает навести порядок в документации проекта со SDD (spec-driven development). Ты копируешь в свой проект шаблоны, промпты и навыки для ИИ-агентов. Устанавливать ничего не нужно.

Что появится в проекте:

- **Карта проекта:** какие есть области, где их код и какие гайды читать.
- **Словарь:** один термин = одно значение.
- **Гайды:** для аналитика (что и зачем) и для разработчика (как и где).
- **Единые правила:** как писать и обновлять документацию.
- **Навыки для ИИ-агентов:** обновляют и проверяют гайды после изменений в коде.

Версия 0.1. Изменения версий смотри в `CHANGELOG.md`.
