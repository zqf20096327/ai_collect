<h1 align="center">MindMux</h1>

<p align="center">
  <strong>Your project remembers.</strong><br>
  The project brain for builders and agents.
</p>

MindMux is a local-first AI workbench for durable project memory.

Discuss your project with AI, distill the parts you've figured out into a portable `brain/` of Markdown files, and dispatch the executable parts to coding agents — so context survives across sessions, models, and agents.

This repository is the public home for MindMux releases and product updates. The application source code is being published progressively.

## Why MindMux

- **Context that survives** — important discussions become part of your project’s brain.
- **Portable by default** — your brain lives in local Markdown files, not a locked database.
- **Built for execution** — clear decisions can be handed off to coding agents.

## Download

MindMux is currently in **early testing**.

- Grab the latest build from the [**Releases**](https://github.com/mindmuxai/mindmux/releases) page.
- Requires **macOS** (Apple Silicon and Intel).
- After the first install, updates are delivered automatically.

> Windows and Linux support are planned, but not available yet.
