# 人生指南 · 离线查账版

把《高性价比人生指南》（HowToLiveBetter，671 条 / 34 节）和《程序员延寿指南》（HowToLiveLonger）装进一个网页。

**知识库完全离线可用**；贴入自己的 API Key 后，写下一件正在困扰你的事，它先查书，再按层给结论、给忠告，并标出「第几节第几条」。

不是聊天窗口——输入、思考过程、分层结论、忠告都在同一页，从上往下读。

## 特点

- **671 条**循证条目，34 节，可按节浏览或全文检索
- **同一页给结果**：思考进度条（五步）→ 一句话结论 → 01/02/03 分层分点 → 忠告与建议 → 本次查到的条目
- **今日忠告**：每 15 分钟自动换一条，也可点「换一批」
- **出处可点**：`（第X节第Y条）` 和来源条都能直接跳到原文
- **查不到就说查不到**：检索不到直接相关条目时，页面会如实说明，不编数字
- **单文件分发**：`人生指南.html` 一个文件即可发给别人，对方自己贴 Key
- **可选本机模型**：装了 Ollama 可全离线使用，不需要 Key

## 快速开始

1. 下载或用浏览器打开 [`人生指南.html`](人生指南.html)。
2. 点右上角「设置」，选服务商，按页面三步教程申请并贴入 API Key。
3. 回到「诊断」，写下你的事，点「开始算账」。

不配置 Key 也能浏览、搜索全部条目。

### 服务商选择

默认选 **硅基流动**：有免费模型，接口允许网页直接调用，双击文件就能用。

| 服务商 | 免费 | 网页直连（file://） |
|---|---|---|
| 硅基流动 | 有免费模型 | 支持 |
| 豆包（火山方舟） | 有免费额度 | 支持，需填 `ep-` 开头的接入点 ID |
| DeepSeek | 无，但便宜 | 支持 |
| 智谱 GLM-4-Flash | 有免费额度 | 接口会拦跨域 |
| 腾讯混元 Lite | 有免费额度 | 可能拦跨域 |
| 本机 Ollama | 全离线 | 可能受浏览器跨域限制 |

跨域被拦时，换一家支持的，或在本机用下面的本地服务打开。

## 本地服务（可选）

浏览器直接调模型接口遇到跨域时，可以用本机服务转发：

```bash
node server.mjs
# 打开 http://localhost:8317/
```

服务只监听 `127.0.0.1`，只放行已知模型服务商，并限制代理来源。Windows 也可以双击 `启动服务.bat`。

页面从 `http://localhost` 打开时会自动走本机转发；双击 HTML 文件时直连，不会经过任何本地服务。

## 构建与测试

需要 Node.js 18+。`guides/`（两本书的只读副本）放在本项目上一级目录：

```
your-workspace/
  guides/
    HowToLiveBetter/
    HowToLiveLonger/
  life-guide/
```

```bash
node _src/build_kb.mjs       # 解析两本书 → site/kb.js（应为 671 条 / 34 节）
node _src/build_single.mjs   # 内联为单文件 人生指南.html
node _src/test_cdp.mjs       # 无头 Chrome + 假模型服务，跑完整验收
```

也可以用 `npm run build` / `npm test`。`guides/` 不在上一级时，用 `BOOK_DIR`、`HTLL_FILE` 指定路径。

## 隐私与安全

- 仓库里没有任何 API Key；`.env.local` 已加入 `.gitignore`。
- 页面默认只在内存里保存 Key，关掉页面即失效；勾「记住」才会明文写入本机 localStorage。
- 问题内容与检索到的书内条目只发送给你选择的服务商，不经过本项目作者或第三方。
- 页面没有统计、埋点或远程上报。
- 本地服务只监听 `127.0.0.1`，代理目标有域名白名单，且只接受本机页面来源。
