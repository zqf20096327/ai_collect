**A notes bank by UBIT students, for this batch and the next.**

I started this notes bank because the PDFs we shared in **The UBIT Hub**, my WhatsApp community for students at the University of Karachi, kept getting lost in the chat. Someone would need the same notes again, and if I was offline, they had to wait. I wanted a place they could open and find the file themselves.

Most of the notes here are mine, with contributions from friends. Use them to keep up with classes, revise before an exam, or start learning during the semester break. Students from **any UBIT batch or program** are welcome to use the material and share their own.

## How to use this repo

<img src="assets/readme/study-notes.svg" align="right" width="16%" alt="">

1. **Choose what you need.** Open the course guide or a PDF from the list above. Check the teacher where listed; for programming material, check the language too.
2. **Read or download.** Read the PDF on GitHub, or use the file viewer’s download button to save it. You don’t need to clone the repo or install anything.

Studying with a different teacher? You can still use the material, but compare it with your own outline and exam guidance. Even the same teacher may change the course between batches.

<details>
<summary>PDF not opening?</summary>

If a large scan does not preview, use the download button in the file viewer and open the saved file. If it still fails, [report the filename](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=resource-problem.yml) so we can check it.

</details>

## UBIT Results Portal

I built **UBIT Results** with the same idea behind this library: students should not have to search through scattered posts and spreadsheets for something important. It brings your results, GPA, class standing, and transcript together in one place, so you can understand your progress without doing the calculations yourself. I am still improving it for our students, so if something is missing or looks wrong, [let me know](mailto:codewithmahad@gmail.com) and I will check it.

## Help improve the library

If you made notes that helped you understand a course, someone else could use them too. Scan the pages while you still know which notebook they’re in. You do not need a whole semester ready: a clear set on one difficult topic is welcome. Say what it covers and what is missing.

- **Share your notes:** [follow the contribution guide](./CONTRIBUTING.md) and open a pull request, a proposed addition we review before it joins the collection. You can choose a name, alias, or no public author credit.
- **Ask for notes or a correction:** [request a set](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=notes-request.yml) or [report a problem](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=resource-problem.yml). Include the course and teacher so others can help.

<details>
<summary><strong>How the notes are organized</strong></summary>

Start with the course, then the teacher. Larger collections separate notes, assignments, and labs:

```text
resources/
└── operating-systems/
    └── miss-nazish-imran/
        ├── notes/
        ├── assignments/
        └── labs/
```

Courses with only a few files keep them directly in the teacher’s folder. Larger collections group notes, worked assignments, and labs, with a course guide linking the files. There are no extra guides at teacher or file level. The DSA roadmap and Functional English topic resources use `general/`. Programming Fundamentals has a `practice-sheets-by-shaikh-mahad/` collection for students studying with any teacher.

My course notes end with `_Shaikh_Mahad.pdf` so the credit stays with them when they’re shared. The PF practice collection carries my name in its folder instead of repeating it in every filename. Other authors keep their own credit. See the [file-naming guide](./CONTRIBUTING.md#file-names) before adding material.

</details>

I’m **Shaikh Mahad**. We put hours into understanding a course, fill a notebook, and often forget about it once the exam is over. I would like that work to help the next student too. A junior could use these notes next semester, or start learning during the break without waiting for someone to find an old register. Later, they might leave their own notes here for the next batch. That is how I hope this keeps going after I graduate.

Have a study question or want to compare how a course is taught? [Start a conversation](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=study-question.yml). Include the course and what you’ve tried, and help another student when you can.
