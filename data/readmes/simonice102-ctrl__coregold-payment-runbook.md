# 📖 海外支付与绑卡避坑运行手册 (Runbook)

> **关于本手册**：专门排查并解决在海外平台绑定信用卡、充值 API、订阅工具时遇到的各类拦截问题。包含常见错误码速查、底层判定逻辑，以及如何利用 **CoreGold** 虚拟卡规范化完成支付。

## 🛑 常见支付报错速查表

在绑定 Stripe、Paddle 等主流收单网关时，若遇到以下报错，可对照排查：

| 错误提示 (Error Message) | 触发根源 | 对应解决思路 |
| :--- | :--- | :--- |
| `Your card was declined.` | 发卡行直接拒绝请求，通常因跨国风控、号段被列入高危名单或卡内无余额。 | 使用 CoreGold 纯净商业号段，并在卡内预留至少 $2 缓冲金。 |
| `Zip code does not match.` | AVS（地址验证系统）比对失败，输入的邮编与发卡行系统内登记的地址不一致。 | 务必完整复制 CoreGold 详情页自带的英文街道、城市、州和 ZIP。 |
| `Card does not support 3DS.` | 平台强制要求 3D Secure 动态验证，但发卡行未开通或不支持该协议。 | 在 CoreGold 后台选择标有“支持 3DS / 强验资”的专用卡段。 |
| `Unable to authorize charge.` | 预授权验资扣划（$0 或 $1）失败，通常是卡片单笔限额设得过死。 | 将单卡限额至少设为“目标金额 + $3”，留足预授权扣款空间。 |

---

## ⚙️ 绑卡前的底层环境自检清单

为避免触发网关的反欺诈（Fraud Detection）规则，在进入支付页面前，请确保以下环境项已配置到位：

1. **浏览器环境**：
   * 优先使用全新无痕（Incognito）窗口，或使用干净的浏览器独立 Profile。
   * 关闭可能修改页面表单数据的非必要脚本插件。

2. **IP 属地与系统时区**：
   * 确保出口 IP 为纯净的机房或原生节点，避免频繁切换节点属地。
   * 建议将本地系统时区、语言调整为发卡国对应区域（例如选择美卡时，时区调至美东/美西）。

3. **账单地址（Billing Address）规范**：
   * 严禁随意填写拼音地址或虚构邮编。
   * 严格对照 CoreGold 卡片详情中配发的 **Street、City、State、ZIP Code** 逐项粘贴。

```

[1. USDT 充值] ──> [2. 按需开立独立卡] ──> [3. 录入卡密与地址] ──> [4. 扣款完成/按需关卡]

### 1. 资产注入
进入 [CoreGold 后台](https://app.coregold.io/signup?invite_code=ADvlj9b)，在资产管理选择 USDT 充值，充值确认后系统将按实时汇率折算为美元可用额度。

### 2. 生成专用虚拟卡
* 进入 `卡管理` -> `开通新卡`。
* 根据目标场景（AI 订阅 / 广告投放 / 服务器租赁）选择对标卡段。
* **关键设置**：设置合理的单卡限额（例如订阅 $20 的服务，建议设为 $23-$25，以承接小额验资）。

### 3. 前端录入与结算
* 逐项复制 16 位卡号、Exp（MM/YY）、CVV。
* 准确粘贴配发的海外英文账单地址。
* 提交支付请求，等待系统完成结算。

### 4. 生命周期管理（可选）
若仅为单次采购或测试环境：
* 扣费成功后，可随时在后台调整单卡最高消费限额。
* 业务废弃后直接点击“注销卡片”，未消耗的美金将实时退回母账户资金池。
