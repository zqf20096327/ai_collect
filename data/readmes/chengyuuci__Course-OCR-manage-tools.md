# 课表识别助手（TimetableOCR）

从 **PDF** 或 **Excel** 课表文件自动识别课程信息，并导出为 Excel 课表、JSON 或可导入日历的 **ICS** 文件。

- 技术栈：Python + PyQt5
- 扫描版 PDF 使用 **Windows 内置 OCR**（无需额外安装识别引擎）
- 支持复杂版式：一格多课、合并单元格、跨页断单元格、多工作表、无表头工作表、单双周

项目仓库：<https://github.com/chengyuuci/Course-OCR-manage-tools>

---

## 功能特性

- **输入**：`.pdf`（含文本层课表，以及扫描件的 OCR 兜底）、`.xlsx` / `.xlsm` / `.xls`
- **版式**：网格课表（行=节次、列=星期）、列表课表（每行一门课）、合并单元格、多工作表
- **字段**：课程名称、星期、节次、周次（含单双周、离散周）、教师、教室、具体时间
- **多工作表选择**：导入含多个工作表的 Excel 时，可勾选要导入哪些表
- **班次筛选**：识别出多个「教学班」时，弹窗选择要保留的班次
- **设置**：作息时间（每节课开始时间与时长）、ICS 导出提醒（含「每周第一天」与事件里的「当前周次」标注）、外观与实验性功能统一在「设置」窗口配置
- **主题切换**：设置里可切换浅色（白）/ 深色（黑）主题
- **课表存档**：把识别结果保存成 `.crs` 文件（JSON 文本），下次启动自动载入
- **固定到桌面**（实验性，需在设置里开启）：把课表做成一个无边框的**置底**小窗（可拖动、可缩放、位置记忆、不透明度可调），普通窗口始终盖在它上面；可设置只显示当前选中的那一周
- **托盘图标**：固定到桌面后主窗口自动收进托盘，只留桌面课表；可从托盘恢复窗口 / 解除固定 / 退出
- **课程编辑**：双击/按钮新增、编辑、删除课程
- **按周预览**：左侧「预览周次」下拉选某一周，网格只显示该周的课程；「本学期第一天」用日历选择器
- **时间冲突检测**：识别出同一时段有多门课时，自动高亮并弹窗提醒
- **导出**：Excel（课表网格 + 课程列表两张表）、JSON、ICS 日历（可选提前提醒）
- **崩溃日志**：程序异常时自动记录，便于排查问题

## 快速开始

### 方式一：使用打包好的程序（推荐）

1. 解压发布包（如 `TimetableOCR-vX.X.X-win64.zip`）。
2. 双击 `TimetableOCR.exe`（或 `课表识别.exe`）即可运行，无需安装 Python。
3. 注意：exe 必须和 `_internal` 文件夹放在同一目录，不要只拷贝 exe 本体。

> 若使用扫描版 PDF，请先确保系统安装了中文 OCR 语言包（见下方「常见问题」）。

### 方式二：从源码运行

需要 Python 3.10+（Windows）。

```bash
pip install -r requirements.txt
python main.py
```

## 使用说明

### 1. 添加文件

点击「**添加文件**」按钮（或快捷键 `Ctrl+O`），选择 PDF 或 Excel 课表文件，可一次选多个。

### 2. 选择工作表（仅多工作表 Excel）

如果某个 Excel 里有**多个工作表**，点击「开始识别」后会弹出「**选择工作表**」窗口：

- 默认全选，可「全选 / 全不选」，至少保留一个；
- 取消勾选的工作表会被跳过；
- 隐藏的工作表不会出现在列表里，也不会被识别。

### 3. 开始识别

点击「**开始识别**」按钮（或快捷键 `F5`）。识别过程在后台进行，进度显示在状态栏，详细过程写入「识别日志」。

### 4. 选择班次（仅识别到多个教学班时）

如果 Excel 最后一列是「教学班」且存在多个班次，识别完成后会弹出「**选择班次**」窗口，勾选要保留的班次即可。未标注班次的课程会始终保留。

### 5. 查看与修正

- **左侧「识别结果」表格**：列出所有课程（课程名称 / 星期 / 节次 / 周次 / 教师 / 教室）。
- **双击某行**可编辑该课程（也可用「编辑选中」按钮），修正识别错误。
- 可「新增课程」「删除选中」。
- **左侧「预览周次」下拉**：选「第 N 周」后，右侧网格只显示**这一周**要上的课；选「全部周次」则显示整学期（未填周次的课程按每周都有处理）。范围会随课表自动扩展到最晚的那一周。
- **右侧「周课表预览」**：以网格形式查看一周课表，同一格多门课会纵向排列。
- **时间冲突提示**：如果两门课在同一星期、节次和周次重叠，会在识别结果里用**浅红色高亮**，并弹窗提醒，方便你删掉重复或冲突的课程。

### 6. 导出

顶部右侧「导出」区提供三种导出：

| 按钮 | 产物 | 说明 |
|------|------|------|
| **Excel** | `课表.xlsx` | 含「课表」网格 +「课程列表」两张工作表 |
| **JSON** | `课表.json` | 结构化数据，便于二次处理 |
| **日历 ICS** | `课程表.ics` | 导入系统日历 / Google / Outlook 等 |

导出前请确认顶部「**本学期第一天**」的日期正确——点日期框右侧的箭头会弹出日历，直接点选**这一学期开始上课的那一天**即可（不一定是周一）。它和「每周第一天」一起决定每个课程事件落在哪一天。

### 7. 设置（作息时间 + 导出提醒 + 外观 + 实验性功能）

点击「**设置**」按钮打开设置窗口，包含四个标签页：

**作息时间**：逐节设置每节课的**开始时间**和**时长**（结束时间自动计算，支持「恢复默认」）。修改后，周课表预览的节次时间、Excel 导出的「时间」列、ICS 日历事件时间都会随之更新。

**导出提醒**：为每门课添加最多 3 个开始前提醒，每个提醒可选：

- 不提醒（关闭该提醒）
- 事件开始时
- 提前 5 / 10 / 15 / 30 分钟
- 提前 1 小时
- 提前 1 天

提醒按先后顺序排列，**后面的提醒时间不能比前面的晚**（例如提醒1为 30 分钟前时，提醒2不能为 15 分钟前）；提醒的最小时间是事件发生时。选择后，每个日历事件都会附带对应的多个提醒（`VALARM`）。将导出的 `.ics` 导入日历 App 即可看到课程日程。

同一页下方还有「**每周第一天**」下拉（周六 / 周日 / 周一，默认周一）。它决定两件事：

1. **第 1 周从哪天开始**：第 1 周起点 = 不晚于「本学期第一天」的那个周首（默认周一时就是本学期第一天本身）。每节课的日期按「第 1 周起点 + (周次-1)×7 + 星期偏移」排出来；早于「本学期第一天」的日期会被跳过，导出日志里会写「N 个日期早于「本学期第一天」，已跳过」。
2. 事件详情里那句「**当前周次**」：程序用这条课的实际日期落在第几周来算，写进 `DESCRIPTION`（例如「节次：1-2节；周次：1-16周；当前周次：第 3 周」）。这个数是**某个具体日期落在第几周**，和课程本身的「周次」（老师排课的 1-16 周）不是一回事，两者可能相差 1。

**外观**：选择界面主题——**浅色（白）** 或 **深色（黑）**；并用滑块调整**桌面课表的不透明度**（10%–100%，默认 30%）。点「保存」后立即生效（桌面课表正在显示时也会实时变淡/变实），下次启动也会沿用。

**实验性功能**：三个开关，默认都**关闭**。

- 「**启用「固定到桌面」**」：关闭时界面上没有「固定到桌面」按钮；打开并保存后，保存过课表（`.crs`）就会出现该按钮。这项功能还不稳定，且受系统环境影响（见下方 Q7），所以先收在实验性开关后面。
- 「**桌面课表跟随「预览周次」**」：打开后，贴在桌面上的课表只显示左侧「预览周次」下拉里选中的那一周（跟着切换实时刷新）；关闭时桌面显示整学期课表。只想在桌面上看「本周」时很方便。
- 「**只显示今天和明天的课**」：按系统日期、「本学期第一天」和「每周第一天」自动推算出当前是第几周，桌面课表只显示今天和明天这两天的课（没有课就不显示）。和上面的「跟随预览周次」**只能二选一**，打开一个会自动关掉另一个。

所有设置保存在**应用目录下的 `settings.ini`**（打包后与 exe 同目录，源码运行与项目同目录），重启程序也不会丢失。

### 8. 保存课表与固定到桌面

识别、修正完课表后，建议先点「**保存课表**」，把结果存成 `.crs` 文件（本质是 JSON 文本，记录课程、作息时间和本学期第一天）。存过之后：

- 下次启动程序会自动载入上次保存的课表；
- 若已在「设置 → 实验性功能」里**打开开关**，顶部会出现「**固定到桌面**」按钮（开关关闭时不显示）：点它会弹出一个**无边框、置底的课表小窗**——没有标题栏，圆角卡片样式，位于所有普通窗口之下（切到别的程序时它自动被盖住），鼠标按住可以拖动，拖右下角可以缩放，位置和大小会自动记住（下次固定回到原处）；
- 小窗的透明度在「**设置 → 外观**」里用滑块调整（10%–100%，默认 85%），字与格子会随窗口大小整体缩放；
- 想让小窗只看某一周：在「**设置 → 实验性功能**」打开「桌面课表跟随「预览周次」」，之后左侧选第 N 周，小窗就同步只显示第 N 周（改周次会立刻刷新，不用重新锁定）；
- 想让小窗只看「今天和明天」：在「**设置 → 实验性功能**」打开「只显示今天和明天的课」（会自动关掉上面那个），程序按系统日期、「本学期第一天」和「每周第一天」算出周次，桌面只留今天、明天两天的课；
- 固定到桌面后，**主窗口会自动收进系统托盘**，桌面上只留课表；点托盘图标（或在任务栏上）可以「显示主窗口」「解除固定」或「退出」。托盘图标如果还是找不到：右键桌面课表 →「**把图标放回任务栏**」，程序会重新把它提到任务栏；也可以点开任务栏的「^」自己把它拖出来。程序启动时会把托盘图标的注册表状态写进「识别日志」（例如「托盘：已设置为「显示在任务栏」」），方便排查；
- 想换一份课表，点「**打开课表**」选择别的 `.crs` 文件即可（当前锁定会先解除）。

课表存档默认建议保存到应用目录（`课表.crs`），这样重启后能自动载入。

## 常见问题

**Q1：扫描版 PDF 识别不出内容？**
扫描件依赖 Windows 自带的「中文 OCR」。请确认系统已安装中文 OCR 语言包：
设置 → 时间和语言 → 语言 → 添加「中文（简体）」，并勾选/安装其 OCR（手写）组件。

**Q2：导入日历后课程时间错乱或重叠？**
- 时间错乱：确认顶部「本学期第一天」选的是**这学期开始上课的那一天**（不是今天），并在「设置 → 导出提醒 → 每周第一天」选对贵校的周起始日（多数学校是周一）。
- 课程重叠：课表本身可能包含多个平行班（不同班同一时段上课）。识别后可用「选择班次」只保留自己要的班次；或在结果里删掉不需要的课程。

**Q3：识别结果有误怎么办？**
双击对应课程直接修正；也可以把样例文件反馈给开发者调整解析规则。

**Q4：程序崩溃了，日志在哪？**
- 崩溃日志位于**应用目录下的 `logs\` 文件夹**（打包后与 exe 同目录，源码运行与项目同目录）：
- Python 异常日志：`logs\crash.log`
- 原生崩溃日志：`logs\native.log`（其中 `0x8001010d` 是 Windows/Qt 的良性 COM 异常，可忽略）

**Q5：`.xls`（旧版 Excel）无法解析？**
源码运行需安装 `xlrd`（`requirements.txt` 已包含）；打包版已内置。

**Q6：固定到桌面后找不到程序、关不掉？**
固定后主窗口会**自动缩到托盘**。点任务栏右下角的托盘图标：选「显示主窗口」回到界面，选「解除固定」只关掉桌面小窗，选「退出」则彻底退出程序。小窗本身右键也有「显示主窗口 / 把图标放回任务栏 / 解除固定」。
**托盘图标看不见时**按顺序试：① 点桌面课表右键 →「把图标放回任务栏」；② 点任务栏的「^」溢出区，把本程序的图标拖到任务栏；③ 看「识别日志」里「托盘：…」那行——如果提示「以管理员权限运行」，请改用普通权限启动（Windows 不会在任务栏显示管理员程序的托盘图标）。

**Q7：课表小窗挡住了桌面图标、或者想看整学期？**
小窗是**置底**的，任何普通窗口都会盖在它上面；但它仍然在桌面之上，所以会和桌面图标重叠（图标被压在下面）。三个办法：按住它拖到空白处；在「设置 → 外观」把不透明度调低（10% 几乎只剩轮廓）；或者右键「解除固定」。如果它只显示一周或只显示两天的课，把「设置 → 实验性功能」里的「桌面课表跟随「预览周次」」和「只显示今天和明天的课」都关掉即可恢复整学期。
另外，「固定到桌面」是实验性功能：按钮没出现时，请到「设置 → 实验性功能」打开开关并保存，再保存一次课表。

**Q8：系统缩放 125% / 150% / 200% 时界面会不会糊或错位？**
程序已启用 Qt 的高 DPI 缩放：界面尺寸、字体、表格、作息时间输入框、深色主题的上下箭头，以及课表小窗、托盘图标，都会按屏幕的缩放倍数重新计算，100%–250% 下布局一致。有两种情况值得知道：
- **多显示器、缩放不同**时，窗口拖到另一块屏会按那块屏的缩放重新排版（Qt 负责），不会出现文字被裁；
- **课表小窗的位置会记住**：下次固定时的坐标/大小按逻辑像素还原；若那块屏已经拔掉，会自动挪回当前屏幕可见区域。

如果发现某处文字被截掉，请把屏幕缩放倍数和截图反馈给开发者。

## 从源码打包

```bash
python -m PyInstaller --noconfirm --clean TimetableOCR.spec
```

产物在 `dist/TimetableOCR/`（onedir 模式，入口 `TimetableOCR.exe`）。发布时把该目录下的内容压成 zip 即可。

> 打包体积已做过裁剪：排除了 RapidOCR（onnxruntime/numpy/cv2）、Qt Quick/QML、软件 OpenGL、Qt 翻译文件、未用到的图片插件等，解压后约 78 MB。

## 目录结构

```
.
├── app/
│   ├── gui.py           # PyQt5 图形界面
│   ├── pdf_parser.py    # PDF 课表解析（文本层 + OCR）
│   ├── excel_parser.py  # Excel 课表解析（多工作表）
│   ├── parsing.py       # 通用解析逻辑（网格/列表/周次等）
│   ├── ocr.py           # OCR 后端（Windows 内置 OCR，RapidOCR 可选回退）
│   ├── exporters.py     # Excel / JSON / ICS 导出
│   ├── models.py        # 数据模型
│   ├── crs.py           # 课表存档（.crs 读写）
│   ├── desktop.py       # 桌面课表小窗与托盘图标
│   ├── settings.py      # 设置持久化（作息时间 + 导出提醒 + 主题 + 课表路径）
│   ├── theme.py         # 浅色 / 深色主题样式
│   └── crashlog.py      # 崩溃日志
├── main.py              # 程序入口
├── requirements.txt     # 依赖
├── TimetableOCR.spec    # PyInstaller 打包配置
└── LICENSE
```
