# Studsmith

### The AI agent for Roblox Studio.

Studsmith is a free Windows app that helps you build Roblox games faster. Describe what you want in plain language, and the agent writes the Luau scripts, sets things up in your game and explains what it changed.

## What you can do

- Describe a feature in plain language and get a clear plan, then working Luau code
- Create and organize objects in your game from a text description
- Review every change as a diff before it is applied to your place
- Undo a change, or a whole task, with restore points
- Let the playtest loop run your game, read the errors and fix them
- Use a local model or your own API key
- Find and fix bugs in your scripts, with plain-language explanations

## Install

1. Open the [latest release](../../releases/latest) and download `Studsmith-win-x64.zip`.
2. Unzip it anywhere.
3. Run `Studsmith.exe`.

Requires Windows 10 or 11 (64-bit). Windows may show a SmartScreen warning because the app is new and not code-signed: click **More info**, then **Run anyway**. The SHA-256 hash of every release is listed in its notes so you can verify the download.
