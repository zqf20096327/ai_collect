# PocketAgent

**把电脑上的 AI 助手装进口袋：手机连上你自己的电脑和服务器，随时随地接着干活。**

算力在远端、文件在远端、密钥只在你手机上 —— 手机只负责发号施令和看结果。

## 为什么在手机上做这件事

写代码、跑训练、查日志这些活，本质上需要一台性能机器。但你**不一定每次都坐在那台机器前**：

通勤路上想把 bug 修掉、在客户现场要确认服务状态、半夜躺床上想起一个改动 —— 手机是唯一在手边的设备。

PocketAgent 把「电脑」和「手机」接起来：

| 你想要的 | PocketAgent 怎么做 |
| --- | --- |
| 手机不跑模型、不跑代码 | 模型请求直接发给你配置的服务商，命令在远端机器执行 |
| 手机不装项目、不占空间 | 工作区指向远端目录，代码和文档都落在服务器上 |
| 电脑上聊到一半，路上接着聊 | 手机 ⇄ 电脑双向同步会话，冲突时由你选保留哪边 |
| 不在公司内网也能连 | 公网跳板机 / 反向隧道，手机在任何网络下都能连回机器 |
| 手机丢了也不怕 Key 泄露 | API Key 与 SSH 私钥用系统密钥库加密，不可导出、不进备份 |

## 三个真实场景

**1. 下班路上的最后一段**
在远端电脑或服务器上和 Codex 讨论到一半，出门后打开手机同步会话，`/workspace` 切到那台仍在线的主机，
直接说「把刚才那段改完，跑一下测试」—— 续接电脑原来那条原生 session，完整历史、模型、
skill 和工具都在远端；手机接收进度和结果。手机说完再回到电脑，`codex resume` 同一条就能
继续，不需要重新解释上下文。

**2. 在客户现场查服务器**
手机 SSH 连到机房里的机器，让 agent 读日志、`nvidia-smi`、查磁盘，每一步执行前都会弹窗确认；
发现问题直接让它改配置、重启服务，不用先找一台电脑。

**3. 手机上没有项目，也能改代码**
工作区设成远端目录后，读写的都是服务器上的真实文件；改完的东西留在远端，手机存储一点不占。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| **远程执行** | SSH 到你的 Mac / Linux 服务器，读写文件、跑命令；公网跳板机与反向隧道都支持 |
| **上下文双向同步** | 手机和电脑的会话互相同步；可按单条同步；无变化时只传 67 字节清单令牌，正文只在确有更新时传输 |
| **电脑端免安装适配** | 同步脚本随 App 内置，首次连接自动部署并校验 SHA-256，电脑端无需手工下载或安装额外程序 |
| **远端工作区** | `/workspace` 一键切本地或远端目录，代码与文档不落在手机上 |
| **远端 Codex harness 接力** | `/workspace` 自动检测目标机器的 Codex，支持 Mac / Linux 及常见 Node 安装器，可手动指定特殊安装路径；检测到后整轮交给该机 Codex；同步来的历史直接 resume 原生 session，手机新建会话也先落成同 id 原生记录，不在电脑上产生重复对话；JSONL 事件边跑边回传，手机能看到命令、MCP、文件修改和回答整理进度 |
| **多模型** | DeepSeek、OpenAI/Codex、Claude，或任意 OpenAI 兼容接口（含自建中转） |
| **Codex 式 harness** | Codex 工具循环结合 DeepSeek Chat 协议；回传 reasoning、修复工具配对，搜索/读取类工具并行执行；支持多文件 `apply_patch`；手机本地 `exec_command` / `write_stdin` 支持后台长任务、轮询输出和 stdin；单轮内工具结果逼近窗口时按完整工具轮自动折叠，不拆散调用与结果 |
| **Codex skills / 上下文观测** | 同时读取 `skills/` 与标准的 `.agents/skills/`；`AGENTS.md` 会从工作区父目录向上合并，同目录 `AGENTS.override.md` 优先；`/context` 显示窗口、系统与工具预留、历史 token |
| **MCP（HTTP）** | 设置 → 工具扩展里接入 Streamable HTTP 的 MCP 服务器，模型就能直接调用它的工具；令牌存 Keystore、默认逐次确认、`/mcp` 查看状态并刷新 `tools/list` |
| **只读子 agent** | `delegate_task` 把互不依赖的调研并行派给子 agent：子 agent 只有只读工具，步数/并发/超时有硬上限，只回一段结论，不把中间过程塞进主上下文 |
| **计划与步骤可见** | `update_plan` 的计划在对话里渲染成勾选列表（已完成 / 进行中 / 待办），工具调用按「步骤 N」编号，长任务能一眼看到进度 |
| **执行中补充要求** | 回复、`/goal` 自主任务和 `/workspace` 远端任务运行中可直接发送新要求；在安全节点调整方向，显示等待读取和已读取状态 |
| **后台保活** | 回复和同步期间挂前台服务 + 唤醒锁，切到别的 App 或锁屏也能跑完；设置里有电池白名单入口 |
| **审批机制** | 读写在应用沙箱内；`ssh_exec`、`ssh_write`、`fs_delete`、`apply_patch` 永远逐次确认；只读、联网、MCP 等按类别放行 |
| **看图** | `view_image` 直接读取工作区里的截图/图表进上下文（单张 1.4MB 内） |
| **斜杠命令** | `/model` `/reasoning` `/approvals` `/permissions` `/goal` `/compact` `/workspace` `/sync` `/mirror` `/test` … |
| **长会话体验** | 流式输出、一键到顶/到底；消息正文和思考过程支持选择与复制，也可一键复制整条回复 |
| **弱网保护** | 输出被截断时自动接着写一次，并明确提示，而不是只给半句话 |
| **安全** | Keystore AES-256-GCM 加密、强制 HTTPS、关闭系统备份、可选应用锁与防截屏 |
| **中英双语** | 跟随系统，或手动切换 |

## 快速开始

1. **装 App**：下载 Release 里的 `PocketAgent-<版本>.apk` 安装（首次会要求确认隐私政策）
2. **配模型**：设置 → 模型来源 → 选 DeepSeek / OpenAI / Claude，填自己的 API Key → `/test` 验证
3. **接远端（可选）**：设置 → 远程主机 → 新建 → 填主机、端口、用户，导入私钥 → 测试连接；首次同步时 App 会自动部署同步脚本
4. **允许后台（建议）**：设置 → 后台运行 → 允许后台保持回复，把 App 加入电池优化白名单
5. **开始干活**：对话里 `/workspace` 选远端目录，直接说需求

> 想先不配置也能看：没填 Key 时所有界面和帮助都可以浏览。

## 下载与校验

只从本仓库的 **Release** 下载安装包。每次发布的说明里都会给出该版本 APK 的
SHA256 与签名证书指纹，下载后可以自己核对：

```bash
shasum -a 256 PocketAgent-<版本>.apk
apksigner verify --print-certs PocketAgent-<版本>.apk
```

- SHA256 与 Release 说明一致 → 文件没被篡改；
- 证书指纹与官方一致 → 是你发布的那份包（重打包的签名一定不同）。

电脑上可用 Android SDK 的 `apksigner` 核验签名；手机上需使用可信的 APK 检查工具，
系统应用信息页面不一定提供证书摘要。

## 斜杠命令速查

| 命令 | 作用 |
| --- | --- |
| `/model` | 切换模型，或给模型选思考强度档位 |
| `/reasoning` | 调思考强度（低 / 高 / 最高） |
| `/thinking` | 远端工作区中显示/隐藏远端 harness 的思考过程，默认隐藏 |
| `/approvals` | 工具审批策略 |
| `/permissions` | 按类别放行工具：搜索/读文件默认放行，写/删/命令可单独开关 |
| `/mcp` | 查看已配置的 MCP 服务器和工具；`/mcp refresh` 重新拉取 `tools/list` |
| `/goal` | 设定目标让 agent 自主推进，完成后自动结束 |
| `/compact` | 压缩上下文，省 token |
| `/workspace` | 切换工作区：本机 / 远程主机目录 |
| `/sync` | 与电脑双向同步会话；冲突时选择保留哪边 |
| `/mirror` | 每轮把会话写到远端 `sessions/<id>.md`；`/mirror pull` 把电脑上的改动并回来 |
| `/remember` | 记一条长期偏好 |
| `/test` | 测试所有模型来源连通性 |
| `/help` | 查看全部命令 |

## 构建

需要 JDK 17 与 Android SDK 35。

```bash
./gradlew :app:testDebugUnitTest    # JVM / Robolectric 用例
./gradlew :app:assembleRelease
```

### 构建命令

```bash
./gradlew :app:assembleRelease
```

完整版默认包含 SSH 远程执行与上下文同步。

可选参数：`-PoperatorName=…` `-PcontactEmail=…` `-PicpNumber=…` `-PappBeian=…`（显示在隐私政策与「关于」页）。
