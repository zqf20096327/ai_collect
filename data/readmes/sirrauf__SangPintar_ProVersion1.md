## 🚀 Cara Menjalankan Proyek di Flask

Ikuti langkah-langkah mudah berikut untuk menjalankan server Flask dan Bot Telegram:

### 1. Buka Terminal / PowerShell
Masuk ke direktori proyek:
```cmd
cd "lokasi_path_SangPintar_ProVwrsion1"
```

### 2. Aktifkan Virtual Environment & Install Dependensi
Buat dan Gunakan Python virtual environment (`venv`) yang tersedia:
```cmd
# Buat virtual environment (Windows)
python -m venv venv

```cmd
# Aktivasi virtual environment (Windows)
Venv/Scripts/activate.bat

# Install dependensi yang dibutuhkan
pip install -r requirements.txt
```

### 3. Jalankan Aplikasi Flask & Bot Telegram
Jalankan file `app.py`:
```cmd
python app.py
```

Atau juga bisa perintah dibawah ini:

```cmd
flask run
```

Setelah perintah dijalankan, server Flask akan aktif dan Bot Telegram langsung berjalan otomatis di latar belakang (*background thread*).

### 4. Buka di Browser
Akses antarmuka Front End melalui browser Anda:
- **Halaman Setup Wizard:** [http://localhost:5100/](http://localhost:5100/)
- **Halaman Isi Data User:** [http://localhost:5100/user-data](http://localhost:5100/user-data)
