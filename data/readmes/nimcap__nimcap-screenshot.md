# NimCap 截图工具 · 离线 AI，让截图继续发挥作用

**简体中文** | [English](README.en.md)

[GitHub](https://github.com/nimcap/nimcap-screenshot) · [Gitee](https://gitee.com/lilongjiang/SnapSharp) · [官方网站](https://jietu.nimcap.com/) · [下载发布版](https://github.com/nimcap/nimcap-screenshot/releases)

NimCap 截图工具（NimCap Screenshot）是一款面向 Windows 的开源桌面工具，把**截图、标注、贴图、长截图和录屏**，与**本地 OCR、翻译、表格与公式识别、抠图、去水印及图像修复**放在同一个工作流程中。从屏幕取一张图，既可以直接分享，也可以继续提取文字、整理表格、生成 LaTeX、移除背景，或将参考资料贴在桌面。

**离线 AI 是它的核心能力：图片和文字在本机处理，无需上传云端完成本地识别、翻译与图像处理。** 提前准备好程序、对应模型和运行依赖后，这些功能可在断网电脑或无互联网连接的内网中使用，适合整理内部资料、制作教程、阅读外文文档和日常办公。基础截图、标注、贴图、取色、测量与条码解码无需下载 AI 模型。

项目属于 `nimcap`，原名 SnapSharp，当前仓库为 `nimcap/nimcap-screenshot`；已有用户数据目录保持兼容。软件使用 C#、WPF 和 .NET 10 构建，面向 Windows x64，通过系统托盘和全局快捷键调用。

## 离线 AI 可以做什么

| 需要完成的工作 | 本机处理方式 | 得到的结果 |
|---|---|---|
| 把截图变成文字 | PaddleOCR；也可选择 Windows OCR 或 Tesseract | 可编辑文字、复制或导出 TXT |
| 提取证件信息 | 本地 OCR 配合字段规则 | 可编辑字段、复制或导出 TXT |
| 把表格图片变成数据 | SLANet 识别结构，结合 OCR 填充文字 | 校正行列与合并单元格，导出 CSV／XLSX |
| 把公式图片变成源码 | 本地 LaTeX-OCR | 可编辑 LaTeX、复制或导出 `.tex` |
| 阅读外文资料 | Qwen3.5 GGUF + llama.cpp | 在本机翻译 OCR 结果或输入的文字 |
| 移除图片背景 | U²-Net、BiRefNet 系列模型 | 保留原尺寸和透明度的图片，可保存 PNG／WebP |
| 去水印与图像修复 | MI-GAN、LaMa、Moebius；SLBR 辅助自动检测 | 对照原图检查结果，撤销、复制、保存或贴图 |
| 分享前遮盖敏感文字 | 本地 OCR + 规则；可选本地 Qwen 辅助识别人名、地址 | 模糊敏感文字所在范围 |

### 离线使用如何准备

模型按需配置，不必为了截图一次性下载所有模型。OCR、表格、公式、抠图和本地翻译可在设置中下载配置；去水印页面支持下载或导入对应模型。内置模型下载流程提供来源选择、进度、文件校验与配置，普通使用无需安装 Python 或 CUDA。

如果目标电脑无法联网，先在可联网环境准备程序、所需模型和运行库，再连同本地配置一起部署，并在目标电脑上核对模型路径与设备设置。图像 AI 使用 ONNX Runtime，可选择 CPU 或 DirectML；本地翻译使用独立的 llama.cpp 运行库，可选择 CPU 或 Vulkan。模型越大，对内存、显存和处理时间的要求通常越高。

**本地处理与联网功能分开控制。** 在线翻译和以图搜图默认关闭，启用后每次发送仍需确认。模型下载和更新检查也需要网络；离线 AI 表示推理可脱离互联网运行，不表示程序绝不发起网络请求。历史图片保存在本地，未加密；保存位置、模型管理和数据目录迁移见[配置与依赖](docs/配置与依赖.md)。

## 软件介绍

启动后，NimCap 截图工具驻留系统托盘，通过快捷键或托盘菜单工作。截图后可以标注、脱敏、复制、保存、贴图，或继续识别。处理已有图片时，先复制图片，按 `Ctrl+Shift+V` 创建贴图，再从贴图右键菜单打开“图像工具”。

下方配图选用仓库已有素材，部分来自更名前的界面或真实 WPF 组件渲染，按钮布局与当前版本可能不同；操作入口以本文和当前程序为准。图像来源与制作方式见[配图说明](Screenshot/Blog/README.md)。

<a id="selection"></a>

### 截图与标注：把重点直接写在图片上

按 `Ctrl+Shift+A` 开始区域截图，既可拖动框选，也可通过元素模式吸附控件。支持全屏、当前窗口、延时截图，以及矩形、椭圆、自由套索和多边形选区；多显示器和混合 DPI 场景使用统一选区流程。元素模式捕获当前可见内容。

选区确定后，使用箭头、文字、序号、荧光笔、马赛克或模糊说明重点；标注对象支持移动、缩放、旋转、层级调整和撤销／重做，也可以保存标注模板供后续复用。适合制作教程、反馈界面问题和说明操作步骤。

![截图选区与标注工具栏](Screenshot/1.png)

### 一键脱敏：分享截图前检查敏感信息

截图和贴图编辑工具栏提供一键脱敏。本地 OCR 与规则定位手机号、身份证号、银行卡号、邮箱、车牌号、姓名字段和地址，对对应文字范围应用模糊；可选本地 Qwen 辅助识别人名和地址。此功能需要先配置 OCR，分享前仍应核对漏识别和误识别。

![一键脱敏后的图片示例](Screenshot/一键脱敏-脱敏后.png)

<a id="recognition"></a>

### 文字、证件与条码：让图片内容可以复制

在“图像工具”中选择文字 OCR，识别后可编辑、复制和导出文本，识别框与文字结果支持互相定位。PaddleOCR、Windows OCR 和 Tesseract 均为本地引擎，分别需要相应模型、系统语言包或字库。

证件模式复用本地 OCR，提取身份证正反面及合图、驾驶证、行驶证、户口本、护照、银行卡和营业执照的当前页字段，可编辑后复制或导出 TXT。二维码和一维码可直接离线解码，无需 AI 模型。证件字段提取基于 OCR 与规则，不提供真伪鉴定。

![本地 PaddleOCR 的中文识别结果示例](Screenshot/Blog/14-ai-ocr-chinese.png)

### 表格与公式：从截图到可继续编辑的资料

表格模式用本地 SLANet 识别结构，再结合 OCR 填入文字。可修正行列、内容和合并单元格，导出 CSV 或 XLSX，适合把单张表格截图整理成电子表格。

![本地表格识别与单元格校正示例](Screenshot/Blog/16-ai-table-recognition.png)

公式模式将单个公式图片转为可编辑 LaTeX，可复制或导出 `.tex`。表格与公式各需配置配套模型，复杂结构和识别结果应对照原图校正。

![本地公式识别为 LaTeX 的示例](Screenshot/Blog/17-ai-formula-latex.png)

### 本地翻译与屏幕取词：在本机阅读外文

先识别图片文字，再翻译全文或选中的一段；也可输入文字进行翻译。本地翻译使用 Qwen3.5 与 llama.cpp，在 CPU 或 Vulkan 设备上运行，不需要云端 API。按设备资源选择模型并完成首次配置后，即可离线使用。

托盘“屏幕取词”在本次会话中启用，鼠标停留后对附近内容做局部 OCR。界面语言、OCR 语言和翻译源／目标语言分别配置。

![已有本地翻译结果的局部展示](Screenshot/Blog/20-ai-local-translation.png)

*此图裁自已有翻译结果，展示译文内容，未在本次文档更新中重新运行模型。*

<a id="cutout"></a>

### 一键抠图：保留主体，输出透明背景

根据设备与素材选择 U²-Net 或 BiRefNet 系列预设，执行本地背景分离，再对照原图检查边缘。结果保留原图尺寸和透明度，可复制、保存或贴图；需要保留透明背景时使用 PNG 或支持透明度的 WebP。CPU 模式提供 U²-Net 与 General Lite，其他内置预设在 DirectML 模式下提供。

![原图与 General Lite 本地抠图结果对比](Screenshot/Blog/19-ai-cutout-comparison.png)

### 去水印与图像修复：选择范围，在本机补全

“图像工具 → 去水印”提供三种处理方式：涂抹模式手动绘制需要修复的范围，选定区域模式检测框选范围，智能模式检测全图。区域与智能模式使用 SLBR 自动检测，再交给所选修复模型补全；手动涂抹无需 SLBR。

| 模型 | 用途与选择 |
|---|---|
| MI-GAN | 快速修复 |
| LaMa | 新配置的默认修复模型 |
| Moebius | 可选精细候选，资源开销较大，CPU 处理可能较慢 |
| SLBR | 区域／智能模式的检测模型，与修复模型配合使用 |

选择尚未安装的模型时，可在软件内确认下载来源与大小，下载、校验并自动配置。界面提供左侧原图、右侧结果及同步缩放和平移，支持蒙版编辑、撤销和输出。被遮挡内容由模型推断，无法保证准确恢复文字、数字或人物细节；详见[去水印与图像修复](docs/去水印与图像修复.md)。

![新版图像工具：LaMa CPU 去水印的原图与处理结果对照](Screenshot/去水印.png)

<a id="pins"></a>

### 桌面贴图：把参考资料留在手边

复制图片、文字或颜色内容后，按 `Ctrl+Shift+V` 或使用托盘“贴图”创建置顶参考。图片贴图滚轮缩放，`Ctrl+滚轮` 调整透明度；右键菜单提供图像工具、编辑、旋转、鼠标穿透和分组。支持隐藏／恢复全部贴图，以及恢复最近关闭的贴图。

![图片、文字与颜色贴图的场景示意](Screenshot/Blog/12-pin-workspace.png)

<a id="scrolling"></a>

### 滚动长截图：把连续内容整理成一张图

从托盘“滚动长截图”选择区域后，可手动滚动采集，也可自动发送滚轮输入。采集结束后预览拼接、检查接缝、调整裁边，再继续标注或导出长图、分页 PDF。`.ssscroll` 项目保存原始帧与调整参数，方便后续继续整理。

当前以竖向内容为主，动态页面、固定浮层和重复纹理可能影响拼接，应检查结果。

![长截图拼接预览、裁边与接缝调整界面示例](Screenshot/Blog/02-scrolling-preview.png)

<a id="recording"></a>

### MP4／GIF 录屏：记录操作过程

在矩形选区工具栏点击录像图标，或从托盘进入录屏工具栏。支持单显示器内的区域录制、倒计时、暂停／继续、定时停止，以及光标和点击高亮。

MP4 使用 H.264，可选择系统声音、麦克风和摄像头，音频使用 AAC；GIF 不含声音，最高 15 fps、最长 60 秒。音频和摄像头初始关闭，后续录制记住选择。实际帧率取决于设备与编码性能。

![MP4 录屏配置示例](Screenshot/Blog/06-recording-mp4.png)

*图中展示录制配置，不代表实际录制性能。*

<a id="output"></a>

### 取色、测量、导出与历史

截图放大镜可取色，独立屏幕尺子可测量直线、宽高、两点距离与角度，支持参考线和像素读数。

![屏幕尺子与测量工具](Screenshot/屏幕尺子.png)

图片支持 PNG、JPEG、WebP、TIFF、BMP 和 A4 分页 PDF，保存前可调整尺寸与编码并预览结果。自动保存支持日期目录和文件名模板；截图历史独立开关，保存合成 PNG、缩略图和索引，便于回看与复用，不保留可编辑标注对象。

## 下载与快速上手

1. 从 [GitHub Releases](https://github.com/nimcap/nimcap-screenshot/releases) 下载 Windows x64 发布包，完整解压，运行 `NimCap.Screenshot.exe`。
2. 在任务栏右下角找到托盘图标；启动后没有常驻主窗口是正常现象。
3. 按 `Ctrl+Shift+A` 截图，添加标注后复制、保存或贴图，按 `Esc` 取消。
4. 处理已有图片时，复制图片后按 `Ctrl+Shift+V`，右键贴图打开“图像工具”，选择识别或图像处理功能。
5. 首次使用 AI 功能时，按需配置模型与运行库；配置完成后可断网运行相应本地功能。

| 默认快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+A` | 区域截图 |
| `Ctrl+Shift+F` | 全屏截图 |
| `Ctrl+Shift+W` | 当前窗口截图 |
| `Ctrl+Shift+V` | 从剪贴板创建贴图 |
| `Ctrl+Shift+H` | 隐藏／显示全部贴图 |

可在“设置 → 快捷键”修改绑定，为屏幕尺子、恢复贴图等动作配置快捷键。界面支持中文、英文、日文、韩文、德文、法文等语言／地区资源包，在“设置 → 常规 → 界面语言”选择并保存；部分翻译为机器翻译初稿。

## 首次配置与运行要求

| 功能 | 配置入口与条件 |
|---|---|
| 文字 OCR | 设置 → OCR 与识别：一键配置推荐 ONNX OCR，或选择 Windows OCR／Tesseract |
| 表格与公式 | 设置 → OCR 与识别 → 本地表格与公式：分别配置配套模型；表格还需要 OCR |
| 抠图 | 设置 → 一键抠图：选择设备、下载模型并设置默认项 |
| 本地翻译 | 设置 → 翻译、API 与隐私：配置 Qwen3.5 GGUF 和配套 llama.cpp，选择 CPU／Vulkan |
| 去水印 | 图像工具 → 去水印：选择或导入修复模型；区域／智能模式另外配置 SLBR |
| 录屏 | 设置 → 录屏：检查并配置录屏环境 |

系统要求为 Windows 10 2004 及以上或 Windows 11，x64。自包含发布版已带 .NET；依赖框架的构建版需要匹配的 .NET 10 Desktop Runtime。录屏可能需要 VC++ x64 运行库与 Windows 媒体组件。

ONNX 图像推理在独立子进程中执行；GPU 初始化、推理失败或显存预算不足时，可在条件允许时回退 CPU。本地翻译的 Vulkan 失败不会自动切换 CPU。模型与设备限制见[配置与依赖](docs/配置与依赖.md)，常见问题见[使用指南](docs/使用指南.md#faq)。
