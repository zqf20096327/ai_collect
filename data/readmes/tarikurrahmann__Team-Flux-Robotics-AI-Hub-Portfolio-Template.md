# 🤖 Team Flux — Robotics & AI Hub Portfolio Template

A sleek, ultra-modern, and fully responsive portfolio template designed for robotics squads, tech clubs, or AI research teams. Featuring a dark cyber theme, an interactive particle background, and a dedicated project and success milestone tracker.

🚀 **Live Demo:** **[teamfluxbd.netlify.app](https://teamfluxbd.netlify.app/)**

## 🛠️ Tech Stack Used
*   **HTML5:** Dynamic page structures (`index.html`, `projects.html`, `ideas.html`).
*   **CSS3:** Neon glowing effects, custom grids, and interactive cyber-tech UI elements.
*   **JavaScript:** Responsive navigation, page transitions, and the interactive background system.
