## 🌟 Overview & Quick Summary

`Reels_detector_yolov26` captures desktop monitor frames, flags distraction objects like cellphones and TVs, identifies multi-person video patterns, and prompts a GUI popup alarm with sound when distraction is detected.

---

## 🔥 Key Features

- ⚡ **High-speed continuous screen capture**
  - Uses `mss` to capture desktop frames efficiently
- 🧠 **AI-based distraction detection rules**
  - Detects phones, screens, remotes, and suspicious window titles
- 📈 **Terminal status dashboard**
  - Shows uptime, scan count, distraction percentage, and last alert
- 🚨 **Interactive GUI popup alert**
  - Plays audio alarm and displays a “Back to Work” button

---

## 🛠️ Tech Stack & Dependencies

- Python 3.12+
- OpenCV
- Ultralytics YOLO
- MSS
- Pillow

Install dependencies:

```powershell
pip install opencv-python ultralytics mss pillow
```
