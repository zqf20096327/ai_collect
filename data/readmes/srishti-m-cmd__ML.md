# Machine Learning Lab Programs

This repository contains the implementation of various Machine Learning algorithms and data analysis techniques as part of the Machine Learning Laboratory course.

## 📚 Experiments

### 1. Exploratory Data Analysis (EDA)
- Generate histograms for all numerical features.
- Analyze the distribution of each feature.
- Create box plots to identify outliers.
- **Dataset:** California Housing Dataset

### 2. Correlation Matrix and Pair Plot
- Compute the correlation matrix.
- Visualize feature relationships using a heatmap.
- Create pair plots to analyze pairwise relationships.
- **Dataset:** California Housing Dataset

### 3. Principal Component Analysis (PCA)
- Reduce the dimensionality of the Iris dataset.
- Transform the dataset from 4 features to 2 principal components.
- **Dataset:** Iris Dataset

### 4. Find-S Algorithm
- Implement the Find-S algorithm.
- Learn the most specific hypothesis consistent with the training examples.
- **Dataset:** CSV training dataset

### 5. K-Nearest Neighbors (KNN)
- Generate 100 random values in the range [0,1].
- Label the first 50 samples.
- Classify the remaining samples using KNN.
- Perform classification for different values of K:
  - K = 1, 2, 3, 4, 5, 20, 30

### 6. Locally Weighted Regression (LWR)
- Implement the non-parametric Locally Weighted Regression algorithm.
- Fit the dataset and visualize the regression curve.

### 7. Regression Algorithms
- Implement Linear Regression.
- Implement Polynomial Regression.
- **Datasets:**
  - Boston Housing Dataset (Linear Regression)
  - Auto MPG Dataset (Polynomial Regression)

### 8. Decision Tree Classifier
- Build a Decision Tree classifier.
- Train using the Breast Cancer dataset.
- Predict the class of new samples.
- **Dataset:** Breast Cancer Dataset

### 9. Naive Bayes Classifier
- Implement the Naive Bayes classification algorithm.
- Train using the Olivetti Faces dataset.
- Evaluate the model using test data.
- **Dataset:** Olivetti Faces Dataset

### 10. K-Means Clustering
- Implement K-Means clustering.
- Visualize the clustering results.
- **Dataset:** Wisconsin Breast Cancer Dataset
