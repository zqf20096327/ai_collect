# PTCG Agent Table

本地运行的 PTCG AI 对战牌桌。导入自己的卡组后，可以与 AI 对战，或观看两个 AI 对战。AI 对手保留策略版本，并通过赛后复盘积累经验；对局支持逐步回放和记录导出。

牌桌执行移动、洗牌、投币、状态标记等操作；规则与卡牌效果由玩家或 AI 判断。

## 安装与启动

需要 **Node.js 22.23.2 或更高版本**及 npm，以及可用的模型连接。模型支持复用本地 ChatGPT / Codex 登录凭证，或使用 OpenAI 兼容接口。

克隆仓库并启动：

```sh
git clone https://github.com/CharAznable98/ptcg-agent-table.git
cd ptcg-agent-table
npm ci
npm run build
npm start
```

打开 [http://127.0.0.1:3001](http://127.0.0.1:3001)。服务运行期间保持终端开启，按 `Ctrl+C` 停止服务。

## 开始第一局

1. 在「资料库 → 卡组」点击「导入 JSON」，选择自己的卡组，或使用仓库中的 [合成练习卡组](./examples/decks/合成练习卡组.json)。示例由非官方合成卡组成。
2. 在「系统配置 → 模型连接」设置[模型连接](#配置模型连接)，测试连接并保存。
3. 在「资料库 → AI 对手」点击「创建 AI 对手」，填写名称并绑定卡组。初始策略可留空，系统生成策略后保存 AI 对手。
4. 返回首页，点击「新建对局」，选择「人机对战」或「AI 对战」。人机对战选择你的卡组与一名 AI 对手；AI 对战需要两名独立的 AI 对手，两者可以绑定相同卡组。
5. 勾选「建局后立即运行 AI」，点击「创建对局」。人机对战通过拖拽摆放初始宝可梦，点击「准备完成」；进入对局后直接操牌。AI 对战可以直接观战，在对局页运行、暂停或单步执行 AI。

### 直接操牌

将能量拖到宝可梦上附着，将进化卡拖到对应宝可梦上进化，将基础宝可梦拖到备战空位出场。训练家卡拖到牌桌中央使用；点击场上的宝可梦放大卡牌，使用招式、特性或选择撤退。也可用空格提起卡牌、回车放下，`Esc` 取消。

回合开始的抽牌与状态处理自动执行；需要选牌、目标、数量或顺序时由玩家确认。代理处理状态显示在牌桌中央，多步操作按顺序播放动画，可点击「跳过动画」查看最新牌桌。

操作失败时会居中显示完整原因，点击「确认」关闭提示；已经执行部分效果时，须用「代理修正」完成结算或回滚后再进行新行动。

操作代理解释卡文并执行。需要选牌、数量、顺序或可选效果时，由你在牌桌内完成选择。代理遇到执行错误优先尝试修正；「更多 → 手动调整」提供异常时的直接操牌与伤害、状态调整。

## 使用自己的卡组

在「资料库 → 卡组」中新建、编辑或导入卡组。JSON 文件包含卡组名称、每种卡的数量及完整牌面资料，格式可参考[合成示例](./examples/decks/合成练习卡组.json)。

真实卡组由你导入。卡牌支持文字牌面；如需显示卡图，在卡牌编辑器中填写图片地址。

### 从 PTCG Live 卡表转换

仓库提供 [ptcg-live-to-json 技能](./.agents/skills/ptcg-live-to-json/SKILL.md)。使用支持仓库技能的编程助手，输入以下请求并粘贴完整卡表：

```text
使用 $ptcg-live-to-json，将下面的 PTCG Live 卡表转换为本项目的简中卡组 JSON。
```

转换需要 Python 3；首次获取资料及卡图时需要联网。卡表须包含数量、英文卡名、系列码与编号。

转换完成后，将生成的 `deck.json` 导入「资料库」。

## 接入 AI

### 配置模型连接

打开「系统配置 → 模型连接」，选择一种方式：

| 连接方式 | 需要填写或准备的内容 |
| --- | --- |
| 本地 ChatGPT / Codex 凭证 | 运行服务的电脑上已有的登录凭证。凭证文件位置可留空，默认读取 `~/.codex/auth.json`；设置了 `CODEX_HOME` 时，从该目录读取。 |
| OpenAI 兼容接口 | 在页面填写接口地址和 API Key，选择接口协议、模型与思考强度。支持 Responses 与 Chat Completions 两种协议。 |

本地凭证方式由本项目读取凭证并直接请求模型。凭证过期时，更新本地登录凭证后重试。

使用兼容接口时，直接在页面填写 API Key，点击「刷新模型」获取可选模型。API Key 保存在本机 `data/model-credentials/`，保存后页面只显示配置状态；修改其他设置时留空即可继续使用已保存的密钥。

接口地址填写 API 基础路径，例如 `https://api.openai.com/v1`。接口需提供 `/models` 模型列表，并支持所选协议的工具调用。

模型与思考强度通过下拉框选择，点击「刷新模型」同步接口提供的档位和默认值。选择「接口默认」时由提供方决定强度；接口未提供档位时，页面保留当前配置并提示未确认。初始配置为 `gpt-6.1-terra`、`medium`，不开启 fast。「测试连接」使用页面当前设置，无需先保存。连接测试会实际请求模型，对局、人类操作代理、创建 AI 对手和赛后总结也会消耗模型用量。

### 管理 AI 策略

AI 对手会保存策略历史，普通对局结束后通过赛后总结更新策略。可在资料库查看、编辑或导出 AI 对手及其策略版本。模型和提示词可在「系统配置」修改，保存后用于新对局。

### 比较策略版本

首页「策略评估」可对照同一 AI 对手的不同策略版本：选择双方 AI、策略版本与被评估席位，先运行版本 A；该局结束后，再选择版本 B 运行对照。

对照复用相同开局、固定对手策略与模型配置，评估期间保留参评策略版本。每局手动启动，可结合多个起点的结果比较策略表现。

## 查看与保存对局

右侧「对局记录」按完整行动显示，默认展开最新两个回合，其余可手动展开。行动的「细节」保留全部原子操作。点击行动或「逐步回放」，每一步自动演示该次行动的关键变化；旧 AI 记录仅合并能确定的步骤。AI 观战默认全知并实时显示最新牌桌。人机对战进行中仅开放你的视角，结束后可切换全知回放并导出完整记录。

桌面窗口建议至少 **1366 × 768**。卡牌详情可悬停预览或点击固定；小屏通过「对局记录」打开记录面板。放逐区与暂存区的操作保存在对局记录中。

数据保存在运行服务的电脑上。默认位置如下：

| 目录或文件 | 内容 |
| --- | --- |
| `data/` | 卡组、AI 对手、策略历史、对局记录和模型调用轨迹 |
| `system/agent.json` | 保存的模型连接配置；未保存时使用 `system/agent.example.json` |
| `system/prompts.json` | 当前提示词配置；默认副本为 `system/prompts.example.json` |
| `data/assets/card-back.png` | 可选的自定义 PNG 卡背，缺省显示占位卡背 |

备份或迁移时，停止服务并保留 `data/` 与 `system/`，其中的 API Key 文件请妥善保管。迁移后在页面重新填写 API Key；本地 ChatGPT / Codex 凭证需在新电脑上配置。同一数据目录只运行一个服务；重启后已有对局以暂停状态恢复，可在对局页继续。

可以在启动服务前设置以下环境变量；相对路径均以启动时的工作目录为准：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `3001` | 服务端口 |
| `HOST` | `127.0.0.1` | 监听地址 |
| `PTCG_DATA_DIR` | `data/` | 数据目录 |
| `PTCG_SYSTEM_DIR` | `system/` | 配置目录 |

服务面向本机使用，访问者均可修改资料库、对局和系统配置。
