# AI 求职工具箱 🧰

> 一个非技术背景的秋招人，用 AI 把「信息获取 → 投递 → 面试准备 → 模拟面试 → 复盘」五个环节全流程搭成系统，跑通完整闭环，适合正经历秋招阶段的大学生食用。

秋招要投几十上百个岗位，**重复劳动**和**过程失控**太痛了：

| 痛点 | 具体表现 |
|---|---|
| **信息漏看** | 每天海量岗位/资讯/面经，看不过来，错过值得投的岗位 |
| **投递失控** | 每个公司都要重填一遍姓名/学校/经历，投了哪些、什么状态全靠脑子记 |
| **准备靠猜** | 拿到 JD 不知道从哪准备，只会背模板，面试官一问就露馅 |
| **练习无门** | 没人陪练，答得含糊缺数据自己也不知道 |
| **复盘凭感觉** | 面完只知道"没戏"，说不清哪道题答砸了、下次怎么改 |

所以我把这五个环节分别做成 5 个 AI 工具，串成一个闭环：

```
┌──────────────────────────────────────────────────────────────┐
│  秋招早报  →  网申 Bot  →  面试准备引擎  →  模拟面试官  →  复盘教练  │
│ (信息获取)   (自动投递)     (JD拆解+匹配)     (追问式陪练)   (转写+复盘) │
│     ▲                                                        │
│     └────────────  复盘结论反哺下一轮准备 ←──────────────────────┘
└──────────────────────────────────────────────────────────────┘
```

## 5 个工具一览

| 工具 | 解决什么 | 核心能力 |
|---|---|---|
| [01-秋招早报](01-秋招早报Agent/) | 每天信息看不完、错过岗位 | 自动搜岗位/资讯/面经 → COT 四维打分筛选 → 生成个性化早报推飞书 |
| [02-网申Bot](02-网申Bot/) | 重复填表、进度失控 | Playwright 浏览器自动化填表 + CSV 仪表盘追踪，内置安全边界 |
| [03-面试准备引擎](03-面试准备引擎/) | 面试前不知道怎么准备 | 输入 JD → 拆解硬性/加分/隐藏要求 → 匹配真实经历 → 预测问题 → 给答题要点（只给框架不给背稿） |
| [04-模拟面试官](04-模拟面试官/) | 没人陪练、缺数据不自知 | 读 JD 读简历的 AI 面试官，顺着回答连环追问，命中"只有结论没过程"就追问，结束后五维评分 |
| [05-面试复盘教练](05-面试复盘教练/) | 面完说不清问题 | 录音 → 火山 ASR 转写（51 分钟约 13.6 秒）→ 结构化复盘（逐题 / 共性问题 / 与简历库差距 / 行动清单） |

## 技术栈

- **编排**：Dify Chatflow / Workflow（每个工具是一个 Dify 应用）
- **模型**：DeepSeek（生成）、qwen3-rerank（知识库重排）
- **信息获取**：Tavily 搜索 + 飞书 webhook 推送（秋招早报）
- **语音转写**：火山引擎 ASR（极速版）+ Supabase Edge Function 中转
- **知识库**：个人简历库（真实经历）+ 面试框架库（STAR / GMV 拆解 / 归因五步 / COT 等方法论），双库分离检索
- **浏览器自动化**：Playwright（网申 Bot）
- **数据记录**：本地 CSV（投递进度，零依赖）

## 使用方式

每个工具的 `skill.md` 都是完整的「技能说明」，包含：
1. **触发词**：口语怎么说能唤起这个工具；
2. **执行步骤**：正确的 COT（思考链），一步步该干什么；
3. **安全约束**：允许做什么、禁止做什么。

把它们交给支持 Skill 的 Agent（如 Claude Code），或按 `skill.md` 的描述在 Dify 里搭成应用即可复用。

## 设计原则（为什么这么搭）

1. **不编造**：所有"改进版答法"必须引用简历库里的真实项目和数据，杜绝 LLM 胡编经历；
2. **只给框架不给背稿**：面试准备引擎只给要点和框架，练的是"会答"不是"会背"，面试官一问就知道真假；
3. **双 LLM 职责分离**：模拟面试官的"提问"和"评分"用两个 LLM，混在一起会打架；
4. **安全边界优先**：网申 Bot 绝不绕过验证码/登录，最终提交前必须人工确认；
5. **人只做决策**：AI 负责重复劳动（搜索、填表、转写、检索、归因），人只做判断和拍板。
