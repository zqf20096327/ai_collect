# agy-capsule

**中文** | [English](./README.en.md)

在 Antigravity 输入框底栏显示上下文占用、多模型配额、缓存状态和生成速度，悬停胶囊即可查看面板详情，点击胶囊即可固定面板。

## 上下文

显示上下文占用、缓存命中率与缓存状态。上限按当前会话和模型实时读取。**以下为可选项**。
- **缓存过期提醒**：胶囊图标距上一轮默认满 3 分钟变黄、满 4 分钟变红 `Cache` 过期，右侧输入框可自定义变黄/变红分钟数（上限 998 / 999 分钟）。面板里的 Cache 行同步变化。

- **上下文过载提醒**：上下文超过 75% 时，胶囊数字变黄，超过 90% 时变红。

- **生成速度**：显示本轮最近一次请求的速度，每完成一次请求更新一次。

- **速度动效**：在模型生成回复时会闪烁的小圆点。在生成速度低于 10 tok/s 时红色，10 至低于 25 时黄色，25 及以上绿色。停下后保持颜色 15 秒再变灰。

- **上下文明细**：将上下文拆分成首轮、读取、思考、写入四个部分，分别显示数值和占比。可选横条显示或竖列显示。横条显示可选方块或圆点标记。竖列显示可逐项开关名称、数值、百分比，可自由调节顺序。
- **最近请求**：显示最近一次请求从首 token 到结束的耗时范围（如 `4.5s–8.6s`）和生成速度。
- **本轮统计（默认关闭）**：显示本轮的耗时、请求数、思考和写入。

## 额度

显示当前或所有额度池的 5 小时与每周剩余额度和重置倒计时。

**Vertex AI（Google Cloud 按量计费）**：当未返回套餐额度且 Antigravity 确认账号使用 Cloud 按量计费时，隐藏整个额度胶囊。

**以下为可选项**。

- **突出当前模型**：高亮当前所选模型所在的额度池，弱化其他池。
- **隐藏不存在的配额窗口（默认开启）**：例如 AI Pro 用户的 Argon 池没有 5 小时额度，会被隐藏掉。


## 报错与首字等待提醒

**以下均为可选项**，共用底栏第三胶囊（同时触发时优先显示请求失败）：

- **请求失败胶囊**：仅在请求失败时弹出红色胶囊，悬停或点击后可在面板上查看原始报错和相关说明。提示原因包括：额度耗尽、限流（429）、断连、验证异常、服务繁忙、未知原因。
- **首字等待提醒**：本轮等待达到阈值时显示黄色胶囊（默认 `30s`，可设 `1–999s`）。`等待×2 40s` 表示本轮有两段等待达到阈值，当前一段估计为 40 秒。工具执行和流式输出会停止实时计时，历史提醒仍可查看。

## 优化模型胶囊

**默认关闭**，开启后在底栏原位无缝替换原生模型按钮，提供与原生外观一致的模型与思考强度选择器（支持已有对话与新对话）：悬停多档位模型即可在右侧一步选择思考强度，直接点击模型行会自动继承当前强度（目标不支持 `XHigh`/`Extra`/`Max` 时自动降至 `High`）；宿主版本接口不匹配或窗口极窄折叠时会自动退回原生入口。

- **隐藏模型标签**：隐藏菜单中的 `New`、`Notice` 等标签徽章。
- **隐藏默认强度**：在下拉模型列表中隐藏档位预览（底栏当前档位与右侧展开的子菜单照常显示，直接点击仍按规则继承强度）。
- **定制模型列表**：展开当前可用的模型列表，点击即可按模型隐藏或恢复显示（不会隐藏到列表为空）。
- **思考强度滑条（默认关闭）**：开启后，点模型不关面板，也不再弹出悬停子菜单。可在底部点击、拖动或用方向键切档；拖过档位就切换，无需松手。右键滑条可调整动画、刻度和 Codex / Claude 样式。关闭时继续使用原来的悬停子菜单。

## 用量统计

侧栏统计页底部的可选区块，在设置页底部作为独立分组开关，汇总当前产品目录本机对话里记录的 Token 用量。**以下为可选项**。

- **Token 活动（默认关闭）**：显示今日、本周、本月和累计用量，以及最近一年的活动图，可在“每日”（一格一天）和“每周”（一格一周）之间切换，颜色越深用量越多；侧栏较窄时只保留最近的若干周。鼠标停在汇总数字或格子上可查看请求数以及非缓存输入、缓存读取、缓存写入和输出四项构成。
- **按模型统计用量（默认关闭）**：用堆叠柱状图按模型系列显示用量，可切换日（一页 14 天）、周（一页 12 周）、月（一页 12 个月），用 ‹ › 翻到更早的时段。下方列出这一页里每个模型系列的用量和占比；默认去掉思考档位后缀按模型系列归并（档位拆分与四项构成在悬停提示里查看）。

## 语言和外观

- **设置语言**：English、简体中文、繁體中文。决定设置界面使用的语言。

- **显示语言**：English、简体中文、繁體中文。决定面板显示使用的语言。

  两项语言设置只影响 agy-capsule 自己的界面，不会翻译 Antigravity 本身。

- **面板高度**：自然高度下各面板按内容决定，对齐高度让所有面板等高。

- **面板间距**：紧凑、标准、舒展。

- **面板大小写**：全小写、首字母大写。

- **额度图形**：圆圈、长条。

- **缓存图形**：图标、圆环、进度条。选择圆环或进度条后，面板的 Cache 行会随距上一轮的时间线性增长，依次变黄、变红，变红后保持满状态。

- **重置倒计时**：紧凑、本地化样式。

## 设置

在对话顶部 **… → Extensions → agy-capsule** 打开侧栏，顶部切换“统计”和“设置”两页。

设置页顶部一行显示当前版本号、**「更新提醒」**开关（点击切换蓝亮状态；默认开启，后台自动检查 GitHub 新版本并在侧栏顶部弹出提示，关闭后不再后台检查）和**「检查更新」**按钮（已是最新时按钮原地显示「已是最新」）。发现新版本时，可点击**「一键更新」**直接从 GitHub Release 下载校验并自动重载完成更新，无需重启 Antigravity（保留所有用户设置），也可点击打开 GitHub Release 手动更新或暂不更新。

设置保存在 <code>~/.gemini/config/agy-capsule/settings.json</code>（Windows 为 <code>%USERPROFILE%\.gemini\config\agy-capsule\settings.json</code>），更新和卸载插件都不会覆盖；旧版本留下的文件缺少新选项时自动使用默认值。

在仓库目录运行 `sh install.sh` 安装，`sh update.sh` 更新（先拉取新版代码），`sh uninstall.sh` 卸载。插件装在 <code>~/.gemini/config/plugins/agy-capsule</code>。装好后在 **Plugins** 面板启用。底栏胶囊需要用 `--remote-debugging-port=0` 参数启动 Antigravity。

### 常见问题

> **客户端更新后胶囊消失，需要重新更新 agy-capsule 吗？**
> **不需要。** Windows 上，Antigravity 自动更新后可能沿用带 `--remote-debugging-port=0` 的开始菜单快捷方式。只有重启时没带调试参数，底栏胶囊才会因为调试端口没开而消失，侧栏统计不受影响。只需**完全退出 Antigravity 再从带参数的快捷方式（或 macOS 的启动图标）重新打开**即可恢复。如果之前已启用过底栏胶囊，插件会自动识别这一场景：在侧栏顶部提示「无需更新插件」（Windows 还会自动检测快捷方式参数是否被更新清除，支持一键补回），并可在设置中开启/关闭每次异常启动弹一次系统提醒（默认开启）。

## 数据口径

- **生成速度** = 总输出 ÷（TTFT + 流式耗时），包含等待首 token 的时间。
- **最近请求**只看最近一次模型请求，不是整轮；缺失的数据显示 `—`。
- **本轮统计**从你最近一条消息开始累计，耗时包含排队、等待和工具执行。
- **缓存过期提醒仅供参考**：缓存状态（默认 3 分钟变黄 / 4 分钟过期，可在设置中调整）系根据距上一轮对话的时间间隔本地估算，实际命中情况以服务端为准。
- **首字等待提醒**结合请求记录的 TTFT 与本地步骤时间估算。实时计时可从消息开始处理或上一步结束时算起，不使用消息入队的时间。等待原因未知；下一条消息开始处理后重新统计。
- **用量统计**：把当前产品目录的本机对话数据库里每次模型请求记录的非缓存输入、缓存读取、缓存写入和输出相加。合计包含缓存读取（长对话中占比通常很高，与额度消耗无直接换算），不等于账单；仅统计当前产品目录且不含已删除的对话（删除对话后累计数字会相应回落），同一个响应出现在多个对话文件里时只算一次。日期按本机时区划分，每周从周一开始。鼠标悬停汇总数字与活动图格子可查看四项构成。只有开启任一用量统计选项并打开侧栏统计页时才按需增量读取：对闲置闭库且无非空 `-wal` 的文件以 `immutable=1` 打开避免残留 `-wal` / `-shm`，对活跃或近期修改过的库改走普通只读并在读前 / 读后核对 `.db` / `-wal` 文件指纹（读取期间发生写入则丢弃本轮、下轮重读）；结果只留在内存里，不写文件、不上传。按模型统计优先取显示名称（缺失时回退响应模型名，再没有则归为“未知模型”），默认去掉思考档位后缀按模型系列归并（档位拆分见悬停提示）；模型系列多于 6 个时，累计用量最少的合并为“其他模型”。

<details>
<summary>详细说明</summary>

**最近请求**

- 速度的分子是总输出，等于回复（含工具调用指令）加思考。计时不全或分母为零时，不计算速度。
- TTFT 和流式耗时都取自 Antigravity 的记录，请求耗时是两者之和，不含工具执行。TTFT 的计时起点和首 token 的判定边界尚未确认，不能当作纯 prefill 耗时。

**本轮统计**

- 从最近一条已发送的用户消息开始，包含排队时间；新消息重新累计。
- 耗时用首尾时间相减，包含等待和工具；运行中本地计时，结束后固定，取消且缺少明确时间则显示未知。
- 请求数包含已记录的重试，不含纯预检和注入回复，不保证覆盖未记录的后端调用。

</details>

## 其他场景

- **子 Agent 对话**：打开子 Agent 对话时，底部除额度胶囊外具备完整的底栏功能（模型为只读，本轮统计按最近一次执行计算）。缺少对应记录时隐藏该胶囊；父对话的模型和数据不会被拿来补位。
- **云端项目**：云端项目对话目前已能显示底栏胶囊（上下文、生成速度、最近请求等），但 Antigravity 宿主暂未在云端项目窗口中提供插件侧栏。插件设置仍与本地窗口共用，可在本地项目侧栏里修改。
- **Antigravity CLI（`agy`）**：如果你也在终端里使用 `agy`，可以搭配姐妹项目 **[agy-capsule-cli](https://github.com/Lumidarin/agy-capsule-cli)** —— 面向 Antigravity CLI 的可定制 statusline，支持自由开关与配色，并提供[在线配置器](https://lumidarin.github.io/agy-capsule-cli/)。
