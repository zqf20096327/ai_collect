Every template ships the exact prompt that built its demo and a DESIGN.md, so you can paste it into Claude Code, Cursor, Codex or any other AI coding tool and get the same kind of site: landing pages, SaaS sites, portfolios, online stores, dashboards, 3D scenes and browser games. Preview every site live on [VibeFather](https://vibefather.ai/?utm_source=github&utm_medium=readme&utm_campaign=awesome-vibe-coding-websites&utm_content=intro).

It's made for developers, designers, indie hackers and anyone who builds websites with AI. Browse by site type, style or AI model, see how Claude, GPT, Gemini and the other models handle the same front-end prompt side by side, and start your next project from a prompt that has already been tested. The sites use real front-end stacks — React, Tailwind CSS, Motion, Three.js, Plain HTML and GSAP — and each one was checked on desktop and mobile before it went live.
