## 关于功能边界：聊天机器人 vs 完整 Agent

这一点必须说在前面。

| 能力 | 无 root | 有 root |
|---|---|---|
| QQ 聊天、扫码登录 | ✅ | ✅ |
| 发图（本地图库 / 联网搜图） | ✅ | ✅ |
| 人设、多服务商、控制台 | ✅ | ✅ |
| **执行命令 / 读写任意文件** | ❌ | ✅ |
| **截屏 / 点按 / 全局操作手机** | ❌ | ✅ |
| **静默安装应用、发短信、调音量** | ❌ | ✅ |
| **给 QQ 里的自己装东西、改配置** | ❌ | ✅ |

也就是说：

- **没有 root**：它是一个会聊天、会发图的 QQ 机器人，控制台能看到状态、换模型、改人设
- **有 root**：它才成为真正的 **Agent** —— 能听懂「帮我截个图」「装个 App」「看一下电量」「把这张图发我」，并真的去执行

部署工具会**自动检测** root：

- 检测到 root → 走全自动路径，装完即完整 Agent
- 没有 root → 仍然能装好并运行，但上面的工具能力会不可用（部署日志里会说明）

> 想用完整功能，请在一台可以 root 的手机上部署（本项目在小米 6 / LineageOS 18.1 + Magisk 上验证）。

## 特性

### 对话

- 支持 **私聊**、**群聊（@ 触发）**、**关注账号自动接话**
- **流式输出**：边生成边发，不用等整段说完
- **多服务商**：DeepSeek / OpenAI / 通义千问 / 本地 Ollama / 任何 OpenAI 兼容接口
- 上下文记忆 + 长期记忆，会记住你说过的事
- **人设可改**：写一段话换性格，下一句生效，不用重启

### 工具能力（需 root）

- 网页搜索、图片搜索
- 发图片、发文件、打包发送
- 读屏/点按/截图（需授权）
- 执行命令、读写文件（仅主人）
- 定时抓图填图库

### 手机控制台

五个页签，装在手机上点开就用：

| 页签 | 功能 |
|---|---|
| 对话 | 直接在手机上跟它聊，和 QQ 里是同一套能力 |
| 状态 | QQ 在线状态、端口、图库数量，2 秒实时刷新 |
| 模型 | 填 API Key、切换服务商 |
| 控制台 | 重启 Bot / 协议端、重新生成登录二维码、抓图、看日志 |
| 设置 | 三套主题、人设编辑、使用说明、意见反馈、更多设置 |

另外还有：

- **人设编辑**：写它的名字、性格、说话方式
- **使用说明**：首次打开自动弹出，之后随时可看
- **图库管理**：抓图模式开关（含风险确认）、每日自动换新、配置备份/恢复
- **意见反馈**：App 内直接提交

### 电脑一键部署

```
插线 → 填 QQ 号 → 点「开始部署」
```

自动完成：

1. 检测设备、判断是否有 root
2. 手机没装 Termux → 自动下载并安装
3. 配置存储权限、后台运行、电池优化白名单、开机自启
4. 推送程序 + 配置，生成访问 token
5. 启动服务，等端口就绪
6. 装上手机控制台 App 并打开

**有 root 全自动，没 root 也能全自动**（通过 adb 驱动 Termux 完成输入）。

还带 **一键卸载**：可选保留配置，可选连 Linux 容器一起删。

### 不用 root 也能操作手机（无障碍通道）

以前"让 AI 点屏幕"必须 root。现在装了 `Botagent` App 并开启**无障碍服务**后，**不 root 也能**：

```
读当前界面（文字 + 坐标）   a11y_dump
按文字点按                  a11y_tap
填字 / 滑动 / 返回桌面       a11y_type / a11y_swipe / a11y_key
按包名打开 App              a11y_launch
截屏（Android 11+）         a11y_shot
```

开启方式两种：

```
① 部署时自动开（部署器用 adb 直接写系统设置，不需要 root）
② 手动：手机设置 → 无障碍 → 已下载的服务 → Botagent → 打开
```

App 里也能开：**设置 → 让 AI 操作手机（无需 root）→ 打开无障碍设置**，状态会显示是否已开。

**和 root 的差别**

| | 有 root | 无 root（无障碍） |
|---|---|---|
| 读界面 / 点按 / 输入 / 滑动 | ✅ | ✅ |
| 截图 | ✅ | ✅（Android 11+） |
| 打开 App / 返回桌面 | ✅ | ✅ |
| 执行 shell 命令 | ✅ | ❌ |
| 静默装应用 | ✅ | ❌（只能弹安装器） |
| 读写任意文件 | ✅ | ❌（限共享存储） |

> 一句话：**日常"操作手机"够用，重活（shell、静默装包）还得 root。**

**注意**：重装 App 后系统会把无障碍关掉并标记为崩溃，需要重新开一次（
部署器会自动处理：先清空再写入，然后校验）。

## 安装

### 方式 A：电脑一键部署（推荐）

1. 手机打开「开发者选项 → USB 调试」，插线，屏幕上点「允许」
2. 解压发布包，进入 `Windows一键部署` 目录
3. 双击 `BotagentDeploy.exe`
4. 选服务商、填 API Key（**可以留空，装好后在控制台填**）、填你的 QQ 号
5. 点「开始部署」

装完会自动打开控制台。

### 方式 B：手机手动部署

前提：手机已装 [Termux](https://github.com/termux/termux-app/releases)（官方版，不要用应用商店版）。

```bash
# 1. 把 aibot 目录拷到手机
# 2. 在 Termux 里
pkg install -y python curl proot-distro
cd ~/aibot && bash install.sh
```

## 配置

程序读取 `aibot/config.json`，主要字段：

```jsonc
{
  "api_key": "sk-...",              // 大模型 Key（也可在控制台填）
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-chat",

  "owner_uid": 1000001,             // 主人 QQ
  "bot_uin": 1000002,               // 机器人 QQ

  "allowed_groups": [],             // 允许的群
  "safe_groups": [],                // 这些群只发安全内容
  "allowed_private_uids": [],       // 私聊白名单（空=只有主人）

  "persona": "",                    // 人设（也可在控制台写）
  "quiet_start": 3,                 // 夜间免打扰
  "quiet_end": 7,

  "rotate_enabled": true,           // 图库每日自动换新
  "rotate_hours": 24,
  "rotate_count": 40,

  "allow_remote": false             // 控制台是否允许局域网访问
}
```

改完不用重装：控制台点「重载配置」即可。

### 驱动与连接

**原理**：部署走的是 **adb（Android Debug Bridge）** 通道，不依赖手机助手，也不需要安装手机厂商的全家桶。

**正常情况**：

- Windows 10 / 11 自带 **WinUSB** 通用驱动，插上并在手机上点「允许 USB 调试」后即可识别
- 设备管理器里应出现 **Android Device → Android ADB Interface**（或类似名称），且无黄色感叹号

**判定是否连接成功**：打开命令提示符，执行

```bat
adb devices
```

| 输出 | 含义 | 处理 |
|---|---|---|
| `<序列号>    device` | ✅ 正常 | 可以开始部署 |
| `<序列号>    unauthorized` | 手机未授权 | 看手机屏幕，点「允许」，勾选「一律允许」 |
| `<序列号>    offline` | 连接异常 | 拔插数据线，或 `adb kill-server` 后重试 |
| 列表为空 | 未识别 | 见下方排查 |
| `adb: command not found` | 没找到 adb | 用发布包内置的 `adb.exe`，不要用其它版本 |

**识别不到时的排查顺序**：

1. **换线**：部分数据线只有充电针脚，必须用支持数据传输的线
2. **换口**：优先插主板后置 USB 口，避开前置面板和 USB Hub
3. **看设备管理器**：出现「未知设备 / Android」带黄色感叹号 → 装厂商 USB 驱动
   - 小米：Mi USB Driver 或小米助手（装完可卸载，驱动会保留）
   - 高通平台通用：Google USB Driver 也可尝试
4. **关掉会抢占 adb 的软件**：豌豆荚、手机助手、360 手机卫士、各类刷机工具会同时占用 adb 服务，表现为 `offline` 或列表为空。退出这些程序（必要时结束进程）后重试
5. **换一条 USB 2.0 口**：个别 USB 3.0 控制器与老机型兼容性差

**无线调试（可选，Android 11+）**：

不想用数据线可以走无线，但需要先用一次命令行：

```bat
:: 手机：开发者选项 → 无线调试 → 使用配对码配对
adb pair 192.0.2.10:配对端口
adb connect 192.0.2.10:调试端口
adb devices
```

连接成功后再运行部署工具，它会正常列出该设备。

> 注：无线调试对网络稳定性敏感，部署阶段建议还是用数据线，装完再拔。




## 常见问题

**检测不到设备**
换一根数据线（有些线只能充电），重新打开 USB 调试。

**提示未授权**
看手机屏幕，点「允许」，勾选「一律允许」。

**小米 / MIUI 装不上**
开发者选项里打开「USB 安装」和「USB 调试（安全设置）」。

**无 root 自动化没成功**
确认装了官方 Termux，并且首次初始化完成（出现 `~ $` 提示符）。

**拉不出二维码**
控制台点「重新生成二维码」。如果提示需要短信验证，去协议端后台完成验证。

**消息不回**
看控制台日志尾部，通常是 API Key 或网络问题。

**滑动有条白边**
用发布包内的最新 `Botagent.apk`，旧版 App 有这个问题。

### 成人图源的三层开关（2026-11-05 起）

成人向图源**默认全局关闭，连主人也不开**。要用必须同时满足：

| 层级 | 在哪控制 | 说明 |
|---|---|---|
| **① 总开关** | 控制台 → 设置 → 更多设置 → 深度抓图 | 关着时**任何人都不能用**（含主人），工具层直接拒绝 |
| **② 白名单** | 同一页的「深度抓图白名单」 | 只有名单里的 QQ 号 / 群号能用；**留空 = 谁都不能用** |
| **③ 临时授权** | 主人私聊发「给 123456 r18 权限」 | 写入 `perms.json`，可随时收回 |

三者是**与**的关系：总开关关 → 白名单失效；总开关开但白名单没你 → 用不了。

查看当前状态：私聊发「看权限」，会返回总开关、白名单、临时授权三层信息。

```jsonc
// config.json
{
  "r18_prefetch": false,              // 总开关，默认 false
  "r18_allowed_uids": [],             // 白名单 QQ 号
  "r18_allowed_groups": []            // 白名单群号
}
```

关掉总开关时，模式会自动降回 normal，界面也不会再显示 R18。

### 让 AI 自己操作手机（有 root）

除了执行 shell，它还带一套界面自动化工具，能"看懂"界面再动手：

| 工具 | 作用 |
|---|---|
| `ui_dump` | 读出当前界面的文字控件和坐标（可筛选） |
| `ui_tap` | 按文字点按钮，找不到会返回候选让你改口 |
| `ui_type` | 往输入框填字（可自动定位输入框） |
| `ui_swipe` | 列表翻页 / 滑动 |
| `ui_key` | 返回、Home、删除等按键 |
| `ui_wait` | 等某个文字出现，确认上一步生效 |

工作方式是「看清再点」，不是瞎猜坐标：

```text
ui_dump  →  看到「网络和互联网 @(360,1112)」
ui_tap   →  点它
ui_wait  →  等「互联网」出现，确认进去了
```

**实测**：让它"点进设置里的网络和互联网"，它会先 dump、再按文字点、再等待确认，
最后前台真的切到了 `Settings$SubSettings`。

**边界（很重要）**：

- 需要 **root**（无 root 拿不到 `uiautomator`）
- 依赖 App 暴露控件文字：**原生界面好用**；WebView / 游戏 / 图片界面读不到时，
  自动回退到 **OCR**（tesseract + 中文包，离线，约 2~5 秒/屏）
- OCR 文字会被拆出空格（「模型 状态」），匹配前统一去空白再比
- 纯图标按钮用 `icon_save` + `icon_tap`：先 `icon_save("back", x, y)` 现场裁模板，
  之后 `icon_tap("back")` 长期可用；匹配是边缘图 + 多尺度互相关，
  同界面实测 0.72~0.98 命中、换界面 0.46 会被拒
- 用程序画的几何图标**不可靠**（真实截图上只有 0.5~0.66 分，会误点），必须用实拍裁剪
- 没有"看一眼截图就懂"的能力（当前文本模型看不了图），靠的是控件树的文字
- 涉及付款、删除、给别人发消息，提示词里要求它先问确认
- 访客拿不到这组工具，只有主人能用

## 已知限制与反馈

### 这个项目还不完善

先把话说清楚：它是一个**个人项目**，能跑通、够自己用，但离「成熟产品」还有距离。下面这些是已知的短板，遇到了不必意外。

**兼容性**

- 只在**小米 6 / LineageOS 18.1（Android 11）+ Magisk** 上完整验证过
- 其它机型、其它 ROM 可能遇到：proot 启动失败、后台被系统杀、adb 识别异常
- 32 位（armeabi）手机**无法运行**（Linux QQ 只提供 arm64 包）

**能力边界**

- 没有 root → 只能聊天和发图，**没有工具能力**（详见上文功能边界）
- **语音消息、表情包：暂未支持，后续版本计划加入**（见下方「后续计划」）
- 视频消息、语音通话：暂无计划
- 群管理只做了基础功能（部分操作未实现）
- 单账号，不支持同时挂多个 QQ
- 记忆长度有限（上下文和长期记忆都有字数上限）
- 并发多人同时提问时会排队，响应会变慢

**稳定性**

- 依赖 NapCat + Linux QQ，**上游一改登录机制就可能失效**，需要等适配
- 二维码约 3 分钟过期，过期要手动重新生成
- proot 容器长时间运行可能被系统回收，需要保活（部署时已配白名单，但不保证）
- 图库抓图依赖外部图源，图源挂掉时会抓不到
- **没有自动更新**，升级需要手动重新部署或替换文件

**体验**

- 控制台是网页套壳，不是原生 App，动效和手感一般
- 界面文案只做了中文
- 首次部署要下载约 2 GB，网络差时很慢

### 后续计划（Roadmap）

已经排上日程、但**当前版本还没有**的能力：

| 计划 | 说明 | 状态 |
|---|---|---|
| **语音消息** | 收到语音能听懂、也能回语音 | 计划中 |
| **表情包** | 会发表情、能识别你发的表情 | 计划中 |
| 更多图源 | 提高抓图成功率，减少“什么都没有”的情况 | 计划中 |
| **插件机制** | 第三方插件 + 本人审查后才加载（哈希锁、权限声明、审查页） | 规划中 |
| 自动更新 | 不用手动重新部署 | 待评估 |
| 原生界面 | 目前是网页套壳，手感一般 | 待评估 |
| 多账号 | 同时挂多个 QQ | 远期 |

> **关于插件**：不做「随便装」，而是「提交 → 我审代码 → 批准后才加载」。
> 批准时记录文件哈希，之后文件被改动就自动失效，需要重新审。
> 插件必须在清单里声明权限（联网 / 读写文件 / 执行命令 / 收发消息），审的时候一眼能看到。

> 说明：这些是**计划**，不是承诺。个人项目时间不确定，做出来会写进更新日志。
> 如果你特别需要其中某一项，可以开 Issue 说明场景，会优先考虑。

### 遇到问题怎么反馈

**方式一：GitHub Issue（推荐，方便追踪）**

👉 <https://github.com/Yehua-1145/-QQbot-/issues>

新建 Issue 时请带上：

```
1. 手机型号 + Android 版本 + ROM（如 小米6 / Android 11 / LineageOS 18.1）
2. 是否 root、用的哪种部署方式（一键部署 / 手动）
3. 复现步骤：我做了什么 → 期望什么 → 实际发生什么
4. 日志尾部：控制台 → 日志页签，复制最后 30 行左右
5. 截图（如果有界面问题）
```

**方式二：软件内反馈（最快）**

打开手机上的 **Botagent** App → **设置** → **反馈** → 写清楚问题 → 提交。

反馈会直接发到开发者那里，不用注册账号、不用开浏览器。

**方式三：QQ 群里问**

看仓库主页右侧的链接，或者直接开 Issue 问。
