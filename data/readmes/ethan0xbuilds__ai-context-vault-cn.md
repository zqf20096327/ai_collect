# AI 个人上下文档案库 (AI Context Vault CN)

🌐 [在线预览](https://vault.oasaka.xyz) &nbsp;·&nbsp; [GitHub](https://github.com/ethan0xbuilds/ai-context-vault-cn)

> 让 AI 真正理解你，而不是每次都从零开始。

灵感来源于 [Allie K. Miller 的 AI Context Vault](https://www.alliekmiller.com/ai-context-vault)，针对中文用户的语境、文化和使用习惯进行了本地化重构。

## 这是什么？

每次打开 ChatGPT / Claude / Gemini / DeepSeek / Kimi，你都在和一个「失忆」的 AI 对话。它不知道你是谁、你在做什么、你在乎什么。所以它只能给你泛泛的、谁都适用的回答。

**AI 个人上下文档案库**是一套 Markdown 文件，记录了关于你的核心信息。每次开启新对话时，把相关文件丢给 AI，它就能立刻进入「懂你模式」——像一个认识你多年的顾问，而不是一个冷冰冰的客服。

## 为什么需要这个？

没有上下文的 AI 对话 vs 有上下文的 AI 对话：

| 没有上下文 | 有上下文 |
|-----------|---------|
| "你可以考虑学习编程" | "以你现在的 Go 基础和对分布式系统的兴趣，建议直接看 etcd 源码" |
| "建议你多运动" | "你说过周末带娃时间有限，可以试试早起 30 分钟做 HIIT" |
| "创业需要考虑市场需求" | "你上次说 B 端客户的续费率在下降，这个比拉新更紧急" |

## 它包含什么？

### 核心档案（7 个访谈 Prompt）

通过 AI 访谈生成，每个 prompt 会引导 AI 对你做一轮深度提问，最终输出一份结构化的上下文文档。

| # | 文件 | 说明 |
|---|------|------|
| 01 | [个人宪法](prompts/01-个人宪法.md) | 你的价值观、信念和原则——一切的基础 |
| 02 | [职业生涯](prompts/02-职业生涯.md) | 你的职业现状、技能、挑战和发展方向 |
| 03 | [创业与事业](prompts/03-创业与事业.md) | 适合创业者/老板/自由职业者 |
| 04 | [个人生活](prompts/04-个人生活.md) | 日常作息、健康、爱好、精力管理 |
| 05 | [社交关系](prompts/05-社交关系.md) | 朋友圈、社交模式、人际关系 |
| 06 | [家庭](prompts/06-家庭.md) | 家庭结构、亲密关系、养育、原生家庭 |
| 07 | [年度目标](prompts/07-年度目标.md) | 今年的真实目标，而不是许愿清单 |

## 快速开始

### 第 1 步：生成你的档案

1. 打开任意 AI 对话（推荐 Claude / ChatGPT / DeepSeek）
2. 复制 `prompts/01-个人宪法.md` 中的 prompt，粘贴发送
3. AI 会开始对你进行访谈，如实回答即可
4. 访谈结束后，AI 会输出一份结构化的上下文文档
5. 把输出保存为 `my-vault/01-个人宪法.md`
6. 重复以上步骤，完成其他模块

### 第 2 步：使用你的档案

开启新的 AI 对话时，根据需求组合加载：

- **求职/跳槽咨询** → 个人宪法 + 职业生涯 + 年度目标
- **创业决策** → 个人宪法 + 创业与事业 + 财务状况
- **生活规划** → 个人宪法 + 个人生活 + 家庭 + 年度目标
- **人际关系问题** → 个人宪法 + 社交关系 + 家庭
- **理财建议** → 个人宪法 + 财务状况 + 年度目标
- **任何对话** → 个人宪法 + AI 交互偏好（这两个建议每次都带上）

### 第 3 步：持续维护

- 每季度检查一次，更新变化的部分
- 每年重新跑一次年度目标模块
- AI 给出不符合预期的回答时，想想是不是档案里缺了什么

## 隐私提醒

这些文件包含你的深度个人信息。请注意：

- **不要**把档案推送到公开的 GitHub 仓库
- 建议使用**私有仓库**或**本地存储**（如 Obsidian）
- 涉及高敏感信息（身份证号、银行卡号等）时使用 `[已脱敏]` 占位
- 详见 [隐私分级指南](templates/隐私分级指南.md)

## 与原版的区别

本项目不是 Allie K. Miller 原版的简单翻译，而是针对中文用户做了以下调整：

- **职业语境本地化**：覆盖体制内/体制外、国企/私企/外企等中国特色职业路径
- **家庭模块重构**：纳入原生家庭影响、婚恋压力、养老责任等中国家庭议题
- **新增财务模块**：房贷/车贷、教育支出、养老规划——中国人的核心财务焦虑
- **新增 AI 交互偏好**：让 AI 知道你喜欢的沟通风格
- **隐私分级体系**：区分可以给云端 AI 的信息和只能本地使用的信息
- **访谈问题重写**：不是翻译，是基于中文语境重新设计的问题
