# Luwi

**DSH** for Android —— 把 [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）装进手机的一个应用

一台安卓设备同时当 dsh 的**主机**与**受控端**：界面就是 dsh 自己的 Web GUI（装在 WebView 里），原生那一半把屏幕、输入与系统能力做成 dsh 原生工具交给模型。装好就能用，不需要第二台电脑，也不需要 Termux；想接着用电脑那一套时，开「局域网访问」用浏览器连过来，或者开 `luwi-dsh-sync` 把两边的会话与工作区镜像成一套（默认关，见下文）。

一句话：**让 AI 像人一样操作你的手机。**

**系统要求：Android 13（API 33）及以上。** 应用声明 `minSdk = 33`，Android 12 及以下装不上 —— 安装器会直接判为不兼容；历史版本也一路都是 33，没有更低的旧包可以退。

使用虚拟屏需要 **[Shizuku](https://github.com/RikkaApps/Shizuku) 或 root（KernelSU / Magisk）之一**，二选一。

## 背景

这几年市面上没有任何一款真正的 AI 手机 —— 即使是目前最新的「AI 手机」，也谈不上「完全 AI」：各家软件厂商都在极力限制 AI 自动化，而个人开发者不可能去开发系统层面的 AI。

所以这个应用只从**应用层**解决：让 AI 像人一样操作手机，完成手机上的自动化。即使有一天 AI 手机真的来了，这个应用也还有用 —— 起码能让旧手机继续发挥作用，大家不必为了一个功能去换更贵的新手机，可以多一个选择。

## 功能

### 1. 唤醒：离线，锁屏也能叫

- 喊一声唤醒词就能把 dsh 叫起来，默认是「**肥鱼肥鱼**」。
- **锁屏时也能唤醒**：屏幕不会亮，只把语音输入叫起来对话 —— 亮屏本身是一种打扰，所以故意不亮。
- **唤醒词支持容错读音**：一个词可以配多条拼音，每条一行（注意每段都要分行）：

  ```
  肥鱼肥鱼=fei2 yu2 fei2 yu2
  肥鱼肥鱼=hui2 yu2 hui2 yu2
  肥鱼肥鱼=fei2 yi2 fei2 yi2
  肥鱼肥鱼=hui2 yi2 hui2 yi2
  ```

  拼音写音调数字（`fei2`）或带调号的字母都行；词表按音节逐个核对后才写入，写错会指名到是哪一个音节。
- 唤醒模型（zipformer KWS，约 5.3 MB）不进安装包，第一次用时才下载，**识别全程离线**。
- 设置页有「允许唤醒」与「省电模式 / 省电时段」（例如 `23:00-07:00`）：省电时麦克风整个关掉（喊不醒），host、浮标与通知都还在，点球照样能说一句话。

### 2. 视频、手机：两个模式，一句话就切

- **手机模式**（默认）：能看能动的全能模式，屏幕操作默认在自建虚拟屏上后台完成，不占你手里的屏；**手机自己那块屏也归它管**（「屏幕上写着什么」「有几条未读」「顺手在这块屏上点一下」都是它的活）。
- **视频模式**：用手机自己的摄像头看镜头前的东西（「这是什么」「前面写着什么」），回复会被念出来；这个模式里识别链常驻，接着说话不用再喊唤醒词。
- 说一句「打开视频模式」或者让模型调 `lw_mode` 就换；切换只换人设与对应的开关，不从你的手机下面抽走任何东西。
- **说「这个」「屏幕上」「照片里」这类话时不用先切什么**：浮标与语音那条路上，那句话在送出去之前会自动附一张主屏截图（设置页「截图」段可以关），模型直接就看得到你手指着的东西。原来说惯的「打开识屏模式 / 退出识屏模式」不再是一个模式 —— 前者按普通一句话对待（要的就是看那块屏），后者仍然当收工。

### 3. 浮标 ball：任何应用前台都能对话

- 常驻浮标取代原来的顶栏菜单按钮：**可拖到应用内任意位置**，按住微微放大、松手回弹，空闲 5 秒半隐到屏幕边（只留一半在外面、透明度减半），碰一下恢复。
- **不影响前台正常操作**：半隐之后就是屏幕边上一小块半透明图案。
- 点一下球就能说话，也可以打字输入；球上写着「正在听 / 正在想 / 正在念」，**「正在想」时双击它 = 打断**那一轮。
- 输入框还能浮在别的应用上面：那扇窗里装的是同一个 GUI，所以在任何应用里都能直接跟 dsh 说话。
- 球的外观（立绘 / 动作 / 尺寸）与半隐、半藏两档都能在设置页里调；一个状态可以挂多支动作，进档随机起头、演完自动换下一支。

### 4. 自带虚拟屏：后台跑任务

- 想开几块开几块，宽高与 dpi 随便给，建完还能换形状；预览是合成器直接画进原生 SurfaceView 的，零 native、不编码不解码。
- 屏在后台跑着，你可以一边看它一边用 dsh 界面；虚拟屏小窗整条标题栏就是拖动把手，右端减号把整扇窗收掉。
- **一任务一屏、先到先用**：默认规则是一块虚拟屏只给一个任务用，后来的任务轮询等待；这条规则写在模式人设里，**可以用提示词改它**。
- **已知缺陷**：虚拟屏在后台运行时可能对前台造成误触，使用前请知悉。

### 5. 语音输入：离线，一套就够

不联网、不要密钥、音频不出设备；模型不在包里，第一次用时才下载：

- **SenseVoice**（sherpa-onnx，约 240 MB）：快，一句话不到 1 秒 —— **会话输入框那个麦克风、浮标对话、唤醒对话与视频模式都走它**，这就是唯一的一套，没有第二个引擎要选。

### 6. 说话输出：四档引擎

- **系统 TTS**：用手机自带的语音引擎，不联网不要密钥。
- **导入音色**：自己放进来的 sherpa-onnx 音色（设置页「朗读」）；这条引擎有自己的音量：以它本来的电平当 100%，往上到 300% 是加增益。
- **Edge-TTS** / **API-TTS**：想用在线音色或自己的接口时选这两档（这两条是你自愿启用的，会联网）；API 音色可以登记进「音色库」，也能单次点名。

### 7. 一整套手机操作工具

屏幕与输入是一套 dsh 原生工具（`lw_*`，共 61 个）：列屏 / 建屏 / 换尺寸 / 关屏 / 点 / 拖 / 长按 / 按键 / 组合键 / 打字 / 滚动 / 启动应用 / 打开链接 / 截图（可分区、可连拍、可拼网格）/ 读无障碍树 / 端侧 OCR / 列应用 / 通知与震动 / 剪贴板 / 文件 / 媒体与照片 / 图片与相册（`lw_image`）/ 电池与存储 / 音量与媒体 / 网络 / 传感器与定位 / 系统设置读写 / 多指手势与捏合 / 等一件事发生 / 读日程与写日程（`lw_calendar`）/ 快捷指令（`lw_quick`）/ 自动指令（`lw_automation`）/ 插件（`lw_plugin`）。

主屏也看得到动得了（`displayId 0` 就是手机自己那块屏）。破坏性操作（卸载 / 清数据 / 停应用 / 装包 / 停用）**调用即执行** —— 应用侧已经不再弹确认框，唯一那道闸是模型被要求动手前先问你一次（见 `skills/android-device-control`）。

读屏是两条腿：**无障碍树**给结构（哪个控件、叫什么、能不能点），**端侧 OCR**（PP-OCRv6 tiny，ONNX）给画面上的字；两条都能读，读不到就如实说读不到，不会编。

### 8. 日程与快捷指令

`lw_calendar` 让模型真的读得到、写得进你的日程：列日历 / 查一段时间 / 读一条 / 建一条 / 改一条 / 查空闲（`free` 按 09:00–22:00 算空档，可以调）。时区就是设备时区，写入落在第一本可写的日历上，一本可写的都没有时会**如实拒绝**而不是假装写进去了。这一版**没有删除** —— 删日程还是去日历应用里删。

「快捷指令」是"点一下就把一段工作流交给模型"：一条 = 一个 md 文件（住在 `$DSH_HOME/quick-commands/`），设置页有一段列表，**点一下**就把它投进当前会话（没有会话就新建一场）；在会话里说或打「用快捷指令: <名字>」是同一件事。**新建不用写表单**：说一句"这条要做什么"，模型自己起名字、自己把步骤写成文件。随包带两条样例：「制定旅游计划」（天气 → 日程空档 → 搜索当地状况 → 落进日历）与「今天要做什么」。技能库里另带四份技能（网络搜索 / 天气 / 日程 / p 图），首次启动会自动放进 `$DSH_HOME/skills/`。

### 9. 自动指令

「自动指令」是"到什么时候做什么"：一条规则 = 一个 JSON 文件（住在 `$DSH_HOME/automations/`），条件有六种 —— **通知**（哪个应用、正文或标题里有哪几个字）、**前台应用**（切到某个应用时）、**光感**（亮过 / 暗过某个亮度，可要求持续几秒）、**时间**（每天或某几个星期的几点）、**地点**（到某个地名几百米以内）、**天气**（某个地方的气温 / 降水 / 天气代码达到某个数）。命中之后它把一句话开进一场新会话：**提醒**那一种由模型现写一句短话、发一条通知并念出来；**干活**那一种会真的去动手机（2.8.0 起没有全局总闸，那一道「允许它自己动手」2026-11-07 撤了）。防骚扰是一整套：静默时段（默认 23:00–07:00）、每条规则的冷却与每天上限，以及设置页里一份"最近做了什么、为什么没响"的账。规则由模型写（说一句"每天八点提醒我带伞"就行），设置页负责开关、新建、改一改与删掉。

**功耗**是按"没有启用的规则就一个监测器都不注册"做的：通知与前台应用是事件驱动（前台应用只认无障碍事件，不看使用情况统计），时间只排一个闹钟，轮询只有天气（默认 60 分钟）与地点（只用网络定位，默认 10 分钟 · 500 米）；省电模式一生效，轮询那两条整个停下来。

### 10. p 图：把屏幕上那张图改掉

说一句「帮我把这张图的背景改为海边」，它会**截下你正看着的那块屏**，交给生图模型（图生图）改完，把成图放进相册的 `Pictures/Luwi` 并直接打开给你看。主人自己发的那张图、工作区里的文件也能当源图；改完不满意就接着说"再改成…"，每一版都留一份。

生图那一半是随包发的第三方插件 [`@dickpy/dsh-imagegen`](https://github.com/dickpy/dsh-imagegen)（Apache-2.0，作者 dickpy），渠道与密钥在「设置 → 生图配置」里自己配（OpenAI 兼容接口，以及 grok-imagine / nano-banana / seedream / qwen-image / glm-image / MiniMax 等预置渠道）；它自己还带一整套界面：画廊、无限画布、提示词模板库、电商套图、文生图（不带源图时用「生图」面板或让模型调 `generate_image`）。**改图会走你配的那条 API 并花钱，图也会发给那个服务** —— 模型被要求如实说明这一点。

### 11. 插件：别人写的包，给这台手机加能力

不重编本应用就能加东西的那一层（协议 `lw-plugin/1`）。**在设置页的「插件」段粘一个 https 链接，
装完就能用** —— 它注册的工具与内置的 `lw_*` 长得一样，模型下一轮就能调；停用、卸载与"最近调了哪些
能力"的账都在同一页上。

三个域，先挑最省的那一个：**`art`（一包资源，零代码，零第二次安装）/ `inline`（一份 dex 跑在本应用
的 `:plugin` 进程里）/ `companion`（另一个 APK，只在"要主 APK 清单里没有的权限与组件"时才用，而且
不许带启动器图标）**。桌面上那两格（动画 / 图文）由主 APK 自己声明成"宿主槽"，插件只往里填内容 ——
所以**装一份 `.lwp` 就完了，桌面上不会多一个应用**；同一个槽同一时刻只挂一只插件。

- **粘一个地址就够**：那份 `.lwp` 里写着它要绑的那个包与那个包的 https 地址，所以装完它会顺手把伴侣
  APK 也下下来装上（有 root / Shizuku 时静默装，没有时把文件交给系统安装器让你点一下），再接着启用。
  它要哪几条能力会在装之前列一次（敏感档默认不勾）；**一条能力都不要的插件连这一次都没有**
- **包里没带地址的老包**：`.lwp` 只说"绑哪个包、哪个 Service"，那个伴侣 APK 要另外装；装完之后在
  那个插件的详情里点一下「启用」
- **装一个插件就是信任它**：它拿到的能力就是你勾给它的那些，勾了 `privileged.shell` 就等于把特权交给它；
  `inline` 那一档与 Luwi **同一个 uid**，所以它**只对白名单作者开放**（与 Luwi 同签名，或把公钥指纹
  写进 `$DSH_HOME/plugins/.inline-allow.json`），第三方未经审核的提交不要走这条路
- **必须签名**（ECDSA P-256）：发布者指纹显示在插件页上，第一次见到一把新公钥会单独提示一句；改过包的会被拒装。没签名的包只在设置页打开「开发者模式」之后才收，界面上常驻红字
- 样例与写法：零代码那份 [`samples/art-whale-widget/`](samples/art-whale-widget/)、
  dex 那份 [`samples/inline-timer/`](samples/inline-timer/)、伴侣那份 [`samples/companion/`](samples/companion/)；
  签包工具是 `tools/lw-plugin-sign.mjs`，判据是 `tools/check-plugins.mjs`
- **这一版接通的能力**（设备读数 / 传感器 / 通知 / 朗读 / 剪贴板 / 读自己的目录 / 往会话投一句话 /
  往宿主槽推桌面内容 / 提供浮标外观 / 读指定前缀的文件 / 访问声明的域名）；带参数的那两条边界就是声明里
  那一截（`files.read:/sdcard/DSH`、`net.http:api.example.com`，只走 https 且重定向每一跳重查），
  其余能力可以声明，调用时会如实回一句"这一版还没接通"，不会假装成功

### 12. 酒馆：一张最多十个人的桌子

它不是会话，是一层独立的小应用：**角色卡 + 故事书 + 存档 + 主题**。人物卡可以导入 PNG（`chara` / `ccv3` 块）、JSON（V1 / V2 / V3）或 CHARX，故事书认 SillyTavern World Info 的 JSON；一张桌子最多十个人，一轮可以点几个人**按勾选顺序依次回几条**（不勾就照旧一轮一人，`@名字` 优先、其余加权随机）。每个角色能单独配一对 `provider + model`，也能单独开「主动说话」—— 检查间隔、安静阈值、触发概率三个旋钮都以"轮"为单位，只在聊天页开着、一轮结束之后才判定，模型回一句 `[SILENT]` 就是不想说。六套主题可切（玻璃那一套在没有 `backdrop-filter` 的 WebView 上退成不透明），背景图压在 30% 主题色底下，主题是全局设置、存档跟着主题（没有存档也能选），首页 / 聊天页顶栏 / 状态栏图标都跟同一套走。

它**不建 dsh 会话、不注册工具、不读写记忆**，数据只在 `$DSH_HOME/lw/tavern`；换工作区就锁上（门闸只看 host 的 `cwd`）。酒馆要登录与有效服务时长：登录走官网的设备码那条路，签到与购买只在官网 `/tavern`，**应用里没有任何签到或支付写操作**（入口叫「去签到」）。

### 13. 局域网、Linux 沙盒与存储

- **可选局域网访问**：打开后别的设备用浏览器就能连；手机一套小字体、PC 一套大字体，各存浏览器本地。
- **工作区在你自己的存储里**：`/sdcard/DSH/`，文件管理器翻得到；dsh 自己的配置与凭据留在应用沙盒（`filesDir/dsh-home`），**自带的 Linux 沙盒也读不到它**（沙盒以 shell uid 跑，凭据那条边界是内核的）。
- **内置的轻量级 Linux 兼容层**（Alpine minirootfs + proot，随包发一份 base，装在 `/data/local/tmp/lwlinux`）：可以 `apk add` 装 python、编译脚本 —— **它不是虚拟机，也不是安全沙盒**，沙盒里只看得到工作区、网络是通的。
- **dsh 与它的 Web GUI 一起进 APK**：Node 24 随包发，前台服务常驻，关掉界面也活着；两个模式的人设与技能随应用发布，模型按模式的人设作业。

## 注意事项

> [!WARNING]
> **没有沙盒限制。** Luwi 能拿到手机几乎所有权限，权限审批是全部放行的（而且这是有意的决定：模型点屏幕时应用自己在后台，审批框没人点得到，摆在那里只会让每次点击卡到超时），模型操作主屏不会询问任何人 —— 2026-10-08 起连"真人一碰屏幕就停手"那道软停也删了，主屏只靠提示词层的规矩。**安全性由用户自行判断，不要装在主力机或存有重要数据的手机上**；v3.0.0 之前都是开发版。内置的 Linux 沙盒只是"手机里多了一个 Linux 命令行"，它换来的是 **shell 一档的能力**（不是更严的一档），**不要把它当安全边界用**。

> [!NOTE]
> **不联网。** Luwi 自身不收集、不上传任何数据。会联网的只有四处：① dsh 调用你自己配置的模型 API；② 你亲手触发的模型下载（语音识别、唤醒词）；③ 你自愿启用的 Edge-TTS / API-TTS；④ 你在「插件 → 浏览插件仓库」里**亲手点的「刷新索引」与「装它」**（取官方索引 JSON 与你选中的那份插件包，其余时候只读缓存）。p 图与在线音色都走你自己配的接口，改图会把图、朗读会把文本发给那个服务 —— 这两条都要你配了 key 才会发生。
