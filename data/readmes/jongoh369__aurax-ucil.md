# AuraX-UCIL Community Edition (v3.5.0)
> **Open-Source Non-Regression Guardrail Engine for LLMs and AI Document Amendment**

AuraX-UCIL Community Edition is a free, developer-friendly open-source toolkit implementing Differential Preservation Contracts (DPC) to prevent correction-induced regressions in generative AI workflows.

## Features
- **Deterministic DPC Pipeline**: Extract multi-attribute communication identities (NUMERIC, TEMPORAL, INTENT, SEMANTIC).
- **Dual Gate Non-Regression**: Ensures required updates are applied without breaking pre-existing terms.
- **One-Click Launch**: Double-click `start_ucil.bat` to run locally on Windows.

## Quick Start (Windows)
1. Double-click `start_ucil.bat`
2. Browser opens automatically at `http://localhost:8000`
3. To exit cleanly, double-click `stop_ucil.bat`
