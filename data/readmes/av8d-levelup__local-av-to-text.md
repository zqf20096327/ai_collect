# 影音轉文字工具（本地・免費・資料不外流）

> 一鍵把**影片 / 語音**變成**逐字稿**，還能**配背景音樂**、**產生摘要**。
> 全程在你自己電腦上跑 — **不上傳、不外流、可離線**。Mac / Windows 都能用。
>
> Local video/audio → transcript + summary. Runs 100% on your machine.
> Traditional-Chinese optimized. No cloud, no upload, works offline.

---

## ✨ 特色

- 🔒 **地端運算**：轉文字、配樂、摘要**全部在本機**，資料不進任何雲端
- 💰 **完全免費**：用的都是免費開源工具，量大也不加價
- 🈶 **繁體中文優化**：自動偏向繁體輸出（可搭配 opencc 簡轉繁）
- 🎬 **四個模式**：1)影片轉稿＋配樂 / 2)純語音轉稿 / 3)整資料夾批次 / 4)摘要
- 🎙️ **各種副檔名**：mp3 / m4a / wav / aac / flac / ogg / opus…（影片也行）
- 🧠 **本地摘要**：用 Ollama 產生「一句話重點＋條列＋可發文摘要」，一樣不外流

---

## 🚀 快速開始

1. 依 [安裝說明_Mac 與 Windows.md](安裝說明_Mac與Windows.md) 裝好工具（一次就好）
2. 執行啟動器：
   - **Mac**：點兩下 `點我開始_Mac.command`
   - **Windows**：把檔案拖到 `點我開始_Windows.bat` 上
3. 選 **1 / 2 / 3 / 4**，把影片或音檔拖進來，按 Enter
