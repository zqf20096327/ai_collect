# 知友 · 微信增强模块

> 本项目是 [wcx](https://github.com/Johnny520/wcx/) 的二次开发，一个跑在 LSPosed 上的微信增强模块。

## 模块介绍

知友是一个微信增强模块，功能分三块：

- **好友档案** —— 标签、带时间的记忆、关键事件、人格侧写；配智能建议与自动回复。
- **群聊摘要** —— 按频率把群聊压成「一句话标题 + 要点 + 待办」，首页红点提醒。
- **常规增强** —— 239 个开关、15 类：聊天 · 联系人与群组 · 红包与支付 · 朋友圈 · 系统与隐私 ·
  音视频通话 · 界面美化 · 公众号 · 小程序 · 视频号 · 个人资料 · 调试 · 批量操作 ·
  首页右上角菜单 · 密友功能。常用的有防撤回、对话归拢、隐藏联系人、主题工坊、
  朋友圈批量删除、自动抢红包、指纹支付、虚拟定位、临时通话。

另有 46 项内部服务，不占列表、没有开关。入口在 `微信 → 我 → 设置 → 知友`，设置页分
主页 / AI / 日志 / 设置四个 Tab。完整清单见 [docs/features/README.md](docs/features/README.md)。
数据与 AI 配置只存在本机。

**他喜欢什么、在做什么。** 跟一个人聊了两三年，几千条消息——他做什么工作、孩子几岁、爱喝什么、
上次提过想换个城市，记得个大概，细节已经模糊。想翻聊天记录核对，又不知道该搜什么词。

**答应过什么。** 还有些事当时说得很轻：「我帮你问问」「下次一起吃个饭」。一年过去，他还记着，
你早忘了，对方也不好意思再提。

**怎么回。** 想好好回一句，打了删、删了打，最后只发了个「嗯」。或者手头正忙，消息一条条进来，
知道该回，就是腾不出手。

**群里聊出了什么。** 工作群、行业群、家长群，一天上千条，八成是闲聊和表情包。开免打扰，怕漏掉
重要信息；不开，又总被拽回去看。

知友把这些摘出来，按人存好——**爱好、工作、家庭是标签，约过什么、答应过什么是带时间的记忆**；
回话时按你们的相处方式拟几条候选，没空就让它替你回；看不完的群，按你定的频率压成一条摘要。

## 一个好友，一份档案

档案里存的就是你跟这个人之间，本来就该记住的那些事。

| 档案里有什么 | 长什么样 |
| --- | --- |
| 标签 | `咖啡：手冲，不加糖` · `运动：周末打羽毛球` · `孩子：女儿今年上小学` · `沟通：话少，正事一次说完` |
| 记忆 | `2026-03 搬去杭州，房子在滨江` · `2026-05 答应帮他问问内推` · `2026-08 吵过一次，已和好` |
| 关键事件 | 记忆里的承诺、争吵与和解、关系转折、家庭或健康变故，会单独标出来 |
| 人格侧写 | 说话短、少用表情、不爱寒暄——不是通用人设，是这个人的 |
| 聊天目标 / 回复风格 | 这次想推进什么、用什么口吻；两者打架时以哪个为准 |

打开档案第一屏就是这些，不用往上翻记录。

这些也不是手填的：选一个起始年份，它把这整段历史读完，自己整理出来；之后每聊一段，新的事会
补进去。不想让它乱记，审查页会先把「该合并的标签、该删的记忆」列出来，你点了确认才写进去。

有了这份档案，开口前不用再翻几屏：

| 场景 | 做法 |
| --- | --- |
| 看了两遍，还是不知道怎么接 | 打开「智能建议」，聊天页双击出几条候选，挑一条发出去（卡片打开时再双击换一批） |
| 完全没空，又不想已读不回 | 打开「自动回复」，默认等对方说完 8 秒再回（AI → 设置里可改 3~60 秒） |
| 怕它说错话 | 档案里写清聊天目标和禁忌；自己一发消息（哪怕一张图、一个表情），这次自动回复立刻作废 |
| 想确认它记住了什么 | 好友管理弹窗七页：概览 · 聊天目标 · 标签 · 记忆 · 审查建议 · 变动记录 · 回复风格 |

开了自动回复之后，还有两件事不用你记：

**对方说定的事会自己进总览。** 「明天见一面」「周六帮你搬东西」这类话，它会记一条到首页标题栏的
「总览」，带红点提醒，点进去按 1、2、3 列出，每条带记录时间。看过清红点但不会删，要清掉自己点
「清空」。详见 [总览](docs/features/ai/overview.md)。

**朋友圈也不用想怎么回。** 长按对方朋友圈的文字，菜单里多一项「帮我评论」，读这条动态和对方的
标签、近期事件，写三条不同风格的评论，点一条复制。图片只用本地已缓存的，不为评论去下载；视频
不解析。详见 [朋友圈帮我评论](docs/features/ai/moments-comment.md)。

AI 相关配置都在 `微信 → 我 → 设置 → 知友 → AI` 里，页面分好友 / 群组 / 设置三段。

## 一个群，一条摘要

群还在，只是不必每条都看。按你设的频率把这段聊天压成一条：**一句话标题 + 要点 + 待办**。
不写谁说的，只写聊了什么、定了什么、还有什么没定——想追细节再进群翻原文。

| 你在意的 | 它怎么处理 |
| --- | --- |
| 多久一次 | 每 1~168 小时（预设 1 / 6 / 12 / 24 / 48 / 72），从开启那一刻算起 |
| 群太安静 | 不到 3 条文字就跳过：不生成、不加红点，也不会冒出一条「今天没聊什么」 |
| 消息太多 | 分段读完再合成一条（最多 8 段），注明实际覆盖了多少条 |
| 在哪看 | 首页标题栏的「总览」图标，带未读红点：最上方是今日总结，下半是好友事件与群卡片（开启群总结或好友自动回复后出现） |
| 会不会积压 | 每群留 100 条 / 90 天，翻过的自动清未读，长按删除 |

只在微信运行时跑；没跑的那段，下次打开补一条，不会一次冒出好几条，最多往前补 7 天。

在 `AI → 群组` 里添加群（可多选、可搜索），点进群能改频率、看历史、手动总结。立即总结按你设的
频率往前取——设 24 小时，就是最近一天。

## 从哪开始

| 你现在的处境 | 可以这么做 |
| --- | --- |
| 想快速想起一个人：做什么工作、有什么爱好、最近有什么变化 | 好友 → 标签与记忆 |
| 答应过对方的事快忘了 | 好友 → 记忆（承诺会标成关键事件） |
| 消息堆着没回，又不想只发个「嗯」 | 好友 → 智能建议 / 自动回复 |
| 群消息量大，只想知道「有没有正事」 | 群 → 定时总结 + 首页红点 |
| 群已免打扰，但怕漏掉重要信息 | 群 → 摘要里的要点与待办 |
| 想把上面这些之外的老功能找出来 | [全部功能](docs/features/README.md) |

这两块互不依赖，只用其中一个也行。

## 安装与使用

安装包在 [Releases](../../releases)，选 arm64-v8a。手机需要 root，并装好 LSPosed。
装过旧版的不用重下，在「设置 → 更新 → 检查更新」里升级即可。

1. 在 LSPosed 里启用「知友」，作用域勾选**微信**，然后强制停止微信再打开。
2. 打开 `微信 → 我 → 设置 → 知友`，主页的 AI 卡片点「配置」，填 **API 地址 / Key / 模型名称**。
   兼容 OpenAI 格式的都行（DeepSeek、通义、自建中转等），只存在本机；要看图的场景，选支持图片
   输入的模型（识图默认关）。
3. **好友**：AI → 好友 → 添加，选一个起始年份，等它读完这段历史。然后点进这个好友，在概览页的
   「功能」里打开「智能建议」（双击出候选）或「自动回复」——两个都默认关。
4. **群**：AI → 群组 → 添加群，选个群、设个频率，点「立即总结」看第一次效果。首页标题栏会多一个
   「总览」图标，有未读时带红点，点开上半是好友的重要事件、下半是群卡片和历史。

装完不生效，看 [快速开始](docs/getting-started.md) 里的排查步骤。

## 适配与兼容

适配微信 **8.0.80**。装到别的微信版本也能开：对不上的功能会在自检页标成「待适配」跳过，
不影响其他功能，也不会让微信崩溃。
