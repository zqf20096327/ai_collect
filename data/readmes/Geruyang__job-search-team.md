# AI 求职小组 · Job Search Team

**让 AI 帮你找岗位、读 JD、比较机会，再按你的授权沟通投递。**

一个可迁移、可配置的求职 Agent Skill，附带 BOSS 直聘 / 猎聘本机网页助手。你决定求职方向、评分权重和一票否决项；AI 负责整理证据、分工执行和核对结果。

## 你只管决定什么工作值得去

找工作最费时间的，往往是重复筛选：读一遍 JD、查一遍公司、对照一次经历，再确认有没有投过。

这个技能把这些步骤组织成一支求职小组：搜索收集岗位，评估核对证据，资料角色检查简历，沟通角色准备介绍和处理回执。支持多个智能体分工，也可以由一个模型按角色顺序完成。

| 能力 | 怎么帮你 |
|---|---|
| 自定义评分 | 匹配、成长、薪资性价比、用工评价、行业知名度，权重可调 |
| 你的底线优先 | 一票否决条件由你确认、删除或重新提供 |
| 新鲜度可控 | HR 活跃、岗位更新、岗位发布时间分别设置 |
| 基于证据比较 | 未知项保持未知，不用虚构分数把资料不足变成“高匹配” |
| 分工协作 | 总协调与分平台角色，明确标签页和文件所有权 |
| 本机网页助手 | 随包提供扩展、服务和 CLI，自动部署或复用 |
| 查重与回执 | 区分聊天送达、附件发送、实际投递，未知结果先对账 |
| 本地经验库（可选） | 经授权创建空问题文件与知识库；启动先读、遇错先查，每次结果和人工介入当次更新；不覆盖已有记录 |
| 招聘者意向 | 每次读聊分析HR态度，区分明确推进与初步兴趣，展示重点岗位及下一步 |
| 每20岗复查 | 仅打招呼也计岗，同平台同需去重；只读检查待定态度，不自动催问 |
| 可迁移 | 不绑定模型提供方，不依赖作者的项目路径或账号 |

## 一句话开始

将完整技能目录导入支持文件与本机工具的智能体环境，然后告诉它：

> 使用这个求职技能，先收集我的简历、目标、评分占比、否决项和所需权限，再编写或适配安装助手，让我登录招聘平台，尽可能验收功能。先筛选，不联系HR或投递。

已有偏好也可以直接说：

> 匹配占 40%，成长 20%，薪资性价比 20%，用工评价 10%，行业知名度 10%。岗位优先最近 7 天更新；未知时间单独标记。其他否决条件先让我确认。

初始评分预设为 **30 / 10 / 20 / 15 / 25**，只是待确认模板。适用于你的策略，由你决定。

## 初始化与搭建

1. 先私下提供自己的简历、目标、评分占比、否决项和所需权限；可沿用已确认内容，不要求全部授权。详见[初始化清单](job-search-team/references/initialization.md)。下载解压完整技能包，准备 **Node.js ≥22**、兼容 Chromium 扩展的桌面浏览器，以及一个空白可写工作区。
2. 替换实际路径后执行：

```sh
node "<技能目录>/scripts/ensure-assistant.mjs" --workspace "<工作区>"
```

3. 按输出路径安装/加载插件、接受所需浏览器权限、导入本机配对文件，再由用户在同一浏览器登录招聘平台。
4. 按[功能验收表](job-search-team/references/acceptance.md)尽可能检查所有功能：未测与失败明确标记，真实外发只在获准任务中验证。

经验留存已获授权时，可先运行：

```sh
node "<技能目录>/scripts/init-knowledge.mjs" --workspace "<私有工作区>" --enable
```

它创建缺失的空白问题文件、知识库、会话接续入口，并向项目规则追加维护协议；已有内容保留，重复运行不会重复追加。拒绝建库则跳过。已有知识库可通过 `--knowledge-dir "<工作区内相对目录>"` 复用。

其他会话导入完整技能ZIP并按[会话接续说明](job-search-team/references/session-handoff.md)访问自己的私有工作区。只有入口文件或纯云端上传不能代替本机工具。项目规则是Agent要执行的协议，不是后台自动记录服务；个人历史不包含在公开包里。

助手支持Chrome活动标签截图与自动切页，不主动刷新。图片识别由宿主图像工具完成；最小化可能出现旧画面或失败，按授权使用文字回执。BOSS附件弹窗迟滞优先切回目标页，不重复发送。详情见[故障与最终办法](job-search-team/references/troubleshooting.md)。

运行代码只使用 Node 内置模块，**无需 Python，无需 npm install**。完整步骤、首次验收和常见问题见[安装说明](job-search-team/references/setup.md)。

## 工作流程

```mermaid
flowchart LR
    A[确认偏好与规则] --> B[搜索与采集 JD]
    B --> C[证据核验与评分]
    C --> D[候选比较与材料准备]
    D --> E{已有外发授权?}
    E -->|否| F[交付清单和草稿]
    E -->|是| G[查重与机会认领]
    G --> H[单次沟通或投递]
    H --> I[回读核验与记录]
```

## 已验证什么

2026-11-08技能源及完整ZIP独立解压后分别101项测试通过，其中新增7项验证知识库初始化的授权、文件保留、目录边界、重复运行和独立CLI。新环境仍须按验收表检查真实浏览器，测试不代表所有宿主已实机兼容。

最新意向复查规划器新增8项通过的离线行为测试，覆盖20岗边界、同岗去重、跨平台计数、未知/失败/人工动作排除、跨轮游标及3日/7日时长。超过3日已读无HR回复，或超过7日的待定岗位退出例行复查；后来有新消息仍优先处理。规划器不操作网页，真实态度需结合原会话判断。详情见[意向跟踪](job-search-team/references/recruiter-interest.md)。

V2.0的86项本机自动测试通过：77项桥接/图像逻辑、7项评分、2项部署与复用测试。独立解压包也须通过相同验收，详见[发布验证](job-search-team/VALIDATION.md)。测试使用Windows本机临时服务及模拟浏览器，不代表所有网站/系统已实机通过。

当日历史实测曾确认独立Chrome两平台截图和双向切页；最小化实时图像、锁屏和长期无人值守仍不保证。公开包不携带真实截图或聊天证据。新环境必须自行验收。

## 使用前了解这几点

- **模型不限，执行环境有要求。** 纯云端聊天无法直接访问你电脑的本机服务；自动操作需要本机命令与文件工具连接。
- **首次安装和登录需要配合。** 扩展加载、登录与验证码遵循浏览器及招聘平台规则。
- **筛选不等于授权投递。** 没有明确授权时，只准备候选清单与沟通草稿。
- **当前助手适配 BOSS 直聘和猎聘。** 不承诺其他招聘网站直接可用，也不保证录用结果或永久无人值守。
- **个人数据留在你的使用环境。** 仓库不包含账号、配对令牌、个人简历、历史求职记录或私有解决方案知识库。不要上传运行生成的 `.local`、意向跟踪状态、聊天回执或本地案例。
