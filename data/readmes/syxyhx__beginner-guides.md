# 新手开发环境指南

写给刚上手的学生：不假设你有基础，每一篇都从「第一次听说这个东西」讲到「能自己跑起来」。

三份教程，三件绕不开的事——**把代码托管起来**、**有一台自己的服务器**、**拿到能调用的模型 API**。都是排版定型的 PDF，按顺序照做即可，不需要看完全部。

## 不知道从哪篇开始

按你现在的处境对号入座：

| 你的处境 | 从这里开始 |
|---|---|
| 没碰过 git，作业还在用压缩包发 | **01**，A 线（只用桌面端）：第一至三章打底 + 第四章跟着走一遍就能上手，第五章命令行可以按需延后 |
| 想让程序一直跑着，不想开着自己的电脑 | **02**，第 1、2 部分讲怎么买，第 4 部分讲怎么装 |
| 只想尽快拿到一个 API Key 试试大模型 | **03**，13 页、15 分钟，全程不写代码 |
| 三个都想做 | 顺序无所谓。**02 和 03 共用同一个阿里云账号**（实名做一次即可），但和 01 的 GitHub 账号没有任何关系，两套学生认证彼此独立、各做各的 |

## 阅读约定

这几条写在每篇开头，这里再说一次，因为踩过的坑最多：

- **文中出现的用户名、邮箱、仓库名、IP、端口、密钥都是占位符**，形如 `你的用户名`、`123.45.67.89`、`sk-你的密钥`，执行时换成你自己的。
- **提交身份别用真名**。写进 `user.name` 的那个名字会永久留在每一次提交记录里，建议用网名或拼音缩写。
- **密钥等同于密码**。`sk-` 开头的 API Key 不要发给任何人、不要截图发群、更不要提交进仓库。它只在创建成功那一刻完整显示过一次，丢了只能重建。
- **价格、界面、活动规则都在变**。文中数据核对于 2026 年，下单和操作前请以官方页面当期显示为准；教程只保证「路径是对的」，不保证「数字一直是对的」。
