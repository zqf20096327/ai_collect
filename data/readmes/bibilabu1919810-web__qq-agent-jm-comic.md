# JM 本子（小白也能上天~堂~）

> 众所周知，人总是要上天堂的~
>
> 所以嘛……既然你都点进来了，那大概是想要这个吧？
> 就是那个——@ 一下机器人、丢个车牌号，它就会把本子下好、
> 把被切碎的图一张张拼回去、打包成 PDF 递过来的小东西。
>
> 唔，提前说好，这可不是特意为你做的哦。
> 只是刚好顺手写了一下而已。你要是想用……那、那也不是不行啦。

一个给 **[QQ Agent](https://github.com/Kondius/qq-agent) v0.3.1** 用的技能。

---

## 它到底能做什么

**① 你说个类型，它列一堆给你挑**

```
你  ：有没有校园题材的
它  ：「校园」的搜索结果：
      1. 衣冠禽兽 — 李东宪 金世兰  [JM1461316]
      2. 不纯吸血鬼 — 李成治  [JM1418103]
      3. 蛮横无理的大小姐… — 木下由一  [JM1245041]
      （共约 4645 个结果，这里只列了前 8 个）
      回我 jm<车牌号> 就给你下这本
```

**② 你丢个车牌号，它直接下**

```
你  ：jm1461316
它  ：[发来一个 PDF]
```

**③ 图不会是碎的**

这是它跟别的实现最不一样的地方。禁漫服务端返回的图**本身就是被切成好几段、段序倒过来的**
（你没看错，不是你的问题）。这个技能会把顺序拼回去再打包，所以打开是完整的画面。

**④ 不需要一直挂着 VPN**

它会自己去试"走代理"和"直连"哪条路快，也会自己找你的代理客户端在哪。
你机器上有的东西它不会动（点歌、B站搬运那些照常）。

## 装它（三步）

### 第 1 步：把技能放进去

把这里的 `skills/jm-comic/` **整个目录**复制到你 QQ Agent 项目的 `skills/` 下：

```
<你的项目>/skills/jm-comic/
```

放进去就生效（QQ Agent 默认开着热重载，不用重启）。

### 第 2 步：装它唯一的依赖

在你 QQ Agent 项目的根目录执行：

```bash
npm install sharp
```

> `sharp` 是图像处理库，**拼图和打包 PDF 都要靠它**。
> 不装的话技能会加载成功、但一调用就报"缺少 sharp 依赖"——不会让你一脸懵。

### 第 3 步：打开开关

打开 QQ Agent 控制台 → **「技能」页签** → 找到 **「JM 本子」** → 勾选启用。

然后在它的**设置**里填：

| 必填项 | 填什么 |
|---|---|
| **允许的群号** | 只有这些群里 @ 机器人才响应。**留空 = 群里完全不响应**，只在私聊能用 |

放心，默认就是**私聊能用、群里闭嘴**。想开哪个群再填哪个群。

| 设置 | 默认 | 说明 |

## 出问题了？

| 现象 | 先看这里 |
|---|---|
| 技能页里看不到「JM 本子」 | `skills/jm-comic/` 是不是**一级子目录**（加载器只扫一级、不递归）；里面有 `skill.json` 吗 |
| 有技能但工具不出现 | 开关勾了吗（默认关）；页签上会写不可用的**具体原因** |
| 一调用就报"缺少 sharp 依赖" | 在**项目根**执行 `npm install sharp`，然后重启 |
| 群里 @ 它没反应 | 群号填进「允许的群号」了吗？**留空是故意不响应的** |
| 连不上 / 一直失败 | 看它返回的报错，一般会直接说是不是代理的事；确认你的代理客户端在运行 |
| 图是错位的条纹 | 这本的段数没判准。把**车牌号**反馈一下，是能修的 |
| 下载很慢 | 线路速度波动很大，换个时间；或者确认代理是通的（走代理通常快好几倍） |

## 它是怎么工作的（好奇再看）

<details>
<summary>点开看技术细节</summary>

**网络层**：走禁漫的**移动端 JSON 接口**，不走网页端。
网页端挂了 Cloudflare 交互盾，非浏览器请求一律 403；移动端接口是另一套域名，直接返回 JSON。

**两个别人常写错的地方**：

1. 分流表的密钥是「**32 字符的 hex 字符串直接当 AES-256 key**」，
   不是"先转成 16 字节"。写成后者会解密失败。
2. 响应体的 `data` 字段是密文，密钥里的**时间戳必须是发请求那一刻的**，用当前时间解不开。

**段数（本技能最核心的难点）**：
被打乱的图要按"正确的段数"把顺序倒回去。常见实现都用同一个公开公式，
但实测这个公式**只对一部分本子成立**——有一本 16 页的真实段数是
`4,14,4,6,8,2,8,12,10,6,6,6,16,12`，而公式对每一页都给 10，结果整本都是条纹。

所以这里**不猜公式**：把候选段数各试一遍，用「缝隙得分」挑画面最连贯的那个。
判据经过真实数据标定（打乱的图得分 3.0~8.8，正常画面 1.04~1.10，零重叠），
判定开销约 3ms/张。

**PDF**：零依赖手写生成器，每页一条 DCTDecode 图像流。
**不做加密**——早期版本做过 RC4，后来移除了：加密会让"文件打不开"这件事变得没法归因
（到底是密码错了还是文件坏了，别人分不清）。现在任何阅读器都能直接打开。

**临时文件**：落在 `%TEMP%\qq-agent-jm-comic\<任务id>\`，**发送完立即整个目录删掉**。
正常情况那个目录是空的，你可以自己去看。

</details>
