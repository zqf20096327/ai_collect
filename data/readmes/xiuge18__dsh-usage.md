<h1 align="center">DSH记账</h1>

<p align="center">统计本机 <b>DeepSeek Harness（dsh）</b> 会话的 <b>token 用量</b>与<b>花费</b>：一共跑了多少量、折成多少钱、花在闲时还是高峰。</p>

<p align="center"><i>关键词：DeepSeek Harness · dsh · token 用量统计 · 会话花费 · 成本估算 · 用量监控 · 时段计费 · WinForms 桌面工具</i></p>

![主界面](screenshot-main.png)

## 这是什么

DeepSeek Harness 会在 `~/.dsh` 下保存每一轮对话的 token 用量和原始记录。这些数据一直都在，但没人告诉你一共跑了多少量、折成钱是多少。

DSH记账 就是把这些本地记录读出来做汇总：按会话、按子智能体、按时间段、按闲时/高峰分别统计，能做多选对比，也能导出 CSV。

界面是原生 WinForms 自绘，没有 Web 内核、没有 Electron，单个 exe 双击就跑，冷启动解析上百个会话大约 70ms，之后走增量缓存。

如果你正在找「DeepSeek token 用量统计」「dsh 会话花费怎么算」「Harness 用量监控」这类工具，大概就是它。

## 功能

- **总览**：总 token、本月花费、会话数、高峰占比
- **会话表**：主对话与子智能体分开算，可折叠子会话，点表头任意列排序
- **筛选**：标题搜索、今天 / 近 7 天 / 近 30 天 / 自定义时段、只看主对话或只看子体、只看低命中率
- **多选合计**：勾选任意几个会话，底部实时算出合计 token、费用、闲时/高峰拆分，并标注"合计里含几个当前列表上看不到的会话"
- **N 个会话对比**：选 2 个以上横向对比 token 构成、费用、命中率；2 个时给差值和倍数，3 个以上用极值句式
- **花费/用量双图**：按天堆叠柱，上半是花费（¥）、下半是 token 消耗，两张图横坐标对齐，一眼看出"量涨了钱没涨"
- **按小时统计**：看用量都堆在一天里的哪几个小时
- **逐轮明细**：某个会话每一轮花了多少，顶部有合计与平均每轮
- **导出**：整表 CSV，Excel 直接打开
- **首次启动有内置教程**，可勾选"以后不再自动弹出"，主界面右上角随时能重开

## 数据安全（重要）

- **只读**：只读 `~/.dsh/storages/session_projcache/sessions`（会话用量缓存）和 `~/.dsh/sessions`（原始记录，用于判断峰谷时段）
- **不改**：不写入、不删除、不移动 dsh 的任何文件
- **不联网**：不发任何网络请求，不开端口，不收集也不上传任何数据
- **自己的东西放在自己家**：配置、缓存、错误日志都在 `%APPDATA%\dsh-usage`，删掉这个目录就是彻底重置

## 它算得准吗

分时计价的做法是：按每一次请求**发生的时刻**判断落在闲时还是高峰，把未命中输入、命中输入、输出三类 token 分开累加，再乘各自单价。

所以这是**按官方价估算出来的数字**，和官方账单通常差几个百分点，不是精确扣费。默认单价取 DeepSeek 官方 `deepseek-flash` 的价格，在设置里可以改（闲时/高峰各三项）。

峰谷判断依据 2026 年公布的放假安排，内置了法定节假日与调休补班表，也可以自己在设置里补。

- Windows 10 / 11（64 位）

## 使用

1. 到 [Releases](../../releases) 下载最新版本的 `DSH-Jizhang-*.exe`
2. 双击运行，首次会弹出使用教程
3. 如果列表是空的，说明没自动找到 dsh 数据目录：点右上角【设置】，用右侧「…」选目录，或点「自动检测」

## 编译

需要 Windows 自带的 `csc.exe`（.NET Framework 4.x 工具链），不需要 Visual Studio：

```powershell
.\build.ps1
```

产物是 `DSH记账.exe`，图为内嵌资源，图标已打进 exe，分发给别人只需要这一个文件。

## 常见问题

**列表是空的**
本机还没有 dsh 的会话缓存。先用 dsh 聊过天、产生了会话，再点【刷新】；或者在【设置】里手动指目录。

**提示"未知发布者"**
个人开发的小工具没有代码签名证书，Windows SmartScreen 会提示。点"更多信息 → 仍要运行"即可。想验证安全性可以直接读 `dsh-usage.cs`，也可以自己编译。

**数字和官方账单对不上**
见上面"它算得准吗"，这是按单价估算的结果，不是账单复刻。

**换了 exe 但图标没变**
Windows 有图标缓存。改文件名或重启资源管理器可以刷新。

**会话标题太长被截断**
表格里按固定宽度截断显示；导出的 CSV 和对比窗里是完整标题。
