# Bank RAG Benchmark

一套面向中文银行知识库 RAG（Retrieval-Augmented Generation，检索增强生成）系统的评测基准，包含 100 份 PDF 文档和 450 条测试案例。

本基准用于验证知识库系统在基础事实、多跳检索、相似文档区分、版本更新识别，以及逻辑推理与边界判断等场景下的表现。

> 本仓库内容仅用于检索与问答系统测试，不构成真实银行业务制度、操作规范、合规意见或业务办理依据。请勿直接用于生产业务决策。

## 测试案例字段

| 字段 | 说明 |
| --- | --- |
| 案例编号 | 测试案例唯一标识 |
| 问题类型 | 该问题测试的能力或场景类型 |
| 测试问题 | 提交给待测 RAG 系统的问题 |
| 难度 | 简单、中等或困难 |
| 预期答案 | 用于人工核验回答正确性的参考答案与判定要点 |
| 应命中文档 | 预期应检索到的 PDF 文档编号或文件名 |

公开版工作簿仅提供测试内容，不包含内部评测结果、公式、统计汇总、填写列或答题记录。

## 使用方法

1. 将 `documents/` 中的 100 份 PDF 全量导入待测知识库，并保留原始文件名，便于追溯文档编号。
2. 用 Microsoft Excel、WPS Office 或其他兼容表格软件打开 `bank-rag-benchmark-test-cases.xlsx`。
3. 按“测试问题”逐条调用待测 RAG 系统，并在自己的评测流程中记录检索结果与最终回答。
4. 对照“应命中文档”检查系统是否检索到正确文档。
5. 对照“预期答案”检查回答是否覆盖关键结论、适用条件、排除条件和版本要求。
6. 根据需要计算文档召回率、答案正确率、响应时延等指标。

本仓库不限定模型、向量数据库、切片策略、向量模型、重排模型或评分工具。GitHub 网页不能可靠预览全部 `.xlsx` 内容，建议下载到本地后查看。

## 建议评测口径

- 文档命中：检索结果中出现“应命中文档”列指定的目标文档。
- 答案正确：回答与“预期答案”的核心结论一致，且未遗漏会改变结论的关键条件。
- 版本识别：涉及新旧版本时，应优先采用问题所述时点有效的文档。
- 边界判断：涉及排除项、例外项或适用范围时，不应只凭关键词作答。

为了使评测结果可复现、可比较，建议记录模型名称与版本、提示词、检索 Top K、切片策略、向量模型、重排模型和测试日期。

## 数据完整性

- 450 条测试案例的 6 个字段均已填写。
- 450 个案例编号均唯一。
- 测试集引用 A01-A100 共 100 个文档编号。
- 每个引用的文档编号均可在 `documents/` 中找到对应 PDF。
- `documents/` 中的每份 PDF 至少被一条测试案例引用。

## 使用限制与责任
