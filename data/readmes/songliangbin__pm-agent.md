## 这是什么

PM Agent 不是代码生成器，而是一位**有流程、有门禁、有记忆**的搭档。

一套严格流程、质量门禁、会自我纠错、越用越聪明的工程化智能体技能——不替你写代码，而是陪你想透、补全、对齐需求，交出能上评审会的交付物。

| 能力 | 说明 |
|:--|:--|
| 听懂需求 | 文档、聊天记录、口头想法，都能拆成结构 |
| 追问闭环 | 发现逻辑漏洞必须追问，不猜测、不含糊 |
| 共创推演 | 需求模糊时用框架引导，先聚焦再动手 |
| 专业交付 | PRD + 可交互原型，过门禁才算数 |

## 四条设计哲学

1. **机制优先于自觉** —— 能靠脚本和门禁拦住的，绝不靠口头叮嘱。蓝图、UI 走查、PRD 都由机器把关，缺一项直接打回。
2. **契约优先于生成** —— 多端项目先立「宪法」再动手：配色、术语、状态机一次锁死，各端不许各自发挥。
3. **经验沉淀到机制层** —— 每次踩的坑都变成规则和检查项。**197 条实战踩坑库**，下个项目不再重犯。
4. **交付物必须可演示** —— 零死按钮、零报错、零占位，还能离线打开。拿去就能给老板和客户演示。

## 它能产出什么

一次对话，四份交付——全部独立 HTML，断网也能演示。

| 交付物 | 说明 |
|:--|:--|
| 需求文档 · 详细版 | 决策层 → 方案层 → 实现层三层结构；内置全文搜索与智能助手问答 |
| 需求文档 · 简易版 | 面向开发：只保留功能逻辑、规则、状态机与数据结构 |
| 可交互原型 | 移动端手机模拟器 + 桌面端三种布局范式；可点击、可切换、业务闭环完整 |
| 自检报告 | 五层验证、120+ 检查项的通过明细与修复记录全部留痕 |

## 核心优势

### ① 它背后有一支专家团

- **产品经理蓝图**：动手前先产出蓝图（定位 / IA / 主流程 / 状态机 / 边界态 / 不做清单 / 易错预判），后续所有生成必须照着它来
- **14 个行业知识库**：电商、本地生活、医疗、金融、教育、出行……常规行业内置零等待
- **UI 设计系统**：真实 App 设计常识、设计令牌与行业 UI 特征
- **27 项 UI 走查**：生成后自动逐屏截图，按清单逐屏走查、出报告、修复复验

### ② 别人从零开始，你从 80 分开始

- 5 套范式模板（移动端底座 + 桌面端三范式 + PRD 双模板）
- 5 个行业组件库（电商 / 本地生活 / 医疗 / 金融 / 通用）
- 系统管理黄金模块（组织 / 角色 / 菜单 / 字典 / 日志整体复用）
- 质感 + 动效规范（复合阴影、毛玻璃、零 Emoji、等宽数字、标准缓动）
- **197 条踩坑库**（按端拆分精准加载：120 移动端 + 35 PRD + 42 桌面端）

### ③ 把 Token 花在刀刃上

| 指标 | 说明 |
|:--|:--|
| 53–77% | 踩坑库按端拆分，单端项目立省 Token |
| 105KB+ | 模板注入式生成，零进入上下文 |
| 120+ | 检查项由脚本确定性强制执行 |

## 八步工作流

```
①理解 → ②推演(+PM蓝图) → ③确认🔒 → ④决策🔒 → ⑤生成 → ⑥门禁 → ⑦自检(+UI走查) → ⑧交付
```

- ③④ 为**阻塞点**：必须你显式回复「确认 / 同意 / OK」才推进
- ⑤-⑦ 为**无人值守生成时段**（约 1–2 小时），可以放心走开
- 四种模式：**执行**（需求清晰）/ **共创**（四段引导）/ **修改**（快照 + 局部改）/ **多端编排**（契约先行、并行生成）

## 五层质量门禁

| 层级 | 名称 | 内容 |
|:--|:--|:--|
| 第 1 层 | 静态 Lint | 42 项：函数定义、结构平衡、模板残留、手机号脱敏——秒级拦截 |
| 第 1.5 层 | 产品逻辑评审 | 支付闭环、空态兜底、表单校验、返回按钮——像资深 PM 一样审逻辑 |
| 第 2 层 | 浏览器机械断言 | 真实打开页面：自动登录、逐页点击、表格验数据——死按钮无处藏 |
| 第 2.5 层 | 流程产物门禁 | 蓝图、UI 走查报告、无默认登录页、PRD 必交付——缺一件直接打回 |
| 第 3 层 | 页面自验证 | 打开即自检，断言结果人眼可见 |

## 快速开始

### 下载安装

**方式一：下载技能包（推荐）**

> [⬇️ 下载 pm-agent-5.41.zip（4.9MB）](https://github.com/songliangbin/pm-agent/releases/download/v5.41/pm-agent-5.41.zip) —— 解压后得到 `pm-agent-5.41` 文件夹

**方式二：下载最新源码**

> GitHub 仓库页 → 绿色 **Code** 按钮 → **Download ZIP**；或克隆仓库：
> ```bash
> git clone https://github.com/songliangbin/pm-agent.git
> ```

### 环境要求

- 任一支持 Agent Skills 的 AI 编程工具（见下表）
- Python 3.10+（首次运行会自动检测并安装 Playwright / Chromium）

### 安装

把整个文件夹复制到对应工具的 skills 目录即可，**无绑定、无激活**：

| 工具 | skills 目录 |
|:--|:--|
| 千问办公 QwenWork | `~\.qwenworkcn\skills` |
| WorkBuddy | `~\.workbuddy\skills` |
| Claude Code | `~\.claude\skills` |
| OpenAI Codex | `~\.codex\skills` |
| Cursor | `~\.cursor\skills` |
| VS Code · Copilot | `~\.copilot\skills` |
| Trae Solo CN | `~\.trae-cn\skills` |
| Trae 国际版 | `~\.trae\skills` |
| Gemini CLI | `~\.gemini\skills` |

> macOS / Linux 把 `~\` 换成 `~/` 即可；也可放入开放约定 `~/.agents/skills/`。

### 使用

1. 环境自检（可选，任务开始时也会自动执行）：
   ```bash
   python scripts/check-env.py
   ```
2. 在你的 AI 工具里直接描述需求，例如：
   > 帮我做一个茶叶商城的用户端 + 商家端，主色 #2E7D32，移动端=A / 桌面端=B / 文档=A
3. 按「确认 → 拍板风格 → 走开 → 回来验收」的节奏推进即可。

### 用得更好的七个习惯

1. 需求写具体：目标用户 / 核心场景 / P0 功能 / 明确不做的事
2. 主色早点定：有品牌色直接给十六进制
3. 三个字母定风格：移动端=A / 桌面端=B / 文档=A
4. 多端说「先出契约」：触发编排模式
5. 微调走修改模式：快照 + 局部改，绝不推倒重来
6. 点名行业：14 个行业知识库内置，点得越准产出越贴行
7. 交付后大胆反馈：死按钮、错位、颜色不对，逐条修

## 项目结构

```
pm-agent/
├── SKILL.md                    # 技能主手册（流程 / 铁律 / 变更索引）
├── history-pitfalls*.md        # 踩坑库（全量 + 按端拆分子集）
├── cross-platform-diff.md      # 跨平台差异说明
├── assets/vendor/              # 离线资源（图标 / 图表 / 字体，内嵌用）
├── components/                 # 组件说明
├── scripts/                    # 门禁与构建脚本（纯标准库 + Playwright）
│   ├── check-env.py            # 环境自检门禁
│   ├── build-prototype.py      # 确定性拼装构建
│   ├── agent-lint.py           # 静态 Lint（42 项）
│   ├── pm-review.py            # 产品逻辑评审
│   ├── browser-check.py        # 浏览器机械断言
│   ├── gate-check.py           # 流程产物门禁
│   ├── ui-snapshot.py          # UI 逐屏截图走查
│   ├── embed-offline.py        # 交付物离线内嵌
│   ├── split-pitfalls.py       # 踩坑库按端拆分
│   ├── deliverables-check.py   # 交付物完整性检查
│   ├── sync-templates.py       # 模板同步
│   └── verify-all.py           # 全量验证
├── standards/                  # 规范库（产品逻辑 / UI / 组件 / PRD 等）
└── templates/                  # 范式模板 + 注入说明
```

## 常见问题

<details>
<summary><b>能连真实数据库 / 接口吗？</b></summary>
不能。产出为高保真原型 + 需求文档，使用示例数据，用于评审与沟通。
</details>

<details>
<summary><b>只有模糊想法能用吗？</b></summary>
能。共创模式四段引导（用户 → 场景 → 价值 → 范围），收敛出方向与需求框架摘要。
</details>

<details>
<summary><b>环境配置麻烦吗？</b></summary>
不用你配。任务开始前环境自检，缺什么自动装什么，装好才开工。
</details>

<details>
<summary><b>没网会不会坏？</b></summary>
不会。交付物自动内嵌图标 / 图表 / 字体，离线照样演示。
</details>

<details>
<summary><b>改了一半想退回上一版？</b></summary>
说「回到上一版」，从 <code>_snapshots/</code> 恢复对应快照。
</details>
