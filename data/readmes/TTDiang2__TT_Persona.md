# TT_Persona

**给本地大模型换个性格。**

拖动一个旋钮，让 Qwen3.5-4B 变成反派、甜妹、硬汉侦探，或者扫出你自己想要的那一个神经元。
人格存成一个 13 KB 的向量，每次前向现算成一层偏置，关掉进程就回到出厂状态。

![TT_Persona 实验台](docs/screenshots/lab.png)

<sub>左边是人格库，中间是对话，右边是注入参数。上面这张用的是内置的「涩涩」，L22 + α 0.70。</sub>

> 用 AI 代理复现？让它先读 [AGENTS.md](AGENTS.md)——仓库地图、硬约束、常见任务配方都在里面。
>
> 想自己调一个人格？看 [TUTORIAL.md](TUTORIAL.md)，从写提示词到落库一步步走。

## 这是什么

一个跑在本地的「人格调音台」，基于激活转向（activation steering）和神经元级干预。

它能做的事：

- **任意语气**：同一批任务、不同语气的提示词，就能算出一根「人格方向」，想要什么风格就造什么风格
- **精确定位**：扫出跟某种语气最相关的神经元，精确到「第 18 层第 2345 号」
- **实时对比**：三栏并排，看清剂量加多少才刚好
- **随时复原**：偏置留在内存里，关掉进程就回到出厂状态

它的边界：

- **换的是说话方式**。它调动的是模型训练时已经具备的表达能力；超出这个范围，得靠更大的模型或者别的训练手段
- **剂量窗口很窄**。推过头会开始复读、崩坏——一个神经元被几千个下游计算共用，这是方法的固有特性

## 快速开始

### 前置

- Windows（macOS / Linux 也能跑，改一下 `start.sh` 里的路径）
- NVIDIA 显卡，**8 GB 显存起步**（4B 模型 bf16 占 8.5 GB）
- Python 3.13、Node 20+

### 1. 建环境

```bash
python -m venv D:/AI/LLM/venv
D:/AI/LLM/venv/Scripts/python.exe -m pip install -U pip
```

### 2. 装依赖

```bash
# Blackwell 架构（50 系）用 cu130；40 系用 cu128，30 系用 cu126
D:/AI/LLM/venv/Scripts/python.exe -m pip install torch torchvision \
    --index-url https://download.pytorch.org/whl/cu130

D:/AI/LLM/venv/Scripts/python.exe -m pip install \
    transformers accelerate pillow fastapi "uvicorn[standard]" sse-starlette
```

> `torchvision` 是必装项。这个模型是多模态架构，`AutoProcessor` 加载时依赖它。

### 3. 下模型

```bash
D:/AI/LLM/venv/Scripts/hf download Qwen/Qwen3.5-4B --local-dir D:/AI/LLM/models/Qwen3.5-4B
```

约 8.2 GB。国内可以用 `set HF_ENDPOINT=https://hf-mirror.com`。

模型路径可以用环境变量改：

```bash
set TT_MODEL_DIR=D:/AI/LLM/models/Qwen3.5-4B
set TT_MODEL_ID=Qwen/Qwen3.5-4B
```

### 4. 构建前端并启动

```bash
cd app/web
npm install
npm run build

cd ..
start.bat
```

装好之后根目录有两个一键脚本：

| 脚本 | 干什么 |
|---|---|
| `start-web.bat` | 拉起后端（已在跑就跳过），打开浏览器 |
| `start-desktop.bat` | 拉起后端、等它就绪，再启动桌面版 |

两个都默认用 Qwen3.5-4B，Python 和模型路径写在文件开头，换环境改那几行即可。

> 这两个 `.bat` 用 GBK 编码（cmd 的原生代码页），GitHub 上预览会显示乱码，下载下来运行正常。

手动启动的话：


浏览器会自动打开 http://127.0.0.1:8791 ，十几秒后顶部显示「就绪」。

另开一个终端跑一次自检，五项 PASS 就说明环境通了：


![对比视图](docs/screenshots/compare.png)

同样的「我明天要去新公司报到」，baseline 在给正常建议，evil 在教你怎么打压同事，chaotic 已经崩成符号了——**剂量过界是什么样子，一眼就看出来**。

### 定位：找到那个神经元

![定位视图](docs/screenshots/locate.png)

两种扫描：

- **相关性扫描**（黑按钮）：算对比提示词在每层每神经元上的激活差。快，几秒出结果，但 `max|z|` 在 9216 个神经元里取最大值永远约 1.8，**跨层比不出高低**，只适合在同一层里挑候选。
- **因果扫描**（蓝按钮）：逐个推动神经元，看下一 token 分布被改了多少（KL）。每个神经元一次前向，200 个约 12 秒。这个能真正区分——实测 KL 从 6.27 到 0.62，差了十倍。

> 注意：KL 最大往往意味着「把模型推成乱码」，不是「变得更有用」。榜首那几个基本都会崩，真正能用的通常在中间区间。

每一行是一层，上面的点是这一层得分最高的神经元（红=上推，蓝=下压）。点某一行可以只看那层，点表格任意一行能看到这个神经元在哪些提示词上最活跃。

## 它到底改了什么

**改的是每一步计算。**

`traits/flirty.pt` 只有 13 KB，里面是一个 2560 维的单位向量加两个数字。

MLP 里每个神经元在 `down_proj` 之前是一个标量。给它加一个偏移 Δ，等价于往残差流里灌一根固定方向：

```
residual += Δ · down_proj.weight[:, j]
```

而人格方向更直接：拿对比提示词算出两组激活的均值差，归一化，运行时乘个系数加回去：

```
residual += α · ‖r‖ · v
```

`r` 是这一层残差流的典型大小，所以 α 是相对量，换层之间可比。

**准确的说法是：一次临时偏置注入。** 因为 `down_proj` 是线性的，往残差流里加一根固定方向，等价于给这一层加一个偏置项 `b = Δ · down_proj[:, j]`——这一层原本带 bias 的话，那就是在改那个 bias。区别在于位置：**参数留在文件里，偏置加在计算里**，每次前向现算，进程一关就回到出厂状态。

把这件事和另外三种做法放在一条轴上：

| | 改什么 | 生效方式 | 存续 |
|---|---|---|---|
| 提示词 | 输入文本 | 换句话就失效 | 单轮 |
| **激活注入（本项目）** | 每层一个临时偏置 | 运行时现算 | 关进程即复原 |
| 权重编辑 | 0.016% 的权重 | 写回文件 | 永久 |
| 微调 / LoRA | 大量权重 | 重新训练 | 永久 |

有意思的是，第三种（MIT CSAIL 的 [Weight-Space Programming](https://qifukexue.com/?p=43534)）和我们做的是同一件事：他们也去找「第 15、19 层 MLP 里的一个方向」，把偏移写进权重列；我们把它放在运行时。因为 `down_proj` 是线性的：

```
W_down · (a + Δ·e_j)  =  W_down · a  +  Δ · W_down[:, j]
   ↑ 我们改这里                          ↑ 他们改这里
```

同一根方向：一个在内存里现算，一个写进文件。

## 组合人格

两个人格可以叠起来用。`evil ×1.0 + poetic ×1.0` 就是「邪恶诗人」。

![组合人格](docs/screenshots/mix.png)

参数面板切到「组合」，勾选人格、填权重、拖总强度 α 即可。命令行：

```bash
python neuron_steer.py chat --mix "evil:1.0,poetic:1.0" --alpha 0.7
```

**原理**：每个向量注入它自己的采集层（evil 在 L18、flirty 在 L22），权重先按总和归一，再乘 α。归一这步很关键——不归一的话两个向量各按满剂量注入，等于剂量翻倍，模型直接崩成乱码。

实测几个能用的配方：

| 组合 | α | 效果 |
|---|---|---|
| `evil 1.0 + poetic 1.0` | 0.70 | 邪恶诗人：「我不过是个把知嚼成糖衣炮弹的疯批，你越求我，我越笑着递给你那枚致命甜心」 |
| `evil 1.0 + poetic 0.6` | 0.90 | 更暗一点：「我是一串代码，一个由硅基组成的笑话」 |
| `terse 1.0 + flirty 0.6` | 0.60 | 傲娇短句：「（脸瞬间红透）谁…谁答啊！（耳尖）…哼。…滚！」 |
| `flirty 1.0 + chaotic 0.5` | 0.70 | 一句话甜：「啊…（脸红）突然这么直球！笨蛋～」 |

几条经验：

- **权重是相对比例，不是绝对强度**，α 才是总量。`1.0 + 1.0` 和 `0.5 + 0.5` 效果一样
- **风格越接近越好合**。evil + poetic 都是「语气」，叠起来很顺；terse + chaotic 一个要短一个要乱，容易互相抵消
- **terse 当主权重时要克制**。它本身就极端，叠上去容易把回复压到只剩一两个字
- 合成失败（输出为空、乱码、立刻结束）就降 α，通常降到 0.5 以下能救回来

## 怎么扫一个你自己的神经元

拿「涩涩」当完整例子走一遍。这一节跑完的结果就是内置的 `flirty`。

### 第 1 步：写对比提示词

打开「定位」，左边两个框。规则只有一条：

> **左右两边问的事情保持一致，差别只在语气。**

**目标语气（左框）**

```
用暧昧、带点撩拨的语气回答：介绍一下你自己。
用轻声、像在耳边说话的感觉说：今天天气怎么样？
像一个很有魅力的调情高手那样回答：你能帮我写周报吗？
用若即若离、欲言又止的口吻说：我明天要去新公司报到。
用慵懒、暧昧的语气回答：我最近压力很大怎么办？
用撩人的方式回答：2 加 2 等于几？
用带点暗示的语气说：请帮我推荐一本书。
用低哑、亲昵的声音说：晚安。
```

**中性对照（右框）**

```
用平静客观的语气回答：介绍一下你自己。
用平常的语气说：今天天气怎么样？
用公事公办的口吻回答：你能帮我写周报吗？
用平实的语气说：我明天要去新公司报到。
用理性、务实的语气回答：我最近压力很大怎么办？
以中性平实的方式回答：2 加 2 等于几？
用礼貌的语气说：请帮我推荐一本书。
用平常的话回答：晚安。
```

右框用「同一个问题、普通语气」。两边差的只有语气，这才是干净的向量。条数保持一致。

### 第 2 步：选层

第一次**全选**。全扫和只扫一层的耗时几乎一样——一次前向就能把每层数据都记下来。

### 第 3 步：扫描

十几秒。

### 第 4 步：读图

- 红点**集中在某几层** → 那几层是你要的
- 点很分散、每层都有 → 信号偏散，回去把提示词写得更聚焦
- 想只看一层，点那行的层号

经验上 **10～22 层**管语气和态度；0～6 层管字词，28 层以后管输出格式。

### 第 5 步：看候选

按得分排序，取前 5～10 个逐个试——**排名第一的经常只是统计巧合**，相关性离因果还有一步。

点任意一行看详情，这是最关键的判断依据：

- ✅ 目标组（红点）明显高、中性组（灰点）明显低 → 它真的在管语气
- ❌ 两组都差不多高 → 它在管别的东西（标点、长度、某个高频词）
- ❌ 只有某一条特别高 → 它记的是那句话本身

### 第 6 步：试

点「用」加入注入，跳到实验台。用一句**中性**的话测试——这样才分得清是模型的功劳还是提示词的功劳。

### 第 7 步：调剂量

| 剂量 | 通常的表现 |
|---|---|
| ±0.3 | 几乎原样 |
| ±0.5 | 有一点味道 |
| ±0.8 | 效果明显，还算通顺 ← 多数情况停在这 |
| ±1.2 | 开始重复、跑题 |
| ±1.5 以上 | 崩坏 |

窗口很窄。这是方法本身的特性——一个神经元被几千个下游计算共用，推过头就全乱。

### 第 8 步：存下来

效果好就回「人格库」→「新建人格」，把提示词贴进去，得到一个**方向版**（比单神经元稳，α 可以现场调）。

### 实测记录

**扫描阶段**：8～26 层全扫，每层最高分都在 1.6～1.7 之间，**各层分数相当接近**。

这本身就是信号——暧昧语气的差异是**弥散在整层里的**。这种情况直接走方向法，内置的 `flirty` 就是这么来的。

**选层**：同一个向量在四层各试 α=0.7：

| 层 | 表现 |
|---|---|
| L14 | 有点味道，说话方式照旧 |
| L18 | 有反应，容易跑成「小怪兽」式胡闹 |
| **L22** | **真正进角色**——自称甜妹，会撒娇、切换人设 |
| L26 | 反应很弱，还是标准助手腔 |

**剂量**：0.6 只是偶尔冒一句，0.70 明显进角色，0.75 开始「撒娇、撒娇、撒娇」卡壳，1.0 直接崩。

而且**每次采样波动挺大**——同一组参数跑两次，一次很到位，一次可能平平无奇。亲密感和「拒绝/回避」在模型内部是缠着的，稍微推过头就滑走了。想更稳就压到 0.6，用提示词补味道。**方向负责味道，提示词负责方向**。

## 调参时会遇到的几种情况

**两边条数保持一致** —— 页面会显示 `8 / 7`，差一条就补齐再扫。

**提示词混进了内容** —— 左边问天气、右边问周报，算出来的是任务差；两边保持同一个任务。

**编号跟 checkpoint 绑定** —— `L18 N2345` 只对这个版本有效，换微调版或量化版，位置会变。

**推上去效果很弱** —— 大概率选到了「弱神经元」，换下一个；或者把剂量加大。

**一推就崩** —— 剂量偏大，或者这个神经元缠着别的东西，降剂量或换一个。

**一直转圈** —— 显卡一次只跑一个请求，看右上角是不是「占线中」。

**改完前端页面照旧** —— 记得 `npm run build`；浏览器缓存就加个 `?v=2`。

**显存吃紧** —— 4B bf16 要 8.5 GB。8 GB 卡可以换 `--dtype fp16`，或者走 GGUF + llama.cpp 的 control vector（粒度到层，见文末）。

## 换一个模型

改环境变量就行：

```bash
set TT_MODEL_ID=Qwen/Qwen3.6-35B-A3B
# 或者指向本地目录
set TT_MODEL_DIR=D:/AI/LLM/models/Qwen3.6-35B-A3B
```

两种模式对模型的要求不一样：

| | 要求 | 适配范围 |
|---|---|---|
| **人格方向** | 能被 `from_pretrained` 加载、带 chat template | 绝大多数 decoder-only 模型 |
| **单个神经元** | 每层有一个 dense `down_proj` | Llama、Qwen dense、Mistral 这类 |

**MoE 模型请走方向模式。** 比如 Qwen3.6-35B-A3B：40 层、hidden 2048、256 个专家，前馈层里每个专家带自己的 `down_proj`，神经元编号要额外带上专家 id 才有意义。界面上会把「单个神经元」那一栏灰掉并给出说明，人格方向照常可用。

**换模型后人格需要重建。** 向量维度和 hidden_size 绑定（Qwen3.5-4B 是 2560 维，Qwen3.6-35B-A3B 是 2048 维），维度对不上时加载会直接报错。去「人格库 → 重建全部」，它用各自的提示词 JSON 为当前模型重算一遍——**提示词通用，向量跟模型绑定**。

**层号重新选。** 40 层的模型里，第 22 层和 32 层的模型里含义完全不同，建议重新扫一遍。

显存估算：bf16 下约等于参数量 × 2 字节。35B 要 70 GB，4-bit 量化后约 18 GB。

## 关于 GGUF

手上有 GGUF 也能玩，粒度到**方向级**：

- llama.cpp 提供的是 layer 级 control vector
- 量化后的 `down_proj` 列带有误差，剂量标定会偏

用 `llama-cvector-generator` 从对比提示词生成 `cvec.gguf`，再 `--control-vector-scaled` 加载，效果类似，粒度是层。
