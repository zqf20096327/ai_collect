## 为什么建议你做个人 IP

> 个人 IP，就是一份持续更新、公开可查的简历。—— 阿东玩AI

你是谁、做过什么、怎么思考，可以从你持续公开的作品里看到。论文、开源项目、真正跑过的 Agent 任务轨迹，以及做事过程中的判断，都值得留下来。对正在读本硕博、找工作、做产品或独立创业的人，这些记录能让别人更具体地了解你的能力，也更容易找到与你合作的理由。

我在 GitHub 上已经遇到过这样的事：猎头、投资人、合作方先看到项目和内容，再来联系。**我越来越觉得，账号和作品会承担越来越多原本属于简历的作用。** 把真正做过的事、想过的问题、跑通过的路径公开留下来，别人才能顺着这些记录认识你。

持续做这件事，要花不少时间在选题、整理素材、改稿、排版和平台适配上。阿东IP工作台把这些步骤接起来，让你把更多精力放在自己的判断和实践上。

**阿东IP工作台，把选题、写作、图文排版、口播视频和账号运营放进一个本地工作台。** 看到一条资讯，记成灵感；有了一个想法，直接生成稿子；再把同一篇内容做成长文、图文卡片、口播和各平台版本，接着排期、存草稿、看数据和复盘。

它运行在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）里。你可以在对话中让 Agent 搜资料、读素材、加图、改稿，看到实际工具过程，右侧同步展示内容；同一篇稿子持续共用会话。账号、文风和素材由你自己配置，稿件与设置保存在本机，模型使用你在 DSH 中配置的服务。

```
信息源 → 灵感 → 成稿 → 排版 → 平台版本 → 发布（到草稿） → 数据 → 对标        另有：视频工作区
```

**社区版 0.1.0** · [公开源码](https://github.com/adongwanai/adong-media-desk) · [下载安装包](https://github.com/adongwanai/adong-media-desk/releases/tag/v0.1.0) · [English introduction](README.en.md)

每个人安装在自己电脑上，首次使用没有账号、稿件、署名、密钥或开发者个人文风。下方保留作者账号的实际使用截图；成稿、长文、图文卡片、口播和视频页面已于 2026-11-22 更新，使用作者提供的《建议本硕博都去做个人 IP》笔记演示。截图中的账号和内容不随安装写入。尚未发布到 npm 或插件市场。

## 新增与重点增强

| 能力 | 现在可以怎么用 |
| --- | --- |
| **DSH 原生 Agent 创作** | 在同一个对话里生成、检索、加图和修改；查看思考与工具过程，右侧流式更新，回来继续聊。 |
| **选题雷达与每日早报** | 聚合 RSS、热榜和一手资讯，按关注方向筛选；从已有资讯提炼最多 5 个选题和切入角度，一键记为灵感。 |
| **自己的文风与资料** | 配置风格卡、写作规则、原声样本和代表作，按任务选择性读取；需要时再补目标读者、写作模式和核心判断。 |
| **一篇内容，六个工作视图** | 正文、长文、图文卡片、口播内容、视频录剪、平台版本并列切换；口播单独保存，可直接导入视频工作台。 |
| **局部改稿与版本回看** | 选中文字精简、去 AI 味或补充说明；对话修改同步到稿件，查看红绿修改对比和历史快照，随时恢复。 |
| **图文卡片与长文排版** | 30 套主题、封面独立页、紧凑连排、手动分页、重点高亮、图片拖拽与四边缩放；长文支持外链脚注，卡片导出 PNG / ZIP。 |
| **配图与 Obsidian 衔接** | 通过原生工具、已安装 Skills 或配置的生图服务处理配图，工作区图片自动同步到正文；可读取自己的言起署名、头像、页脚和主题配置。 |
| **从口播到视频** | 提词录制、摄像头或屏幕录制、导入素材、停顿粗剪、字幕与模板成片；MP4 导出使用本机 ffmpeg。 |
| **账号运营与内容复盘** | 大屏汇总粉丝、涨跌和收入，配合账号数据采集、对标与单篇诊断；内容可排期、适配平台并按支持范围送到草稿。 |
| **独立安装与加载优化** | 每位用户从空白数据开始，使用自己的工作区；信息源先读缓存、每日增量检查，英文词典按需加载，撤销记录压缩保存。 |

导航：大屏 · 信息源 · 灵感 · 内容 · 排期 · 发布 · 视频 · 复盘 · 对标，「写作风格」在右上角。界面有中文和英文。

第一次打开工作台会自动弹出「怎么用」：按手上要做的事分五条路（接了一篇推广笔记、看到一条热点想写、把旧稿搬进来、每天早上看什么、做一条口播视频），每步一句话，点「带我去」直接跳到那一页或打开那个框，下次回来接着上次的那一步。之后随时点右上角的 `?` 图标，或在命令面板里搜「怎么用」再打开。

## 它能做什么

### 大屏

![大屏](docs/preview/board.png)

- 顶部一行：各平台粉丝合计，以及今日、7 天、30 天的涨跌。某天没记就不出数字；涨跌只在两头都记过时显示；部分平台缺数时标明是几个平台的合计（比如「1/7 个平台」）。
- **粉丝合计怎么算**：把每个平台最新记下的粉丝数加起来，**GitHub 的 Star 总数算在里面**，**谷歌学术的被引次数不算**（它不是粉丝，卡片照常显示，但不进合计，也不进每日净增）。只有约数的平台（比如后台只给了「1.13万」）按约数加。合计的平台范围是所有记过数的平台，和下面卡片选了显示哪些无关。
- 近 30 天每日净增（可以切成表格看逐日数字）、最新发布（自动排版的封面，最近几篇轮播）、几句按规则算出的分析。不调模型。
- **收入**：右侧一个小方块，显示今天、本月、累计到手多少，和最近几笔。点「记一笔」填金额、到账日期、来源（商单、平台分成、付费咨询、课程与社群、打赏、其他）、是哪篇内容带来的（可不关联）和备注；记错了可以删（能撤销）。数字只是你自己记的加总，不接任何收款平台，不估算；一笔都没记时只显示「记一笔收入」的提示，不显示 ¥0。
- 下面一排平台卡片，可以自选显示哪些平台、什么顺序。每张卡片：主数字（粉丝；GitHub 是 Star，谷歌学术是被引）、今日 / 7 天涨跌、数据从哪来和读于何时（「后台读于」「自动读于」「上次记录」）、最多 4 项账号数据（获赞、作品、播放、净涨粉、曝光、主页访客等，标出是近 7 日还是某一天的数，其余的放在悬停提示里）、近 30 天粉丝走势、读到时的最新一条内容。读不到、要重新登录、粉丝数待确认时，卡片底部写明原因，并给「去登录」或「手动记录」。
- 顶部的状态条可以展开看最近一轮自动读取每个平台读到了什么、没读到的原因；「更新数据」菜单里有立即读取、手动记录粉丝、手动补数据。
- 11 个平台的创作后台入口：公众号、小红书、抖音、B 站、视频号、知乎、头条、TikTok、Instagram、YouTube、X。在 DSH 右侧的内置浏览器里打开；宿主没有这个能力时（比如独立运行）打开系统浏览器。
- 导航上挂着每一站的数量，点进去就是对应页面。

### 信息源

![信息源](docs/preview/sources.png)

- **订阅**：任意公开的 RSS / Atom 地址。每个源取最新 20 条，合计最多 120 条，按时间倒序。点「记为灵感」进灵感库。
- **一键源包**：14 个公开订阅地址，分四组（英文 AI 官方、英文技术社区、中文 AI 与开发、中文科技与产品）。第一次使用时预置其中 7 个：OpenAI News、GitHub Blog、Simon Willison、量子位、InfoQ 中文、少数派、阮一峰的网络日志。都可以删。
- **内置源**（4 组，读公开 JSON，第一次使用时全部打开，可以关）：
  - 一手 · X 建设者、一手 · 建设者播客：读 [follow-builders](https://github.com/zarazhangrui/follow-builders) 放在 GitHub 上的公开 feed
  - 论文 · HF Daily Papers：Hugging Face 每日论文，按点赞排
  - 中文 AI 资讯：经 ainav.cn 每日汇总，覆盖 36氪、量子位、机器之心、智源社区、HelloGitHub、新智元、AIbase、IT之家、极客公园
- **热榜**（10 个，免登录，每个最多 30 条）：GitHub Trending、Hacker News、微博热搜、B 站热门、百度热搜、知乎热榜、头条热榜、掘金热榜、少数派热门、抖音热搜。每个榜单独成败，读不到时显示原因，失败时显示带原读取时间的缓存，不把旧数据标成刚更新。
- **今日选题早报**：点击「生成今日 5 个选题」，结合已缓存的订阅与热榜、关注方向和当前文风，提炼最多 5 个建议标题与切入角度；每条保留原来源链接，可直接记为灵感。模型不可用时显示规则筛选结果，缓存为空时提示先抓取资讯。
- **我的方向**：最多 12 个方向词和 30 个「不想看」的词。设了方向后，订阅和热榜按相关度 65%、新鲜度 25%、热度 10% 排序（也可以切回原始顺序），命中了哪个方向会标出来。同一件事出现在多个热榜上时标为「多榜同现」。

打开工作台后后台预取信息源，进入页面先显示缓存；按北京时间每天自动检查一次，同一天切页不重复抓取。新增订阅只抓新来源，失败保留旧内容和原读取时间，也可以手动刷新。

### 灵感

![灵感](docs/preview/ideas.png)

- **随手记**：在 DSH 里任何地方按 `⌘⇧I`（Windows / Linux 为 `Ctrl+Shift+I`）弹出小窗。写一句回车就记下；`#标签` 会变成标签；只贴一个网址就按链接收藏；可以直接粘贴图片；`⌘回车` 记下后接着记下一条。
- **灵感库**：按标题、正文、标签、来源搜索，按常用标签筛选。
- **选题评分卡**：热度 30%、相关度 40%、切入价值 30%。热度按记下时的榜单名次换算；相关度对照「我的方向」；切入价值由你打 1–10 分，也可以让模型给一个建议分。哪项不知道就不计入，权重重新分配。7 天内写过相近内容扣 3 分，7–30 天内扣 1 分。
- **今日回顾**：从你自己记下、7 天以上没动过的灵感里，每天挑 3 条拿出来看。同一天固定，换一天换一批；够格的不到 3 条就不显示。可以设成先不提醒。
- **导入 Markdown 文件夹**：读 Obsidian 风格、带 YAML 头的稿子。只读不写；文件夹必须在用户主目录下；最多 500 个文件，单个不超过 1 MB；正文不到 200 字、Excalidraw 画板会跳过；文件里没写的日期和数据不补。稿子里引用的本地图片可以显示。

### 成稿

记下选题后直接点 **生成小红书图文**，无需先填写目标、观点或结构。由 DSH 原生 Agent 按任务读取独立工作区的 `CLAUDE.md`、你保存的风格和相关文档 / Skills，直接生成自然段正文，流式显示，完成后自动打开图文卡片。卡片在本地排版，不依赖生图模型。只有实际收到模型文字才显示；模型失败会显示错误，可重试，不把空模板当完成稿。

内容工作区有 **正文 / 长文 / 图文卡片 / 口播内容 / 视频录剪 / 平台版本** 六个并列视图。口播内容可以从正文改写，也可以直接粘贴。点 **导入视频工作台** 后保存稿子并打开对应内容；原正文不会被替换。生成前的输出选项也可改成文章或口播稿。


![新版成稿：六个内容视图与章节大纲](docs/preview/studio-current.jpg)

新版创作截图来自社区版独立预览，正文和口播为手工整理的演示稿；截图中的「未连接」表示此预览没有接入 DSH，AI 对话需按下方安装步骤在 DSH 内使用。

- **原生 Agent 成稿**：生成、检索、配图和对话修改使用 DSH 原生会话。左侧显示文字流、思考和工具运行过程，右侧同步稿件；同一篇内容沿用会话上下文。
- **写作定调（可选）**：需要更明确的方向时，再补目标读者、核心判断和写作模式；一句选题仍可直接开始。
- **局部改稿与历史**：选中片段后可精简、解释清楚、去 AI 味或输入自己的改写要求；对话中的局部修改支持原生文件编辑和补丁同步。成稿保留版本快照，方便查看和恢复。
- 标题、封面、配图和分镜能力保留；是否生成图片由本次任务和模型 / 图片服务配置决定。可连图带稿保存成文件夹，默认在 `~/Documents/自媒体工作台/`。
- **风格卡**：内置 8 个板块共 16 张通用预设，社区版默认「清晰实用」，不含开发者个人文风。可以贴自己的稿子或链接提炼一张，风格卡可以导出、导入，规则可以逐条改。
- **作者信息**：文末署名和一句话介绍由每个用户自己填，不写在内置风格里。没填就不署名。
- **标题台**：模型出 10 个候选，每个注明用的方法（具体结果、反直觉判断、提问、数字清单、对比、第一人称经历、场景、直接给结论）。工作台在本地查长度、绝对化用词和数字有没有出处，并推荐三个方法不同的。
- **素材（一份灵感可以挂多份）**：记灵感时一次选多份 .md / .txt，或贴多个路径；一次最多 10 份，一条灵感累计最多 30 份、20 万字。成稿面板里能看每份的名字和字数、能删（可撤销）。超过 2 万字的素材只把开头放进状态文件，全文存在数据目录的 `files/` 里。事实只能来自灵感和这些素材，模型不会因为素材里有示例就编经历。
- **写作工作流**（可选）：默认只索引独立工作区的 `CLAUDE.md`、`style.md`、`voice/`、`examples/` 和 `methods/`；设置里可以填写自己的文件 / 文件夹并勾选。不会自动扫描桌面和私人内容目录。DSH 根据当前任务选择性读取，未变化的参考在同一会话中复用；方法里的例句不能变成作者的真实经历。
- **继续对话修改**：直接在现有对话栏说要求，沿用这篇稿子的 DSH 会话；正文和口播分开保存。运行过程可展开查看实际读过的文档和工具调用。Skills 使用 DSH 原生发现机制，第三方技能需使用者自行安装；项目不附带私人 Skills 或第三方付费资料。
- **素材库**（可选）：在设置里指一个本地 Markdown 文件夹，写平台版本前挑几篇相关的当参考。文件名含「说明书、规则、README、CLAUDE、AGENTS」的默认不当素材，可以改。

### 排版

![长文排版：重点高亮与外链脚注工具](docs/preview/layout-current.jpg)

![图文卡片：紧凑连排与排版检查](docs/preview/cards-current.jpg)

长文（公众号）和图文卡片共用一套编辑、主题与预览工具。

- 30 套主题、12 套卡片骨架、14 种字体。
- 封面 16 种：言起的 5 种，加 11 套新增的固定版式（大字报+、左右对比、上下对比、清单数字、问句、教程步骤、金句引用、数据冲击、截图框、刊头大图、便签）。带封面检查清单。
- 左边写、右边看：光标移到哪一节，预览翻到哪一页；点预览上的块，光标跳回原文那一行。有打字机模式、行号、锁定预览。窄窗口下变成「原文 / 预览」两个标签。
- 图片可以拖动、从四边或四角缩放，并按图记住调整；表格可以缩放；主题编辑器可以改出「我的主题」。
- 卡片可以选择封面只放标题或紧凑连排，保留手动分页；支持重点加粗、高亮和长文外链脚注。头像、昵称和页脚初始为空，可自行填写，也可从自己指定的 Obsidian 素材库同步言起 `note-to-red` 配置。
- 卡片比例 3:4、1:1、4:3、9:16，每种按短边 1080 / 1242 / 1350 三档导出 PNG（3:4 对应 1080×1440、1242×1660、1350×1800）。可以复制单页为图片，或「导出全部 ZIP」。预览里可以叠一层安全区虚线框。
- 长文里的本地图片可以先传图床：公众号素材库（地址只能在公众号文章里用）、自定义图床（HTTP POST），或者不上传（复制时提示哪些图会丢）。

小红书的尺寸和安全区数字来自第三方指南，小红书没有公开的官方规格页。

### 平台版本

![平台版本](docs/preview/versions.png)

- 母稿就是公众号版。其余平台各写一版，标题、正文、标签按各自规则：小红书、抖音、B 站、视频号、知乎、头条、X、YouTube、TikTok、Instagram。
- 每个平台走同一套流程：How I 判断（从文字里的说法判断你是亲手做过、只研究过，还是都看不出来，决定能用哪种口吻；依据会摆出来让你确认）→ 翻旧稿和素材库 → 按风格卡里的平台规则写 → 不调模型的自检 → 有没过的项才定向改一次。改完还没过的项照实留着给你看。
- **小红书分两份**：短总结（默认 200–300 字，放在卡片外）和长图文（合计 800–1100 字，按语义分节、按版面自动分页），图片版直接进卡片排版。这些数在风格卡里可以改。
- **X** 写成一条，或 3–7 条的串，每条按 X 的算法计数（中文算 2）不超过 280。
- **自检项**包括：标题长度、正文长度、标签个数、禁用词、机器腔句式、「你应该 / 建议你」的次数、加粗和高亮处数、emoji 个数、署名、没做过的事写成做过、母稿里没有的数字、和母稿太像。小红书另查页数、每页字数、合计字数、页标题长度、占位图、正文和图片版是否重复；X 另查每条长度、条数、是否以问题收尾。
- 公众号可以「按公众号规范整理」：不改观点和事实，只整理结构、开头、结尾、加粗和高亮。
- **配图建议**：模型为小红书图片版每页、公众号每节提议要不要配图、画什么，你勾选之后才生成。

### 发布

![发布](docs/preview/publish.png)

- 每个平台一个「去发布」：复制这个平台的版本（没有就复制母稿），打开平台的发布页，记一笔「已复制去发布」。发完可以贴上发布链接，标为已发布。状态分四种：未处理、已复制去发布、已推草稿、已发布。
- **发布前检查**（不调模型）：电话、微信号或 QQ 号、邮箱、外链（按平台分拦截和提醒）、引导私下联系、绝对化用词、医疗和收益承诺、没替换的占位符、Obsidian 写法、第一人称经历、标题和正文长度、标签个数，以及从「说人话」「Humanizer-zh」移植的 AI 腔规则。有拦截项时会再确认一次。
- **公众号草稿**：用官方接口推进草稿箱，正文带你选的排版主题（HTML 先按白名单清洗）。
- **公众号发布**：只在你每次在确认框里点了确认、且确认的正是当前那份草稿时才提交；不自动发布，不定时发布。公众号的发布接口只对认证号开放，未认证的号会收到 48001。
- **填到草稿（目前只做了小红书图文）**：点「填到草稿」，工作台用读创作后台的那个专用浏览器打开小红书的发布页，切到「上传图文」，把这篇小红书版本的图片版按当前排版导出成 PNG 一张张传上去，填标题、正文，一个个打上话题，再点页面上的「暂存离开」存进草稿箱就停下，标签页留在前台给你检查，这一平台记为「已推草稿」。页面上找不到暂存按钮时只填好，不点别的。每一步都过一道黑白名单：只点「上传图文」「我知道了」「暂存离开」这三个按钮，发布、定时、群发一类的按钮一律不点；跳去白名单以外的地址、遇到登录过期或验证码就立刻停，并说清停在哪一步。同一篇同一平台 60 秒内不会重复填，传过的临时图片用完就删。**其他平台没有做**：公众号走官方接口推草稿，知乎和 B 站专栏走 Wechatsync，其余平台仍然只有「去发布」复制后自己粘。验证情况见[已知限制](#已知限制与未验证)。
- **多平台同步到草稿**：通过你自己装的 [Wechatsync](https://github.com/wechatsync/Wechatsync) 浏览器扩展，只开放**知乎**和 **B 站专栏**。这两个平台的扩展适配器读过源码，确认只建草稿；头条、小红书、抖音、X 的适配器不公开源码，没法确认，所以没开。
- **排期**：做好的稿子拖到日历上的某一天，右侧列表可以搜索、按平台筛选。

### 数据

![复盘](docs/preview/insights.png)

数据有两种自动采集方式，读不到的平台再手动补：

| 方式 | 怎么用 | 能拿到什么 |
| --- | --- | --- |
| **主页链接** | 大屏里填各平台主页地址 | 只读公开接口：GitHub（Star、仓库、最新仓库）、B 站（粉丝、获赞、投稿）、X（经第三方 FxTwitter：粉丝、帖子数、最新一条）、谷歌学术（被引、h 指数、最新论文）、YouTube（最新一条视频，订阅数只有约数不记） |
| **登录后的创作后台** | 设置里打开「登录后的创作后台」，点「打开专用浏览器去登录」，在那个浏览器里自己登录一次 | 小红书、抖音、公众号、视频号、B 站后台首页上的粉丝、获赞、作品数和近 7 日 / 昨日的曝光、播放、点赞、评论、收藏、分享、净涨粉、主页访客；作品列表页上每条作品的播放 / 阅读和互动（视频号的作品列表在内嵌框架里，读不到） |
| **手动补数据** | 复盘页「手动补数据」：录入数据、粘贴数据表 | X、YouTube、知乎等后台读不到的平台 |

- **创作后台怎么读**：工作台用一个专用浏览器（资料目录在数据目录下的 `browser-profile`；电脑上要有 Chrome、Edge 或 Chromium）在新标签页里打开白名单里的后台地址（首页和作品列表页，每轮每个平台最多两页），只取页面上的文字，读完关掉自己开的标签页；不点击、不输入、不提交，不读写 cookie。页面文字交给 DSH 里配好的文字模型，只让它抄出每个数的原文；代码再核对每段原文确实在页面上（作品列表还要在那一条作品的那一段里，没有文字标注的数按实测的列顺序核对），然后自己换算「1.13万」「1,278」「14%」。只有约数的（「1.13万」）标成约数，大屏上写「约 1.13 万」。粉丝数和上一次记录相差超过一半时不覆盖，标成「待确认」。跳去了登录页就写「需要重新登录」，给「去登录」按钮。
- **多久读一次**：登录后的创作后台每天两轮，默认 06:30 和 18:30；第一个时间点跑一整轮（公开接口 + 创作后台），第二个时间点只读创作后台。两个时间都能在设置里改，第二个可以留空关掉。DSH 到点时没开着，之后打开会补跑一次；打开大屏不会触发创作后台的读取。主页链接的公开数据同样是每天 06:30 一轮，另外打开大屏时如果超过 6 小时没更新，会在后台补读一次。手动「立即读取」两次至少隔 10 分钟，同一平台和上一轮离得太近时这一轮会跳过并说明。某个平台这一轮没读到，结束 20 分钟后只重读没读到的那几个，还不行再过 40 分钟读第二次，之后当天不再自动重读；要重新登录的、粉丝数待确认的不重读，等你处理。同一天后台读到的数不会被主页链接读到的覆盖。
- **它只读，不替你操作**：创作后台这条路上工作台只打开页面读文字，不点任何按钮、不填任何输入框、不发布；唯一会主动点按钮和打字的是发布页的「填到草稿」，那里也只点「上传图文」「我知道了」「暂存离开」三个按钮。
- **数据只留在本机**：读到的数写进本机的 `state.json`；页面文字只发给你在 DSH 里配的那个模型，用来认数。后台跳去登录页或页面是空的时，会把那一页截一张图存进数据目录的 `files/`（每个平台最多留最近 3 张），方便看卡在了哪。
- **风险**：用的是你自己的登录状态。读得越频繁，越可能触发平台风控；平台改版后可能认不出数，界面会写明原因。

- **贴后台表格**：从平台后台复制或导出的表格，按表头自动认列（日期、标题、播放 / 阅读、曝光、赞、评论、转发、收藏、完播、新增关注、制作分钟）。认不出的行列进「没导入」并说明原因。重复导入是更新，不会翻倍。
- **没记的数不当 0**：比率只在分子分母都有时才算，否则显示「—」。
- **单篇诊断**：只和你自己在同一平台的作品比，不拿行业数字。沿漏斗（曝光 → 点击率 → 完播率 → 深度互动 → 涨粉）只报最前端的那个明显偏低的环节。某一项有数的作品不到 10 篇时，这一项不下结论，并注明样本量。
- **内容复盘**：查看趋势、平台分布、表现最好的内容；从数据里提炼的建议可以写进写作规则，规则可以导出成 DSH 的 Skill。

### 对标

![对标](docs/preview/rivals.png)

- 添加对标博主的主页，按天记录粉丝数。和自己账号的主页链接用同一套公开接口：B 站（昵称、粉丝数、投稿数）、X（经第三方 FxTwitter）、GitHub（Star）、谷歌学术（被引）能自动读；YouTube 只公开约数，不记订阅数；其他平台不登录读不到粉丝数，会直接说明。
- 粘贴对标博主的作品数据，按他自己平时的表现分级：拿这条的互动值除以他最近其他作品（5–20 条）互动值的中位数，2 倍以上为「潜力」，4 倍以上「爆款」，8 倍以上「现象级」。倍数够了但互动值不到 20 的标「虚高」，防止小账号几个赞的波动被当成爆款。可比的其他作品不到 5 条时标「样本不足」。
- 互动值权重：赞 1、评论 3、收藏 3、转发 5（小红书收藏记 4；B 站转发记 4）。表里缺的项只用有的项算，并标为「部分数据」。

### 视频

![口播内容：目标时长、逐句气口与视频入口](docs/preview/spoken-current.jpg)

![视频工作台：导入后的口播稿与逐句时长](docs/preview/video-current.jpg)

按六步走：稿子 → 录制 → 粗剪 → 字幕 → 成片 → 发布包。

- **口播稿**：可以改；按语速估算逐句时长和总时长，可设目标时长；给三个备选开头；核对分镜秒数。
- **提词与录制**：摄像头口播时提词浮在画面上，只录摄像头那一路，提词不进视频；录屏时提词放在单独的小窗里。手机拍好的、系统录屏录好的视频也可以直接上传，一样记成这篇的录像。
- **粗剪**：在浏览器里按音量找停顿（停顿参数移植自 auto-editor），可以跳着预览；跟着提词录的录像还能「按文稿剪」，删掉哪句就剪掉哪段。时间线可以缩放（`⌘` / `Ctrl` + 滚轮、触控板捏合）。
- **导出粗剪**需要本机装 ffmpeg：「精确导出」重新编码成 MP4（H.264 + AAC）；「无损导出」不重新编码，还需要 ffprobe。没装 ffmpeg 时可以下载一份剪辑清单自己剪。
- **字幕**：按语速从字数估算时间，不和真实音频对齐。可以下载 SRT。
- **成片**：6 个模板（口播精剪、知识讲解、图文解说、录屏教程、金句短片、对比评测），套在一条录像或这篇的图文上，在浏览器里实时渲染成 webm。转成 MP4 需要 ffmpeg；没有的话可以用剪映等工具导入 webm 再导出。
- **没有内置配音**：浏览器自带的朗读录不进视频，旁白要用你自己的声音；不选旁白就是一条只有画面和字幕的无声视频。
- **发布包**：标题、口播稿、封面（1920×1080）、视频、SRT 字幕放在一处。

## 数据从哪来，哪些要你自己配

插件不带任何密钥。下面这些按需配置，没配的那一项就用不了，别的照常。

| 功能 | 需要 | 没有时 |
| --- | --- | --- |
| 成稿、去 AI 味、平台版本、标题台、配图建议、切入价值建议分、助手 | DSH 里配好的文字模型 | 提示未连接 DSH 原生 Agent，不把本地模板当成模型成稿 |
| 封面、配图、分镜图 | 图片 API（OpenAI 兼容接口、阿里云百炼、万相），或 DSH 已注册的订阅生图工具（`dsh-plugin-subscriptions` 的 `image_generate`），在插件设置里选 | 文字照常；视频封面用封面大字合成一张纯文字版 |
| 公众号草稿、确认发布、公众号素材库图床 | 公众号的 AppID 和 AppSecret（在插件设置里填），并把本机出口 IP 加进公众号后台「设置与开发 → 基本配置 → IP 白名单」；发布另需认证号 | 只能复制正文到公众号后台手动粘贴 |
| 登录后的创作后台自动采集 | DSH 里配好的文字模型（用来从页面文字里认数）；本机装有 Chrome、Edge 或 Chromium；在设置里打开「登录后的创作后台」，并在专用浏览器里自己登录各平台 | 只能用主页链接读公开数据，其余手动记或贴表格 |
| 小红书「填到草稿」 | 同一个专用浏览器里登录小红书创作平台；这篇已经生成小红书版本（标题、正文、图片版） | 用「去发布」复制后手动粘贴 |
| 知乎、B 站专栏同步到草稿 | Wechatsync 浏览器扩展，在扩展设置里打开「MCP 连接」，把它的 Token 填进插件设置 | 用「去发布」复制后手动粘贴 |
| 长文本地图片上传 | 公众号凭证，或自己的图床（上传地址、字段名、令牌） | 复制时提示哪些图会丢 |
| 视频粗剪导出、转 MP4 | 本机 ffmpeg（无损导出另需 ffprobe） | 可以预览粗剪、下载剪辑清单；成片只有 webm |
| 海外信息源、HF 每日论文、X 主页数据 | 能访问这些站点的网络，国内一般要代理，见[网络与代理](#网络与代理) | 对应来源显示连不上的原因 |

所有密钥（生图 Key、AppSecret、Wechatsync Token、图床令牌）只存在本机的 `settings.json`，不发给浏览器，也不发给文字模型。

## 它不做什么

- 不做无人值守的自动发帖或群发。发布停在草稿一级，唯一的例外是公众号：你每次在确认框里点了确认，才提交那一篇。
- 不自动回复评论或私信。
- 不估算数据，不放示例数据，收入也只加总你自己记的。没记的数就是不知道，界面显示「—」。社区版首次启动使用空白数据；文档截图保留作者个人版的实际使用效果。
- 不替你登录平台。创作后台要你自己在专用浏览器里登录一次；自动采集只读你自己账号后台页面上的文字，不点击、不发布、不读写 cookie。读不到的平台直接说明原因，请你手动记或贴表格。
- 不替你点发布。小红书的「填到草稿」每次都要你自己点开始，停在「暂存离开」存草稿这一步；发不发、什么时候发由你在专用浏览器里自己决定。
- 不替你编经历。成稿提示词要求事实只来自素材，How I 判断和「没做过的事写成做过」自检会把可疑的第一人称说法标出来；最后仍需要你自己过一遍。

## 网络与代理

- 对外请求优先走环境变量里的代理（`MEDIA_DESK_PROXY`、`HTTPS_PROXY`、`HTTP_PROXY`，只认 `http://主机:端口` 写法）；没有时在 macOS 上读系统网络设置里的 HTTPS 代理；都没有就直连。从程序坞启动的 DSH 桌面版拿不到终端里的环境变量，靠的是系统代理。
- 本机、内网和保留网段一律拦截，粘贴的链接访问不到这些地址。走代理时，工作台也会先在本机解析一次域名，指向内网的同样拦下。
- **Clash 的 TUN + fake-ip 模式**会把域名解析到 `198.18.0.0/15`，工作台把这个网段当成内网拒绝，表现为请求失败、报 `blocked private address`。只设代理解决不了，因为工作台仍会在本机解析域名。解决办法：关掉 TUN，或把 Clash 的 DNS 换成非 fake-ip 的模式；需要代理时打开 Clash 的「系统代理」，或者在启动 DSH 的终端里设 `HTTPS_PROXY=http://127.0.0.1:<端口>`。
- 公众号的接口一律直连，不走代理。IP 白名单只认一个出口，所以要加进白名单的是本机直连的出口 IP。公众号返回 40164 时，报错里会带上被拦的 IP。
- 几处需要说明的请求：
  - 抖音热搜每次是两次请求：先打开抖音登录页拿访客 cookie，再读热搜。
  - X 主页的数据经第三方服务 FxTwitter（`api.fxtwitter.com`）读取，用户名会发给它。
  - 创作后台经本机的专用浏览器读取，调试接口只连 127.0.0.1。
  - X 建设者和建设者播客读的是 GitHub 上 follow-builders 的 feed；中文 AI 资讯读的是 ainav.cn 的每日汇总。

## 安装

### 版本要求

- Node.js 24 及以上、npm。
- 已安装官方 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)，`dsh --version` 可用。社区版当前在 macOS、DSH 0.2.2-rc.1 上检查；其他平台尚待验收。

### 从源码装进独立 DSH

本版包名为 `dsh-ip-workbench`，还没有发布到 npm 或插件市场。npm 上的 `dsh-media-desk` 不安装本版。克隆仓库（或从 [Releases](https://github.com/adongwanai/adong-media-desk/releases) 下载压缩包）后，在项目目录运行：

```bash
git clone https://github.com/adongwanai/adong-media-desk.git
cd adong-media-desk
npm ci
npm run dsh
```

脚本构建后安装到独立的 `~/.dsh-ip-workbench`，打开本机网页（默认 4372 端口）。登录你自己的 DSH 模型账号，在侧栏进入「阿东IP工作台」。端口被占用可用 `npm run dsh -- 4382`。

终端没有 `dsh` 时，先使用 DSH 提供的 CLI 安装方式，或设置 `DSH_BIN` 为其可执行文件路径。首次安装可能需要联网获取宿主依赖。`IP_WORKBENCH_HOME` 可指定另一个独立数据目录。

高级用法：构建后可用 `dsh plugin --profile <名称> add "file:$PWD"` 安装到自行选择的 profile。此时使用该宿主的数据目录。本版与 `dsh-media-desk` 共用面板 ID 与 `/media-desk` 接口，请不要在同一个 profile 同时启用两者；推荐使用上面的独立启动方式。

### 不装 DSH，独立运行

```bash
npm ci
npm start
```

打开 http://127.0.0.1:4372/ 。端口被占用用 `npm start -- 4382`。只监听本机，默认同样使用社区版独立数据目录。

独立运行仅供内容管理和排版体验，没有 DSH 模型、工具或原生对话；需要真实生成时结束预览进程，运行 `npm run dsh`。

### 数据存在哪

独立启动的数据默认在 `~/.dsh-ip-workbench/ip-workbench/`；手动安装到其他 profile 时为 `$DSH_HOME/ip-workbench/`，不会读取个人版的 `media-desk/`：

| 文件 | 内容 |
| --- | --- |
| `state.json` | 灵感、稿子、平台版本、数据、风格卡、订阅等内容 |
| `settings.json` | 设置和密钥，文件权限 600；不随源码分发 |
| `files/` | 生成和导入的图片、录像 |
| `browser-profile/` | 使用者自己的平台登录状态 |
| `workspace/` | 通用规则模板、自己的文风补充和方法文档 |
| `image-host-cache.json` | 已上传图片的地址缓存 |

保存的稿件文件夹默认在 `~/Documents/自媒体工作台/`，可以在设置里改。`IP_WORKBENCH_WORKSPACE` 可明确指定自己的写作工作区；初始化只补缺失模板，不覆盖已有文件。DSH 本身的用户级规则与全局 Skills 仍按宿主机制加载，独立目录不等于操作系统文件沙箱。

### 卸载

停止进程后，在对应的数据目录和 profile 中移除插件，例如 macOS / Linux 默认环境：

```bash
DSH_HOME="$HOME/.dsh-ip-workbench" dsh plugin --profile web remove dsh-ip-workbench
```

卸载不会删除数据。重新安装后仍可使用原有内容。

### 开发与分发

`npm test`、`npm run build`、`npm run check:release`、`npm pack`。源码采用 MIT；`private: true` 仅防止误发布 npm，不妨碍本地安装和源码分发。当前验收记录见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)，分发说明见 [RELEASE.md](RELEASE.md)。

## 已知限制与未验证

以下保留原版的功能边界。社区版新增的隔离与安装检查另见 [验收记录](docs/ACCEPTANCE.md)；历史测试不等于本次对所有真实平台重新验收。

**没有在真实环境端到端验证过**

- 公众号的推草稿、确认发布、素材库图床：只用模拟请求测过，没有连真实公众号。
- Wechatsync 同步：按扩展公开的本地协议实现并测过协议，没有连过真实安装的扩展。
- 复制到公众号编辑器后的格式、图片批量下载、Safari 下的剪贴板。
- 桌面版专属的行为：右侧内置浏览器、在 DSH 里随时可用的快捷键、摄像头和屏幕录制，都没有在 DSH 桌面版里实测（录制在浏览器里用模拟设备测过）。
- 英文界面：翻译已补齐，但新增功能（收入、「怎么用」、创作后台采集、填到草稿）没有在英文界面下逐项走过。
- 小红书「填到草稿」：页面元素按 2026-11 实测的小红书发布页定位；自动化测试（黑白名单、点击落点核对、登录页和验证码停下、完整流程）用的是模拟页面。写这份 README 时没有在真实账号上重新走一遍完整流程。小红书改版后可能找不到某个元素，会停下并说「页面可能改版了」。
- 登录后的创作后台：只在 macOS 上用作者自己的账号读过；Windows、Linux 上找 Chrome / Edge 的路径写了但没实测。解析样例源于原版 2026-11 的页面结构，社区版已替换作者标识：小红书、抖音、公众号、视频号的首页，小红书、抖音、公众号、B 站的作品列表；B 站后台首页没有样例。平台改版后需要重新核对。
- 「怎么用」里的「带我去」跳转有单元测试，没有在 DSH 桌面版里逐条点过。

**已知问题**

- 用 deepseek-flash 这类模型时，成稿里偶尔仍会出现没有出处的第一人称说法（比如「我原来把三个后台分别开在三个窗口」）。自检会把它标出来，发布前要人工过一遍经历类句子。
- 小红书的篇幅预算对信息密度高的技术稿经常超标，一次定向修改往往压不下来，未过项会如实显示。可以在风格卡里放宽。
- How I 判断为「没做过也没研究过」时，仍会用观察口吻生成并提示，不会直接停下。
- 导入大量稿件后，`state.json` 和撤销记录会变得很大。
- Wechatsync 的本地端口只校验请求来自浏览器扩展，没有限定是哪个扩展。
- 公众号发布提交超时后，可能允许再次确认提交。
- 删除录像后再撤销，会留下一条找不到文件的记录。
- 窗口窄于约 1300px 时，右侧助手栏会盖住页面右侧的按钮。
- 登录后的创作后台：靠模型从页面文字里认数，代码只能核对「这段原文在页面上」，核对不了「它是不是这一项」。同一页面上相邻的两个数（比如抖音的「关注」和「粉丝」）模型偶尔会拿错，粉丝数靠「和上次相差超过一半就待确认」兜住，其他项没有这层保护。公众号发表记录和 B 站稿件管理的数没有文字标注，只收了能确认的第一列（阅读 / 播放）。B 站后台首页「视频数据」那组数没写统计周期，按页面原样记。

### 本地 DSH 原生 Agent 对话（2026-11-22）

工作台所有对话入口共用 ChatPanel → /media-desk/chat → NativeAgent → DSH sessionController。首页、选题、成稿、视频页使用同一套流式回复和工具运行过程；选题保存 dshSessionId，视频页跟随当前稿件，全局助手单独保存会话。重新打开页面及插件后仍复用 session。清空某个对话只断开该会话关联，不删除 DSH 历史或其他选题对话。

AI 能力复用本地 DSH 的模型与工具服务。对话、默认成稿、标题候选、平台版本、风格提取、口播改写和配图规划通过原生 Agent 执行；连续对话复用选题或全局 session，专用任务保存状态和工具记录。为减少等待，编辑器的选中片段改写、创作后台数字提取优先调用 DSH 的底层模型服务，使用局部上下文，不创建完整 Agent 会话、不自动展开工作区文档或 Skills；该通道不可用时尝试原生任务。需要联网检索、工具操作或连续讨论时使用对话栏。独立预览没有这些模型能力。

个人风格与已选工作流通过引用交给原生 Agent 按需读取。风格核心、各平台补充、配图偏好分开保存为本地参考快照；工作流只检查文件元信息，不预载全文、不另造技能路由。DSH 按当前任务选择相关方法与 Skills。相同 session 只在设置、参考文件或稿件变化时同步对应上下文，未变化则复用；手工改稿会在下一轮同步。原生工具记录是实际读取的证据，勾选清单不代表已执行。偏好优先级是本次用户要求、CLAUDE.md、当前个人风格、平台 Skill 模板。小红书成稿将图文正文放在右侧，另在对话中给出带标题和标签的短总结；篇幅由选题与当前风格规则决定。

口播快捷按钮通过当前稿件的连续对话改写，展示真实思考、工具过程和右侧流式口播；保留原正文。取消操作会取消原生会话运行，未完整生成的稿件不写回。风格选择器的内部滚动不再触发定位与选项自动滚动，键盘导航仍可自动显示当前选项。

配图优先服务文章论证：用户素材、真实截图、机制流程与对比图；按需读取 baoyu-article-illustrator，可按需读取可用的 Excalidraw Skills 或使用图解工具，保留可编辑源文件并导出 PNG 插入文章。原生 Agent 可通过 src/native-image-cli.js 复用工作台 HTTP 生图配置，密钥留在本地，返回可直接引用的图片地址；接口失败如实显示，不生成占位图冒充成功。

### 信息源缓存（2026-11-18）

打开工作台即在后台预取信息源，进入信息源页优先显示本地缓存。按北京时间每天自动检查一次，同一天切页或重开插件不重复抓取；添加订阅只抓新来源。订阅和内置条目按链接增量合并，保留同链接的最新内容；热榜整体替换以保持最新排名。失败保留旧内容及原读取时间，页面仍可手动重新抓取。缓存保存于数据目录 sources-cache.json，页面列表按需展开。

口播内容单独存为 production.spoken，与正文分开；对话生成、手工编辑和视频工作台读取同一份口播，导入前等待保存成功。

卡片预览按真实高度合并相邻短小节，保留手动分页和封面。标题输入框在隐藏视图重新显示时重测高度，避免只显示半行。
