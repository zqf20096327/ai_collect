# 麦麦派对策划团 · McD Party Planner

> 基于麦当劳 MCP 的儿童派对策划专家团。说一句「给 6 岁女儿办个生日会，预算 1000 元，在上海市中心」，拿到一份**可以直接下单**的派对方案。

**问题**：想给孩子办麦当劳生日会，家长现在的做法是打一圈电话——哪家店能办、哪天有空、几点、能坐几个孩子、多少钱、包场还是和人拼？信息全在门店端，无法自助比价。

**方案**：麦当劳 MCP 把这套能力开放成了接口，但**接口不是产品**——六级依赖链、单位不一致、滚动窗口、成团人数约束，任何一环理解错都会得到无效方案。本项目把这条链产品化，让一句话变成一份可下单的方案。

## 它是怎么工作的

麦当劳派对的六级依赖链——**每一级的入参都来自上一级的返回值**，这是本项目的核心工程约束：

```
① mall-points-products      派对商品池            → spuId
        ↓
② query-party-city          可预约城市 + 经纬度    → code / lat / lng
        ↓
③ query-party-store         可办派对门店          → storeCode
        ↓
④ query-party-store-date    可预约日期（滚动10天） → dateStr
        ↓
⑤ query-party-store-session 场次/成团人数/余位/价格 → 场次 id
        ↓
⑥ party-order-create        下单（包场 / 拼团）
```

专家团按这个依赖关系编排协作：

```
Phase 1  蔡有趣 ── 主题定调 ──────→ spuId
                                      ↓
Phase 2  谭佳期 ── 场地档期 ──────→ 门店 + 场次 + 余位        【串行】
                                      ↓
Phase 3  廉子惠 ── 预算测算 ──┐
         甘知味 ── 餐食搭配 ──┘                                【并行】
                                      ↓
Phase 4  贺喜来 ── 汇编 ─────────→ 派对方案 + 下单参数卡
```

前半段串行、后半段并行——**这个编排是被 MCP 的数据结构倒逼出来的，不是形式上的多角色**。

## 快速开始

### 1. 申请麦当劳 MCP Token

前往麦当劳 MCP 控制台，用手机号登录后在控制台申请 Token。

### 2. 配置连接器

在 WorkBuddy 左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置 MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> 完整的脱敏配置见 [`mcp-config.example.json`](mcp-config.example.json)。**仓库内不含任何真实 Token。**

### 3. 安装专家团

**方式 A —— 直接使用打包文件（推荐）**

将 `mcd-party-planner.zip` 解压到专家目录：

```
$WORKBUDDY_CONFIG_DIR/plugins/marketplaces/my-experts/plugins/mcd-party-planner/
```

**方式 B —— 从源码安装**

把仓库内 `expert/` 目录整体复制到上述专家目录，然后注册：

```bash
python3 <expert-manager>/scripts/register_expert.py <expert-dir>
```

### 4. 开始对话

在 WorkBuddy 中选择「麦麦派对策划团」专家团，输入：

```
帮我给 6 岁女儿办一场麦当劳生日会，预算 1000 元，在上海市中心
```

### 5. （可选）独立验证 MCP 链路

不依赖 WorkBuddy，直接用脚本验证六级链路是否可用：

```bash
export MCD_MCP_TOKEN="your_token"
python3 tools/verify_chain.py --city 上海市 --spuId 5224
```

脚本仅使用 Python 标准库，无需安装任何依赖，且不会打印或写入 Token。

## 四条工程约束

开发中实际踩到并沉淀进 `mcd-party-booking` Skill 的约束：

1. **价格单位不统一** —— 场次 `price` 是**分**（5800 = ¥58），商品 `price` 是**元**（"58"），混用直接算错预算
2. **日期是滚动窗口** —— 实测约未来 10 天，窗口外无数据
3. **成团人数是硬约束** —— `partyMin`–`partyMax`（实测 5–12 人），不足无法成团
4. **下单仅支持 `shopId=5`** —— 选址阶段就必须核对
