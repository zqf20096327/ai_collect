## Tools and integrations

- [lazycat-mcp](https://github.com/lazycat-contrib/lazycat-mcp) - MCP bridge connecting LazyCat hardware and local LLMs.
- [lazycat-skills](https://github.com/whoamihappyhacking/lazycat-skills) - Agent Skills for Cursor / Claude (`npx skills add whoamihappyhacking/lazycat-skills`).
- [apps-scheduler](https://github.com/lazycat-contrib/apps-scheduler) - Cron-style scheduling for LazyCat store applications.
- [lazycat-contrib](https://github.com/lazycat-contrib) - Community organization for unofficial LazyCat app ports and utilities.
