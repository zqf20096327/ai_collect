## Inclusion criteria

**Included**

- Third-party tools, libraries, integrations, and Agent Skills / MCP bridges.
- Community-maintained application repositories and ports.
- Independent tutorials, reviews, and hands-on write-ups.
- Items maintainers would personally recommend to another LazyCat user.

**Not included**

- Official documentation pages, setup guides, or API references (use the Getting started entry points below).
- App Store catalog listings or official first-party app pages.
- Vendor marketing, changelogs, or incentive program pages.

See the contribution guidelines before opening a PR.

## Tools and integrations

- [lzc-dtl](https://github.com/jn7163/lzc-dtl) - Convert Docker Compose projects to LazyCat LPK apps (`npm i -g lzc-dtl`).
- [LazyCat UID Impersonator](https://github.com/glzjin/lzc-uid-impersonation) - UID simulation helper for app development and testing.
- [lazycat-mcp](https://github.com/lazycat-contrib/lazycat-mcp) - MCP bridge connecting LazyCat hardware and local LLMs.
- [lazycat-skills](https://github.com/whoamihappyhacking/lazycat-skills) - Agent Skills for Cursor / Claude (`npx skills add whoamihappyhacking/lazycat-skills`).
- [apps-scheduler](https://github.com/lazycat-contrib/apps-scheduler) - Cron-style scheduling for LazyCat store applications.
