Свой ИИ-чат на вашем компьютере в один клик. Программа сама смотрит, какая у вас видеокарта, сколько памяти и места на диске, **подбирает подходящую модель**, ставит [Ollama](https://ollama.com) и скачивает модель. Дальше — обычный чат: без интернета, без подписки и без аккаунта, диалоги не покидают ваш ПК.

![Local AI: чат с локальной моделью, слева список чатов и статистика модели](docs/screenshots/ru/02-chat.png)

**[⬇ Скачать последнюю версию (zip)](https://github.com/OlegChe77/local-ai/releases/latest/download/LocalAI.zip)** (`LocalAI.zip`, около 41 МБ, внутри один `LocalAI.exe`)

Ставить ничего не нужно, Python тоже. Работает на Windows 10 и 11.

## Что умеет

- **Подбирает модель под железо.** Определяет видеокарту (NVIDIA, AMD), видеопамять, ОЗУ и свободное место. Рекомендует самую сильную модель из каталога, которая целиком влезает в видеопамять; без видеокарты — лёгкую модель для процессора. В окне выбора показаны только подходящие вашему ПК.
- **Каталог из 34 моделей:** Qwen3, Gemma 3 и 3n, Llama 3.1 и 3.2, Mistral, Phi-4, DeepSeek-R1, Qwen2.5-Coder, Qwen2.5-VL, LLaVA, gpt-oss. У каждой — размер, режим работы (видеокарта, смешанный, процессор) и значки возможностей: текст, код, рассуждения, картинки, инструменты. Чего модель не умеет, видно сразу.
- **Всё ставит само.** Скачивает установщик Ollama с докачкой, проверяет цифровую подпись, ставит тихо (без прав администратора), скачивает модель с прогрессом. Папки для Ollama и для моделей можно выбрать, модели переносятся одной кнопкой.
- **Чат.** Потоковый ответ, Markdown и блоки кода, несколько чатов, режим «Рассуждать» (показывает ход мысли), прикрепление текстовых файлов и картинок (для моделей, которые их понимают), скорость ответа в токенах в секунду.
- **Панель «О модели»:** возможности, размер, длина контекста, где модель работает (видеокарта или процессор), версия Ollama.
- **Обновления:** программа проверяет новую версию Ollama и моделей и обновляет по кнопке.
- **Удаление без следов:** кнопка «Удалить всё…» стирает по вашему выбору модели, Ollama и саму программу.
- Любое изменение модели (установка, переключение, удаление) — только после вашего подтверждения.
- Интерфейс на **русском и английском**, тёмная и светлая темы.

## Установка

1. Скачайте **[LocalAI.zip](https://github.com/OlegChe77/local-ai/releases/latest/download/LocalAI.zip)** (всегда последняя версия) и распакуйте.
2. Запустите `LocalAI.exe`. Программа покажет ваше железо и рекомендованную модель.
3. Нажмите «Установить и открыть чат», подтвердите. Ollama (около 1,6 ГБ) и модель скачаются сами; потом откроется чат.

Если Windows показала синее окно SmartScreen («Windows защитила ваш компьютер»): программа не подписана цифровой подписью. Нажмите «Подробнее» → «Выполнить в любом случае». Антивирусы иногда ругаются на exe, собранные PyInstaller; исходный код открыт, можно собрать самому (см. ниже).

Что понадобится на диске: установщик Ollama и сама Ollama — около 3 ГБ, плюс размер модели (от 1 до 20 ГБ). Для скачивания нужен интернет, для чата — уже нет.

## Что и куда идёт

- Чат работает через Ollama на этом же компьютере (`127.0.0.1`), наружу ничего не уходит.
- Сеть нужна только для скачивания Ollama с ollama.com, моделей с registry.ollama.ai и для проверки обновлений (GitHub и реестр Ollama).
- Настройки лежат в `%APPDATA%\LocalAI`, чаты — в локальном хранилище окна программы; никаких аккаунтов и телеметрии.

## Сборка из исходников

Нужен Python 3.10+. Стек: Python, [pywebview](https://pywebview.flowrl.com/), встроенный HTTP-сервер и чистый HTML/CSS/JS в `ui/` (без сборщиков и фреймворков).

```
pip install -r requirements.txt
python app/main.py                       # запуск из исходников
powershell -ExecutionPolicy Bypass -File build.ps1   # dist\LocalAI.exe (PyInstaller, один файл)
```

Отладка интерфейса в браузере без Ollama: `set LOCALAI_DEMO=1` и `python app/dev.py` (имитация установки и чата; порт — `LOCALAI_PORT`).
