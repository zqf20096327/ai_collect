## What is Claude Code Unlock?

**Claude Code Unlock** is an independent Android application that integrates a **Claude Code CLI-based agent** into a mobile environment.

The goal is simple: bring the capabilities and workflow of an AI coding agent to Android, making development tasks accessible beyond the desktop.

No desktop required to get started.

## Key Highlights

- **Claude Code CLI Agent** — an agent-based coding workflow integrated into Android.
- **Mobile development workflow** — interact with your coding agent directly from your phone.
- **AI-assisted coding** — work with code and development tasks through the agent.
- **Integrated API** — API connectivity is integrated into the application.
- **Free Android application** — no separate app purchase required.
- **APK distribution** — download and install directly from GitHub Releases.
