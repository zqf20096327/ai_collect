# 星露谷物语 AI 队友（Stardew Valley AI Coop Companion）

给《星露谷物语》添加一位会聊天、能干活的 AI 队友。

她会在第二个游戏窗口中，通过原生局域网联机加入你的农场。你可以直接在游戏里和她聊天，告诉她今天想做什么，让她陪你一起经营农场、探索矿洞。

## AI 队友可以做什么？

### 聊天与陪伴

- 在游戏内直接用中文和她聊天，不需要输入固定前缀。
- 可以让她跟随你、前往指定地点，或者陪你一起行动。
- 可以记住一些角色设定、相处信息和当前存档的游玩记录。
- 支持在面板中查看和编辑长期记忆。

### 农场工作

- 锄地、播种、浇水、施肥。
- 清理杂草、树枝和石头，砍伐普通树木。
- 观察附近地形与作物，根据当前游戏状态尝试完成任务。
- 可以使用自然语言下达指令，例如“帮我浇水”“清理附近的杂草”或“停手”。

### 探索与其他活动

- 陪你前往矿洞，尝试挖矿、清理障碍和战斗。
- 安排她前往水边钓鱼。
- 查询已接入的游戏信息，例如角色状态、任务和地图数据。
- 支持部分邮箱、物品、菜单和剧情交互。

### 游戏数据修改

明确提出要求后，AI 队友可以通过已接入的接口帮你：

- 暂停、恢复或调整游戏时间。
- 增加或调整金币。
- 恢复体力和生命值。
- 生成指定物品，例如种子、工具或材料。
- 调整部分角色或游戏数据。

例如，你可以说“把时间暂停”“给我加一些金币”或“刷一把铱斧头”。

> AI 可能误解指令，部分操作会直接修改存档数据。使用这些功能前，请先备份重要存档。

## 使用前准备

1. 自备《星露谷物语》，并安装 [SMAPI](https://smapi.io/)。
2. 准备一个兼容 Chat Completions 的模型接口、模型名称和 API Key。
3. 农场需要有可供 AI 队友使用的联机小屋。

> 本项目发布包不包含游戏本体、SMAPI、API Key 或 JEV 模型。

## 安装

1. 前往 [Releases 发布页面](https://github.com/KotokaYuzu/stardew-ai-coop/releases/tag/v0.5.20)。
2. 下载 `0.5.20.AI.zip`，完整解压到可写目录。
3. 双击 `星露谷物语AI启动面板.exe`，也可以使用 `启动面板.cmd`。
4. 程序会尝试查找游戏；如果没有找到，请选择包含 `StardewModdingAPI.exe` 的游戏目录。
5. 如需更换游戏目录，可以使用 `重新选择游戏目录.cmd`。

发布包自带便携 Python 和预编译模组，正常使用无需另装 Python 或 .NET SDK，也不需要把整个发布包放进游戏的 `Mods` 文件夹。

## 开始使用

1. 在启动面板中填写自己的模型接口地址、模型名称和 API Key，保存后测试连接。
2. 点击启动游戏，打开主人和 AI 队友两个游戏窗口。
3. 在主人窗口选择“合作 → 主持”，进入自己的存档。
4. 等待队友连接，在 AI 窗口手动选择农场帮手。
5. 两边进入同一存档后，在面板读取联机信息并启动模型大脑。
6. 回到游戏，按 `T` 打开聊天框，例如输入“帮我浇水”“跟着我”或“去矿洞”。

模型服务需要兼容 Chat Completions，并能按照项目要求返回规划 JSON。连接测试通过，不代表所有模型或中转站都能可靠完成游戏操作。

## JEV

**JEV / AgentJev** 是可选组件，不随发布包提供模型权重和依赖，默认关闭。

不安装 JEV 也可以使用基础功能。相关接入说明见 [AI必读.md](AI必读.md)。

## 隐私与注意事项

- API Key 使用 Windows DPAPI 加密，保存在本机的 `stardew-coop/runtime/agent/settings.json` 中。
- 游戏聊天、筛选后的记忆和模型按需读取的游戏数据会发送给你配置的模型服务。
- 分享发布包或排查文件时，不要上传自己的 `runtime/`、`memory/`、API Key、令牌或存档。
- AI 可能误解自然语言指令，使用游戏数据修改功能前请先备份存档。
- 如不需要直接修改游戏数据，可在 `stardew-coop/config/companion.json` 中关闭 `gameEdits.enabled`。
- 强制结束游戏进程不等于正常存档，请按游戏原有方式保存进度。

## 常见问题

### 为什么需要打开两个游戏窗口？

一个窗口由玩家操作，另一个窗口由 AI 队友使用。双方通过游戏原生局域网联机进入同一农场。

### 为什么队友没有加入？

请确认主人已经进入联机存档，农场有可用小屋，并在 AI 窗口手动选择农场帮手。

### 为什么 AI 没有按要求完成任务？

请先确认队友已经进入同一存档、模型大脑已经启动、模型接口连接正常。AI 的表现也会受到模型能力、游戏场景和当前功能完成度影响。

### 可以不用 JEV 吗？

可以。JEV 默认关闭，不安装也可以使用基础功能。

### 下载包里有游戏吗？

没有。需要自行准备《星露谷物语》并安装 SMAPI。

## 项目组成

- `stardew-coop/agent/`：启动面板、Python 大脑和测试。
- `stardew-coop/config/`：角色设定、游戏常识和行为配置。
- `stardew-coop/mod/`：CoopLink 模组源码。
- `stardew-coop/profiles/`：主人和 AI 队友的独立模组配置。
- 发布包内另含便携 Python、预编译模组和启动器。
