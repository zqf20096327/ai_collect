# 涛涛的教学 Skills（开源合集）

一线初中语文教师用 AI 助手（WorkBuddy）积累的一套**教学向 Skill（技能）**。
覆盖备课、备考、写作、阅读、古汉语、文档审查等真实教学场景，全部可免费安装、自由使用与再创作。

> 作者：涛涛 · 江西初中语文教师 / AI 教育实践者
> 代码仓库（当前主入口）：https://github.com/ichangting/taotao-skills ｜ 个人网站（规划中）：待上线后补充

## 你要做什么？（按场景选）

21 个技能按 6 个教学场景组织。找到你正在做的事，直接用：

### 备一节课

| 对 AI 说 | 自动编排的技能链 |
|---|---|
| "帮我备七年级上册《次北固山下》" | 备课助手 → 古诗文 → 鉴赏 → 迷思预判 → 课件 → 审核 |

**核心技能**：备课助手（生成教案+学生材料+听课模板三份 Word）
**条件分支**：文言文自动插入古诗文+鉴赏；可选追加迷思预判、课件生成、知识卡片、形成性测评
**链末收口**：文稿审核自动审核全部产出

### 出一张卷

| 对 AI 说 | 自动编排的技能链 |
|---|---|
| "出一张七年级期中卷" | 江西中考备考 → 命题组卷 → 古诗文 → 审核 |

**核心技能**：命题组卷（对标江西中考卷面结构，输出打印即用 Word 含答案）
**条件分支**：江西地区用江西中考备考数据，其他地区用中考分析通用框架；含文言文自动插入古诗文核对字词

### 批作文

| 对 AI 说 | 自动编排的技能链 |
|---|---|
| "帮我批改这篇学生作文"（粘贴作文） | 作文批改 → 古诗文核对 → 语言关审核 |

**核心技能**：作文批改（维度评分+问题清单+评语草稿+升格示例，仅教师端不判分）
**条件分支**：作文含古诗文引用时自动插入古诗文核对

### 中考备考

| 对 AI 说 | 自动编排的技能链 |
|---|---|
| "江西中考三年命题趋势，出张模拟卷" | 江西中考备考 → 命题组卷 → 古诗文 → 审核 |

**核心技能**：江西中考备考（2023-2025 三年真题数据+备考方案）
**条件分支**：非江西用中考分析通用框架；名著板块联动整本书阅读；二轮复习插入形成性测评

### 写论文 / 课题

| 对 AI 说 | 自动编排的技能链 |
|---|---|
| "写一篇《整本书阅读教学策略》论文" | 教研写作 → 古文核对 → 语言把关 → 审核 |

**核心技能**：教研写作（出框架+Word 排版，含 PDF 文献解析）
**条件分支**：含古文引用插入古诗文+王力视角把关；含现代汉语分析插入吕叔湘视角

### 整本书阅读 / 名著导读

| 对 AI 说 | 自动编排的技能链 |
|---|---|
| "《昆虫记》怎么教，出一份导读方案" | 整本书阅读 → 知识卡片 → 词频分析 → 审核 |

**核心技能**：整本书阅读（导读方案+章节分析+中考链接，对标统编 12 部必读名著）
**条件分支**：可选插入跨学科设计、知识卡片、文本词频、配图规划

## 5 分钟体验路径（装完先试这个）

不确定好不好用？花 5 分钟试一个，感受最直接：

| 试什么 | 对 AI 说 | 你会得到 |
|--------|----------|----------|
| **教学工作流**（推荐入口） | "帮我备七年级上册《次北固山下》" | 自动识别备课场景，推荐技能链：备课→古诗文→鉴赏→迷思→审核 |
| **文稿审核**（零门槛） | "帮我审一下这段话：通过这次教研，使我的认识提高了。" | 一份标注了语病类型、修改建议和依据的审核报告 |
| **古诗文**（查词） | "'之'在'予独爱莲之出淤泥而不染'里是什么意思？" | 一张字词卡片：义项排序、语境判定、中考频度、易错提醒 |
| **江西中考备考**（看数据） | "江西中考语文三年命题趋势是什么？" | 2023-2025 分值变化、考点热度、备考建议 |

> 提示：前三个开箱即用，不需要任何额外依赖。备课助手需要本机有 Python 与 `python-docx`。

## 技能全景

### 编排层（L0）
- **教学工作流** `teacher-workflow` — 意图路由器 + 技能链编排器：说"备一节课""出张卷""批作文"，自动识别场景、推荐技能链、末步推荐审核收口 ｜ MIT

### 备课设计
- **备课助手** `k12-lesson-planning-zh` — 一键生成「教案 + 学生材料 + 听课模板」三份 Word（统编教材·2022 版课标）｜ Apache-2.0
- **整本书阅读** `whole-book-reading` — 整本书阅读与名著导读体系化设计（对标统编 12 部必读名著）｜ MIT
- **跨学科设计** `interdisciplinary-learning` — 语文跨学科学习设计（含小学+初中案例、模板、评价标准）｜ MIT
- **迷思预判** `anticipated-misconceptions` — 预判学生常见错误理解 + 诊断性问题（文言文/古诗文/作文/阅读理解）｜ MIT
- **分层教学** `lesson-differentiation` — 按学生水平 below/at/above 三层分层设计（借鉴 Tomlinson 框架）｜ MIT
- **知识卡片** `knowledge-card` — 字词卡 / 名著人物卡 / 古诗文默写卡 / 考点卡（A4 打印 + HTML 预览 + Word + 长图）｜ MIT
- **配图规划** `article-illustration` — 文章配图规划与生成（含小红书配图）｜ MIT
- **课件生成** `kejian-generator` — 教案→课件骨架：幻灯片大纲 + 逐页精简文本 + 板书设计 + 配图建议（Markdown/JSON 输出，不直接生成 .pptx）｜ MIT

### 文言与古汉语（数据中枢）
- **古诗文** `gushiwen` — 中学文言文词汇助手（自包含）：查字词、一词多义辨析、通假/古今异义/词类活用提示、句子串讲、江西中考高频词速查自测、教材版本核对 ｜ MIT
- **王力视角** `wangli-perspective` — 王力学术思维视角：用语言学家的眼光审视古汉语问题 ｜ MIT
- **古诗文鉴赏** `gushi-appreciation` — 单篇古诗文鉴赏教学支持：意象 / 艺术手法 / 主旨情感 / 名句赏析 / 中考考法，区分"主流定评"与"可讨论点" ｜ MIT

### 现代汉语
- **吕叔湘视角** `lvshuxiang-perspective` — 吕叔湘语文教育思维视角：语法、用词、语文教育、现代文教学顾问 ｜ MIT

### 评价与考情
- **江西中考备考** `jiangxi-zhongkao-beikao` — 基于 2023–2025 真题的命题规律与备考方案 ｜ MIT
- **中考分析** `zhongkao-analysis` — 中考真题深度分析与考情研判（通用框架 + 模板）｜ MIT
- **形成性测评** `formative-assessment` — 单课单篇轻量理解检查（5-10题，两档难度，即测即判）｜ MIT
- **文本词频** `wordfreq` — 文档词频分析统计（Word / PDF / EPUB / TXT，表格 + 图表）｜ MIT
- **作文批改** `zuowen-grading` — 学生作文结构化批改参考（仅教师端）：维度评分建议 / 夹批问题清单 / 评语草稿 / 升格示例 / 亮点标注，不判分不排名 ｜ MIT
- **命题组卷** `mingti-zujuan` — 完整试卷命制（周练/单元/期中期末/中考模拟），对标江西中考卷面结构，输出打印即用 Word（含答案）｜ MIT

### 教研与写作（含质量护栏）
- **教研写作** `jiaoyan-writing` — 教研课题 / 论文 / 教学案例辅助撰写（含 PDF 解析、Word 排版）｜ MIT
- **文稿审核** `doc-review` — 语文教师写作审核（资深编审级咬文嚼字）：文字差错 / 语法硬伤 / 用词精准 / 文风规范四关 + 轻量古文引用审核 ｜ MIT

### 数据底座（L2）
- **课程标准库** `curriculum-standard` — 义务教育语文课程标准（2022年版）全文 + 行号锚点，全仓库课标单一数据源 ｜ MIT

## 手动串联（不用 teacher-workflow）

不想装 teacher-workflow，也可以手动按场景串联技能：

| 场景 | 怎么串 |
|------|--------|
| **从零备一节课** | 备课助手 →（文言/语法点）古诗文查词 + 王力/吕叔湘视角把关 → 文稿审核收口 |
| **古诗文赏析备课** | 古诗文鉴赏出意象/手法/情感/考法 → 古诗文查字词与默写易错字 → 文稿审核收口 |
| **中考总复习** | 江西中考备考出考情与方案 → 名著板块联动整本书阅读 → 命题组卷出模拟卷 |
| **写教研论文** | 教研写作出框架与 Word → 引古文处经王力视角把关、字词考据交古诗文 → 文稿审核润色 |
| **整本书阅读课程** | 整本书阅读出导读方案 → 知识卡片做学生素材 → 文本词频做文本分析 → 配图规划做视觉 |

> 原则：每个"生产类"技能都输出**格式锁死**的产物（如备课助手的 Word、古诗文的查词卡）；品牌声音统一见 [docs/品牌声音与品牌规范.md](docs/品牌声音与品牌规范.md)。
> 场景包完整预设（含条件分支、5 分钟体验路径）见 [skills/teacher-workflow/references/场景包预设.md](skills/teacher-workflow/references/场景包预设.md)。

## 怎么安装

这些 Skill 是给 **WorkBuddy**（以及兼容的 Claude Code / CodeBuddy 类客户端）用的。
把对应技能文件夹放进客户端的 Skills 目录即可：

- **用户级（对所有项目生效）**：`~/.workbuddy/skills/<技能名>/`
- **项目级（仅当前项目）**：`<项目>/.workbuddy/skills/<技能名>/`

例如安装语文备课技能：

```bash
# 把整个 skills/k12-lesson-planning-zh 文件夹复制过去
cp -r skills/k12-lesson-planning-zh ~/.workbuddy/skills/
```

> 提示：k12-lesson-planning-zh 生成 Word 需要本机有 Python 与 `python-docx`
> （详见该技能目录内的 README）。其余多为纯提示词，开箱即用。
