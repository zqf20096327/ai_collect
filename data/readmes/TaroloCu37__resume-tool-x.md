## Executive Summary & Design

**AI Resume Builder — AI Resume Builder — resume tool x suite** (`resume-tool-x`) is a portable Windows 10/11 runtime suite: drop the prebuilt package, point it at `config/settings.json`, and go. No compiler, no external dependencies, live hot-reload included.

## Building from Source

```bash
git clone https://github.com/TaroloCu37/resume-tool-x.git
cd resume-tool-x
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
