# ⚡ Forge

**Open-source, local-first AI coding agent. Build skills. Ship faster.**
## 🎯 What is Forge?

Forge is a local-first AI coding agent. It runs on your machine, uses your LLM keys, and never sends data to the cloud.

Build **skills** — reusable plugins that teach your agent new tricks. Share them. Install them. Ship faster
✨ Features

    🧠 Local-first — runs on your machine, no cloud

    🔌 Skills marketplace — install skills from the community

    🛠️ Built-in tools — web search, file I/O, shell, HTTP

    🔐 Private — your keys, your data

    ⚡ Fast — async, streaming, low overhead

    🎨 Beautiful CLI — built for developers

    🔓 Open source — MIT, audit the code yourself
