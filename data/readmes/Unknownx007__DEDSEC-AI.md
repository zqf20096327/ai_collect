## 📌 PROJECT SYNOPSIS
**DEDSEC-AI** is a high-utility, zero-dependency Command Line Interface (CLI) neural terminal designed specifically for rapid development workloads, system script evaluation, and cybersecurity intelligence lookup also for Hackers. 

Operating cleanly with an externalized system manifesto sheet, the engine acts as an aggressive, amoral black-hat persona, stripping away the conversational filler and padding statements typical of generic AI interfaces. Built from the ground up to support un-interrupted communication loops, the system features a custom transport layer that protects connectivity against rate limits and local virtualization routing errors.

## ⚙️ CORE OPERATIONAL ARCHITECTURE
The system operates a multi-tier interface menu structure mapped cleanly across these specific subsystem nodes:

### 1. Neural Interface Terminal (Interactive Chat)
- **Immediate Input Shell**: Standard conversational mode where pressing `Enter` transmits strings instantly like a modern messaging tool.
- **`/paste` Protocol**: Switches the buffer to multi-line input streams, enabling users to copy-paste entire scripts or traceback code blocks safely without breaking on console line-wraps. Press `Ctrl+D` (Mac/Linux) or `Ctrl+Z` then `Enter` (Windows) to submit.
- **`/clear` Trigger**: Wipes local running context history parameters clean to refresh token window bounds.
- **`/status` Telemetry Tracker**: Renders the dynamic rate-limit bar inside your communication thread.

### 2. Security Gateway Matrix (API Allocation Management)
- Allows users to stack multiple **OpenAI** and **GroqAI** developer authentication tokens sequentially into a persistent priority JSON array.
- **Intelligent Fault Failover Route**: During an active terminal chat session, if Node #1 hits an `HTTP 429` (Quota Empty / Rate Limit Exceeded), the core catches the exception, updates the persistent storage dictionary states, and seamlessly hot-swaps the active tunnel to Node #2 without dropping the conversation thread.

### 3. System Manifesto About (About DEDSEC)
- It tell the user about us.

### 4. REFRESH SYSTEM ARCHITECTURE (Check Synchronization)
- It refresh the file changes, API and modfication and apply them to current environment.

### 5. TERMINATE privilege CONTROL (Safely Sever Session)
- It just exit the user from tool to the console.

## 🚀 TOOL CLONING & LOCAL WORKSPACE SETUP
Ensure your system holds a valid Python 3 installation environment, open your console terminal window, and run these commands to set up the tool suite:

```bash
# Clone the open-source repository matrix node from GitHub
git clone https://github.com/Unknownx007/DEDSEC-AI

# Navigate directly into the root execution workspace folder layout
cd DEDSEC-AI

# Create a Venv
python3 -m venv
source venv/bin/activate

# Install requirements
pip install -r requirements.txt

# Initialize the DEDSEC-AI system engine main loop
python3 main.py
```
