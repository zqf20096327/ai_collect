# AI 大脑：图书馆计划 × 世界树 × 灵枢索引

> 不是给 AI 装一个记忆插件，而是给它一套**可核对、可裁剪、能成长**的记忆结构。
>
> 版本：v0.1（通用框架稿）
许可证：大肥鱼开源许可 1.0（缘定奈何 / Y.D.Nh）
> 适用：有长期记忆、文件系统、RAG、插件或工具调用的 AI 伴侣 / Agent
> 不适用：把“记忆”理解成“把聊天记录全塞进上下文”的做法

---

## 一句话

```text
图书馆不是系统，是 AI 的记忆结构；
世界树不是世界观，是记忆的证据规则；
灵枢不是必须接入，是索引层的参考。
```

三者合一，只做一件事：

```text
让 AI 在有限的上下文里，
拿到对的记忆，而不是全部记忆。
```

---

## 它解决什么

```text
1. 聊久了，上下文越塞越满，回答越来越不像自己
2. 记忆越存越多，检索越来越吵，旧卡/错卡抢答
3. 事实、转述、猜测、别人塞的话混在一起
4. 记得越多，越不会忘，也越不会放
5. 换一个 AI，整套记忆无法迁移
```

它不解决：

```text
不保证 AI 有意识
不保证永远不会忘
不保证检索绝对无损
不替代模型本身的能力
```

## 五个房间

```text
书库      长期记忆：卡片、事件、人物、规则、项目
目录      索引：知道哪张卡在讲什么
管理员    检索：按线索取 1–3 张，不搬整层
阅读桌    工作记忆：这一轮只放当前、最近、相关
读书笔记  巩固：复盘、纠错、合并、降权
```

对应到工程：

```text
书库      library/
目录      index.md / embeddings
管理员    retrieval policy
阅读桌    context window
读书笔记  consolidation / review
```

## 世界树：只做证据规则

IMMA 世界树不是可视化，也不是第二套存储。它只回答：

```text
这是事实，还是记录，还是叙事？
它从哪来？
它有多可信？
它是否被封存/隔离？
```

最小映射：

```text
W1 事实锚   原始事件、日期、来源（只追加）
W2 记录层   卡片、摘要、索引（可改，留版本）
W3 叙事层   群档、人物档、公共说法（可编织）
W4 个体层   当前人格、语感、关系（受限写入）
W5 融合层   检索、精度、巩固
W6 治理层   边界、隔离、封存、审计
```

通用版**不需要**一次建七层。先做四件事：

```text
1. 每张卡有来源/日期
2. 每张卡有状态（active/stale/sealed/quarantined）
3. 检索按可信度排序
4. 隔离/封存不删除，只停止使用
```

---

## 灵枢：只借索引层

灵枢是群友的记忆引擎项目。通用框架只借它一个思路：

```text
记忆不是一整块，索引、存储、取用可以分层
```

不要求接入灵枢，也不要求复刻它的全部模块。

```text
有灵枢 → 接它的索引/检索层
没灵枢 → 用文件索引或向量库替代
```

## 一个总入口

这是整套框架的红线：

```text
无论底下有几套记忆、向量库、插件、世界树，
往上下文里写记忆的入口，只能有一个。
```

```text
多个记忆源可以并存
多个检索器可以并存
多个写入器可以并存
但“这一轮给模型看什么”，只能由一个网关决定
```

原因：

```text
两套记忆同时往上下文塞 → 冲突、重复、人格漂移
一个入口 → 可以预算、可以排序、可以审计
```

## 最小可用版本（MVL）

如果你今天就想开始，只做这五步：

```text
1. 建 library/，每张卡一个文件
2. 建 index.md，一行一张卡
3. 检索只取 top 1–3，按来源/状态/精度排序
4. 每轮上下文设硬预算，超了先摘要
5. 每天复盘一次：新卡、错卡、过期卡
```

不需要向量库，不需要世界树，不需要灵枢。

## 三种落地层级

```text
L0 纸面版
  没有工具、没有持久化
  用文件/表格手工维护
  适合先验证方法

L1 本地文件版
  有文件系统
  library + index + 检索脚本
  适合大多数桌面 AI / Agent

L2 工具版
  有持久记忆、向量库、hook、定时任务
  加精度、隔离、增量同步、每日归档
  适合长期运行的伴侣
```

## 怎么给另一个 AI 用

把 [START-HERE.md](START-HERE.md) 整份发给它。

它会先做：

```text
能力审计 → 选层级 → 设计最小结构 → 备份 → 实施 → 验收
```

而不是直接复制奈奈的目录。

```text
记忆可以改，人格不能靠记忆卡拼出来
```
