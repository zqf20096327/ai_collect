## 8.0.1（她为什么变安静了）

  `mark_replied()`，分段引擎发完主动通知心流清除暂停；

## 7.6.9（扣款幂等与身体状态）

- **失败不再被永久缓存**：余额不足那次只挡 60 秒并发重试，补钱后同一个号还能再扣；
- **成功单落库**：幂等号写进 `charge_ok`（kv），终端重启后同一笔不会再扣第二次；
- 幂等号同时交给金融（`request_id`），账本自己也认这笔扣过没有；
- 命中重复时不再重复写记忆（同一笔只记一次支出）；
- **身体状态以医疗插件为准**：以前治好就写「健康」，把医疗的「恢复中」覆盖掉；
  现在终端只同步 `medical.status()`，不再自己掷骰子也不会前后矛盾；

## 7.6.5（她的工资）

- 新增 `extract_salary()`：从人格里读月薪（「月薪 8000」「工资 1.2 万」「年薪 24 万」都认，
  年薪 ÷12），读不到就不推，交给金融按城市平均；

  被跳过时不再记成焦虑（以前会误判成「没看成病所以焦虑」）；
- wiki 补「她的工资怎么算」和「她自己去看病还是你点按钮」。

## 7.6.4（心流判定：上游 503 不再刷屏，叫她还是应）

- 判定模型的上游在整片 503（`API node is temporarily unavailable`），旧实现每条消息
  都打一条 `ERROR` 然后一律不回复——日志全是噪音，她还会在这段时间里变成哑巴；
- 失败日志改成「60 秒最多一条 + 连续 N 次」，`ERROR` 降为 `WARNING`；
- 连败 3 次熔断 60 秒：期间不再打上游，直接走兜底判断；
- 兜底不是一律沉默：**名字/别名被叫到、或连续被打扰**，照样回复；
- 5xx/429/超时这类瞬时错误重试一次（间隔 0.4s），解析错不重试；
- 新增 `tests/test_heartflow_resilience.py` 7 条用例：限频、熔断、熔断过期、
  被叫到要回、没叫到别插嘴、强制回复、成功复位。

## 7.6.3（关系图：不再缩成一个点）

- 修：关系图谱（那个转着的神经球）在人多的时候会整张缩成一个点——
  旧的力导向把力一路累加进速度，线上 144 个节点实测坐标能跑到 2e49，
  归一化之后所有节点挤在原点上。换成 Fruchterman-Reingold 位移制 +
  温度收敛，实测 144 个节点、最近点距 24px、不出画面；
- 归一化加兜底：真发散就退回球面撒点，宁可整齐也不留一个点；
- 节点标签颜色改跟主题走（`--canvas-label`）：深色模式里原来写死的深色等于看不见；
- 顺手清掉图例里重复赋值的一行。

## 7.6.0（钱的链路：审批 → 金融 → 记忆）

- `charge()` 改成真正的中枢：先审批（金额必须 > 0、单笔不超过 10 万）、
  再交给金融、最后把结果写进记忆——**成功失败都写**。只写成功的话，
  聊天里她会以为钱没花，或者不知道自己为什么没钱；
- 新增幂等号 `request_id`：同一个号重试只扣一次，医疗重试和网络重发都不会扣两遍；

- 每日生图张数只认相片插件（`quota()`），主插件不再自己记一份：
  一张图被数两遍，两边迟早对不上；冷却和概率仍留在终端；
- 终端面板不再展示挂载状态，连接状态由每个挂载插件自己在面板顶部显示。

## 它是怎么工作的

群聊：

```
用户消息
  → 心流引擎（五维评分 + 动态阈值 + 沉浸模式 + 防抖 + 群聊独立配置）
  → 达到条件时设置 event.is_at_or_wake_command = True
  → AstrBot 原生 LLM 生成回复（人格、上下文都走 AstrBot）
  → on_decorating_result 交给完整本地分段引擎
  → 按符号分段、成对符号保护、打字延迟、群聊引用
```

私聊：

```
健康 / 生理期 / 日程门控
  → 通过则走 AstrBot 原生回复
  → 完整本地分段引擎发送（私聊不引用）
```

没有修改 AstrBot 核心代码，也没有替换它的回复链路；心流只负责“要不要说”，分段只负责“怎么说”。

## 功能

- **完整心流（内置）**：五维评分、动态阈值、沉浸模式、判断暂停、防抖、群聊独立阈值、白名单、自定义评分规则、详细日志、心流命令。
- **完整本地分段（内置）**：强制分隔符、字数范围、超长处理、短尾合并、断句符号、标点保留、连续符号顺延、成对符号保护、排除关键词、超长跳过、固定/随机/按字/智能延迟、主动消息处理。
- **生理期**：28 天周期可配置，月经期、卵泡期、排卵期、黄体期；影响心情、体力、疼痛、回复概率与主动求安慰。
- **九维心情**：开心、平静、郁闷、生气、委屈、疲惫、焦虑、兴奋、依恋；直接影响语气。
- **世界观与日程**：基于 AstrBot 人格生成世界观，再由世界观生成每日日程；天气、健康、生理期共同参与。
- **天气**：和风天气；未配置 Key 时本地模拟。
- **长期记忆**：本插件不再自带记忆库，只读写外挂记忆插件（天使之魂 / 我会牢牢记住你 / livingmemory）；记忆会注入回复与主动消息。
- **用户档案**：自动建立，记录名字、称呼、生日、关系、好感；相恋仅管理员可设。
- **用户画像界面**：状态 / 用户画像 / 设置三个页签；可搜索、编辑画像、查看记忆、同步陪伴插件档案，直接调整关系（仇恨/抵触/普通/熟识/相恋）。
- **全部开关进 WebUI**：设置页加载完整 `_conf_schema.json`，布尔开关、数字、文本、列表/模板列表都可直接改，保存后写入插件配置并重建心流/分段引擎。
- **主动私聊**：概率、频率、每日上限；难受时找相恋的人撒娇，遇到有趣的事分享。
- **九维面板**：查看心情雷达、生理期、健康、天气、日程、阈值。

- 基础陪伴：`period_*`、`proactive_*`、`mem_*`、`weather_*` 等；

- 本地分段完整版：`seg_*`（原始分段配置名前面加 `seg_`）。

## 挂载记忆插件

本插件不带记忆库，记忆来自你装的其他插件。市面上记忆类插件很多，**面板会直接列出你已安装的所有插件**，
选哪个就用哪个的记忆和画像，不用改代码：

| 配置 | 说明 |
|---|---|
| `companion_memory_plugin_name` | 挂载的记忆插件；留 `auto` 自动检测，面板下拉列出已安装插件 |
| `companion_memory_include_profile` | 读取挂载插件的画像（强记忆、边界、表达习惯、偏好、兴趣） |
| `companion_memory_include_important` | 读取挂载插件的长期记忆（不限条数） |
| `companion_profile_sync` | 从挂载插件自动补全用户画像（只补名字/生日/关系） |

**检索是按 `uid` 查的**（QQ 号 / 平台用户 ID）：召回时带着当前说话人的 uid 去插件里查，
查不到再按名字/称呼兜底；画像也以 uid 为主键（同名不同号不会串）。

能自动读取的结构（有哪个读哪个，都不限制条数）：

- `users[uid]["companion_memory"]["items"]` 的 `text` / `weight`；
- `companion_memory["profile"]` 里的 `strong_memories`、`boundaries`、`speaking_style`、`weak_preferences`、`interests`；
- `users[uid]["important_memories"]`；
- `worldbook_member_profiles[uid]["important_memories"]`；
- 实现了 `search_for_event` / `recall_for_event` / `search_memory` 等检索接口的插件（直接调用它的检索）。

只读，不修改挂载插件的数据；没有可用的记忆插件时就不注入记忆（本插件不再自带记忆库）。

> 注意：陪伴插件本身也会回复消息。如果两个插件同时接管聊天，可能出现双回复；建议只保留一个负责回复，另一个作为记忆源。

## 版本号规则

- 三段：`x.y.z`，**第二位和第三位只能是 0-9，逢十进一**：3.8.9 → 3.9.0，3.9.9 → 4.0.0；
- **首位不做限制**，可以是多位数：9.9.9 再进一位是 10.0.0（不是 1.0.0.0）；
- **测试版**：动第三位（7.4.0 → 7.4.1）；
- **发布版**：动第二位、第三位归零（7.4.1 → 7.5.0）；
- **大版本**：首位 +1（7.5.0 → 8.0.0）；
- `python3 tools/check_version.py` 校验四处一致与规则，
  `python3 tools/check_version.py --next test|release|major` 直接算下一个号。
