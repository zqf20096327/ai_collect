# AI 绘画提示词超市 v2.10.0

**中文简体** | [**English**](./docs/en/README.md)

![](https://img.shields.io/badge/version-v2.10.0-blue)
![](https://img.shields.io/badge/license-MIT-green)

本地离线的 AI 绘画提示词生成工具：**点选标签直接生成中文提示词，一键切换中文 / 英文输出**。**零安装、零服务器、完全离线、双击即用**，不调用外部翻译 API。

## 特性

- **全量标签库**：内置 31.7 万+ Danbooru 中英对照标签（含角色 / 画师 / 版权 / 作品分类），随版本过滤重分类更新
- **分类 + 二级分类**：发色 / 发型 / 眼睛 / 表情 / 身材 / 服装 / 姿势 / 场景 / 画风 / NSFW 等，大类可继续细分（如服装 → 上衣 / 裙装 / 内衣 / 鞋配饰）
- **全局搜索**：中文、英文、下划线、空格都能搜，覆盖全库
- **收藏**：★ 收藏常用词，支持「仅看收藏」筛选，跨会话持久化；**搜索结果可直接点 ☆ 收藏**
- **导入 / 导出收藏**：收藏可导出为 JSON 文件备份，也可从 JSON 文件导入合并；导出按字母排序，方便版本管理
- **自动保存**：开启后收藏每次变动自动写入指定 JSON 文件（内置记忆保留，文件为并行备份）；首次开启需在 Chrome/Edge 中手动选择一次保存位置，右键按钮可随时更换
- **全部浏览**：一键查看最常用 1000 条
- **负面提示词**：内置负面词分类，自动分流到负面框
- **输出语言**：首次默认中文，按钮一键切换中文 / 英文并记住选择；切换只改变输出格式，标签身份、顺序、正负、权重、自由文本、收藏和预设均保持不变。英文模式将下划线转为空格（`long_hair` → `long hair`）
- **拖动排序**：提示词下方的中文小胶囊可直接拖动调整顺序
- **中英文回填识别**：正面 / 负面框支持中文、英文、混合文本和 `(标签:1.2)` 权重；未知文本保留原文并标 `?`。含逗号 / 分号的名称支持完整匹配，输出时以双引号保护；中文重名优先匹配已选候选，再按热度、稳定英文键决定
- **选中高亮**：切换一级 / 二级分类、搜索、仅看收藏和加载全部时，正负选中状态均正确恢复，收藏星标可同时存在
- **旧数据兼容**：保留原 localStorage 键；兼容旧收藏数组、`{fav,preset:{pos,neg}}` 文件及旧文本预设。新预设同时保存结构化标签与可读文本，避免中文重名、顺序和权重丢失

## 用法

下载**整个项目 ZIP / Release 压缩包**，解压后双击 `index.html` 即可；不需要 Python、Node、服务器或任何初始化命令。首次默认生成中文，点「输出语言」可切换英文，正面 / 负面均可一键复制。

当前 v2.10.0 发行版仍将运行所需数据与代码完整内联，单独保存 Release 中的 `index.html` 也能离线运行。用户无需运行 `tools/`；这些仅供维护者校验数据和测试。请允许浏览器使用本地存储以保存收藏、预设和输出语言；更换浏览器、移动文件或清理浏览器数据可能改变 `file://` 的存储范围，重要收藏请先导出备份。
