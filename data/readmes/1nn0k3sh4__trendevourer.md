# Trend Devourer 👗✨  
### *AI-Powered Visual Style Analyst*

![Python](https://img.shields.io/badge/Python-3.9+-blue) ![PyQt6](https://img.shields.io/badge/PyQt6-GUI-purple) ![Ollama](https://img.shields.io/badge/Ollama-Local%20AI-green) ![License](https://img.shields.io/badge/License-MIT-yellow)

**Trend Devourer** is an intelligent desktop application that analyzes clothing photos using local AI models and generates stylish, personalized fashion trend reports. Perfect for stylists, shopaholics, and anyone looking to organize their wardrobe.

---

## 🚀 Features

- **🖼️ Image Analysis** — Upload 3+ photos of clothing, accessories, or outfits
- **🧠 Dual AI Model**  
  — **BakLLaVA** (computer vision) describes each look  
  — **Mistral 7B** (text model) creates a coherent style report
- **📝 Smart Reporting** — Output includes:
  - Analysis of colors and key items
  - Trend identification
  - 3–5 mix-and-match ideas
  - Friendly, conversational advice
- **📤 PDF Export** — Save reports in a beautifully formatted PDF
- **🎨 Stylish Interface** — Dark theme with gradient buttons and smooth animations
- **⚡ Local Processing** — All data stays on your computer, no cloud services required

## 📦 Installation & Running

### 1. Install Ollama
Download and install [Ollama](https://ollama.ai/) for your OS.

### 2. Pull Required Models
```bash
ollama pull bakllava
ollama pull mistral:7b
```

### 3. Clone the Repository
```bash
git clone https://github.com/1nn0k3sh4/trendevourer.git
cd trendevourer
```

### 4. Install Python Dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the Application
```bash
python trendevourer.py
```

## 🎯 How to Use

1. **Start Ollama** (must be running on `localhost:11434`)
2. **Open Trend Devourer**
3. **Click "Select 3+ Pictures"** and choose photos of clothing/outfits
4. **Click "Generate Style Report"** — watch the process in the live log
5. **Read the report** in the main window
6. **Export to PDF** with the "Export to PDF" button

---

## 🧠 Architecture

```plaintext
GUI (PyQt6)
    │
    ├── Image Loading → Pillow (preprocessing)
    │
    ├── AnalyzerThread (QThread)
    │   ├── BakLLaVA → describe each image
    │   └── Mistral 7B → generate final report
    │
    ├── Real-time logging
    │
    └── Export → WeasyPrint (PDF)
```
