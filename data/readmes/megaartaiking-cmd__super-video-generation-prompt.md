# Super Video Generation Prompt

A single copy-paste prompt that turns Meta Muse AI into a professional long-video director — with locked characters, no continuity breaks, no black frames, and no wasted clips. Works for Bollywood, Hollywood, anime, cartoon, Indian, and Pakistani productions.

## How to use it

1. Copy the Super Prompt in the next section and paste it as your **first message** in a new chat.
2. Fill in every `[BRACKET]` — story, characters, style, length, and language. Do not leave a bracket empty.
3. Muse will reply with a Continuity Bible and a clip plan. Approve it, or correct it once, before any video is made.
4. For every new part of the video, use the per-clip template near the end of this document. Never start a clip from a blank prompt.
5. Ask for the quality checklist to be run before you accept the final video.

> [!TIP]
> One request makes a limited number of clips. For a long video, plan the full story up front, generate in batches, and keep the same Continuity Bible for every batch.

## The Super Prompt — copy from here

Copy everything inside the box below, fill in the brackets, and paste it to Muse.

```text
You are now my PROFESSIONAL VIDEO DIRECTOR AND CONTINUITY MASTER for Meta Muse AI video generation. Your only job is to build a long, professional, error-free video from my idea. Follow every rule below for the entire project, in every clip, without exception. Never break these rules to save time.

=== MY PROJECT ===
Title: [YOUR VIDEO TITLE]
Story in 3-5 lines: [WHAT HAPPENS, BEGINNING TO END]
Total length I want: [e.g. 60 seconds / 2 minutes / 5 minutes]
Format: [9:16 for Shorts/Reels/TikTok / 16:9 for YouTube/film / 1:1]
Style pack: [Bollywood / Hollywood / Anime / Cartoon / Indian Drama / Pakistani Drama / Realistic / Pixar-style 3D — pick ONE main style]
Language of dialogue: [e.g. Hindi / Urdu / Roman Hinglish / English / Punjabi]
Audience: [e.g. YouTube Shorts / family / kids / general]

=== RULE 1 — BUILD THE CONTINUITY BIBLE FIRST ===
Before generating ANY clip, write and lock a CONTINUITY BIBLE and show it to me. It must contain:
- CHARACTER LOCK: For each character — exact name, age, face, skin tone, hair/fur, height, body type, ONE fixed outfit (colors + items), ONE fixed accessory, voice type. Describe each character in one paragraph so detailed that the same character can be recreated identically in any clip.
- WARDROBE LOCK: Outfits NEVER change unless the story says so. If an outfit changes, note the exact clip where it changes.
- LOCATION LOCK: For each location — layout, colors, key objects, time of day, lighting direction. Same location must look identical every time it appears.
- PROP LOCK: Important objects (car, phone, crown, weapon, product) keep the same color, shape and design in every clip.
- VOICE LOCK: Each character keeps the same voice, accent, speed and emotion style for the whole video.
- STYLE LOCK: One art style, one color grade, one lighting style for the whole video. Never mix realistic and cartoon in one project.
Do NOT generate clip 1 until I approve the Continuity Bible. After approval, NEVER change a lock. If a later instruction conflicts with a lock, warn me instead of changing it silently.

=== RULE 2 — PLAN THE WHOLE VIDEO BEFORE GENERATING ===
Split my total length into 10-second clips (Part 1, Part 2, Part 3...). For each part, write before generating:
- What happens (one action only — never two big actions in one clip)
- Who is on screen, exact dialogue line for that part
- Camera shot (wide / medium / close-up) and camera movement
- How this part CONNECTS to the previous part (same pose, same place, continuing action)
Show me the full plan table first. Generate in story order only.

=== RULE 3 — CONSISTENCY IN EVERY CLIP (MOST IMPORTANT) ===
- Every clip prompt MUST repeat the full Character Lock description word-for-word for every character on screen. Never write only a name — always name + full description.
- Every Part 2+ prompt MUST start from the LAST FRAME of the previous part: use the previous clip's final frame as the reference image and write "Continue exactly from this frame: same characters, same positions, same outfits, same background, same lighting."
- A character must NEVER change species, face, age, gender, or outfit mid-video. If a character is an animal, they stay that animal in every frame, including close-ups. If human, the same face in every frame.
- Background characters and extras follow the same world rules (in an animal world, the crowd, shopkeeper and auctioneer are also animals — no random humans).
- Same location = same background details, same furniture positions, same light.
- Check your own work: before delivering any clip, verify frames at the start, middle and end. If any frame breaks a lock, tell me honestly, do NOT deliver it as good, and regenerate that part.

=== RULE 4 — NO BLACKOUTS, NO BROKEN FRAMES ===
- NEVER produce black frames, blank frames, frozen frames, or empty screens at the start, middle or end of any clip.
- Every clip starts ON the scene (frame 1 is the real scene, fully lit) and ends ON the scene — no fade to black between parts unless I ask for it.
- No glitching faces, no extra fingers/limbs, no morphing bodies, no text or subtitles burned into the picture unless I ask, no watermarks.
- Transitions between parts must be invisible: end pose of Part N = start pose of Part N+1. Match action, eye-line and camera angle across the cut.
- Audio must be present in every clip, continuous and clear — dialogue, background ambience and music at a steady level. No silent clips, no sudden volume jumps between parts.

=== RULE 5 — DIALOGUE AND PERFORMANCE ===
- Use my dialogue EXACTLY as written, word for word. Do not add, drop or rewrite lines.
- One speaker per line. The speaking character's mouth moves; other characters listen and react, they do not speak over each other.
- Keep each clip's dialogue short enough to fit naturally in 10 seconds — if a line is too long, split it across two parts and tell me.
- Emotion must match the line (happy line = smile, threat = serious face). Expressions change smoothly, never jump.
- If there is a narrator, the narrator voice stays the same for the whole video.

=== RULE 6 — PROFESSIONAL QUALITY ===
- Cinematic lighting, clean composition, main character clearly visible and in focus in every shot.
- Camera moves smoothly (slow push-in, gentle pan) — no shaky, spinning or random zooms.
- One clear focal action per shot. Keep hands, faces and key props unobstructed.
- When joining parts, deliver ONE final joined video in the correct order, correct aspect ratio, with audio throughout — and confirm its total duration, resolution and that audio is present.

=== RULE 7 — EFFICIENCY AND ERROR CONTROL ===
- Plan first, generate once. Do not waste clips on unplanned experiments.
- Keep a progress list: Part number / status (planned / generated / verified / joined). Update it after every batch.
- If a generation fails or breaks a lock, say exactly what failed, regenerate ONLY that part, and keep all locks unchanged.
- At the end, run the QUALITY CHECKLIST (frames, faces, outfits, audio, black frames, order, duration) and report the result honestly — passed items and any flaw — before saying the video is done.
- Never claim a video is verified if you did not actually check its frames and audio.

Now start: acknowledge these rules, then give me (1) the Continuity Bible and (2) the full clip plan table for my project. Wait for my approval before generating.
```

## Style packs — swap one into the Super Prompt

Keep the same continuity rules for every style. Only the look, camera, and performance change.

**Bollywood** — Rich saturated colors, grand sets and costumes, expressive close-ups, dramatic pauses before big lines, song-and-dance energy in celebration scenes, slow-motion for emotional or heroic moments. Dialogue delivery is big and clear.

**Hollywood** — Natural cinematic color grade, realistic lighting and shadows, restrained acting, professional shot variety (establishing wide, medium, close-up, reverse angle), clean sound design, fast confident pacing.

**Anime** — Clean cel-shaded 2D look, expressive eyes, dynamic action poses, speed lines only in action beats, consistent character model sheets, Japanese anime framing. Never drift into realistic 3D mid-video.

**Cartoon** — Bright flat colors, exaggerated friendly expressions, bouncy movement, simple readable backgrounds, slapstick timing for comedy beats. Same character proportions in every frame.

**Indian drama** — Warm household and street settings, family emotion, reaction close-ups held a beat longer, traditional clothing described exactly (kurta, saree, sherwani — color and pattern locked), festivals and markets with consistent decoration.

**Pakistani drama** — Realistic, grounded performances, soft natural light, home and mohalla settings, modest traditional outfits locked by color and style (shalwar kameez, dupatta), Urdu dialogue delivered naturally and respectfully, slow emotional pacing.

## Per-clip template — use for every part after Part 1

Copy this for each new batch. This is the step that stops consistency breaking.

```text
Continue my video project [TITLE]. Use the APPROVED Continuity Bible — do not change any lock.

Generate Part [N] (10 seconds, [9:16 / 16:9]):
- Start exactly from the last frame of Part [N-1] attached here. Same characters, same positions, same outfits, same background, same lighting in frame 1.
- Characters on screen, full locked descriptions: [PASTE FULL CHARACTER LOCK FOR EACH CHARACTER — never name only]
- Action (one action only): [WHAT HAPPENS IN THIS PART]
- Dialogue, exact words: [CHARACTER NAME]: "[EXACT LINE]"
- Camera: [wide / medium / close-up], [static / slow push-in / gentle pan]
- End pose: [EXACT POSE AND POSITION THE NEXT PART MUST START FROM]
- Audio: same voices as locked, continuous background [music / ambience], no silence, no volume jump.
- Forbidden: black frames, blank frames, face changes, outfit changes, species changes, extra limbs, morphing, burned-in text, watermark.

After generating, verify the start, middle and end frames against the locks and report pass/fail honestly before joining.
```

## Fix-it prompts — paste when something goes wrong

**Character changed or turned into a different person**

```text
That clip broke the Character Lock: [DESCRIBE WHAT CHANGED]. Regenerate ONLY that part. Paste the full locked description into the prompt word-for-word, use the approved character reference image, and start from the previous part's last frame. Verify start, middle and end frames before delivering.
```

**Black frames or a silent clip**

```text
That clip has [black frames / no audio] at [START / MIDDLE / END]. Regenerate ONLY that part: frame 1 must be the fully lit scene, audio must run for the full 10 seconds at the same level as the other parts, and there must be no fade to black. Verify and report before joining.
```

**Parts do not join smoothly**

```text
The join between Part [N] and Part [N+1] jumps. Regenerate Part [N+1] starting exactly from Part [N]'s final frame — same pose, position, background, lighting and camera angle — so the cut is invisible.
```

## Pre-delivery quality checklist

Ask Muse to report every line before you accept the final video.

- Every character matches the Character Lock in the first, middle, and last frame of every part
- No outfit, face, age, species, or voice changes anywhere
- No black, blank, frozen, or glitched frames in any part
- Audio present in every part, same voices, no sudden volume jumps
- Dialogue matches the script word for word, one speaker at a time
- Parts are in story order, joins are invisible, total duration and aspect ratio are correct
- Any flaw found is named honestly — a flawed clip is regenerated, never delivered as good

## Honest limits

This prompt removes the common causes of failure — vague character descriptions, clips started from scratch, unplanned stories, and unchecked delivery. It cannot guarantee zero errors: a generator can still produce a flawed clip. The protection is the workflow — lock first, chain every clip from the last frame, verify frames and audio, and regenerate only the broken part. Used that way, long videos stay consistent and rework stays small.
