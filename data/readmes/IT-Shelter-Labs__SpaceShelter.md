## Что умеет SpaceShelter

- **Показывает занятое место:** карта, размеры папок, поиск и сортировка файлов.
- **Сканирует один раз:** вложенные папки открываются из сохранённого индекса без повторного обхода.
- **Помогает с помощью ИИ:** объясняет назначение файлов, разбирает вложенные папки и показывает последствия удаления прямо в приложении.
- **Описывает изображения:** учитывает картинку и имя файла. Если в имени явно указаны аватарка, превью или площадка, этот контекст включается в описание.
- **Разбирает текст:** по выбору пользователя читает ограниченные фрагменты текстовых файлов, учитывая их названия.
- **Очищает после подтверждения:** проверяет выбранные объекты, показывает план и по умолчанию отправляет их в корзину.

## Начать работу

1. Откройте [Releases](https://github.com/IT-Shelter-Labs/SpaceShelter/releases) и выберите сборку для своей системы. Если релиз пока не размещён, приложение можно собрать из исходников.
2. **Windows 10/11 x64:** распакуйте архив и запустите `SpaceShelter.exe`. **Linux x64:** распакуйте архив и запустите `./run.sh` — [требования к системе](docs/LINUX.md).
3. Выберите диск или папку и нажмите **«Анализировать»**. Нейросеть для сканирования не нужна.
4. Для рекомендаций перейдите в **«Модель»**, выберите и скачайте модель. В Windows необходимая Ollama подготавливается автоматически; в Linux подключается уже установленная Ollama.
5. В **«ИИ-анализе»** или **«Изображениях»** получите пояснения, выберите ненужные объекты и проверьте план очистки.

## Ваш язык и оформление

Русский, **English**, **日本語** и **简体中文**. При запуске выбирается язык системы; неподдерживаемые языки используют английский. Язык можно сменить в левой панели под темой — выбор сохраняется без перезапуска. Есть светлая, тёмная и системная темы.

## Что получает нейросеть

| Режим | Передаваемые данные |
|---|---|
| Анализ файлов и папок | Ограниченный список имён, путей, размеров и подсказок о назначении |
| Описание изображений | Уменьшенная картинка без исходных EXIF и имя файла; только локальная модель |
| Анализ содержимого текста | Ограниченные начальные фрагменты и имена выбранных файлов; только локальная модель |

Одна мультимодальная модель работает с текстом и изображениями. Необязательный облачный API принимает метаданные только после подтверждения отправки. Язык интерфейса учитывается в новых ответах ИИ; прежние ответы и пользовательские имена автоматически не переводятся.

## Перед очисткой

Модель ничего не удаляет самостоятельно. Установленное ПО лучше удалять штатным способом. Размеры файлов логические и могут отличаться от фактически освобождённого места; корзина занимает место до её очистки. Полное дерево сохраняется в `inventory.ssdb`, краткие отчёты — в HTML/TXT/JSON.

## Сборка из исходников

```sh
cargo build --locked --release
```

Нужны Rust 1.92+ и зависимости платформы. Готовые программы не требуют Python или Rust. Тесты запускаются только в Docker или одноразовой VM на искусственных данных. Windows-бинарники не подписаны; реальные модели, GPU и особенности рабочего стола проверяйте на целевой системе.
