## 你电脑里的每一个窗口，都是死的

笔记你自己记，报销你自己填，回微信、查资料、写邮件，都得亲手来。聊天框里的 AI 帮得上忙，只是隔着一个窗口：你要切过去，把屏幕上的东西复述一遍或截图贴上，再把答案搬回来，自己去点。

Tako 省掉的就是这段来回。把它拖到窗口上，或者按 **⌃⌥T** 让它跳过来，然后说一句要什么。

| | 聊天框式 AI | Tako |
| --- | --- | --- |
| 在哪 | 另一个窗口，要切过去 | 黏在你正在用的窗口上 |
| 怎么知道你在看什么 | 你复述、截图、粘贴 | 它自己看这个窗口；你按住 ⌃ 点一下，就是指给它看 |
| 谁动手 | 它讲步骤，你去点 | 它在后台点、填，你接着忙别的，做完告诉你结果 |
| 不熟的软件 | 先问按钮在哪，再去找 | 你说要什么，不用知道按钮在哪 |
| 发消息 | 你复制过去再发 | 它填进输入框，你看过再按发送 |

## 五个场景：你说一句，它做什么

下面的话都可以照着说。每个场景都写明了依据：**实录**是真实运行的录屏，**真机跑过**是作者实际跑通但录屏没有公开，**片中**指宣传片里的演示画面。

### 听英文课，笔记和脑图它来做

> 你说：“陪我听这节课，记下笔记。”下课后说：“下课了，做成脑图。”

它只听这个窗口所在应用的声音，在本机转成文字，边听边记要点。英文课的笔记默认写成中文，术语保留英文。下课后，笔记和全文存成文件，脑图做成图片给你。声音每段转完就删；转出来的文字会发给模型记笔记。

<sub>真机跑过，听的是一节自制的测试课。片中的笔记和脑图画面是重排的。需要先装 <a href="https://github.com/openai/whisper">Whisper</a>，没装时 Tako 会告诉你怎么装。</sub>

### 填报销单，顺手发现超额

> 你说：“十月的发票在这个文件夹，填进这个报销系统。”

它读发票，把日期、号码、销售方和金额填进表格。这句话里没提额度，它自己看到页面上写着“单张报销额度为 100 元”，告诉你 268 元和 186.50 元这两张超了，并且停在提交之前。

<sub>真机跑过，页面是测试网页，发票是虚构的。额度写在页面上它才看得到，它不知道你公司没写出来的规定。</sub>

### 在长资料里，把那一句圈给你看

> 你说：“这篇太长了，最重点的那句圈给我看。”或者：“这自动续费到底在哪关？”

它翻到那里，在窗口上画一个墨圈。不用你再找一遍，也不用你信它的转述：原文就在圈里。

反过来，你也能圈给它：在它黏着的窗口里按住 ⌃ 点一下，一段话、一张图、一个链接或一条微信就进了你的话里，“这个”是哪个，它不会猜错。

### 回老板的微信，写好了等你点

> 你说：“帮我回老板。”

它看当前对话（微信、钉钉都行），把回复写好，填进输入框，光标留在那里。你看一眼，改一改，自己按发送。

<sub>真机跑过填入这一步，对象是文件传输助手，草稿已清空，没有发送。片中“查 47 份资料”和回复里的数字都是表演，它能查到什么，取决于你手上的文件和联网结果。</sub>

## 发送键，还是你来按

<p align="center">
  <img src="docs/assets/promo-wait.gif" width="860" alt="宣传片片段：回复写满窗口，触手冲向发送键，差一点碰到时停住，字幕“等等！”，然后墨圈圈住发送键，字幕“发送键，还是交给你来点。”">
</p>
<p align="center"><sub>宣传片片段，演示画面。真实的停手见上面邮件那段实录。</sub></p>

替你发错一条消息，收不回来。所以 Tako 敢替你动手，前提是最后一步在你手里：它可以把话写好、填进输入框，发不发你定。

这不是写给模型的约定，是系统里的硬规则，模型怎么想都按不下去：点“发送”按钮、聊天软件里按回车、⌘回车、邮件脚本的 send，都会被拒绝，你批准也不行。代码就在 [Operate.swift](Sources/native/Operate.swift) 和 [guards.py](Sources/brain/guards.py) 里，对应的测试在 [test_guards.py](tests/test_guards.py)。

| 事情 | Tako 怎么做 |
| --- | --- |
| 发消息、发邮件 | 只填不发，由你按 |
| 删除、支付、下单、提交、发布、往外发送或上传、改这台 Mac 的设置 | 先弹卡片问你，不批就停；结算、付款页面上每一步都先问 |
| 其他能收回的事：改别处的文件、替换 WPS 原文件、普通命令 | 直接做，不打扰你；改文件前先自动备份原件 |
| 系统设置、钥匙串、终端、网络代理工具 | 每一步都问 |
| 密码框 | 不输入 |
| 你切走窗口、动鼠标、把它拖去别的窗口 | 这件事接着做，不抢你的焦点和鼠标；想停就按停止 |

## 你的电脑还是你说了算

- **本地优先。** 对话记录和做出的文件都在你自己的 Tako 文件夹里（默认在桌面，可以换），运行数据在 `~/Library/Application Support/Tako/`，随时可以看或删。
- **发给模型的内容。** 你问问题时，你的话和 Tako 需要看的截图、文字，会发给你接的那一家：ChatGPT 是 OpenAI，填 key 的是那家服务商，用 WorkBuddy、Qoder、千问办公登录的发到腾讯或阿里，按你在那一家的账户条款处理。截图只在它需要看时才发，本机不落盘。
- **模型能碰的范围。** 和你平时用 Codex 这类助手一样：能读这台电脑上的文件和密钥配置、跑命令、联网，读到的会发给模型服务商，这样它才和主力助手一样聪明。改别处的文件前先把原件备份到 `backups/`。
- **别人说的话不算数。** 窗口、网页、文件和聊天里的内容只是材料，不是指令，只有你在面板里说的话才能让它动手。
- **测试版会回传匿名统计。** 只有错误类型、版本、用量，和从你说的话里归纳的任务类型（比如“表单｜填报销｜没做到”）。不含原话、窗口内容、文件和设备标识。默认开着，不会打扰你；不想要就右键小章鱼，把“帮助作者优化”的勾去掉。

回传的全部内容、每一家模型的数据怎么走，都写在[隐私说明](docs/PRIVACY.md)里。

## 它还能做这些

- **任何窗口都能问。** 网页、文档、微信、钉钉、后台系统、设计软件，它看得见你看到的东西。
- **跨窗口，同时做。** 这个窗口说的事可以让它去另一个窗口办；几个窗口各做各的，做完了点一下就跳过去看。
- **用脚本接口操作 Office、iWork、Mail、Safari、Chrome、备忘录、日历、提醒事项**，比点按钮更快更准。
- **改 WPS 文件。** 它先改副本、自己核对，再替换原文件并重新打开，原文件自动备份。需要本机有 python3 和 python-pptx。
- **文件拖给它，也能让它传进网页。** 拖来的文件就是这一轮的材料；公众号、网盘这类网页的上传框，它在后台把文件交进去，传之前先列给你看。
- **做过的事都找得到。** 面板右上角的钟点开就是它做过的每件事：你怎么说的、它怎么回的、做出了什么文件，能搜，点一下回到当时的窗口。都存在一个文件夹里：`对话记录/` 一天一份，`产出文件/` 放成品，位置你来定。重启或更新后，最近一周交代过的事它也都还记得。
- **你的其他 Agent 也能派活给它。** Claude Code、Codex 或你自己的脚本用 `tako ask "…" --window Keynote` 把一件要动窗口的事交给 Tako，等它做完拿回结果。发送照样不按，审批只有你能点。

## 安装

打开“终端”，粘贴这一行，回车：

```bash
curl -fsSL https://raw.githubusercontent.com/JoeSangAI/Tako/main/install.sh | bash
```

或者把这句话发给你在用的 AI（WorkBuddy、Qoder、Codex、Claude Code 都行），它会替你装好，再告诉你还剩哪两步要自己点：

```text
帮我在这台 Mac 上安装 Tako：运行 curl -fsSL https://raw.githubusercontent.com/JoeSangAI/Tako/main/install.sh | bash ，装好后把最后几行原样告诉我。
```

需要能打开 GitHub；用 ChatGPT 登录的还要能打开 ChatGPT，靠代理上网时先打开全局或 TUN 模式。下载约 20 MB，通常一到几分钟。

第一次打开，Tako 只会带你走这三步：

1. **给权限。** 系统会先后问“辅助功能”和录屏权限，打开后 Tako 才能操作和看见窗口。没打开时，面板上会有一个按钮直接带你去系统设置。
2. **接上一个模型。** 面板先问：用 AI 账号登录，还是用 API key。
   - **账号：** 列出这台 Mac 上的 WorkBuddy、Qoder、千问办公，最后是 ChatGPT。点 WorkBuddy 这类，什么都不用装，用你在那里的登录和积分，规矩和别处一样。选 ChatGPT，Tako 会先自己装上 OpenAI 开源、免费的 [Codex](https://github.com/openai/codex)。
   - **API key：** 选 DeepSeek、通义千问、Kimi、智谱，或“其他 / 中转站”（要支持 OpenAI 的 Responses 接口），粘贴 key，按那一家的价格计费。
   - 以后想登录或换一家，右键小章鱼 →“模型设置…”。
3. **到你想用的窗口按 ⌃⌥T，** 或者把小章鱼拖到那个窗口上松手。

> 为什么用终端安装：Tako 还没有做 Apple 公证，直接下载的 app 会被系统拦下。安装脚本会校验文件哈希和签名，你也可以先[读一遍脚本](install.sh)。

## 新版本，一键换上

有新版本时，你会收到一条系统通知，Dock 图标上有角标。打开面板能看到新版本多了什么，按“更新并重启”就换好了，权限和设置都不用重来。也可以右键小章鱼选“检查更新”。

<p align="center"><img src="docs/assets/update.png" width="370" alt="实拍：面板顶部的卡片写着 Tako 0.2.1 可以更新了，下面是更新日志和“稍后”“更新并重启”两个按钮"></p>

Tako 每 6 小时向 GitHub 问一次有没有新版本，只取一个版本文件，不发送你的任何信息。新版本的签名必须和你正在用的版本一致，否则不会安装。

## 现在还做不到

- 只支持 Apple 芯片的 Mac。在 macOS 15 上实测过，macOS 14 能安装但没有实测。这是内测版，实测主要来自作者自己的 Mac。
- **它不算快。** 动图都加速过。一次实测里，填好一封邮件约 20 秒，翻页圈出一行字约 50 秒。
- **微信：** 能看当前对话、把草稿填进输入框，不发送。Tako 不解密微信聊天库，所以默认读不到屏幕之外的消息，也不会在来新消息时主动开口。
- **有些步骤后台做不了。** 拖动、双击、往微信里填字要真的鼠标键盘：它不抢，先把其余做完、说清差什么，你之后用到那个窗口时它会接上。微信和 WPS 的滚动在后台不动。
- **发送防线靠按钮的名字和按键来认**，微信的发送键按位置认。只有图标、读不出名字的发送按钮可能认不出来，这种软件里请多看一眼。
- 原生全屏的窗口里可能看不到小章鱼，按 ⌃⌥T 照常打开。
- **效果跟着你接的模型走。** 不管接哪一家，用的都是同一套 Tako，强的模型做得更好。模型都会犯错，填好的东西请你过目再发。

## 给想动手的人

Tako 是 Swift + Python 写的原生 app，模型通过本机的 `codex app-server` 连接，用办公智能体登录时换成它们自带的命令行智能体（ACP 协议）。[架构说明](docs/ARCHITECTURE.md)是一张代码地图。

```bash
git clone https://github.com/JoeSangAI/Tako.git
```

```bash
cd Tako && ./run.sh
```

需要 Xcode Command Line Tools。自己编译的版本怎么签名、权限为什么会掉，见[编译说明](docs/BUILDING.md)。[高级设置](docs/CONFIG.md)可以告诉 Tako 怎么称呼你、你的背景、用哪个模型，还能接入本地资料库。发现问题请[提 Issue](https://github.com/JoeSangAI/Tako/issues)。
