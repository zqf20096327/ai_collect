## What it does

- **Courses from A1 to C2** in English, Spanish, French, German, Turkish and Hungarian (plus Romanian A1), with AI-generated exercises that adapt to your mistakes.
- **Live lessons** with an animated AI tutor: a video-call style conversation with live captions, and you can interrupt any time.
- **Speaking and listening** with local speech recognition (whisper.cpp) and natural local voices (Piper, Kokoro).
- **Stories, roleplay and a practice hub** for mistakes, words and timed challenges.
- **Gamification:** a garden that grows with your streak, XP, quests, a shop and a local league.
- **Private by default:** local SQLite database, keys in the system keychain, works on your phone over Tailscale.

The full list with screenshots is in [docs/FEATURES.md](docs/FEATURES.md).

## Install

macOS, with [Homebrew](https://brew.sh):

```bash
brew install --cask ozerozdas/tap/sprigo
```

macOS or Linux (x86_64 or ARM), without Homebrew:

```bash
curl -fsSL https://raw.githubusercontent.com/ozerozdas/sprigo/master/install.sh | sh
```

Both install the latest release and handle the macOS quarantine flag for you. Windows installers (x64 and ARM) and the other packages (`.deb`, `.rpm`) are on the [Releases](https://github.com/ozerozdas/sprigo/releases/latest) page. Step-by-step instructions per system are in the [wiki](https://github.com/ozerozdas/sprigo/wiki/Installation).

If you install the `.dmg` by hand: the app is not notarized yet, so macOS blocks it the first time. Remove the quarantine flag once:

```bash
xattr -dr com.apple.quarantine /Applications/Sprigo.app
```

## Set up an AI model

On first launch, Sprigo looks for a local model server:

- **[Ollama](https://ollama.com/download)** (recommended): install and start it. If no model is installed yet, Sprigo offers to download `qwen3:8b` (about 5.2 GB) for you. Smaller models run but write noticeably weaker lessons, so Sprigo warns when you pick one under 8B.
- **[LM Studio](https://lmstudio.ai):** start its local server and load a model.
- **Cloud:** you can also use OpenAI, Anthropic, Gemini or OpenRouter with your own API key. Pick one in **Settings → AI & voice → AI provider**; each option has a short note on what it is good at.

Model sizes, hardware and the cloud options are explained in [AI Model Setup](https://github.com/ozerozdas/sprigo/wiki/AI-Model-Setup).

## Contributing

Sprigo is built in the open, and the easiest way to help needs no code: courses are plain YAML files in [`courses/`](courses/) that list units, vocabulary and grammar, and the AI writes the exercises. Adding A2 to Spanish, French, German or Turkish, or starting a new language, is a great first contribution. See [Writing a Course](https://github.com/ozerozdas/sprigo/wiki/Writing-a-Course).

Pick a [good first issue](https://github.com/ozerozdas/sprigo/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22), and read [CONTRIBUTING.md](CONTRIBUTING.md) for setup and workflow. Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
