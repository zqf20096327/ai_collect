# 📽️ PPT-to-Video Agent

An application that **converts PowerPoint slides into videos** with automated voice narration or text-to-speech explanations.  
This tool can be used to quickly generate narrated video presentations from `.ppt` or `.pptx` files with minimal manual effort. :contentReference[oaicite:1]{index=1}

---

## 🧠 Project Overview

The **PPT-to-Video Agent** helps automate the process of creating engaging lecture or presentation videos from PowerPoint slides by:

✔ Converting each slide into a video frame  
✔ Adding voice narration or text overlays  
✔ Providing a streamlined workflow for video generation  
✔ Supporting AI-based narration through text-to-speech (if configured)

> *The project primarily consists of Python backend code and HTML templates for the UI.* :contentReference[oaicite:2]{index=2}

---

## 🛠️ Technologies Used

- 🐍 **Python** – Core programming language  
- 🧠 **AI/ML (optional)** – For enhanced narration or explanation generation  
- 📄 **HTML/CSS** – UI templates for front-end rendering  
- 📑 **PPT input** – Uses `.ppt` and `.pptx` source files  
- 🎤 **Text-to-Speech** – Integrated narration feature
