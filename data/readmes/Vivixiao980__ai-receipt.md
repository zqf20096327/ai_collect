# AI 小票｜今天没白干

任务结束后，给你的 AI 协作打一张「老板视角」的复盘小票。

[在线体验](https://today-not-wasted.vercel.app/) · [使用说明](https://today-not-wasted.vercel.app/guide.html) · [查看 Skill](./SKILL.md)

![AI 小票预览](./docs/assets/ai-receipt-preview.png)

## 为什么做它

Vibe coding 和 Agent 让产出变得很快，但人的理解速度没有一起变快。为了赶结果，我们很容易主动放弃一部分审查权：东西做出来了，却不清楚 AI 为什么这样做、哪里已经验证、留下了什么方法，以及下一次该怎样派活。

AI 小票想把每次任务重新放回「老板视角」里审视：

1. **投入与产出**：花了多少 Token、时间和沟通成本，换回了哪些交付物与决策。
2. **经验与沉淀**：AI 如何定义和拆解工作，留下了什么 SOP、任务记忆、踩坑与交接材料。
3. **个人反馈**：你哪里问得好、带得好，哪里因为沟通不清走了弯路，下次怎样成为更好的 AI 老板。

它不是账单，也不是 AI 给自己写的表扬信。它更像一位有判断力的小秘书：既告诉你「今天真的没白干」，也帮你把一次偶然的成功变成可复用的做事方法。

## 它会生成什么

- 一张可浏览、打印、保存为图片的 HTML 小票
- Token 用量与 API 等价费用估算
- 基于消息、工具调用与文件变化的可观察工作路径
- 投入产出、退款项、小费项、复核章与小 V 批注
- 可复用 SOP、任务记忆、踩坑提醒和下一次派活提示词
- Markdown、JSON 和纯文本证据材料，方便交接与二次加工

> AI 小票不会展示隐藏思维链。它只复盘可观察的目标、动作、证据、结果和阻塞。

## 安装

需要本地安装 Git 与 Codex：

```bash
git clone https://github.com/Vivixiao980/ai-receipt.git "$HOME/.codex/skills/ai-receipt"
```

重新打开 Codex 后即可使用。若你已经安装过旧版本，可以进入目录后执行 `git pull` 更新。

## 最短用法

完成任意一个 AI 任务后，直接说：

> 用小票复盘法复盘刚才的任务，放到桌面。

Skill 会自动读取最近任务的可用日志，在桌面生成一个完整复盘文件夹，并返回可点击的 HTML 小票。

如果同时开着多个任务，请带上关键词：

> 用小票复盘法复盘关于「网页改版」的那次任务，放到桌面。

## 内置展示案例

直接说：

> 用 AI 小票生成内置的「社媒营销研究」模拟案例，放到桌面。

案例模拟一位创业者请 AI 搜索适合产品的社媒营销话术和视频：已经获得选题、内容结构和宣发灵感，但产品 Key Message 仍未拍板，也还没有真正发布验证。小票会区分「已经获得的方向资产」与「尚未发生的增长结果」。

[打开公开案例](https://today-not-wasted.vercel.app/)

## 数字怎么理解

- **Token 与工具记录**来自任务日志，可获得多少取决于当前客户端暴露的日志信息。
- **模型费用**按公开 API 单价估算，是 API 等价费用，不是 Codex 或 ChatGPT 的真实订阅账单。
- **AI 活跃时间**根据日志活动间隔估算，会排除跨天和明显的长时间空闲。
- **真人基线、节省价值和净价值**是用于启发讨论的粗略估算，不是真实雇佣报价。

## 输出文件

默认生成到 `~/Desktop/AI老板小票/日期-项目名/`：

- `AI老板小票.html`：完整可视化复盘
- `复盘证据.md`：便于阅读和交接的摘要
- `复盘证据.json`：结构化复盘数据
- `文本小票.txt`：适合粘贴到聊天或周报

更完整的调用方法、参数和边界见 [中文使用说明](./docs/使用说明.md)。

## 隐私与边界

- Skill 默认只在本地读取 Codex 任务日志并生成本地文件。
- 不会自动上传真实对话、日志或复盘结果。
- 公开案例中的创业项目、Token、费用、研究过程和结果均为模拟数据。
- 当前需要在任务结束后主动调用；未配置完成钩子时，不会自动为每段对话打票。
