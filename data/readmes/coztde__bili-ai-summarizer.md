# Bili AI Summarizer · B站 AI 视频总结助手

仓库名称：`bili-ai-summarizer`。详细总结在插件界面中称为“完整笔记”。

把 B站视频变成可回看的知识笔记：快速总结、章节导航、术语金句，一键保存到 Obsidian。

一个开源的 Microsoft Edge 浏览器插件，使用你自己配置的大模型 API Key。优先读取 B站中文字幕，字幕不可用时，可由你主动选择语音转写（ASR）。

**插件本身免费开源；模型总结和 ASR 转写可能产生服务商费用，需要使用你自己的 API Key。**

> 当前版本：0.1.5，早期预览阶段。面向桌面版 Edge，尚未上架 Edge 扩展商店。项目与哔哩哔哩及各模型服务商无隶属或授权关系。

## 能做什么

- **快速总结**：提炼视频主题、结论、术语和金句，帮助判断是否值得继续观看。
- **完整笔记**：增加按话题划分的章节、思维导图和质量提示；点击时间戳回看原视频。
- **字幕与语音转写**：支持受支持的中文 AI / 普通中文字幕；无字幕时可主动使用 ASR 转写并总结。
- **自选模型**：支持 DeepSeek、阿里云百炼、硅基流动、智谱 GLM 和自定义兼容接口。
- **多视频任务与缓存**：总结和 ASR 各最多并发 2 个，切换视频不主动取消任务，结果保存到对应视频。
- **本地沉淀**：搜索字幕、下载 SRT、导出 Markdown，或保存到自己的 Obsidian Vault。

### 两种总结模式

| 内容 | 快速总结（默认） | 完整笔记 |
| --- | --- | --- |
| 一句话结论、详细摘要、标签 | ✓ | ✓ |
| 术语与解释，最多 10 个 | ✓ | ✓ |
| 金句与时间戳，最多 5 条 | ✓ | ✓ |
| 章节、要点和关键词 | — | ✓ |
| 思维导图与质量提示 | — | ✓ |

导出内容跟随当前选择的模式。快速总结可以复用已缓存的完整笔记基础内容，但不会把完整章节一起导出。

## 安装：从 GitHub Releases 下载

**普通用户不需要安装 Node.js，也不需要自己编译。**

1. 打开本仓库右侧的 **Releases**，在目标版本的 **Assets（附件）** 中下载 **`dist.zip`**。
2. **不要下载 `Source code (zip)` / `Source code (tar.gz)` 当作安装包**；也不需要下载供维护者核验的 FFmpeg 源码材料包。
3. 解压到固定文件夹。后续使用时请保留该文件夹，不要删除或移动。
4. 在 Edge 地址栏输入 `edge://extensions`，开启 **开发者模式**。
5. 点击 **加载解压缩的扩展**，选择直接包含 **`manifest.json`** 的文件夹；不要选择 ZIP 文件或它的上级目录。
6. 打开或刷新 B站视频页面，从浏览器扩展菜单点击本插件，打开侧栏。

如果 Releases 中还没有 `dist.zip`，说明该版本尚未提供构建包，请等待维护者上传；开发者可按文末说明从源码构建。本文提供安装方法，不代表当前仓库已经有可下载的 Release。

**从 GitHub 下载仍需开发者模式，不等于扩展商店安装。** 安装规则见[微软官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。

### 更新插件

下载新版本 `dist.zip`，将其中的文件替换到原来的插件文件夹，然后在 `edge://extensions` 点击插件的 **重新加载**，并刷新已经打开的 B站页面。不需要先卸载插件，以免丢失本地配置和缓存。

## 首次配置

打开侧栏右上角的齿轮，进入设置。

1. 在 **AI 总结模型** 中选择服务商，填写自己的 API Key；预设地址和模型可按需调整。
2. 点击 **保存并设为当前模型**，再 **测试连接**。请确保服务商账户、模型权限和额度可用。
3. **ASR 配置是可选的**：只有想转写没有字幕的视频时，才需要另行配置语音转写服务和它的 API Key。

LLM Key 用于文本总结，ASR Key 用于音频转写，两套配置独立。自定义接口需要兼容相应的 OpenAI Chat Completions 或音频转写协议，并允许插件访问该服务地址；不是任意模型和接口都能通用。

**插件开源不等于模型调用免费。** 费用、额度和网络可用性取决于你选择的服务商；测试总结模型连接也会发送一个很小的真实模型请求。

## 开始使用

1. 打开 B站视频，确认侧栏显示的视频与分 P 正确。
2. 点击 **获取视频字幕**。部分视频需要先在播放器开启“中文 AI”或已有的普通中文字幕，看到字幕后再重新获取。
3. 选择 **快速总结** 或 **完整笔记**，点击对应的生成按钮。
4. 没有可用字幕时，可点击 **使用 ASR 转写并总结**；转写成功后会继续总结，无需再点一次。没有配置 ASR 时会引导你去设置。
5. 阅读结果、点击时间戳回看，或下载 SRT、导出 Markdown、保存到 Obsidian。

重新生成总结会复用已有字幕或转写文本，不会重新产生 ASR 转写请求。刷新 B站字幕需要单独点击“重新获取 B站字幕”。

### ASR 与长音频

- ASR 支持 Groq 和兼容转写接口，只有你主动选择时才上传当前分 P 的音频。
- 当前插件单次上传上限为 **25 MB（25,000,000 字节）**。未超限直接上传，不额外压缩。
- 超限时可主动选择 **省流量压缩后转写并总结**：先在本机压缩，再检查实际大小；仍然超限则提示并停止，**不会自动切段**。
- 待压缩原文件最多 **250 MB**。压缩可能需要数分钟，也可能影响识别精度；服务商还可能有更低的账户或接口限制。
- ASR 失败后不会继续调用总结模型。

### 保存到 Obsidian

在设置中选择已经作为 Obsidian Vault 使用的文件夹，插件会在其中的 `Bilibili AI Notes` 目录保存 Markdown。同名文件会增加序号，不直接覆盖已有笔记。

如果点击“打开 Obsidian”提示 `Vault not found`，先确认该目录已在 Obsidian 中作为仓库打开，且仓库名称与所选目录名称一致；这不代表文件保存失败。

## 常见问题与限制

**为什么已经打开视频，还是获取不到字幕？**

确认当前视频能正常播放；必要时登录 B站，在播放器手动开启中文轨道，等待画面真正出现字幕后重新获取。刚更新过插件时，还要刷新 B站页面。仍无可用字幕时，可主动使用 ASR。

**出现 429、超时或模型输出截断怎么办？**

先确认是字幕、ASR 还是总结阶段出错。字幕阶段的 429 来自 B站，模型阶段的 429 来自所选服务商；不要连续点击重试。检查网络、服务额度或模型输出限制后再手动重试，插件不保证所有模型及视频长度都能成功。

**切到另一个视频，任务会停止吗？**

不会因切换视频或关闭侧栏主动取消，后台会继续处理并保存到对应视频。需要停止时请点取消；浏览器完全退出或后台意外终止后不保证继续执行，也不会自动重试已中断的计费请求。

**能总结全部分 P、画面和 PPT 吗？**

目前一次任务只处理当前分 P，输入是字幕或语音转写文本；不自动总结整套视频，也不识别仅出现在画面、PPT、弹幕或评论中的信息。当前以中文总结为主，不提供自动翻译。

**缓存会一直保留吗？**

缓存保存在本机，默认最多 50 个视频工作区、8 MB 软容量预算，可能因容量限制被淘汰，不是永久备份或跨设备同步。重要内容请导出。总结结果是 AI 辅助笔记，仍可能遗漏或误解，请结合原视频核对。

## 隐私与费用

- 字幕和转写文本会发送给你选定的总结模型；视频音频仅在主动选择 ASR 后发送给转写服务。
- 不经过项目方中转服务器。API Key 保存在本机，调用时会发送给对应服务商；第三方如何保留数据由其政策决定。
- B站登录 Cookie 不会发送给模型或 ASR 服务商。插件不录制麦克风或标签页，不自动在无字幕时发起计费转写。
- 取消排队任务可避免请求发出；已送达服务商的运行中请求，即使取消仍可能计费。
- 下载 Markdown、SRT 和保存 Obsidian 本身不调用模型。详细数据与权限边界见 [SECURITY.md](SECURITY.md)。
