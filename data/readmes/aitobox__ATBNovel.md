# 艾特智能写作工厂 (Aito Intelligent Writing Factory) 🚀

艾特智能写作工厂是一款专为史诗长篇小说创作而设计的**全自动、多智能体深度协同的 AI 写作与管理平台**。平台基于大语言模型（LLM）驱动，通过创新的**多幕场景迭代扩写**与**世界观/角色记忆数据库管理**机制，能够一键将几百字的核心故事大纲，转化为结构严谨、细节丰满、风格统一的十万字乃至百万字的长篇大作。

## 🌟 核心特性

- **大纲切分与任务编排**：系统能够自动分析用户输入的核心小说大纲，并将其切分为结构清晰的章节任务队列（Chapter Task Queue），科学规划每章的卷名、冲突、出场角色与伏笔。
- **三阶段深度场景扩写**：摒弃传统 AI 一次性生成数千字的扁平化写法。每一章都严格分拆为 `环境引入与氛围铺垫`、`核心冲突与多轮对话`、`冲突收尾与高潮余韵` 三幕独立撰写，并在必要时自动执行深度扩写循环，确保字数达标且细节详实。
- **全书文风重塑/重写模式 (Full Novel Rewrite Mode)**：支持导入已有的完整小说或草稿（支持 `.txt` / `.md` / `.epub` 拖拽上传或长文本粘贴），内置章节智能切分与多编码自适应解析引擎（UTF-8/GBK/GB18030/Big5）。提供“逐章文风重塑/润色精修”与“反向大纲重构再创作”双子模式，支持篇幅缩放比例调节（0.5x~20.0x）与风格模版深度对齐，一键赋能老作品重塑与草稿精修。
- **项目克隆与二次分叉创作 (Project Clone & Fork Creation)**：支持一键将现有小说项目克隆为独立副本，完整继承原项目的大纲设定、流派标签、写作风格模版与模型配置，并自动重置生成进度为初始状态，克隆后自动打开配置修改面板，便于进行平行世界分叉构思与版本迭代。
- **智能文风与笔触模仿**：支持导入期望的文风样板段落（如：古龙风格、金庸风格、张爱玲风格、鲁迅风格等），让 AI 在写作过程中深度对齐样板的语调、句式结构和叙事张力。
- **全屏写作风格模版库与 CRUD 管理**：提供沉浸式模版卡片工作台，支持自定义模版的增删查改、关键字搜索、一键复制、重置默认预设；在小说创作表单中实现动态下拉联动，并支持将当前正文样板一键持久化保存为专属模版。
- **单章提示词定向修改与润色 (Chapter Prompt Revision)**：支持创作者对小说中的任意已完成章节进行精细化定向重写与修缮。创作者可输入自然语言提示词（如“强化雨夜氛围”、“丰富心理描写”、“精简对白节奏”等）或选用修章预设标签，指定大模型执行单章润色重写，并通过直观的左右双栏（Original vs Revised）对照视图检视字数变化与修改效果，一键原子采纳更新至 `master_novel.md` 全书手稿并实时同步世界观场记册记忆。
- **世界观记忆数据库**：在写作过程中实时提取并维护`核心角色动态`、`关键道具去向`、`情感关系线走向`和`剧情悬念状态`，并自动作为上下文输入下一章，彻底杜绝长文本创作中角色设定崩塌或“吃设定”的问题。
- **实时执行管线监控**：提供极具科技感的可视化看板。包含章节消费格子图、实时执行日志终端、手稿分段折叠预览器（支持一键收起/展开，只展示一二级标题大纲），以及记忆库动态查看卡片。
- **版本发布日志**：详见 [ReleaseNotes.md](ReleaseNotes.md) 了解各版本更新详情。

## 🛠️ 本地环境部署与运行指南

### 1. 基础环境要求
- **操作系统**：Linux / macOS / Windows
- **运行环境**：Python 3.8 及以上版本

```bash
git clone https://github.com/aitobox/ATBNovel.git
cd ATBNovel
```

### 2. 安装依赖库
在项目根目录下，使用 `pip` 安装所需的全部核心依赖：
```bash
pip install -r requirements.txt
```

### 3. 配置环境变量
在项目根目录下创建一个 `.env` 配置文件，并配置您的 LLM API 密钥和相关参数(我们以接入deepseek为例)：

```
cp .env.example .env
```

```ini
# 默认/首选模型配置 (不带任何引号，支持用英文逗号分隔配置多个模型)
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_API_BASE=https://api.deepseek.com
OPENAI_MODEL_NAME=deepseek-chat,deepseek-coder

# 支持配置多个额外模型，供 Web 界面选择 (可选，亦支持英文逗号分隔)
MODEL_1_NAME=gpt-4o,gpt-4-turbo,gpt-3.5-turbo
MODEL_1_API_KEY=sk-xxxxxx
MODEL_1_API_BASE=https://api.openai.com/v1

MODEL_2_NAME=claude-3-5-sonnet
MODEL_2_API_KEY=sk-yyyyyy
MODEL_2_API_BASE=https://api.anthropic.com/v1
```

> [!WARNING]
> 在配置 `.env` 文件时，请勿在键值两侧加任何单引号或双引号（例如用 `OPENAI_API_KEY=sk-...` 代替 `OPENAI_API_KEY="sk-..."`）。Docker 容器在加载环境参数时，会将引号本身作为 API 密钥的一部分读取，从而导致 401 认证失败。


### 4. 本地源码运行
执行以下命令启动 Web 管理平台：
```bash
uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```
启动成功后，在浏览器中访问：`http://127.0.0.1:8000` 即可进入控制台。

## 🛠️ Docker 容器化部署 (推荐)

本项目支持一键进行 Docker 部署。通过挂载 `projects` 目录，可以确保容器重启后生成的小说手稿与记忆库不丢失。

### 1. 构建镜像

```bash
git clone https://github.com/aitobox/ATBNovel.git
cd ATBNovel
```


在项目根目录下执行以下命令构建 Docker 镜像：
```bash
docker build -t aitobox/atb-novel:latest .
```

或者直接下载我们已经构建好的镜像:

```
docker pull aitobox/atb-novel:latest
```

### 2. 运行容器
1.  `cp .env.example .env`， 填入自己的KEY

2. 使用以下命令启动 Docker 容器：
```bash
docker run -d \
  -p 8000:8000 \
  --name atb-novel-factory \
  -v $(pwd)/projects:/app/projects \
  --env-file .env \
  aitobox/atb-novel:latest
```

*说明：*
- `-p 8000:8000`：将主机的 8000 端口映射到容器的 8000 端口。
- `-v $(pwd)/projects:/app/projects`：将宿主机当前目录下的 `projects/` 文件夹挂载到容器内，保证小说项目数据持久化。
- `--env-file .env`：直接读取宿主机上的环境变量配置文件（包含您的 API 秘钥配置）。

## 📖 平台使用指南

平台支持 **大纲原创模式** 与 **全书文风重塑/重写模式** 两种核心创作路径：

### 模式一：大纲原创模式（从零构思长篇）
1. 点击左上角 **“新建”** 按钮，选择 **“大纲原创模式”**。
2. **填写基本信息**：
   - 输入**小说名称**。
   - 设定**流派风格与风格笔触**（可直接在下方选择快速标签，如 `末世/诡异/单女主`，多标签以 `/` 分割）。
3. **规划字数与章节**：
   - 拖动滑块设置规划章节总数（5 - 100 章）与单章最低字数指标（1000 - 5000 字）。
4. **填入核心大纲**：
   - 在文本框中详细输入小说的故事大纲或背景设定。
5. **设定期望风格样板与模版库联动**：
   - 在下拉菜单中选择一个经典的作家文风模版（如**古龙风格**、**金庸风格**、**张爱玲风格**、**鲁迅风格**等），或者在此粘贴任意您自己期望模仿的短文片段。
   - 点击下拉框右侧的 **“管理模版库”** 即可快速切换到全屏模版管理视图。
   - 若在文本框中输入了满意的样板片段，可点击下方的 **“+ 将当前内容存为新模版”** 按钮快速将其保存至持久化模版库中。
6. 点击 **“一键开启自动化管线”**。

### 模式二：全书文风重塑/重写模式（已有作品重塑与精修）
1. 点击左上角 **“新建”** 按钮，切换顶部 Tab 至 **“全书文风重塑 / 重写模式”**。
2. **导入作品源文稿**：
   - **文件拖拽与上传**：支持直接拖拽或点击上传 `.txt`、`.md`、`.epub` 等格式的小说文稿文件。
   - **直接粘贴长文本**：支持在文本框内直接粘贴完整小说或粗糙草稿文本。
3. **智能解析与实时状态卡片 (Live Analysis Card)**：
   - 导入后系统自动触发智能解析，自适应 UTF-8 / GBK / GB18030 / Big5 / UTF-16 多种中文与国际编码。
   - 自动识别书名、总章节数与全书总字数，并在界面呈现 **解析状态卡片** 与可展开的章节列表预览（包含章节序号、标题、原文字数与开头摘要）。
4. **重写子模式与篇幅比例配置**：
   - **逐章文风重塑 / 润色精修 (`chapter_by_chapter`)**：严格保留原著核心情节走向与人物关系，逐章套用指定文风模版进行描写升级、场景扩写与笔触重塑。
   - **反向提取大纲并重构 (`reverse_outline`)**：先提炼原著故事主线生成结构化大纲，重新规划章节任务队列后重构创作。
   - **篇幅缩放比例滑块 (`0.5x ~ 2.0x`)**：自由调节重写后的篇幅目标（例如 1.0x 保持原篇幅，1.5x 深度扩写，0.8x 浓缩精简），系统将自动按原章节字数动态匹配生成字数区间。
5. **对齐目标写作风格 (Style Template Alignment)**：
   - 选择内置作家模版（如古龙武侠风、金庸豪放风、冷峻赛博朋克风等）或自定义样板片段，驱动 AI 深度重塑全书语言质感。
6. 点击 **“一键开启重写管线”**。

### 模式三：项目克隆与二次分叉创作（平行世界与衍生创作）
1. **触发克隆入口**：
   - **详情操作栏克隆**：在主界面选中任意现有项目，点击上方操作栏中的 **“克隆项目”** 按钮。
   - **侧边栏快捷克隆**：在左侧项目列表中，悬浮并点击项目右侧的克隆图标按钮快速唤起。
2. **确认克隆与命名**：
   - 在弹出的克隆对话框中输入新小说名称（系统默认预填 `原书名 (副本)`）。
   - 弹窗中提供明确继承说明：新项目将完整继承原项目的所有大纲设定（`docs/`）、流派标签、写作风格模版、模型选择及导入的重写文稿，同时重置生成进度为第 1 章初始状态。
3. **二次创作与无缝编辑**：
   - 点击 **“确认克隆”** 后，系统在服务端原子化完成工程隔离复制，前端自动切换选中新项目，并**自动唤起【修改配置】编辑抽屉**。
   - 创作者可立即调整新项目的剧情走向、篇幅章节、风格样板或模型，实现一键平行世界分叉创作。

### 模式四：单章提示词定向修改与润色 (Chapter Prompt Revision)
1. **触发修章入口**：
   - **手稿阅读器章节卡片**：在右侧【最新手稿预览】中，每一章折叠卡片右上角均提供 **“🤖 AI 修章”** 按钮，点击即可唤起修章工作台。
   - **章节任务网格**：在【章节编排大纲与任务消费状态】网格中，点击任意已完成（绿色）的章节方格，亦可快捷唤起该章节的定向修改。
2. **输入修改要求与预设标签**：
   - 系统自动加载该章节当前标题与最新正文。
   - 在修改要求框中输入自然语言提示词，或点击下方的常用快捷标签（如 `【强化环境渲染】`、`【丰富心理描写】`、`【精简对白节奏】`、`【增加悬念反转】`、`【增强武戏打斗】`、`【提升文风契合度】`、`【优化章节收尾】`）。
   - 支持按需选择用于本次润色重写的 LLM 模型。
3. **智能生成与左右双栏对比预览**：
   - 点击 **“开始智能修改”**，AI 将结合项目设定、上下文记忆与文风样板执行定向重写。
   - 生成完成后自动进入双栏对照视图：左栏展示原始章节正文与原字数，右栏展示润色修改后的新文稿与新字数，顶部清晰呈现字数差额变化（如 `+120 字`）。
4. **原子采纳与全书同步**：
   - 点击 **“✨ 采纳并更新到全书手稿”**：系统将原子化安全替换 `master_novel.md` 中的对应章节内容，自动更新任务队列字数，并触发世界观场记册（ScriptSupervisor）同步增量提取记忆，手稿阅读器将无缝热更新呈现。
   - 若对效果不满意，可点击 **“🔄 调整要求重试”** 返回重新补充修改要求，或点击 **“放弃修改”** 安全退出。

### 执行管线监控与最新手稿预览
- **章节编排大纲与任务消费状态**：每个方格代表一个章节任务，悬浮即可查看本章大纲摘要与伏笔要求。灰色代表等待，紫色闪烁代表正在创作，绿色代表已完成。
- **实时执行管线监控终端**：实时输出 AI 创作时的调用日志与运行状态。
- 点击 **“启动管线”**（或暂停），即可开始自动连载生成/重写。
- **最新手稿预览与记忆库**：
  - 点击每一章折叠卡片，可查看具体正文。
  - 支持 **“展开全部章节”** 或 **“收起全部章节”**。点击“收起”后，正文会完全隐藏，仅保留一二级标题的清晰大纲视图。
  - **世界观记忆数据库**：在右下角实时展示提取自已生成章节的角色状态、最新位置、物品所有权变动以及剧情关系。
  - **导出文稿**：点击右上角 **“导出小说文稿”** 按钮，可一键下载格式标准的 Markdown 版小说手稿（`master_novel.md`）。

## 🔌 RESTful API 接口参考

系统提供丰富、标准的 RESTful API 接口，涵盖小说文本智能解析、项目与管线生命周期管理、以及写作风格模版库的 CRUD 操作。

### 1. 长篇小说智能解析接口

#### 预解析小说文稿 (支持 JSON 文本或文件上传)
- **URL**: `POST /api/novel/parse`
- **说明**: 接收长篇小说文稿文件（`.txt` / `.md` / `.epub` 等）或纯文本内容，自适应编码（UTF-8, GBK, GB18030, Big5, UTF-16），自动识别书名、切分章节、统计字数并提取预览摘要。
- **请求格式一 (JSON 请求体)**:
  ```json
  {
    "raw_text": "第一章 风起云涌\n\n夜色如墨，狂风呼啸...\n\n第二章 暗夜追踪\n\n雨水打在青石板上...",
    "filename": "剑道独尊.txt"
  }
  ```
