## 产品介绍

**把网页翻译，做回一件纯粹的小事。**

Chrome 和 Edge 上简洁版的“沉浸式翻译”。不臃肿，只把心思花在你正在读的网页上。

不做视频和 PDF 翻译，也没有账号系统。装好就能免费用，想译得更讲究，就配上自己的模型。

## 功能

### 随处翻译

- **整页翻译**：按 `Alt+A` 或在右键菜单里一键翻译，再按一次恢复原文。
- **双语对照**：原文译文对照，或只看译文，按 `Alt+W` 随时切换。
- **选中翻译**：选中文字按 `Alt+S`，在原位翻译所在段落。
- **输入框翻译**：写完按 `` Alt+` ``（Mac 为 `` Option+` ``）直接换成译文，快捷键可以自定义。
- **悬停翻译**：按住按键，指到哪段就翻译哪段。
- **划词浮窗和悬浮球**：按自己的习惯开启，随手可用。

### 阅读不打扰

- **保留排版**：链接、加粗、斜体、行内代码和小图标都留在原来的位置。
- **边读边译**：滚动到哪里翻译到哪里，长页面和无限滚动同样流畅。
- **避开视频**：自动识别播放器，全屏时不出现任何浮层。
- **译文样式**：11 种样式，颜色、大小和 CSS 都能调整。
- **深浅主题**：跟随系统，也可以手动选择。

### 自由选择模型

- **免费翻译**：内置 Google 和微软翻译，无需配置，一个出错自动换另一个。
- **多种接口**：支持 OpenAI 兼容、Anthropic 兼容、DeepL 和 DeepLX。
- **模型池**：多个模型故障切换或轮流分担。
- **多个 API Key**：可以轮流使用，失效时自动换用其他 Key。
- **按功能选择**：网页、划词浮窗、输入框和页面读取可以各用各的模型。

### 译得更准

- **翻译风格**：内置技术、学术、新闻、财经、法律、医学、文学等 11 种风格，也可以自己创建。
- **智能上下文**：大模型先了解页面主题和关键术语，再结合前文翻译。

### 按网站定制

- **自动翻译**：按网站或页面语言自动开始翻译。
- **网站规则**：为不同网站设置模型、语言、风格、样式和翻译范围。

### 用量一目了然

- **译文缓存**：相同内容直接显示，不重复花费额度。
- **用量统计**：按日期、用途和模型查看调用次数、Token 和估算费用。

### 中英文界面

- **自动跟随**：首次使用时按浏览器语言显示中文或英文。
- **随时切换**：在“更多设置”里切换，立即生效。
