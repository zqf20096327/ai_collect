## 你是不是也遇到过

**写简历的时候**

- 突然被裁，准备重新找工作，不知道简历上的项目怎么写
- 三年前做的项目，现在只剩一句「负责订单模块」，QPS 多少、踩过什么坑全忘了
- 简历项目过于普通，想优化却不知道从哪下手
- 在一个大项目里只担任了小角色，想吃透它、写进简历

**面试之后**

- 面试完当天还记得七七八八，三天后只剩一句「好像问了个分布式锁」
- 想复盘总结，手上却没有任何数据，全凭印象
- 想把每次面试都记录下来转成文本，便于之后分析
- 面试记录零散，没人管理，没有统一入口
- 同一道题，在 A 公司答得磕巴、在 B 公司答顺了，却没有任何东西记下这个差异
- 某一次答得特别好，想让后面每一次都按那个结构来

**练习的时候**

- 想拿自己的简历和项目做模拟面试，而不是背通用题库
- 想摸清自己八股文到底掌握到什么程度
- 找人陪练要欠人情，而且对方并不了解你的简历

**用工具的时候**

- 同一套提示词应付不了后端岗和产品岗，闭源工具连它怎么问你的都看不见，
  答得不对也不知道往哪调
- 简历、项目细节、面试录音是求职者手里最敏感的一批数据，却要交给一个
  不知底细的服务

这些就是 beacon 要解决的事。

## 这是什么

一个 Windows 桌面应用，把你的面试从「过完就忘」变成「可以复用的资产」。

三年前做的那个项目，现在让你讲，大概只剩一句「负责订单模块」。QPS 多少、
当时踩过什么坑、为什么那么设计——全忘了。简历上那一行，你自己都撑不起来。

面试也一样：上周被问倒的那个问题，这周换一家公司又被问一遍，你还是没准备好。

beacon 做的就是把这两件事接起来。

## 主要功能

### AI 帮你整理项目素材

> 对应痛点：不知道简历项目怎么写 / 项目太普通不知从哪优化 / 大项目里只做了一小块

大多数人的项目没有文档，靠回忆写简历必然干瘪。beacon 提供整理提示词，
粘到你平时用的 AI 助手（Claude Code / Cursor / 豆包都行）里，**它会先把你的
代码仓库读一遍**，自己提取技术栈、模块职责、关键实现——这些代码里都有，
不需要你回忆。

然后它只问代码里查不到的部分：业务背景是什么、你负责哪一块、上线后的数据如何。

**问不出来的地方会留一个「待补充」标记，明确禁止编造数字。** 面试现场引用
一个编出来的数字，被追问一次就穿帮，那比没有这份资料更糟。

最后产出三份：**简历卡片、面试腹稿、深度解析**。腹稿和深挖两份拖进知识库，
面试时会被实时引用；简历卡片留着投简历用。

哪怕你在项目里只负责一小块，它也会把整个系统的上下文梳理清楚——
你才知道自己那块在整体里是什么位置。

![AI 帮我整理素材](images/ai-material.png)

### 面试全程记录

> 对应痛点：想把每次面试记录下来转成文本

面试官和你的声音分两轨采集，实时转写，自动区分说话人。不用记笔记，
不用事后回忆，这一场讲了什么逐字都在。

### 自动复盘报告

> 对应痛点：想复盘却没有数据，全凭印象 / 三天后只剩一句「好像问了个分布式锁」

这不是录音转文字——转写只是原料，报告是分析。面试结束后自动生成，
告诉你哪几个点答漏了、本该提却没提的知识点，以及这道题后面通常会追问什么。

![复盘报告](images/review-report.png)

### 面试记录管理

> 对应痛点：面试记录零散，没有统一入口

按公司、轮次归档，一面二面三面连成一条线。录音支持三声道切换
（混合 / 仅面试官 / 仅候选人）与 0.5x–2.5x 变速回放。

挂掉的那几场也留着——挂了才更需要复盘。

### 答题画像

> 对应痛点：某一次答得特别好，想让后面都按那个结构来 / 同一道题两家答得不一样，却没东西记下差异

选中你答得最好的那一场，提炼出四个维度：**内容资产**（你手上有哪些能反复用的
项目和案例）、**表达框架**（你习惯怎么组织一个回答）、**语气习惯**、
**自测验证习惯**。

激活之后，后面每一场面试，AI 给出的建议都会按这个框架来。
你答得最好的那一次，会变成后面每一次的模板。

### 模拟面试

> 对应痛点：想用自己的简历和项目练 / 想摸清八股文掌握程度 / 找人陪练要欠人情

八股文「看懂了」和「能开口讲出来」是两码事。AI 面试官**基于你自己的知识库
出题**，听你回答，然后顺着你的回答追问——答得虚的地方它会接着挖。

不用麻烦别人，也不用向一个不了解你简历的人从头解释你做过什么。
练完同样生成复盘报告，和真实面试的记录放在一起，掌握到什么程度一目了然。

### 提示词可以改

> 对应痛点：同一套提示词应付不了不同岗位，闭源工具连它怎么问你的都看不见

生成建议的、写复盘报告的、整理素材的——**每一处提示词都摆在那里，你能看见
全文，也能改**。内置模板可以直接用，也可以复制一份改成自己的，多个版本随时切换。

投后端和投产品需要的追问角度本来就不一样。对输出不满意时，你能直接改掉它的
指令，而不是只能忍着，或者对着一个黑盒猜它到底问了什么。

### 你的录音留在你自己电脑上

> 对应痛点：简历、项目细节、面试录音是最敏感的一批数据，却要交给不知底细的服务

面试录音**只保存在本机**，不上传服务器：

```
%LOCALAPPDATA%\Beacon\recordings\
```

录音里有声纹，是最敏感的一类个人信息，同时体积也最大（约 460 MB/小时）。
把它留在本地，是这两件事共同的答案。

代价一并说清楚：**换一台电脑就听不到之前的录音**。转写文本和复盘报告跟账号走，
任何设备登录都能看到——那些几十 KB 却最值得跨设备复用。

## 关于定位

beacon 面向**面试练习、模拟面试，以及明确允许使用 AI 辅助的场景**。

它的重心是「面试之后」——记录、复盘、把经验沉淀成下一次的准备，而不是
「面试之中」替你答题。请在你所处场景的规则允许范围内使用。

另外，线上面试请**佩戴耳机**：否则麦克风会串入对方的声音，说话人区分会失效。
