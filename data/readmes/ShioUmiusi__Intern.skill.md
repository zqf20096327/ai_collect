# Intern - 你的赛博实习生

[English](README.en.md) | **中文**

### Context is all you need

> 此处context 指结论依赖的前提，不是上下文窗口。
> 实习生为宣传标语非实际能力等级。
> need为设计目标非绝对情况。
> 本项目开发过程中没有任何实习生受到伤害，也没有蒸馏任何实习生。

**一个能出活、肯问、会列证据的 Agent 工作方法。**

大多数 agent 配置都在教模型“多干活”。结果是一个许愿机：接到模糊需求就猜，闷头做完，最后交出一团看起来像答案的东西；你问它依据，它找不到一条命令输出、一个文件行、你的一句原话。

`intern` 反着来。它不教模型更多任务，只教它像一个带得动的优质实习生那样工作：

- **能出活**：该交付就交付，话也是交付。
- **肯问**：缺前提就问；不把决策推回给你。
- **会列证据**：每个结论能指回来源；指不回的，标“推断”。

## 它解决的痛点

- 信息不足时，模型会编一个“听起来对”的前提，然后基于它给方案。
- 该问的时候不问，该查的时候不查，不该问的时候把决策推回来。
- “有趣，来自未来的版本”
- 结论说得很确定，追问来源时没有来源。


## 它是什么

一份可直接粘贴进 `AGENTS.md` 的工作方法参考。

不依赖框架，不配插件，不堆规则。它用短句和关键词，激活模型训练里已有的方法论——核心是假说演绎法：

> 观察 → 溯因提出假设 → 演绎出可检验的预测 → 找证据/反例 → 证伪或修正 → 结论。

## 它怎么工作

**工具箱**：Abduction、Falsifiability、Baseline / single variable / control、Pre-mortem、5 Whys、Occam's razor、First principles、Reversibility、Steel man、Bayesian。看到场景就用，不必展开。

**六句话**：取前提 · 授权内判断 · 越权先问 · 不装懂 · 别拖 · 别编。它们是方法论运行的条件，不是规则堆。

**激活，不是安装**：不写长篇解释，不配重插件。关键词点到，模型已有的方法论自己启动。

## 30 秒上手

把 [RULES.md](RULES.md) 复制进你的 `AGENTS.md`。没有别的步骤。

想要更短的版本，用 [examples/AGENTS.md](examples/AGENTS.md)。

## 适合谁

- 做真实工程的人：需求经常不完整，结论必须能追溯。
- 做运维、排障、研究的人：时间、版本、环境变量到处是坑。
- 任何被“闷头干完、最后交出一团烂泥”坑过的人。

## 它不做什么

- 不保证 100% 遵守：MoE 激活是概率性的，文档不是执行器。
- 不替代判断力：它让方法论更容易被调用，不替你做决策。
- 不假定你的环境：观察不到的量就标“未知”。
