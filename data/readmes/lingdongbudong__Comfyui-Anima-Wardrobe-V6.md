> **ComfyUI 自定义节点：ANIMA3 提示词随机生成器（V6）**
> 按五级 NSFW 档位随机组合出一整段提示词正文，直接喂给 Anima 出图工作流的「全局正文」节点。

## 一、它解决什么

源脚本 `ANIMA提示词生成器.html` 是个浏览器单文件工具，靠「复制 → 粘贴进 ComfyUI 节点」进入流程。
它有 90% 的资产可以直接搬，但有五个硬缺口：

| 缺口 | 源脚本现状 | 本插件 |
|---|---|---|
| 没有分级 | 只有 `SFW` / `NSFW` 两个按钮，一刀切 | **五级闸门**，逐级放开段落；低档绝不越界 |
| 盲抽后补锅 | `Math.random()<0.65` 先抽，抽完才打补丁，高档内容会漏进低档 | 候选池**先按档位收敛**，抽完再体检、超档回滚 |
| 权重不可调 | 一个写死的概率 | **三层权重**：段 / 字段 / 选项，`0` = 关闭，`3.0` = 必现 |
| 结果出不去 | 只留在浏览器 | STRING 直出，可复现、可批量、可审计 |
| 没有素材库 | 每次都是随机拼，想要"某个场景"只能碰运气 | **场景 524 / 服装 135 套 / 角色 2432**，可勾选、可收藏、可锁定 |

## 二、核心特性

| 特性 | 说明 |
|---|---|
| **五级档位闸门** | `sfw` / `suggestive` / `explicit` / `hardcore` / `extreme` / `不限`，与造型台 `AnimaNSFWGrader` 逐字对齐（有对拍测试钉住） |
| **三层权重** | 段、字段、选项各可调 `0–3`；中间值是相对倾向，`3.0` 是必现，`0` 是强指令 |
| **角色库 2432 位** | 勾选即锁定，人数标签自动联动；支持「每次自动换人」与「仅收藏内随机」 |
| **场景搭配 524 条** | 8 个页签：词库权重 / 角色库 / 服装库 / 场景搭配 / 姿势库 / 艺术构图 / 武器场景 / 特写搭配 |
| **服装库 135 套** | 11 类（含丝袜 / 制服 / 泳装 / NSFW），启用后整套接管，优先级 **角色预设 > 服装库 > 随机** |
| **成品自检 + 自动修复** | 17 条致命项 + 10 条风格项；另有一个独立节点可对**任意**提示词跑同一套判据 |
| **出图元数据注入** | 把正文写进 PNG 元数据，**不改你的工作流**；三类落点都写全以兼容各看图工具 |
| **确定性** | `seed >= 0` 时逐字节可复现（派生种子一律 `zlib.crc32`，不用会加盐的 `hash()`） |
| **零依赖 / 零联网** | 纯 Python 标准库 + 原生前端 JS；运行时不出网、不落盘到插件目录外 |

## 三、节点

分类 `AnimaWardrobeV6`，四个节点：

| 节点 | 作用 | 主要输出 |
|---|---|---|
| **Anima 提示词随机生成（V6）** | 主节点，抽一段完整正文 | `text` 标签串 · `report` 自检报告 · `level` 实际档位 · `cn_summary` 中文摘要 |
| **Anima 提示词分级审查（V6）** | 只判档，不改内容 | `text` 透传 · `num` 档位数字 · `level` 档位 key · `report` 明细 |
| **Anima 提示词拼接台（V6）** | 随机结果 + 手写补充合并 | `text` |
| **Anima 提示词检查与修复（V6）** | 对任意提示词跑自检并自动修 | `text` 修复后正文 · `report` · `level` · `num` |

主节点上另有四个按钮：`⚙ 打开随机面板` · `🔁 换种子` · `🎲 每次重抽` · `🧹 清空权重`。
面板里有 8 个页签，绝大多数设置都在那里配 —— **能在面板里配的项，节点上不重复外露**。

```text
┌─────────────────────┐
│ 提示词随机生成（V6） │──text──▶ CR Text（全局正文）──▶ CLIP ──▶ 出图
│  档位 / seed / 权重  │
└─────────┬───────────┘
          │ ⚙ 打开随机面板
          ▼
   8 页签面板（权重 / 角色 / 服装 / 场景 / 姿势 / 艺术 / 武器 / 特写）
```

> 旧版本的类名与路由（`AnimaV5*` / `AnimaV4*` / `AnimaV3*`、`/anima-wardrobe-v5|v4|v3/`）
> 全部保留为别名 —— **旧工作流照常打开，不用改一根线**。

## 四、安装

```bash
# 方式 A：git clone（推荐）
cd ComfyUI/custom_nodes
git clone https://github.com/lingdongbudong/Comfyui-Anima-Wardrobe-V6.git
```

方式 B：仓库页 `Code → Download ZIP`，解压到 `ComfyUI/custom_nodes/`，
**目录名保持 `Comfyui-Anima-Wardrobe-V6`**。

**不需要装依赖**（没有 `requirements.txt`），**不需要改配置**。放进去重启 ComfyUI 即可。

验证装好了没（不出图、不需要任何模型）：

```bash
curl --noproxy '*' http://127.0.0.1:8188/anima-wardrobe-v6/health
```

或在画布上拖入「Anima 提示词随机生成（V6）」，**什么都不接**直接 `Queue` ——
`text` 有内容、`report` 全 ✅ 就算通过。

## 五、快速上手

1. **拖节点**：双击画布搜 `Anima` → 拖入「Anima 提示词随机生成（V6）」。
2. **接线**：把 `text` 连到 CR Text 节点（节点 1004，全局正文）那个**空着的 `text` 输入端口**。
   拔掉线就回到手写文本框，两套随时切换。
3. **调档**：`nsfw_level` 从 `sfw` 起步，确认画面基调后再往上抬。
4. **要具体内容**：点 `⚙ 打开随机面板` —— 角色、服装、场景、姿势都在页签里勾选或套用。

⚠️ 前三步不涉及任何模型；真正出图需要 Anima 底模（2.9B / 29B）与对应工作流，
模型与 LoRA 不随本仓库分发。

## 八、常见问题

**节点列表里搜不到？** 看控制台启动日志。最常见是目录被改了名、或套了一层同名目录。

**档位选了 `sfw` 还有擦边？** 已知偏差在**湿发**：约 19% 的 SFW 输出会被造型台判成 2 档，
根因在判定表的 `^wet ` 模式，不是闸门漏了。

**同一个 `seed` 结果不同？** 服务端全局状态也参与抽取（当前启用的服装套、角色预设覆盖、
场景覆盖、收藏）。改代码必须重启 ComfyUI。

**双女出现两个一模一样的角色？** `duo_role_fill` 被关掉了，v6.6.0 起默认开。

**角色库里没有头像？** 缩略图 2432 张是随仓库分发的，正常 clone 就有。
缺图多半是浅克隆（`--depth`）或手动删过 `presets/thumbs/`，跑
`<ComfyUI>/python_embeded/python.exe tools/fetch_character_thumbs.py` 重抓即可。

其余 25 条见 [docs/USAGE.md · 八、常见问题 FAQ](docs/USAGE.md#八常见问题-faq)。

## 十、兼容性与已知限制

- **与 `Comfyui-Anima-Wardrobe`（造型台 v2.x）可同时安装** —— 类名、分类、路由全部分开。
- **旧工作流无需迁移** —— V5/V4/V3 的类名与路由保留为别名。
- **新增控件一律追加在 `optional` 末尾** —— 放 `required` 会让老 API 工作流整张输出被丢弃。
- **角色库不含男性**（可能有边界漏网，`tests/check_v3_chars.py` 持续盯）。
- **角色中文名覆盖率 61%** —— 剩下 39% 在公开图库里确实没有中文别名，显示英文原名。
- **场景库与服装库的「启用」是全局状态** —— 不是节点参数，批量出图前要确认。
- **未上架 ComfyUI Registry**。
