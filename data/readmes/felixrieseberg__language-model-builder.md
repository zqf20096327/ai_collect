# Language Model Builder

One of the best ways to understand technology, especially when it seems like magic, is to build a small version yourself. Language Model Builder explains the foundations behind AI and lets you build models from scratch. Choose a tokenizer and training data, watch the loss fall during pre-training, teach the model to answer questions, and end up chatting with something that exists nowhere but your own Mac.

**[languagemodelbuilder.com](https://languagemodelbuilder.com)**

## Download

Grab the latest notarized build from
[Releases](https://github.com/felixrieseberg/language-model-builder/releases/latest).
Requires an Apple silicon Mac running macOS 15 or later. The app updates
itself via Sparkle.
