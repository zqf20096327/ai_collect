# Codex CLI Guide

Practical step-by-step guide in setting up and reference for **Codex CLI general tools** with command-by-command usage, safety notes, and real examples.

## What this includes

1. Core commands (`codex`, `exec`, `review`)
2. Session continuity (`resume`, `fork`)
3. Cloud workflow (`codex cloud ...`)
4. CLI-level MCP management (`codex mcp ...`)
5. Sandbox/debug/app-server commands
6. Feature flags and global safety flags
7. Ready-to-copy command presets
