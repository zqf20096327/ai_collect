# Embodied Research Atlas | 自动驾驶与机器人技术全景

An interactive, bilingual knowledge map connecting research across autonomous driving and robotics, from data and training to execution and feedback.

一个中英双语交互知识地图，连接自动驾驶与机器人领域的研究脉络，覆盖从数据、训练到执行和反馈的完整链路。

**[Explore the atlas / 进入网站](https://weizhi-t.github.io/roadmap-for-autonomous-driving-and-robotics/)**

## Explore | 探索内容

- **[Interactive atlas / 交互全景图](https://weizhi-t.github.io/roadmap-for-autonomous-driving-and-robotics/#atlas):** Browse the research map by stage and method, then follow nodes to explanations and references. 按阶段和方法浏览研究地图，进入节点查看说明与参考资料。
- **[Reference library / 参考文献库](https://weizhi-t.github.io/roadmap-for-autonomous-driving-and-robotics/#references):** Find papers, author projects, code and official documentation. 查找论文、作者项目、代码与官方文档。
- **[Field notes / 研究导读](https://weizhi-t.github.io/roadmap-for-autonomous-driving-and-robotics/#news):** Explore selected research resources and context. 浏览精选研究资料与背景。

The research questions, arXiv, algorithm principles, and project reproduction sections are planned and do not yet contain published content. Automatic arXiv updates are not configured.

深度思考课题、arXiv 文章、算法原理和项目复现栏目仍在建设中，尚未发布内容；arXiv 自动更新尚未配置。

Switch between Chinese and English or filter by autonomous driving and robotics. Use the search button or press `/` to find topics and sources.

可切换中文与英文，按自动驾驶或机器人领域筛选；点击搜索按钮或按 `/` 查找主题和资料。

## Run locally | 本地运行

This is a static site. Clone the repository and serve its root directory with a local HTTP server, for example:

这是一个静态网站。克隆仓库后，在项目根目录启动本地 HTTP 服务，例如：

```bash
git clone https://github.com/Weizhi-T/roadmap-for-autonomous-driving-and-robotics.git
cd roadmap-for-autonomous-driving-and-robotics
python3 -m http.server 8000
```

Then open http://localhost:8000/ in your browser. / 然后在浏览器中打开 http://localhost:8000/。
