# PROS 06｜初五的公关与研究Skill

本仓库只发布当前版12个Skill及其随附参考资料。适用于能够读取`SKILL.md`的AI工具；按任务读取对应Skill目录即可。Skill不依赖创建者的本地路径或私人知识库状态。

## 12个Skill

### 公关

| Skill | 主要任务 |
|---|---|
| [annual-pr-strategy](Skills/PR/annual-pr-strategy/SKILL.md) | 制定全年媒体关系、舆情管理或综合公关战略。 |
| [copy-lens-review](Skills/PR/copy-lens-review/SKILL.md) | 审查广告、社媒、声明等内容在公共语境中的风险并提出修改方向。 |
| [hot-public-opinion-analysis](Skills/PR/hot-public-opinion-analysis/SKILL.md) | 研判外部事件的舆情走势、业务暴露与应对条件。 |
| [judgment-hub](Skills/PR/judgment-hub/SKILL.md) | 在专项分析后判断是否回应、发布、延期或采取其他行动。 |
| [media-narrative-analysis](Skills/PR/media-narrative-analysis/SKILL.md) | 分析单篇报道或文章建立的认知及其对企业的影响。 |
| [pr-contingency-plan](Skills/PR/pr-contingency-plan/SKILL.md) | 为尚可调整的品牌、产品或传播动作制定上线前预案。 |
| [press-release](Skills/PR/press-release/SKILL.md) | 将企业素材写成媒体可读、可引用的新闻通稿。 |

### 研究

| Skill | 主要任务 |
|---|---|
| [consumer-research](Skills/Research/consumer-research/SKILL.md) | 设计或分析消费者研究，并将研究证据转换为有边界的PR主张。 |
| [industry-media-research](Skills/Research/industry-media-research/SKILL.md) | 比较媒体如何理解和呈现行业议题，归纳样本内共识与分歧。 |
| [industry-research](Skills/Research/industry-research/SKILL.md) | 为行业进入、竞争定位等决策提供可复核的行业研究。 |

### 知识与情报

| Skill | 主要任务 |
|---|---|
| [follow-loop](Skills/Knowledge-Intelligence/follow-loop/SKILL.md) | 按使用者选定的问题持续跟踪、核验信息并复盘判断。 |
| [spoken-content-extractor](Skills/Knowledge-Intelligence/spoken-content-extractor/SKILL.md) | 从播客、演讲、访谈等音视频中提取转录、简报或可用洞察。 |

此前独立的消费者研究PR转换Skill已并入`consumer-research`，因此本版共12个Skill。每个目录内的`references`、脚本和共享研究资料属于对应Skill的配套内容。
