# Bome

一个纯前端的 **AI 角色语音聊天网页**。单个 HTML 文件，双击就能用，不需要服务器、不需要安装任何东西。

填入你自己的角色设定，就能拥有一个会说话、有记忆、会写日记、会主动找你聊天的专属 AI 角色。

---

## ✨ 主要功能

- **双语回复 + 语音朗读** — AI 同时用英文和中文回复，英文部分自动朗读（ElevenLabs 语音）
- **语音通话 / 按住说话** — 像打电话一样和 AI 说话
- **长期记忆** — 跨对话记住聊过的事，不是每次都失忆
- **日记系统** — 角色每天 20:00 自动写当天日记
- **表情包** — AI 会根据情境发你准备的表情包
- **小游戏** — 海龟汤、真心话大冒险、故事接龙、一起做饭
- **主动消息** — 角色会主动找你聊天
- **拉黑 & 求和** — 拉黑后角色会主动来哄你
- **回复条数控制** — 限制单次回复条数，省 token
- **联网搜索** — 问时效性问题时自动联网
- **喂食 / 换装 / 经期日历 / 一起听歌 / 角色扮演** — 各种趣味互动
- **看屏幕（视监）** — AI 能「偷看」你的屏幕并反应（仅网页端）
- **存档导出导入** — 数据可备份、可跨设备跨版本搬运

---

## 📦 五个版本，两种形态

同样的功能，五种不同的 AI 大脑，选你有 API Key 的那个：

| 版本 | AI 大脑 | 需要的 Key |
|---|---|---|
| **Claude** | claude-opus-4-6 / sonnet | Anthropic |
| **DeepSeek** | deepseek-v4-flash / pro | DeepSeek |
| **Gemini** | gemini-2.5-pro / flash | Google AI（免费） |
| **GPT** | gpt-5.5 / 5.4-mini | OpenAI |
| **Grok** | grok-4.3 / grok-4-fast | xAI |

每个版本都有 **网页端** 和 **手机端** 两个文件：

| | 网页端 `xxx模板.html` | 手机端 `xxx手机模板.html` |
|---|---|---|
| 适用 | 电脑浏览器 | 手机浏览器（电脑也能开） |
| 顶部按钮 | 一排横向按钮 | 收进「☰」菜单 |
| 看屏幕（视监） | ✅ 有 | ❌ 已移除（手机无法截屏） |
| 存档导出/导入 | — | ✅ 有（iPhone 必备） |

> 五个版本共用同一套存档格式，可以随时切换大脑，记忆和聊天记录都能带过去。

## 🚀 快速开始

1. 在 `files/` 里挑一个版本（看你有哪家的 API Key）
2. **先读对应的教程 `.md`**，里面有完整的填写说明
3. 用**文本编辑器**（VS Code / 记事本，**不要用 Word**）打开 `.html`
4. 把所有 `【...】` 占位符替换成你的角色设定
5. 按教程建好「记忆库文件夹」（含 `stickers/` 放表情包、`music/` 放音乐）
6. 保存，用浏览器打开，输入 API Key，开始聊天

## 🔑 你需要准备的

**必须：**
- 一个 AI 大脑的 API Key（上表五选一）
- ElevenLabs API Key + 音源 ID（语音合成，让角色能"说话"）
- 一个记忆库文件夹（自己新建，里面放 `stickers/` 和 `music/`）

**可选但推荐：**
- OpenAI API Key —— 语音转文字、语音通话
- Google AI API Key —— 长期语义记忆（免费）

> ⚠️ **所有 Key 都只保存在你自己的浏览器本地**，不会上传到任何地方。本项目没有后端服务器。

---

## ⚠️ 注意事项

- **手机上用语音通话/按住说话/通知，必须用 `https://` 网址打开**（浏览器安全限制），教程里有免费拿网址的步骤
- **手机适配需要自行微调**：各手机型号屏幕不同，模板提供通用方案，**填完人设后请在自己手机上测试并按需调整 CSS**（教程里有具体改哪里的对照表）
- **iPhone 不支持「文件夹记忆库」**（苹果限制），请用手机端的「存档导出/导入」代替
- **手机浏览器无法截屏**，所以手机端移除了「视监」功能
- 记忆库功能需要 **Chrome 或 Edge**（Firefox / Safari 不支持）
- API 调用会产生费用（Google AI 的记忆功能免费），请自行关注各平台计费
