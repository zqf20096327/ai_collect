# Compute Flow bricks

This repository contains the reusable building blocks called **bricks** maintained by Arm® for AI
and GenAI applications with [Compute Flow](https://github.com/ARM-software/compute-flow). It
includes brick implementations, model metadata, and the source registry used by the Compute Flow
Brick Manager.

All documentation, tutorials, how-to guides, and examples are maintained in the
[Compute Flow core repository](https://github.com/ARM-software/compute-flow).

[Start there](https://github.com/ARM-software/compute-flow/tree/main/docs) to install and run
bricks, build AI pipelines, or develop new bricks.
