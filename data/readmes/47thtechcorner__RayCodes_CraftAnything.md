## ⚡ Terminal Setup: Install & Launch MCP Server

Run this single PowerShell block in your terminal to clone the engine, compile the CLI binary, verify doctor check, and spin up the live MCP server daemon exposing all 320 tools:

```powershell
# Clone official repo, compile native CLI binary, verify doctor check, and spin up live MCP server
git clone https://github.com/storytold/craft-anything.git
cd craft-anything
cargo install --path apps/craft-anything-cli
craft-anything-cli doctor
craft-anything-cli mcp
```
