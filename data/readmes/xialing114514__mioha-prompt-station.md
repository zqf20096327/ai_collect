## 0.3 创作工作台

- **创作实验室**。把提示词片段存为卡片，组合后按变量批量生成。保留实际参数和种子，筛选、交叉或变异画风候选。
- **分镜与酒馆**。分镜按项目管理角色、画风、场景与画面，生成多张候选并选主图，可导出含设计和图片的 ZIP。酒馆支持角色卡、世界书、会话和创作方案版本。
- **工作流与图像工作台**。在「连接生图」管理 ComfyUI 工作流、参数与缺失依赖。图像工作台支持裁剪、格式转换、蒙版绘制，以及通过兼容工作流提交图片和编辑指令。
- **图库与参考素材**。预览自动适应窗口，支持滚轮缩放和拖动。生成组可收藏、分级和筛选，参考库区分普通参考、Vibe 与精准参考。
- **外部 Agent**。通过现有权限和会话调用组合、批量、画风、分镜、图像编辑和图库管理，继续由内置 AI 按模型 Skill 转换设计。

| 从哪里开始 | 在软件中完成什么 |

## 内置 AI：从描述到模型适用的提示词

![内置 AI 选词与模型 Skill 选择](assets/screenshots/built-in-ai.png)

内置 AI 是工作台的一部分，提供可直接操作的选词、检索和转换流程。它调用在线服务或用户配置的大语言模型，**安装包不包含本地大语言模型权重**。

- **自然语言选词**：中文描述画面，生成标签或完整英文描述，保留正向与负向结果。
- **读取真实本地配方**：查询内置角色与用户新建、编辑的角色，读取外观、服装和角色标签；已删除项不会继续作为可选配方。
- **按绘图模型适配**：Anima、MOSS、Krea 2、NoobAI、光辉 Illustrious、NovelAI 各自加载 Skill，支持手动选择、兼容组合及自定义模型。
- **本地资料检索**：查询已导入的角色、画师、标签、素材与模型知识，保留可用来源信息。
- **可选联网查证**：开启后按工具能力查询角色资料；配置支持看图的接口时可辅助识别参考图。关闭后使用快速、本地资料优先的流程。
- **继续修改**：可以多轮补充要求；结果可以复制、追加或替换到编辑器，也可以发送到生图界面。
- **免费与自定义接口**：内置免费通道默认选择 **NVIDIA: Nemotron 3 Ultra (free)**。自定义连接支持 OpenAI 兼容与 Anthropic Messages 协议，配置区可折叠，保存后记住配置。

免费模型的额度、速度与可用性由服务提供方决定。程序保留用户手动选择，不会在 Ultra 不可用时静默换成 Super VL；可用「恢复默认模型」切回 Ultra。

[阅读内置 AI 使用指南](docs/BUILT_IN_AI.md)

## 模型中心、LoRA 与 Skill

![各模型独立的 Skill 规则与编辑空间](assets/screenshots/skill-center.png)

**绘图模型分类**与**生图引擎**分别管理。Anima／MOSS／Krea 2／NoobAI／光辉／NAI 是模型规范；NeoForge／ComfyUI／NovelAI API 是执行方式。选择某个分类，不代表对应权重已经安装。

- NeoForge 与 ComfyUI 分开读取资源，显示引擎归属、底模兼容性和本地绑定状态。
- 模型及 LoRA 支持信息获取、预览、介绍、触发词、收藏、筛选、批量任务与组合配方。
- 本地资源通过已有元信息或哈希获取 Civitai 资料；支持 Civitai 与 civitai.red 链接。预览受内容模式及来源分级影响。
- LoRA 加载与触发词联动，支持逐项开关；保留两个引擎各自的参数和工作流要求。
- Anima、光辉、NoobAI、NAI、MOSS 二次元／真人、Krea 2 二次元／真人共八个独立 Skill 通道；自定义模型也有自己的目录。

0.2.3 新增首次路径向导：可自动查找常见引擎目录、原生选择文件夹，或直接填写自己的 LoRA 路径。选定后保存并读取。资源有独立的自定义分类，支持创建、重命名、归类和删除；「更新」检查来源新版本，不自动替换权重。

## 原始设计、内置 AI 与外部 Agent

![设计方案与提示词转换工作区](assets/screenshots/design-workspace.png)

外部 Agent 或用户完成创意设计，内置 AI 负责转换为目标绘图模型的表达。原始设计与转换结果分别保存，可查看版本、补充反馈和重新转换。

![本机 AI Bridge 与独立 Agent 管理](assets/screenshots/agent-bridge.png)

AI Bridge 提供 MCP、REST 与 SSE 接口，支持独立 Token、会话隔离、任务查询、追问恢复和权限确认。可配置实际底模、LoRA 与工作流，并管理本 Agent 的创作记录。安装目录附带独立 CLI／MCP 客户端，无需另装 Python。

## 连接生图与图片反推

![连接生图界面：引擎、提示词与参数配置](assets/screenshots/generation-center.png)

支持本机 NeoForge、ComfyUI 与已配置的 NovelAI API，提供提示词同步、模型与 LoRA 选择、任务状态、生成历史及程序内预览。NeoForge 与 ComfyUI 提供本次任务进度和实时预览；进度栏位于生成按钮下方，完成后自动收起。结果支持多图切换、复制图片、保存、原尺寸预览及按页载入的历史图库。MOSS 等特殊架构需要匹配的模型组件和工作流。

反推按以下顺序处理：

1. **图片含生成元数据**：读取文件里的原始提示词、底模／LoRA 及可用参数。
2. **图片没有元数据**：使用已安装的本地 WD14 模型；也可手动选择已配置的视觉接口。

> **WD14 必须准备配套文件。** 只有一个 ONNX 模型文件不够：同目录还需要同一模型版本的 `selected_tags.csv`。安装包只提供插件，不附带模型，也不自动下载。

[**查看 WD14 下载与放置教程**](docs/WD14.md)

## 0.2.4：实时进度与图片浏览

- ComfyUI 通过本机事件流更新当前节点进度，支持新版节点状态事件；NeoForge 显示本次任务的排队、采样及完成状态。
- 未知进度阶段显示等待，不显示来回摆动的假百分比。采样与接收图片分开提示，完成后自动收起进度栏。
- 生成结果提供上一张／下一张、复制、保存、放大与原尺寸查看；展开历史图库按需浏览本地缩略图。
- 折叠图库后停止请求；后台面板不再反复读取整批图片 Base64。增加轻量过渡，遵循系统的减少动态效果设置。
- 内容模式入口使用柔和底色与细边框，保留清晰的开启、悬停与不可用状态。

## 内容显示与安全模式

默认使用安全模式，隐藏标记为 NSFW 的标签、资料和未确认安全的预览。

- 首次可在左侧点「解除 NSFW 限制」，阅读说明并选择取消或明确确认。
- 确认后，侧栏不再保留该入口；之后通过「设置 → 内容显示」切换。
- 「解除 AI 限制」按钮须全局解锁后才可用；它控制软件自己的 AI 内容偏好，不改变服务提供方的规则。
- 安全模式不会删除原来的资源和创作数据。分级与标签筛选不等于图像内容识别，仍需自行核对导入和生成的素材。

## 页面帮助与自主控制

各页面右上角提供圆形问号：悬停说明、点击查看作用与操作步骤。外部 Agent 可以通过 `list_pages`／`get_page_help` 读取同一份介绍。

![页面功能帮助](assets/screenshots/page-help.png)

Agent 可按真实资源 ID 选择底模、多 LoRA、各自权重和工作流，等待配置成功回执后发起生图。自主确认限于自己的已授权请求；也可以在 AI Bridge 切回始终由用户确认。旧 MCP 客户端需重连并使用随新版软件提供的接入工具。

## 开始使用

1. 从 [最新 Release](https://github.com/xialing114514/mioha-prompt-station/releases/latest) 下载 Windows 安装包；校验值在同页 `SHA256.txt`。
2. 自选安装目录，可创建桌面快捷方式。需要 **Windows 10/11 x64** 与 **Microsoft Edge WebView2 Runtime**。
3. 打开软件即可使用本地选词、角色配方等功能。使用 AI 时选择免费通道或配置自己的接口。
4. 需要生图时，再启动对应引擎或配置自己的 NovelAI 凭据；需要 WD14 时按教程安装配套模型文件。
