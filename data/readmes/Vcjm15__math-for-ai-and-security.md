# 从高中数学，走到 AI 与密码学

> 一份写给**高中毕业生**的数学学习路径，外加一整套零基础网络安全与密码学教程。
> 全部内容在一个 HTML 文件里，可以在浏览器直接打开、点、拖、看。

🔗 **在线预览：<https://vcjm15.github.io/math-for-ai-and-security/>**

---

## 这是什么

网上讲「学 AI 要什么数学」的文章很多，但它们几乎都默认你已经修完了大学的高数和线性代数。这份材料不是。

它做了一件不同的事：**先诚实地告诉你，高中和大学之间有一道断层**——高中数学重在"算"，大学数学重在"证"，这是两种完全不同的肌肉。然后再把这条路径一段一段铺出来。

全书分两部分：

- **第一部分 · 数学**（9 章）：从断层补起，经四阶段走到 AI 与安全的分叉点
- **第二部分 · 网络安全与密码学**（9 章）：从零开始的完整教程，不假设任何前置知识

---

## 第一部分：数学路径

路线按「连续数学 vs 离散数学」这条分界线组织——AI 靠前者，安全靠后者，而概率论、信息论、复杂性理论是两者的交汇点。

| 章节 | 内容 |
|---|---|
| 第 0 章 · 先补断层 | 高中到大学之间缺的是什么，怎么补（逻辑与量词、三种证明法、记号升级） |
| 第一阶段 · 基础 | 离散数学、微积分、线性代数 |
| 第二阶段 · 核心 | 概率统计、初等数论、最优化 |
| 第三阶段 · 分叉 | AI 侧：信息论、矩阵分析、随机过程 / 安全侧：抽象代数、椭圆曲线、计算复杂性、格理论 |
| 第四阶段 · 交叉 | 差分隐私、对抗 ML、隐私计算 |

**时间预估是诚实版的**：第 0 阶段 2–4 周，第一阶段 4–6 个月，走完整条路径约 2 年（每天 1.5–2 小时）。从零补矩阵和证明本来就需要这么久，这不是打击。

## 第二部分：从零开始的网络安全与密码学

| 章节 | 讲什么 |
|---|---|
| 1 · 先搞清防什么 | CIA 三元组、威胁模型、Kerckhoffs 原则、四个常见误区 |
| 2 · 古典密码 | 凯撒、单表替换、频率分析、维吉尼亚、一次性密码本 |
| 3 · 对称加密 AES | 混淆与扩散、S 盒的数学构造、ECB 为什么不行 |
| 4 · 哈希与认证 | 三条性质、生日攻击、HMAC、密码存储的三层攻防 |
| 5 · 公钥密码 | 密钥分发问题、Diffie-Hellman、RSA、椭圆曲线、中间人 |
| 6 · 签名与证书 | 数字签名、CA 与证书链、信任的根在哪里 |
| 7 · TLS 协议 | 六步握手、混合加密、前向保密 |
| 8 · Web 安全 | XSS、SQL 注入、CSRF、越权、SSRF——以及它们的共同本质 |
| 9 · 网络攻防与心法 | 渗透测试五阶段、七条安全思维、从零上手路线 |

第二部分贯穿始终的一条主线是：**几乎所有 Web 漏洞都是同一个错误——把「数据」当成了「代码」**。

## 十一个动手实验

页面里嵌了十一个可以真正拖动的实验台。这是这份材料和普通电子书最大的区别。

**数学部分（6 个）**

| 实验 | 在哪儿 | 能玩什么 |
|---|---|---|
| 线性变换与行列式 | 线代 | 拖四个滑块看平面怎么被拉伸；把 det 拖到 0，平面被压成一条线 |
| 梯度下降 | 最优化 | 调学习率看它收敛 / 震荡 / 发散；含非凸双谷地形 |
| 扩展欧几里得 | 数论 | 点「下一步」看算法一步步走，最后自动算出模逆元 |
| RSA 全流程 | 数论 | 改 p、q、e、m，看 n → φ(n) → d → 加密 → 解密 |
| 生日悖论 | 概率 | 拖人数看碰撞概率曲线，23 人过半 |
| 熵与 KL 散度 | 信息论 | 滑块调节分布，看「交叉熵 = 熵 + KL」实时成立 |

**安全部分（5 个）**

| 实验 | 在哪儿 | 能玩什么 |
|---|---|---|
| 凯撒与频率分析 | 古典密码 | 拖滑块直到密文变回英文；「自动破解」演示攻击者只靠频率就能破 |
| AES 的一轮 | 对称加密 | 按顺序点四个按钮，橙色格子标出被改动的字节，看扩散怎么发生 |
| SHA-256 雪崩 | 哈希 | 改一个字符看哈希面目全非；换盐看同一密码得到完全不同哈希 |
| Diffie-Hellman | 公钥密码 | 拖两个私密数，看两人永远算出同一个密钥 |
| 签名与篡改 | 数字签名 | 签名 → 验证通过 → 改掉金额 → 验证失败 |

## 怎么用

**不要一次读完。** 建议：先读第 0 章和第一部分，把六个数学实验台亲手玩一遍，然后做题。做题时不要看详解——错的那几道，就是你现在最该补的地方。

学完第一阶段的数学，再进第二部分。那时候你会发现——第二部分讲的每一样东西，都正好用得上第一部分学过的工具。

## 技术说明

- **纯前端，零依赖**：没有框架、没有构建步骤、没有 npm。整个项目就是一个 HTML 文件。
- **单文件自包含**：CSS、JavaScript、题库、全部内联。
- **密码学原语是真实现的**：SHA-256 通过 NIST 标准测试向量；AES 的 S 盒由「GF(2⁸) 求逆 + 仿射变换」在页面里实时生成，256 个值全部与标准表一致；MixColumns 对上 AES 官方算例。
- **离线可用**：断网也能正常打开。字体走 Google Fonts，加载不到时优雅降级到系统字体。
- **响应式**：手机上左侧目录自动收成顶部下拉框。
- **无障碍**：支持键盘操作，尊重系统的「减少动态效果」设置。
