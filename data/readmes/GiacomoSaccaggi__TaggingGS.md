# TaggingGS

Flask web app for automated text and image tagging using supervised and unsupervised ML classification.

## Features

- **Text Classification**: Multi-language NLP with spaCy (Italian, English, German)
- **Image Classification**: Deep learning with TensorFlow/Keras (CNN)
- **Classical ML**: scikit-learn models (Random Forest, SVM, Naive Bayes)
- **Interactive UI**: Upload content, get predictions, review and retrain
- **Unsupervised**: Topic modeling and clustering for auto-discovery

## Tech Stack

- Python 3.9+
- Flask (web framework)
- spaCy (NLP)
- TensorFlow / Keras (deep learning)
- scikit-learn (classical ML)
- Bootstrap (frontend)

## Quick Start

```bash
pip install -r requirements.txt
python app.py
# Open http://localhost:5000
```
