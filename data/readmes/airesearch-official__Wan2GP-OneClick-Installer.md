# 🚀 Wan2GP One-Click Installer for Windows

> The easiest way to install and run **Wan2GP AI platform** on Windows — no manual setup, no pain.

---

## 🌟 What is this?

**Wan2GP One-Click Installer** is a simple Windows-based installer that automates the entire setup process of the **Wan2GP AI platform**, which is otherwise complex and time-consuming to install manually.

If you struggled with the official installation guide — this is for you ❤️

---

## ✨ Features

✅ True one-click installation  
✅ Automatically installs required dependencies  
✅ No environment configuration needed  
✅ Beginner-friendly (no terminal knowledge required)  
✅ Optimized for Windows users  
✅ Open-source & transparent  

---

## 🖥️ Supported Operating Systems

- Windows 10 (64-bit)
- Windows 11 (64-bit)

> ❌ Linux / macOS users should follow the official Wan2GP guide.

---

## 📦 How to Install

### Step 1: Download the installer
- Go to the [`installer`](./installer) folder
- Download **`Wan2GP_OneClick_Installer_v2.bat`**

### Step 2: Run as Administrator
- Right-click the file  
- Select **Run as Administrator**

### Step 3: Follow on-screen instructions
- The script will handle everything automatically

⏳ Installation time depends on your internet speed.

---

## ⚠️ Important Notes

- An active internet connection is required
- Windows Defender / Antivirus **may show a warning**
  - This is a **false positive** common for `.bat` scripts
  - You can safely review the source code before running
