🤖 ROBOT APOCALYPSE

Ultimate Robot Survival Simulator ☠️

Welcome to Robot Apocalypse, a Python-based survival game project set in a world threatened by robots, aliens and zombies.

Your mission is to survive dangerous challenges, defeat enemies, rescue survivors and protect humanity!

🎮 Project Features

- 🤖 Robot survival simulator
- ⚔️ Robot battle arena
- 👽 Alien invasion missions
- 🧟 Zombie survival challenges
- 🔐 Cyber hacking terminal
- 💰 Underground black market
- 🏆 Player achievements and XP system
- 🛡️ Robot customization and upgrades
- 🎯 Random mission generator
- 👾 AI enemy battle system
- ☠️ Final boss battle

▶️ How to Run

1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Keep all Python files in the same folder.
4. Run the launcher:

python game_launcher.py

You can also run individual game modules separately.
