# 知产小栈 Work · 中国专利撰写与文档管理工作台

**把专利文稿、附图和常用撰写工具，放在一个本地工作台里。**

[品牌官网](https://zcxzz.cn/) · [Work 产品与官方下载](https://zcxzz.cn/work/) · [使用手册](docs/official-user-guide.md)

知产小栈 Work 是面向中国专利撰写场景的桌面软件，支持发明专利、实用新型专利和外观设计专利。可以在本地管理案件，编写专利五书、制作附图和二维 CAD 标注，也可以整理外观设计图片、编写简要说明并导出材料。

适合专利代理师、专利工程师、科研人员，以及需要整理技术方案和专利文稿的个人与团队。核心撰写与资料管理功能在本地运行，无需注册账号即可使用；AI 服务、更新检查等联网功能按各自配置使用。

## 功能介绍

### 外观设计专利工作台

在专利库点击「新建专利」，选择「外观设计」，填写产品名称和客户后即可进入工作台。项目资料存于本地，图片、视图分配和简要说明随案件保存。

- **分配视图。** 可批量导入或拖放图片，按文件名获取初步分配建议，再确认主、后、左、右、俯、仰等视图。可选择六视图或多图模式，并注明省略的视图及原因。
- **批量统一像素尺寸。** 在六视图面板比较对应边的像素尺寸，设置目标尺寸后同步相关方向的数值。确认变更前可先核对预览。
- **编写简要说明。** 选择整体或局部设计，填写产品用途和设计要点。支持填写产品变体，以及静态或动态图形用户界面的专项信息。选定代表图后，可在填写区旁查看图像和简要说明预览。
- **检查与导出。** 导出前查看图片与说明的检查提示，选择 DOCX 或 PDF 格式的简要说明及保存目录。产品图片以白底 JPG 输出，可随简要说明一起打包为 ZIP。已有分层工程保存点可以在导出前应用，无需重新打开修图页面。
- **回到专利库继续处理。** 可按外观设计类型筛选案件，也可按名称或客户查找后重新打开。

### 小栈修图与分层保存

打开外观设计专利案件，导入视图后切换到「小栈修图」即可编辑产品图。也可以在修图界面导入临时图片，完成后另存。

- **分层编辑。** 新建、复制、合并和管理图层，使用图层蒙版控制可见范围。可对局部选区修整，也可对图层或选中内容做自由变换。
- **整理画布和修饰边缘。** 支持裁切、扩展画布、去白边，以及画笔、橡皮擦、仿制图章和局部模糊。编辑中可以撤销、重做。
- **保存可继续编辑的工程。** 保存后，分层工程随案件存放。将编辑结果应用到案件图片后，图片整理和材料导出使用应用后的版本。工程和应用后的图片可分别更新。
- **处理 PSD 和大图。** 支持可兼容的栅格 PSD 图层，临时图片可导出为 PSD。PSD 编解码在后台处理，部分局部操作只记录受影响像素，减少大图编辑时重复复制整张图。

修图使用经过适配的 Klecks 内核，原始许可与来源保存在仓库中。[Klecks 源码与许可证](vendor/klecks/LICENSE)

### 1. 本地专利库与文稿管理

集中管理多件专利，维护专利名称、客户、专利类型等信息，按名称或客户查找、按类型筛选，并通过分组和不同视图浏览文稿。提供回收站与恢复入口，便于管理正在撰写和暂时移除的案件。

支持在本地索引专利五书正文，通过全文检索查找内容并定位到文稿。每件专利还可整理相关文件与工作稿，让撰写资料随案件集中保存。


日常管理中，可以按以下方式组织案件：

- **按案件查找：** 搜索专利名称或客户，按发明、实用新型筛选，按月份分组浏览。
- **按内容查找：** 利用五书正文索引寻找关键词，进入命中文稿继续处理；支持后台索引和手动重建。
- **按资料归集：** 将工作稿和参考文档与案件一起管理，减少在文件夹之间反复寻找。
- **按状态整理：** 通过回收站处理暂时移除的专利，需要时恢复。

### 2. 专利五书编辑与双文档对照

在同一工作台中编辑权利要求书、说明书、说明书附图、说明书摘要和摘要附图，支持多文档标签、双文档显示和工具双视图，方便对照权利要求与说明书、正文与附图。

编辑器提供文字与段落格式、查找替换、选中文字工具、右键操作、格式清理和缩放等常用能力。结构标尺用于查看章节与段落、定位撰写位置。本版本已移除新建和编辑“其他文档”的独立入口；原生资料中的历史附属文档兼容保留，不作为正式五书。


例如，左侧查看权利要求，右侧修改说明书；也可以一边查看结构附图，一边核对具体实施方式。双文档显示用于减少切换，不会自动替用户判断技术内容是否一致。

结构标尺帮助查找长文稿中的技术领域、背景技术、实施方式和段落位置；显示缩放用于调整阅读，不等于改变导出正文的字号。数字加括号等选区工具可处理常见附图标记格式，内置提示说明工具的作用范围。

### 3. 权利要求与说明书撰写辅助

支持权利要求编号与引用处理、插入从属权利要求，并可将权项内容整理为说明书“发明内容”“具体实施方式”的撰写素材，预览后由用户核对采用。

支持部件名称与附图标记登记、补充编号、标记高亮和定位，减少在正文与附图之间反复查找。转换结果和编号关系仍由撰写人员检查，软件不替代技术方案和保护范围判断。


说明书转换先整理、复制内容并定位目标章节，再由用户粘贴到需要的位置，不会直接覆盖已有正文。生成的内容可继续补充连接关系、工作过程、参数和实施例。

部件登记不代表所有文档自动同步修改。新增部件、改变含义或调整编号后，仍应检查权利要求、说明书和附图的对应关系。

### 4. 附图管理与二维 CAD 标注

支持导入、排列和管理专利附图，设置附图说明与摘要附图，处理部件标记及编号。

二维 CAD 工作区支持新建、导入与编辑工作稿，处理 DWG、DXF 图形，添加标号和引线、制作局部放大图、设置填充，并生成图片用于说明书附图；也可导出 DWG、DXF，继续在其他 CAD 软件中编辑。

插入附图时，可以单独选取局部放大图，按插入尺寸规则生成图片。嵌套的放大图保留标记和引线，填充以实际轮廓为界。缩放完成后会清除旧预览，完成阵列后会清除选择状态，可以继续选择和编辑其他对象。

工作稿与正式附图分别管理，修改工作稿后可重新预览并插入或替换附图。复杂 CAD 文件的转换效果与特殊对象保留情况需要检查。


常见流程是：导入或绘制图纸 → 整理图形 → 添加标号与引线 → 预览成图 → 插入说明书附图 → 核对图号、附图说明和摘要附图。

图纸工作稿保留继续编辑的入口，正式附图用于文稿展示和导出。普通图片、PDF 底图与可编辑 CAD 图元不同；本次开源版本也不包含后续的三维建模扩展。

### 5. 表格、公式与化学结构式

支持表格行列增删、单元格合并拆分、宽度调整及内容对齐，满足专利文稿中的参数表、试验数据表等整理需要。

可插入和编辑数学公式、物理公式、化学方程式及化学结构式。保留可编辑源数据的对象可以重新打开修改，便于反复调整技术表达。


| 内容 | 常见使用场景 | 编辑方式 |
| --- | --- | --- |
| 表格 | 参数、对照实验、测试结果 | 调整行列、合并拆分、对齐和列宽 |
| 数学与物理公式 | 算法、计算方法、控制关系 | 输入与预览，插入后重新编辑支持的对象 |
| 化学方程式 | 反应过程、材料制备 | 编辑反应表达并插入文稿 |
| 化学结构式 | 化合物与材料结构 | 绘制结构，保留可编辑源数据 |

复杂表格、跨页内容和公式导出后，应在目标文件中核对版面。普通图片无法自动还原为可编辑公式或化学结构。


### 6. 流程图与电路图

内置流程图绘制与工程管理能力，可创建多个图形工程、导入兼容的 draw.io 工程，并将绘图结果导出为说明书附图。

电路图模式提供元件图形与连接线绘制。关联附图重新导出时，可保留图号、顺序等已有设置。此部分用于图形表达，不提供电路仿真或设计正确性验证。


一件专利可以保存多个流程图工程，并可导入兼容的 draw.io、XML 或带源数据的图形文件。普通截图作为整体图片处理，不会拆回流程节点。

修改工程后，需要重新导出关联附图；仅保存工程不会让已经导出的正式附图自行变化。这种方式便于在继续修改工作稿时，保留已有文稿的附图状态。


### 7. 本地规则检查与问题定位

无需配置 AI 即可检查专利文稿中的权项编号与引用、章节、术语、附图标记，以及部分数值、公式、表格等规则问题。

检查结果按优先级和类别呈现，并提供定位入口，便于修改后重新核对。正文变化后会提示旧报告已过期，避免把旧结果当作当前检查结论。

规则检查用于发现撰写问题，不等同于专利检索、实质审查或授权前景判断。


可按“全文检查 → 查看优先级与分类 → 定位证据 → 修改 → 再检查”的顺序核对文稿。无法精确定位到文字时，按结果入口前往对应段落或文档。

正文改变后，旧报告标记过期；检查达到数量或计算限制时会提示未完成。规则检查辅助找出问题，不阻止编辑，也不能代替现有技术检索或专业审核。


### 8. AI 纠错与小栈 AI 助手（实验功能）

AI 纠错可对当前文档或选区提出文字、标点、术语和一致性建议，核对接受后再写入正文。小栈 AI 助手支持围绕选中文字或撰写需求开展连续对话，辅助润色、解释和整理表达。

本版本对接用户自行配置的 DeepSeek 官方 API，需用户自行取得并填写 API Key，服务费用与使用条件以服务商规定为准。AI 连接默认关闭；启用后，任务所需内容会发送至所配置的服务商。请自行判断未公开技术资料的提交范围，并核实 AI 输出。


两类工具的使用方式有所区别：

- **AI 纠错：** 选择当前文档或选区，查看逐项建议，接受后再写入；原文发生变化时会重新核对对应内容。
- **小栈 AI 助手：** 围绕所选内容或撰写需求连续对话，继续补充条件，再由用户核对采用。
- **可提出的需求：** 整理背景技术、解释技术内容、精简有益效果，或在不改变技术含义的前提下调整表达。

软件不随附 API Key 或免费调用额度，本版本暂不支持任意自定义接口或 Ollama。AI 是可选辅助，关闭连接后仍可进行本地撰写。

### 9. Agent CLI（实验功能）

为具备本地命令执行能力的 AI Agent 提供命令入口，在用户授权范围内读取、编辑和管理专利资料，执行检查、保存、导入导出等操作。

入口默认关闭，支持按专利设置只读、读写或不授权，并分别管理全局操作权限。它与内置 AI 助手相互独立，实际可用命令以本版本 CLI 手册为准。


接入流程为：启用入口并阅读说明 → 复制当前实例的接入指令 → 连同具体任务交给 Agent → 在软件中确认权限 → 执行任务并核对结果。

开启入口不会自动选择或安装 Agent，也不等于授权其读写所有专利。它适合可明确描述的任务，例如“只读这件测试专利，整理权项引用问题，不修改正文”。外部 Agent 的服务商、模型及数据处理方式仍由其自身配置决定。

### 10. 模板与个性化设置

支持管理默认模板和按专利类型区分的模板，调整常用章节与撰写内容，复用公式、化学结构等编辑素材。

结合编辑、显示、快捷键等设置，减少重复排版和重复录入，让工作台适应个人的撰写习惯。


模板可共用，也可区分发明与实用新型；专利题目及“发明／实用新型”可作为随新建案件变化的动态内容。模板只影响后续新建的专利，不批量改写已有文稿；说明书附图、摘要附图及部分辅助模板由各自入口管理。

还可设置页边距、工具栏显示、动画偏好、快捷键、关闭到托盘和开机启动。存在“保存”按钮的设置，需确认保存后生效。


### 11. 自动保存、快照、备份与迁移

文稿在本地自动保存，并显示保存状态；版本快照用于查看和恢复历史内容，可恢复为副本保留当前文稿。

支持 PATDOC 专利文件导入导出、定时备份，以及加密的整库迁移包。整库恢复面向空专利库使用，具体迁移范围与限制见随版本提供的手册。建议将备份另存到独立位置；本地快照不能替代外部备份。


| 保护方式 | 主要用途 | 需要知道的边界 |
| --- | --- | --- |
| 自动保存 | 持续将编辑写入本机专利库 | 查看保存状态，失败时按提示处理 |
| 版本快照 | 恢复误编辑前的内容 | 恢复为新副本；与本机库共存，不能代替外部备份 |
| PATDOC 定时备份 | 独立恢复单件专利 | 指定独立目录，备份文件未加密，应妥善保管 |
| 加密整库迁移 | 换电脑、重装或恢复整库 | 使用 .zxwbackup 和密码，只能恢复到空库 |

整库迁移包含专利库、资源、快照、流程图工程、默认模板和可移植设置；AI 密钥、外部备份目录与打印机等本机配置需重新设置。迁移密码不能找回，请与数据包分开保存。

本地存储不等于全部文件均已加密。正式业务资料还应结合操作系统账户权限、磁盘保护和独立备份管理。


### 12. Word、PDF 导出与打印

支持导入 Word DOCX，以及按单册或合并五书导出 DOCX、PDF，集中处理书册顺序、分页和打印预览。

按正式五书的书册范围导出，相关参考资料请独立归档。复杂表格、公式、图片和 CAD 转换结果应在提交前检查，确保内容、版面与实际提交要求一致。


| 格式 | 适合的用途 |
| --- | --- |
| DOCX | 与 Word 等软件交换可编辑文稿，按单册或五书合并导出 |
| PDF | 固定版式交付、预览与打印 |
| PATDOC | 携带和恢复单件专利 |
| .zxwbackup | 迁移整个专利库及设置 |
| DWG / DXF | 在 CAD 工作区与其他软件交换图纸工作稿 |

五书合并顺序为：**说明书摘要 → 摘要附图 → 权利要求书 → 说明书 → 说明书附图**。每书从新页开始，页眉随书册变化，合并页码连续；其他参考文档不会自动并入正式五书。

打印中心提供纸张、方向、边距、份数、页码范围、缩放等可用设置，具体取决于打印机和驱动。正式提交前，应检查标题、权项引用、表格跨页、公式、附图顺序和清晰度。

## 一件专利的使用流程

以机械领域的实用新型为例，可以这样组织一次撰写工作：

1. **建立案件：** 新建实用新型，填写名称与客户，或导入已有 PATDOC、DOCX 材料。
2. **组织技术方案：** 根据自己的习惯整理权利要求或说明书，登记部件名称和编号。
3. **对照撰写：** 用双文档显示核对技术特征，按需使用说明书素材转换，补充实施方式与工作过程。
4. **制作附图：** 导入或绘制 CAD 工作稿，添加标号和引线，预览成图并插入，选择摘要附图。
5. **检查与修改：** 执行本地检查、定位问题并重新核对；需要时使用已经配置的 AI 辅助。
6. **交付与归档：** 预览并导出 Word、PDF，人工复核后交付，同时保留 PATDOC 或外部备份。

上述流程说明工具之间的配合，不限定撰写顺序，也不能代替申请文件的专业审核。

## 常见问题

**必须注册账号或连接服务器才能写专利吗？**

不需要。核心编辑与专利库管理在本地运行，AI 和其他联网功能按各自配置使用。

**到哪里可以找到外观设计专利工作台？**

下载或克隆仓库默认分支的源码并按照构建说明启动，在专利库中新建「外观设计」案件。

**AI 纠错或本地检查通过，就说明专利可以授权吗？**

不能据此判断。规则检查和 AI 建议处理部分撰写问题，不能代替现有技术检索、技术核查和专业审查。

**修改 CAD 或流程图后，已经插入的附图会自动变化吗？**

不会。工作稿修改后，需要重新预览成图并插入或替换，流程图也需重新导出关联附图。

**说明书转换为什么没有直接改正文？**

工具先整理和复制转换内容，再定位目标章节，由用户核对后粘贴，避免直接覆盖现有内容。

**完整迁移包能直接合并进已有专利库吗？**

整库迁移恢复面向空库，不提供直接覆盖或合并已有专利库的操作。单件专利交换可使用 PATDOC。

**软件里带免费的 AI 额度吗？**

不随软件提供 API Key 或免费调用额度。内置 AI 需要自行配置 DeepSeek 官方 API；外部 Agent 按其自身配置使用。

**开源版可以用于企业业务吗？需要公开撰写的专利吗？**

可以依 GPL-3.0 用于商业用途；对外分发程序或修改版时需履行相应许可义务。用户撰写的专利文稿不因此要求公开。

**Work 包含品牌其他产品吗？**

本仓库是 Work 的指定版本源码，不包含 Search、AI、Manage 等其他产品的源码或在线服务。
