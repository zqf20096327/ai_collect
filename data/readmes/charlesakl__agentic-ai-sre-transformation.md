# Agentic AI — SRE Transformation — Phase 3B

Complete Streamlit application with **LangGraph workflow**, **LangChain model and retriever**, **Chroma vector database**, and **OpenAI reasoning**. All operational data and documents are synthetic.

## Windows setup
Open PowerShell in the extracted folder containing `app.py`:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

Edit `.env` to set your existing `OPENAI_API_KEY` (never commit it). Then:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m streamlit run app.py
```

In **Agent Investigation**, choose **Payment API latency**, enable live OpenAI, and run. The **Retrieve** stage calls OpenAI embeddings and Chroma to search eight synthetic knowledge documents. Initial indexing incurs API charges; subsequent queries reuse the local `.chroma` index. The **Reason** stage uses OpenAI to analyze telemetry plus retrieved documents, and displays citations limited to retrieved IDs. Browse the documents in **Knowledge Explorer**.

## Real versus simulated
Real: LangGraph node execution and streaming; LangChain OpenAI calls; Chroma persisted vector retrieval; RAG context and validated document IDs.
Simulated: All incident telemetry, historical incidents, runbooks, policy decisions and service integrations. No production actions, no real observability integrations, no ServiceNow/OPA/Ansible/OpenShift/GitOps execution. LLM outputs are hypotheses, not verified RCA. A green workflow stage means execution finished, not that the investigation succeeded. Failures are explicitly labeled.

Next: conditional LangGraph loops, governance integrations and measured transformation outcomes.

To rebuild the vector index after editing knowledge docs, stop the app and delete the `.chroma` directory. `.env` and `.chroma` are excluded from Git.

### Terraform / OpenShift infrastructure correlation demo

In **Agent Investigation Lab**, choose **Kubernetes CrashLoopBackOff**, run an investigation, and inspect **Observe** and **Govern**. The Observe section correlates synthetic application errors, OpenShift pod events, and desired Terraform settings. Govern explains a policy-gated, event-driven remediation proposal. No infrastructure actions execute.

The `terraform/` folder contains a minimal reusable Kubernetes Deployment module. It uses a placeholder container image and assumes a namespace already exists. It is **illustrative only**, and should not be applied to a real cluster without review, provider configuration, namespace creation, security hardening, and image replacement. Terraform is not a log source: the demo compares desired IaC configuration against synthetic runtime evidence.

## AIOps Anomaly Detection (Detect stage)

The Agent Investigation Lab's **Detect** inspection view includes a working, deterministic P95 statistical detector using 90 days of **synthetic** OpenShift exception-count data in 10-minute intervals. Adjust the current count to see the computed threshold, time-series chart, and sample anomaly event. The statistical demonstration is independent of the existing LangGraph incident-detection rules; it does not connect to a production log source or automatically initiate remediation. No bank data is included.
