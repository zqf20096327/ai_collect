# 复习小助手 1.12.3

面向医学院校教师与长期备考学生的本地优先 AI 复习与组卷工具。

规则引擎负责复习节奏，AI 负责今日推荐、资料挖空与题目生成；教师始终保留组卷、改题、重出和导出的最终控制权。

## 1.12.3 修复（当前）

- 修复模型列表下拉只显示当前模型的问题：打开时显示全部模型，并支持搜索。
- 聚合平台获取模型列表后，可直接在完整列表中选择，无需再手动搜索。

## 核心能力

### 学生端

- 艾宾浩斯复习排程：基础轮、维持轮、补练、每日上限
- AI 今日计划：在候选任务中推荐今天先做什么，不修改复习日期
- 资料挖空讲义：只从原文抽取答案，点击显示，可复制 Anki Cloze
- 单元错题：答错自动归入知识点单元，可再练、加入补练、标记掌握
- 学习效果：正确率、答题量、完成度、错题、趋势与薄弱点

### 教师端

- 教师组卷工作室：题型分节、题量、分值、顺序、总分
- 9 类题型：单选、多选、判断、名词解释、简答、论述、计算、病例分析、自定义
- 病例分析：病例材料 + 2–4 个小问，附带参考答案与评分点
- 先预览后保存：学生卷默认不含答案，教师卷附答案页
- 逐题编辑与重新出题：题干、选项、答案、评分点、解析、依据
- 大批量后台出卷：最多 200 题，拆批并发、暂停、断点续传、失败批重试/跳过
- 标准 A4 PDF：页脚页码、学生卷/教师卷分开导出

### AI 与数据

- 资料上传：PDF / Word（.docx）/ PPT（.pptx）/ 图片 / TXT；Word/PPT 提取正文，PPT 附带备注；旧 .doc/.ppt 建议转 PDF
- 多平台模型：DeepSeek、Kimi、通义千问、智谱 GLM、硅基流动、火山方舟、MiniMax、自定义 OpenAI 兼容接口
- 本地优先：知识点、资料、错题、试卷、答题记录均在本机
- AI Key 由主进程 `safeStorage` 加密，不进入页面
- AI 请求走主进程代理；单次 50 秒超时，可中断、可重试
- AI 返回 JSON 后先本地校验，再进入产品流程

## 技术方案

```text
界面层     单页 HTML / CSS / 五个工作区
应用层     艾宾浩斯引擎 / 今日计划 / 资料挖空 / 错题 / 教师组卷
AI 代理层  主进程 / 多平台配置 / 超时与 abort / JSON 校验
数据层     IndexedDB / 本地资料 / 试卷 / 答题记录 / AI 缓存
```

核心工作流：

```text
知识点与资料
  → 规则引擎（到期 / 逾期 / 掌握度 / 错题 / 上限）
  → AI 教练（计划 / 讲解 / 挖空 / 组卷）
  → 本地校验（结构 / 答案 / 来源 / 时长）
  → 输出（复习计划 / 讲义 / 试卷 / PDF）
```

## 演示模式

同一个 exe 内可进入/退出演示模式：

- 使用独立数据目录
- 自动载入 8 个演示知识点、8 份资料、演示答题和 1 套演示试卷
- 侧栏显示「演示模式」
- 退出后回到正式数据

## 本地开发

```bash
npm install
npm start
```

或使用已安装的 Electron：

```bash
npx electron .
```

构建 Windows 安装包：

```bash
npm run build
```

主要文件：

```text
app/index.html   单页界面
main.js          主进程、AI 代理、PDF、资料 IPC
preload.js       安全 IPC 桥
materials.js     资料解析与 OCR 辅助
```
