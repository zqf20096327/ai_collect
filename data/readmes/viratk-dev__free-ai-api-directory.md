## 🛠️ Quickstart: How to Use Free APIs

Because 95%+ of providers in this directory are **OpenAI-compatible**, you can switch providers with just 2 lines of code!

### 1. Python (OpenAI SDK)

```python
from openai import OpenAI

# Example: Using Google AI Studio's OpenAI-compatible endpoint
client = OpenAI(
    api_key="YOUR_GEMINI_API_KEY",
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/"
)

response = client.chat.completions.create(
    model="gemini-2.5-flash",
    messages=[{"role": "user", "content": "Explain quantum computing in 2 sentences."}]
)

print(response.choices[0].message.content)
```

### 2. Cursor IDE

1. Open **Cursor Settings** (`Cmd/Ctrl + Shift + J`) -> **Models**.
2. Turn on **Override OpenAI Base URL**.
3. Set URL to: `https://api.groq.com/openai/v1` (or your chosen provider).
4. Enter your provider API key.
5. Add model names: e.g. `llama-3.3-70b-versatile`.

### 3. Claude Code CLI

Set the environment variables before running Claude Code:

```bash
export ANTHROPIC_BASE_URL="https://api.your-router.com/v1"
export ANTHROPIC_AUTH_TOKEN="your_free_token"
claude
```
