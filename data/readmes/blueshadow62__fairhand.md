# 글눈

손글씨로 쓴 서·논술형 답안지(스캔 PDF)를 문항별 글자로 옮기고, 정답표와 비교해 엑셀로 정리하는 선생님용 프로그램입니다.

- 전사(손글씨 읽기)는 선생님 PC에 설치된 Claude Code·Codex(본인 구독 로그인)나 API 키(Anthropic·OpenAI·Gemini)로 합니다. 정확도는 AI 도구에 따라 다르며, 개발자는 Claude를 추천합니다.
- 학생 답안지에는 **학년, 반, 번호만** 입력되어 있는 걸 추천합니다. 이름이 있으면 그림과 함께 AI 제공자 서버(Claude는 Anthropic, Codex·OpenAI API는 OpenAI, Gemini는 Google)로 전송됩니다. 명단(이름)은 PC 안에서만 씁니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md).

## 설치
### Windows
1. [Releases](https://github.com/blueshadow62/fairhand/releases)에서 `fairhand-setup-x.y.z.exe`를 받습니다.
2. 받은 파일을 실행합니다. 코드 서명이 없어 Windows가 '알 수 없는 게시자'나 'Windows의 PC 보호' 창을 띄웁니다. **추가 정보 → 실행**을 누르면 설치가 이어집니다. 관리자 권한은 필요 없습니다(사용자별 설치).
3. 첫 실행에서 **설정**의 '기본 폴더 만들기(문서\글눈)'를 누르거나 학기 폴더를 고르고, AI 프로필을 정합니다.
4. Claude Code로 전사하려면 Claude Code를 설치하고 로그인합니다([설치 안내](https://code.claude.com/docs/ko/setup)). 설정 화면의 '로그인 열기'가 순서를 안내합니다.

### 맥(시험판)
개발자가 맥에서 직접 써 보지 못한 시험판입니다(자동 검사 서버에서 실행과 화면만 확인). 문제가 있으면 [문제 보고](#문제-보고)로 알려 주세요.
1. [Releases](https://github.com/blueshadow62/fairhand/releases)에서 칩에 맞는 파일을 받습니다. Apple 실리콘(M1 이후)은 `fairhand-x.y.z-mac-arm64.dmg`, 인텔은 `fairhand-x.y.z-mac-x64.dmg`입니다. 칩은 Apple 메뉴 > 이 Mac에 관하여에서 볼 수 있습니다.
2. dmg를 열고 **Fairhand**를 응용 프로그램 폴더로 끌어 넣습니다. 맥에서는 앱 이름이 Fairhand로 보이고, 프로그램 안은 똑같이 글눈입니다.
3. 처음 열면 Apple 서명이 없어 'Apple이 확인할 수 없음' 창이 뜹니다. **완료**를 누른 뒤 시스템 설정 > 개인정보 보호 및 보안 아래쪽의 **그래도 열기**를 누르고 다시 엽니다. '손상되었기 때문에 열 수 없습니다'가 뜨면 터미널에서 `xattr -dr com.apple.quarantine /Applications/Fairhand.app`을 실행한 뒤 엽니다.
4. 자동 업데이트가 없습니다. 새 버전은 설정의 '릴리스 페이지 열기'에서 받아 같은 방법으로 덮어씁니다.
5. Claude Code·Codex는 맥용으로 설치합니다. 설정의 '로그인 열기'를 누르면 터미널 창에서 로그인이 시작됩니다.

## 업데이트
- 새 버전이 있는지 켤 때(10초 뒤)와 4시간마다 GitHub에서 확인만 합니다. 새 버전이 있으면 설정 화면에 '내려받아 설치' 버튼이 나오고, 누르면 받은 뒤 프로그램이 다시 시작되면서 설치됩니다. 전사가 돌고 있으면 설치를 미루고 '다시 시작해 적용' 버튼을 보여 줍니다. 새 버전이 있으면 맨 위 버전 옆에도 '새 업데이트가 있습니다'가 뜨고, 누르면 설정의 업데이트 칸이 열립니다.
- 자동으로 받기: '새 버전을 자동으로 받아 두고, 프로그램을 닫을 때 설치'를 켜면(기본 꺼짐) 누르지 않아도 받아 두었다가 프로그램을 닫을 때 설치합니다.
- 끄기: 설정 → 정보 → '새 버전을 자동으로 확인'의 체크를 풉니다. 꺼져 있으면 '지금 확인'을 누를 때만 GitHub에 접속합니다.
- 설치 파일과 업데이트는 코드 서명이 없습니다. GitHub Releases(HTTPS)에서 받으며 electron-updater가 릴리스에 적힌 SHA-512로 파일을 검증합니다. 설치는 사용자가 누르거나, 자동으로 받기를 켰을 때 프로그램을 닫으면 됩니다.

## 샘플 세트
시작 화면은 학기 현황판입니다. 세트마다 정답표 확인·전사·검토 진행과 다음에 할 일 단추를 보이고, 학기 누가기록도 여기서 만듭니다. 처음 실행하면 '처음 시작하기' 3단계(학기 폴더 → AI 도구 확인 → 샘플로 둘러보기)가 나옵니다. 시작 화면에 세트가 없으면 '샘플 세트 넣어 보기' 버튼이 있습니다. 지어낸 짧은 글 '봄비 오는 날'과 **인쇄 글자로 만든 가짜 답안지 3장**, 미리 만든 전사가 들어 있어 AI 없이 검토 화면과 엑셀 만들기를 먼저 해 볼 수 있습니다. 손글씨 읽기 정확도를 보여 주는 자료가 아닙니다.

## 사용 순서
1. **설정**: 학기 폴더를 고르고, AI 프로필을 정합니다(Claude Code 로그인 또는 API 키). 명단(xlsx·csv)은 선택.
2. **문항 설정**: 새 세트를 만들고 정답표(문항 표)를 적습니다. 문제와 지문을 붙여넣어 AI 초안을 받을 수 있습니다. 확인한 뒤 '확인 완료'를 표시해야 채점할 수 있습니다.
3. **채점 실행**: 답안지 PDF를 올려 회전을 맞추고 쪽으로 나눠 저장한 뒤 '전사 시작'. 끝나면 세트 폴더에 채점결과 엑셀이 생깁니다(결과·문항 분석·답안·정답표·정보 시트, 문항 분석 시트에 단위별 정답률과 반별 점수). 저장된 장은 작은 그림으로 보고 한 장씩 또는 여러 장을 골라 지울 수 있고, 같은 파일을 다시 올리면 경고합니다. 답안지 파일은 여러 번 나눠 고르거나 탐색기에서 화면으로 끌어다 놓아 목록 맨 뒤에 더하고(같은 파일은 한 번만), 파일마다 보이는 칩의 x로 하나씩 뺄 수 있습니다. 칩을 끌어 놓거나 칩을 누른 뒤 Alt+←·→로 순서를 바꿀 수 있고, '이름 순으로 정렬'로 파일 이름 순서로 되돌립니다. 고른 파일의 모든 쪽을 작은 그림으로 미리 보며 쪽마다 돌릴 수 있고, 칩의 번호 차례로 저장됩니다. '한 장 채점해 보기'로 답안지 한 장의 전사를 저장하지 않고 시험할 수 있습니다. 전사 시작 전에는 예상 시간(API 키면 예상 비용)을, 전사 중에는 남은 시간을 보입니다. 고급의 '동시에 전사할 장 수'(기본 3)만큼 여러 장을 한꺼번에 보내 세트 전체 시간을 줄입니다(장당 토큰·요금은 같음). '이 세트의 노력 단계'로 그 세트만 노력 단계를 바꿀 수 있습니다(기본은 AI 프로필 설정).
4. **검토**: 먼저 **문항별 검토**가 열립니다. 학생 정보(학년·반·번호·이름)를 가린 채 한 단위씩, 같은 답끼리 묶어 판정을 확인하거나 바꿉니다. AI가 잘못 옮긴 글은 펼친 답의 '글 고치기'로 고칩니다. 동작마다 바로 저장하고 판정이 바뀌면 엑셀도 다시 만듭니다. 필요하면 학생 정보 자리를 칠한 답안지 그림을 볼 수 있습니다. 같은 양식의 답안지라면 '답 칸 지정'으로 한 장에서 그 문항의 답 칸을 한 번 잡아, 모든 답안지의 같은 자리 손글씨를 격자로 나란히 보며 채점할 수 있습니다. **답안지별 검토** 탭에서는 답안지 그림과 전사를 나란히 보고 학생 정보까지 고쳐 저장합니다. 가운데 나눔선을 끌어 두 칸의 너비를 바꾸고, 학생 답 칸을 누르면 긴 답이 다 보이게 펼쳐집니다. 단위 행을 누르면 답안지 그림이 그 답 자리로 내려갑니다(문항별 검토에서 답 칸을 지정한 단위, 또는 채점 실행 > 고급의 '답 위치도 받기'를 켜고 전사한 장).

## 채점 규칙과 사례
- 문항 유형은 빈칸형·단답형·문장형·요소형·논술형·응답형입니다. 배점은 단위마다 정하고(기본 1점), 점수는 맞은 단위의 배점 합입니다. 논술형은 한 편의 글에서 정해진 문장을 거의 그대로 인용했는지, 정해진 용어를 썼는지 하나씩 채점합니다. 전사할 때 학생 글 전체도 받아 두 검토 화면에서 보이고, 정답 문장·용어가 글자 그대로 있는 곳에 색을, AI가 찾은 부분에 밑줄을 긋습니다.
- 세트마다 채점 규칙 세 가지를 고릅니다(문항 설정): 맞춤법이 다른 같은 뜻의 답, 정답보다 넓은 말, 문장형 핵심어(모두/하나라도).
- 검토에서 바꾼 판정은 '사례'로 쌓여(체크로 끌 수 있음) 같은 단위에 같은 답을 쓴 다른 장에 바로 적용되고, 그 뒤에 전사하는 장에도 적용됩니다. 다른 장까지 바뀔 때는 저장 전에 확인 창으로 보여 주고, 저장 뒤 '되돌리기'로 되돌릴 수 있습니다. 문항별 검토에서는 같은 답 묶음 전체의 판정을 바꿨을 때 사례가 됩니다. 문항 설정에서 정답·허용을 바꾸면 그 단위의 사례를 알려 주고, 새 정답과 같은 답을 X로 정한 사례는 사례 표에 '정답과 같음'으로 표시합니다.
- 정답표를 고치면 기존 장을 다시 판정할 수 있습니다. '다시 판정'은 글자가 같은 답만 고치고(모델 호출 없음), '모델로 다시 판정'은 답 글만 보내 판정을 다시 받습니다(그림은 보내지 않음). 다시 판정이 이미 확인한 장의 판정을 바꾸면 그 장의 확인 표시를 풀어, 검토에서 다시 확인하게 합니다.
- 판정을 바꾼 근거는 전사의 비고에 남습니다(`재판정: 4-2 O→X (사례)`, `모델 재판정: …`). 학생이 쓴 답 글은 바꾸지 않습니다.

## 개발
- 요구: Node 24 이상(Electron 45가 품은 Node와 같은 판. CI도 24)
- `npm install` → `npm test` → `npm start`(빌드 포함)
- 설치 파일: `npm run dist` → `release/fairhand-setup-<버전>.exe`(빠른 확인은 `npm run pack` → `release/win-unpacked/Fairhand.exe`). 태그 `v*`를 올리면 GitHub Actions가 설치 파일을 만들어 초안 릴리스로 올립니다.
- 맥(맥에서만 묶을 수 있음): `npm run dist:mac` → Apple 실리콘·인텔 dmg. 한글 제품 이름으로 묶은 맥 앱은 시작하자마자 죽어서(보조 프로세스 앱 이름 문제, 2026-11 확인) 맥만 제품 이름을 `Fairhand`로 덮어씁니다. Apple 서명이 없어 임시 서명(ad-hoc)만 붙입니다.
- 실행 확인: `npm run pack` 뒤 `npm run smoke` → 앱을 띄워 탭마다 화면을 `smoke-out/`에 찍습니다. GitHub Actions의 smoke 작업이 Windows·맥·리눅스에서 같은 것을 돌려 결과물로 남깁니다.
- 개발 중에는 설정·API 키를 저장소의 `local/`(무시됨)에 두고 실행: PowerShell `$env:GEULNUN_USER_DATA='local\userData'; npm start`
- 명령줄 스크립트는 경로에 공백이 있으면 `npm run`으로 인수를 넘기지 말고 빌드(`npm run build`) 뒤 직접 부릅니다.
  - 세트 채점: `node dist/scripts/score-set.js "<세트 폴더>" --roster "<명단.xlsx>"`
  - 세트 전사: `node dist/scripts/transcribe-set.js "<세트 폴더>" --engine cli --out "<세트 폴더>\평가\cli"`(`--positions`를 붙이면 앱의 '답 위치도 받기'와 같은 지시문으로 전사, `--concurrency 3`이면 3장씩 동시에)
  - 평가: `node dist/scripts/eval.js "<세트 폴더>" --got "<세트 폴더>\평가\cli"`
  - 다른 Claude Code 계정으로: PowerShell `$env:CLAUDE_CONFIG_DIR='C:\Users\이름\.claude-max'` 뒤 실행

## 라이선스
Apache-2.0. 가져온 부품은 [NOTICE](NOTICE)에 있습니다. 이 프로그램은 사용자가 설치한 Claude Code를 실행하며, Claude 사용은 사용자 본인의 Anthropic 약관을 따릅니다. Anthropic과 관련이 없는 개인 프로젝트입니다.
