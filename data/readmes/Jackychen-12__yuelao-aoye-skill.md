## ✨ 这是什么

市面上的「AI 情感咨询」有一个共同问题——**太舍不得说真话了。** 你问它「我这条件能找什么样的」，它给你一堆「你很优秀，要相信自己」。

这个 skill 反着来。它按鳌烨的真实尺度干三件事：

| 它做什么 | 怎么做 |
| --- | --- |
| **① 采集** | 分轮问，不一次砸 9 个问题。**男生先问城市收入，女生先打颜值**——两套算法不互通 |
| **② 判决** | 颜值 `X.X 分 + 100 个里第 X`、城市池难度、梯队位置、3 个王牌 3 个硬伤、你的同性对手是谁 |
| **③ 落盘** | 生成**浅色单文件 HTML**：上限画像 / 下限画像双卡 + 两条可执行的路子，双击即开 |

> 全程零依赖、零联网、零安装。没有 Python 脚本，没有 pip，没有 API key——纯 Markdown 驱动的 skill。

## 🧮 打分为什么这么狠

大部分 AI 装「严格的评委」都会失败，因为它舍不得打低分。这个 skill 用三条元规则把这个倾向压住：

```
① 普通人 = 4 分。不是 6 分，不是 5.8。
② 默认所有人 4 分，从 4 分往上加——不是从 6 分往下减。
③ 遇事不决往低打。犹豫 4.2 还是 4.5，永远选 4.2。
```

| 分数 | 真实位置 | 谁在这一档 |
| --- | --- | --- |
| **3.8–4.2** | **中位数** | **绝大多数普通人** |
| 4.3–4.7 | 第 40–45 | 收拾过的普通人（大部分自拍） |
| 4.8–5.0 | 第 30 | 比一般人明显好看 |
| 5.4–5.7 | 第 6–15 | 接近班花门槛 |
| 5.8–5.9 | 防御性 | **不是真分**，是对方自称 6 分时的反射弹球 |
| 6.0 | 第 3–5 | 班花 / 班草 |
| 6.5+ | 第 1–2 | 校花级，极稀缺 |

还有一条最容易被 AI 破坏的铁律——**颜值轴和家境轴彻底独立**：

- ❌ 「她独生女体制内，脸多给 0.5」
- ❌ 「她 25 岁年龄轻，加 0.3」
- ✅ 同一张脸 + 不同的盘子 = 不同的择偶圈子，**但颜值分数不变**

家境只决定这张脸在哪个圈子玩得动，它不抬颜值本身。

## 🎯 核心交付物：上限画像 / 下限画像

这是整份报告最有用的两张卡，直接对应那句「家境是下限，颜值是上限」：

- **下限画像** —— 家境给你兜住的那一档，门当户对，随时能落地
- **上限画像** —— 颜值和王牌能撬动的天花板，要抢，而且牌是有保质期的

两张卡都具体到年龄段、城市、收入区间、家境、能接受的短板。

<p align="center">
  <img src="docs/preview-portrait.png" width="90%" alt="下限画像与上限画像双卡对照" />

**上限画像不许脱离基本盘。** 4 分 + 月薪 6000 的人，上限画像里不会出现「5.5 分小美」——那是讨吃鬼心态，报告会替你把这个格子划掉。

## 📄 完整报告长什么样

九个板块，一气呵成：

```
判词      →  一句话定性 + 一句具象比喻，盖个朱红「判词」印章
基本盘    →  数据回显 + 一句性格快评
颜值分    →  巨大的数字 + 百分位 + 判读标签
梯队定位  →  城市池难度 + 梯队 + 综合百分位（有岔路口就算两个池子）
王牌硬伤  →  恰好 3 条 + 恰好 3 条，左右对照
你的对手  →  同生态位竞争，带一个反问句
双画像    →  下限画像 / 上限画像
两条路子  →  务实路 / 感情路，具体到社交渠道
收尾      →  扎 → 拉平 → 一句古文把你扶起来
```

## 🎭 为什么像

「像鳌烨」这件事，难的不是毒舌，是**毒舌的节奏**。skill 里写死了这些约束：

| ❌ AI 的通病 | ✅ 它会说的 |
| --- | --- |
| 「综合分析，你的核心优势在于…」 | 「王牌就三个——25 岁、独生女、北漂经历」 |
| 「建议您适当放宽择偶标准」 | 「拉倒吧。你别当讨吃鬼啊」 |
| 「眼睛是亮点，但发型有些拉分」 | 「挺普通一姑娘。4 分」（**只看整体，不拆五官**） |
| 「最近你可以多参加社交活动」 | 「咱们现在在黄金择偶期的尾巴」（时间词全金融化） |
| 「加油，你一定会遇到对的人」 | 「没浪费你时间，祝福你啊」 |

还有几条反直觉的：

- **「咱」一段只准 1–3 个。** 每句都塞就从鳌烨变成滑稽相声了——signature 是节奏点，不是底色
- **打分只给数字 + 标签，不解释尺子。** 裁判不是讲师，判决不附推理过程
- **扎完必须拉平。** 只扎不拉平 = 网暴。标准节奏是 `扎 → 我也一般您别生气 → 一句古文把你扶起来`
