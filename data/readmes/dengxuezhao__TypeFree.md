## 📖 详细功能使用说明书（全功能操作指南）

### 一、初始激活与 API 极速配置

1. **三步激活输入法与悬浮球**
   - 打开 **TypeFree** 主应用 → 底部 **「首页」** 顶部引导卡片：
     1. 点击 **「启用输入法」**，在系统设置中勾选 `TypeFree AI 语音输入法`；
     2. 点击 **「切换输入法」**，将当前默认输入法选为 `TypeFree`；
     3. *(可选)* 若希望支持微信/QQ 读屏识图 AI 帮回或全局悬浮语音球，点击 **「开启无障碍服务」** 授予无障碍权限。
2. **三层「统一接口工作台」配置 (`API 配置` 页)**
   - **第 1 层 · 服务商凭证保险箱 (`Provider Vault`)**：点击对应厂商（Google Gemini、阿里云百炼、火山引擎、硅基流动、DeepSeek 或自定义 OpenAI 兼容网关），填入 API Key。所有厂商凭证独立加密保存在本机 `EncryptedSharedPreferences`，切换服务商不会丢失已填 Key。
   - **第 2 层 · 一键推荐组合预设**：填入 Key 后直接点击推荐预设卡片（如「Google 极速流式直出」「国内百炼+豆包极速双阶段」），一键配好 STT 与 LLM。
   - **第 3 层 · 高级路由微调与 `1-Token` 真实测速**：
     - 展开高级设置可分别指定 **语音识别 (STT)**、**智能润色 (LLM)**、**多模态音频直出** 的具体模型；
     - 在模型下拉列表中点击 **「⚡ 测速」**，并发测试当前账号下所有模型的真实首字延迟（`ms`）并自动按速度升序排列；
     - 支持单独切换 **思考模式 (`Thinking`)**：日常输入强烈建议设为 **「关闭思考 (极速)」**。

### 二、AI 语音输入与流式边说边上屏（默认开启）

1. **语音面板录入方式**
   - **单击麦克风**：开始录音，再次点击结束并上屏；
   - **长按麦克风（按住说话）**：按住期间说话，松手即刻完成识别与润色上屏；
   - **取消或清空**：录音过程中点击左侧 `✕` 可随时丢弃本次录音。
2. **流式边说边上屏 (`实时写入`，v3.0 默认开启)**
   - **开关位置**：点击键盘左上角 `⊞` 工具面板 → **「实时写入」**（或在 `设置 -> 输入体验` 中开关 **「流式边说边往输入框写字」**）。
   - **工作机制**：说话同时，增量识别草稿以带下划线的组合态（Composing Text）实时出现在宿主输入框内；松手后自动原地替换为 AI 润色后的定稿，并在顶栏提供 **「↶ 撤回」** 按钮。
   - **防冲突保护**：若说话期间手指手动移动了宿主输入框光标，流式直写自动冻结组合态，防止覆盖其他位置文字。
3. **文风一键切换与宿主自动感知 (`App-Aware Styles`)**
   - 点击语音面板顶栏文风胶囊或 `⊞` 工具面板中的 **「文风」**，可切换 *自然精炼 / 商务得体 / 极简要点 / 俏皮社交 / 学术严谨* 等预设或自定义文风；
   - 在主应用 **「文风」** 页可为不同 App（如微信、飞书、邮件、终端）绑定专属文风，进入对应 App 自动切换。
4. **轻声耳语模式 (`Whisper Mode`) 与外放音频自动避让**
   - 开启 **「轻声耳语增益」** 后，深夜或图书馆低声耳语会自动执行 16-bit PCM 软限幅增益放大；
   - 开启 **「录音时自动暂停外放媒体」** 后，按下麦克风瞬间自动暂停正在外放的音乐/视频，松手后自动恢复播放。
5. **零延迟语音口令短语 (`Voice Snippets`)**
   - 在主应用 **「词典 -> 语音口令与快捷短语」** 中添加触发词（如口令：`发我的工作邮箱` → 展开内容：`name@company.com`），说出该口令本地 **`0ms` 瞬间展开**。

### 三、五大 AI 意图工作台（含 v3.0「📸 读屏截屏多模态 AI 帮回」）

1. **🎙️ 口述净写 (`Dictate`，默认模式)**
   - 自动剔除“嗯、啊、那个、然后”等口癖，识别句中改口（如“明天下午三点，不对，四点开会” → “明天下午四点开会”），自动断句加标点。
2. **📸 读屏截屏多模态 AI 帮回 & ✍️ 帮我写 (`Help Me Write`)**
   - **唤起方式**：在键盘面板点击左下角或顶栏 **「✍️ 帮我写」** 图标。
   - **场景 A：聊天应用内「📸 读屏截屏多模态 AI 帮回」（微信 / QQ / Telegram / 飞书 / 钉钉 / WhatsApp / 短信等）**
     1. **无障碍真实截屏 + 多模态视觉识别**：在 Android 11+ (`API 30+`) 聊天界面点击 `✍️` 时，按需截取当前聊天窗口可视区域（自动裁除顶部状态栏与底部输入法区域，内存内压缩为轻量 JPEG 直传多模态大模型，用完即焚零落盘），彻底解决微信/QQ 自绘 `Canvas` 气泡被隐藏导致只读到昵称/管理员的问题，同时支持直接看懂对方发来的截图、海报与表情包。
     2. **自动识别状态与一键忽略**：面板顶部自动显示 `📸 已识图+N条 · 点此忽略` 或 `📸 已截屏识图 · 点此忽略`；轻点胶囊即可切换为 `已忽略 · 点此恢复`（退回普通盲写）。
     3. **6 枚自然平视快捷态度芯片（支持自定义增删改）**：
        - 默认内置：**「👌 行 / 好的」「🙅 算了 / 婉拒」「🤔 啥情况 / 追问」「😂 接梗 / 调侃」「⚡ 硬气回怼 / 催办」「💼 正式得体」**；
        - 点击芯片尾部的 **「＋ 自定义」**（或进入主应用 `文风` 页）可自由新增、修改或删除专属态度芯片。
     4. **「先选态度 → 再语音补充 / 或点 ⚡ 直接生成」双模交互**：
        - **态度 + 语音补充细节**：轻点一枚态度芯片（如选中 `🙅 算了 / 婉拒`），再按住下方麦克风说出具体原因（如“跟他说周末在外地出差去不了”），AI 自动将「所选态度 + 口述细节 + 聊天画面上下文」三合一生成得体回复；
        - **免开口一键生成**：选中任意态度芯片后，直接点击麦克风右侧的 **「⚡ 直接生成」** 胶囊，无需说话即刻生成回复上屏；
        - **纯口述意图**：不选芯片，直接按住麦克风口述回复想法。
     5. **隐私熔断保护**：在银行、支付宝、密码管理器、系统权限弹窗及密码框中，读屏与截屏捕获硬编码强制熔断；关闭面板、切换键盘标签或隐藏键盘时，内存中的上下文与截图数据立即清零。
   - **场景 B：非聊天应用或未开无障碍时的「✍️ 帮我写」**
     - 可先点选上方态度/灵感芯片再说话补充，或直接按住麦克风说出写作需求。
3. **🪄 选中文本语音改写 (`Speak to Edit`)**
   - 在宿主输入框内选中一段文字 → 点击键盘顶栏自动浮现的 **「AI 改写」** 胶囊，可点击快捷指令芯片或按住麦克风说出修改要求；改写后支持点击顶栏 **「↶ 撤销」** 一键还原。
4. **🌐 实时快译面板 & 悬浮胶囊长按上滑弧形直译 (`Translate`)**
   - 点击顶栏 **「文A」** 切换快译面板，或按住语音麦克风向上滑动呼出弧形语种轮盘，松手即刻翻译上屏。

### 六、💥 智能剪贴板 2.0、大爆炸拆词、Myers Diff 自学习与无痕模式

1. **顶栏刚复制「双胶囊」并排粘贴**
   - 复制包含验证码或取件码的短信（如 `【丰巢】凭取件码425666至南门丰巢柜取件`）后，键盘顶栏左侧自动并排浮现两枚胶囊：
     - **左胶囊（`📦 425666` / `🔢 638291`）**：一键仅填入提取出的纯净取件码/验证码；
     - **右胶囊（`📋 全文`）**：一键粘贴完整短信全文（方便转发给家人或朋友）。
2. **智能剪贴板 2.0 多实体提取与「💥 大爆炸拆词」**
   - **全格式实体提取**：支持 **菜鸟驿站货架码（`3-2-1048`、`A05-2019`）**、**丰巢/驿站取件码（`425666`）**、**主流快递单号（`SF/JD/YT/JT` 等）**、**短信验证码**、**纯净网址**、**手机号**、**邮箱** 与 **收货地址**；当单条文本内含多个实体（如「收件人+手机号+地址」或「取件码+快递员电话」）时，卡片底部并列展示所有实体芯片，点哪枚贴哪枚。
   - **💥 大爆炸拆词 (`BigBang Tokenizer`)**：点击任意剪贴板卡片右上角的 **「💥拆词」**，即可在键盘面板内将该条文本拆解为独立的词块与数字/单号芯片，支持自由点选多个词块、一键「去标点 / 全选 / 清空」并点击 **「✓ 粘贴已选」** 组合上屏。
3. **打字改错 Myers Diff 自动学词与隐私无痕模式 (`Incognito Mode`)**
   - 语音上屏后 60 秒内若手动修改了其中的专有名词，系统通过 Myers Diff 算法自动识别修正词并沉淀至个人词典，下次语音识别自动作为热词注入；
   - 在密码框、宿主隐私输入框或手动开启无痕模式时，自动暂停一切词频学习、Rime 用户词典落盘、剪贴板监听与语音历史记录。

## 🔒 隐私声明与安全性

1. **零中心服务器**：TypeFree 本身不运营任何数据收集服务器，无埋点统计、无广告 SDK、无追踪器。
2. **直连您的服务端点**：您的音频流与改写/帮回内容仅向您在本地配置的 API 端点（或您自建的本地服务）发送。
3. **读屏与截屏上下文严格按需、端侧脱敏与敏感界面熔断**：屏幕上下文仅在用户显式同意披露说明且手动点击 **`✦ 军师`** 时按需读取当前可见聊天视口（裁除状态栏与键盘，手机号/身份证/微信号等在端侧先行正则脱敏为 `[手机号_1]` 占位符，用完即焚零落盘，且在银行、支付、密码框界面强制熔断）；**`✍️ 帮写`** 与 **`🔍 问AI`** 全程零读屏、零截屏。
4. **可控历史留存**：支持选择历史记录留存周期（3 天 / 7 天 / 30 天 / 永久 / 立即清除），敏感凭证加密存储在 Android 私有空间 `EncryptedSharedPreferences` 中。
