## 📖 详细功能使用说明书（全功能操作指南）

### 一、初始激活与 API 极速配置

1. **三步激活输入法与悬浮球**
   - 打开 **TypeFree** 主应用 → 底部 **「首页」** 顶部引导卡片：
     1. 点击 **「启用输入法」**，在系统设置中勾选 `TypeFree AI 语音输入法`；
     2. 点击 **「切换输入法」**，将当前默认输入法选为 `TypeFree`；
     3. *(可选)* 若希望在使用微信键盘/Gboard 时同时拥有悬浮语音球，点击 **「开启无障碍与悬浮球」** 授予无障碍与悬浮窗权限。
2. **三层「统一接口工作台」配置 (`API 配置` 页)**
   - **第 1 层 · 服务商凭证保险箱 (`Provider Vault`)**：点击对应厂商（Google Gemini、阿里云百炼、火山引擎、硅基流动、DeepSeek 或自定义 OpenAI 兼容网关），填入 API Key。所有厂商凭证独立加密保存在本机 `EncryptedSharedPreferences`，切换服务商不会丢失已填 Key。
   - **第 2 层 · 一键推荐组合预设**：填入 Key 后直接点击推荐预设卡片（如「Google 极速流式直出」「国内百炼+豆包极速双阶段」），一键配好 STT 与 LLM。
   - **第 3 层 · 高级路由微调与 `1-Token` 真实测速**：
     - 展开高级设置可分别指定 **语音识别 (STT)**、**智能润色 (LLM)**、**多模态音频直出** 的具体模型；
     - 在模型下拉列表中点击 **「⚡ 测速」**，并发测试当前账号下所有模型的真实首字延迟（`ms`）并自动按速度升序排列；
     - 支持单独切换 **思考模式 (`Thinking`)**：日常输入强烈建议设为 **「关闭思考 (极速)」**。

### 二、AI 语音输入与流式边说边上屏

1. **语音面板录入方式**
   - **单击麦克风**：开始录音，再次点击结束并上屏；
   - **长按麦克风（按住说话）**：按住期间说话，松手即刻完成识别与润色上屏；
   - **取消或清空**：录音过程中点击左侧 `✕` 可随时丢弃本次录音。
2. **流式边说边上屏 (`实时写入`)**
   - **开启方式**：点击键盘左上角 `⊞` 工具面板 → 开启 **「实时写入」**（或在 `设置 -> 输入体验` 中开启 **「流式边说边往输入框写字」**）。
   - **工作机制**：说话同时，增量识别草稿以带下划线的组合态（Composing Text）实时出现在宿主输入框内；松手后自动原地替换为 AI 润色后的定稿，并在顶栏提供 **「退回原文」** 按钮（5 秒内可一键还原未润色的原始逐字稿）。
   - **防冲突保护**：若说话期间手指手动移动了宿主输入框光标，流式直写自动冻结组合态，防止覆盖其他位置文字。
3. **文风一键切换与宿主自动感知 (`App-Aware Styles`)**
   - 点击语音面板底部或 `⊞` 工具面板中的 **「文风」**，可切换 *自然精炼 / 商务得体 / 极简要点 / 俏皮社交 / 学术严谨* 等预设或自定义文风；
   - 在主应用 **「文风」** 页可为不同 App（如微信、飞书、邮件、终端）绑定专属文风，进入对应 App 自动切换。
4. **轻声耳语模式 (`Whisper Mode`) 与外放音频自动避让**
   - 在 `设置 -> 语音与音频` 中开启 **「轻声耳语增益」** 后，深夜或图书馆低声耳语会自动执行 16-bit PCM 软限幅增益放大；
   - 开启 **「录音时自动暂停外放媒体」** 后，按下麦克风瞬间自动暂停正在外放的音乐/视频，防止背景人声被误识别，松手后自动恢复播放。
5. **零延迟语音口令短语 (`Voice Snippets`)**
   - 在主应用 **「词典 -> 语音口令与快捷短语」** 中添加触发词（如口令：`发我的工作邮箱` → 展开内容：`name@company.com`）；
   - 当语音说出该口令时，无需消耗 LLM Token，本地 **`0ms` 瞬间展开**为目标长文本。

### 三、五大 AI 意图工作台（含 v2.8 新增「💬 读屏上下文 AI 帮回」）

1. **🎙️ 口述净写 (`Dictate`，默认模式)**
   - 自动剔除“嗯、啊、那个、然后”等口癖，识别句中改口（如“明天下午三点，不对，四点开会” → “明天下午四点开会”），自动断句加标点。
2. **💬 读屏上下文 AI 帮回 & ✍️ 帮我写 (`Help Me Write`)**
   - **唤起方式**：在键盘顶栏点击 **「帮我写」** 芯片。
   - **场景 A：聊天应用内「💬 读屏上下文 AI 帮回」（微信 / QQ / Telegram / 飞书 / 钉钉 / WhatsApp / 短信等）**
     1. **首次授权披露**：首次在开启无障碍服务的情况下于聊天 App 点击 `帮我写`，面板内会展示「开启读屏上下文帮回？」隐私说明卡（明确告知仅在手动点击时按需读取当前屏幕可见聊天文字并发送给您配置的 AI 服务商，绝不后台常驻监听、绝不写入历史或词库）；点击 **「同意并开启」** 即可激活（也可在 `设置 -> 隐私与上下文` 中随时开关）。
     2. **自动识别双方气泡与一键忽略**：面板顶部自动显示 `💬 已读 N 条 · 点此忽略`，并引用最新一条 `[对方]` 消息摘要；若当前这句不想附带上下文，轻点胶囊即可切换为 `💬 已忽略 · 点此恢复`（退回普通盲写）。
     3. **三种生成回复方式**：
        - **纯手点快捷态度芯片（免开口）**：直接点击面板上的 **「👍 干练应下」「⏳ 委婉顺延」「📋 追问细节」** 任意一枚芯片，AI 立即结合聊天上下文生成得体回复并上屏；
        - **态度芯片 + 口述补充**：先点选一枚态度芯片，再按住麦克风补充具体信息（如选中 `⏳ 委婉顺延` 后口述“改到周四下午两点”）；
        - **直接按住麦克风口述意图**：如说出“婉拒他，说今天在出差”，AI 自动结合对方刚才发来的内容生成高情商回复。
     4. **隐私熔断保护**：在银行、支付宝、密码管理器、系统权限弹窗及密码框中，读屏捕获硬编码强制熔断；关闭面板、切换键盘标签或隐藏键盘时，内存中的屏幕上下文立即清零。
   - **场景 B：非聊天应用或未开无障碍时的「✍️ 帮我写」**
     - 按住麦克风说出核心意图（如“写一份周报总结本周完成了 Rime 引擎集成”），AI 自动扩写为结构清晰的正式文本。
3. **🪄 选中文本语音改写 (`Speak to Edit`)**
   - **唤起方式**：在宿主输入框内长按选中一段文字 → 点击键盘顶栏右侧自动浮现的 **「✨ AI 改写」** 芯片（或在语音面板自动捕获选区）。
   - **操作方式**：
     - 直接点击底部快捷指令芯片：**「润色文采」「扩写详述」「精简摘要」「更委婉专业」「转为英文」**；
     - 或按住麦克风说出自定义修改要求（如“把语气改得更客气一点，加上感谢”）；
     - 改写上屏后若不满意，点击顶栏右侧圆形 **「↶ 撤销」** 按钮即可一键还原修改前的原文。
4. **🌐 实时快译面板 & 悬浮胶囊长按上滑弧形直译 (`Translate`)**
   - **键盘快译面板**：点击顶栏 **「快译」** 芯片，顶部自由选择目标语种（英语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语等），说出中文直接上屏地道外语；
   - **悬浮球上滑弧形直译**：按住全局悬浮胶囊说话时，手指向上滑动呼出弧形语种轮盘，滑到目标语种松手即刻完成翻译并插入光标处。

1. **切换打字全键盘与三种内置方案**

3. **一键下载 58 万雾凇完整词库 & 导入自定义 TSV / Rime 码表**
   - 进入主应用底部 **「词典」** 页：

     - **导入自定义 YAML / TSV 码表**：支持通过系统文件选择器导入自定义 Rime `.yaml` 词典或四码定长 `.tsv` 主码表与反查表，支持随时一键「恢复默认」。

## 📖 自定义音形/Rime 码表制作与导入指引

TypeFree 支持用户将个人常用的码表（如小鹤音形、五笔、自然码等）一键挂载至键盘中：

### 1. 码表格式规范
码表为 UTF-8 编码的纯文本制表符分隔（TSV）文件：
- **主词库 TSV (`dict.tsv`)**：每一行格式为 `编码\t候选词1\t候选词2...`
  ```tsv
  uijm	时间	实践
  xhyx	小鹤音形
  tfre	TypeFree
  ```
- **单字四码反查表 TSV (`dz.tsv`, 可选)**：用于通配符（`` ` ``）查形查音，格式为 `编码\t单字`
  ```tsv
  jibo	瘠
  dkal	丁
  ```

### 2. 生成与挂载方式
1. **使用内置脚本转换 Rime 词典**：
   ```bash
   python3 scripts/build_rime_assets.py \
       --base-dict /path/to/flypy.dict.yaml \
       --dz-dict /path/to/flypydz.dict.yaml \
       --out-dir ./my_tables
   ```
2. **手机端直接导入**：
   - 打开 TypeFree 主应用，切换到底部 **「词典」** 选项卡；
   - 在顶部的 **「四码音形 / Rime 码表」** 卡片中点击 **「导入自定义码表 (TSV)」**；
   - 点击 **「选择主词库文件 (.tsv/.txt)」**（通过 Android SAF 系统安全文件选择器直接选取手机存储或网盘中的码表文件），可选导入单字四码反查表；
   - 确认后后台协程流式写入私有存储并即刻完成热挂载。若需恢复默认词库，随时点击 **「恢复默认」**。

### 环境要求
- **Android SDK**: Compile SDK 35 / Min SDK 26 (Android 8.0 Oreo+)

# 克隆仓库

## 🔒 隐私声明与安全性

1. **零中心服务器**：TypeFree 本身不运营任何数据收集服务器，无埋点统计、无广告 SDK、无追踪器。
2. **直连您的服务端点**：您的音频流与改写/帮回文本仅向您在本地配置的 API 端点（或您自建的本地 Ollama/Whisper 服务）发送。
3. **读屏上下文严格按需与敏感界面熔断**：「读屏上下文 AI 帮回」仅在用户显式同意披露说明且手动点击 `帮我写` 时按需读取当前可见聊天窗口，绝不写入本地历史或词库，且在银行、支付、密码框界面强制熔断。
4. **可控历史留存**：支持选择历史记录留存周期（3 天 / 7 天 / 30 天 / 永久 / 立即清除），敏感凭证加密存储在 Android 私有空间 `EncryptedSharedPreferences` 中。
