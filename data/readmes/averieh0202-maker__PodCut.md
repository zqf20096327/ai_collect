# PodCut

通过文字稿剪辑中文播客：删字同步剪音频，处理停顿和吸气，识别说话人，使用 Agent 初剪，安排独立配乐，并导出剪后音频、文字稿及节目简介。

> 本机单用户源码版，自有代码采用 AGPL-3.0-only 许可证。录音、工程和 API 配置保存在使用者自己的电脑上；仓库不附带私人录音、密钥或历史剪辑。当前主要在 macOS 验证。

## 核心功能

**[观看最新宣传片与全部历史版本](docs/promo/versions/index.html)**

**[观看 36 秒科技风节奏广告（有声版）](docs/promo/tech/index.html)**

五段宣传动画介绍主要编辑流程，已剪去操作等待并加入局部放大与点击提示。[观看 45 秒短片和分段视频](docs/promo/index.html) · [素材与演示说明](docs/promo/README.md)。

**删字同步剪音频**

通过文字选择需要删除的内容，整句删除时同步剪去对应音频，也可撤销或复原。

![长句删除同步剪音频](docs/promo/01-text-edit.gif)

**逐字边界精修，剪到每一个字**

打开单个字的波形，试听并微调起止边界，处理字头、字尾和剪切接缝。

![逐字边界精修](docs/promo/02-word-boundary.gif)

**Agent 初剪，处理重复、改口和含吸气的停顿**

绑定自己的 AI API，结合上下文和可选参考稿，筛选重说与说到一半放弃的表达。参考稿之外的有效内容也应保留。音频分析把识别出的吸气纳入整处停顿处理；初剪后可逐处试听、复原或精修。检测仍可能误判或漏检。

![初剪前后效果样例](docs/promo/03-agent-first-cut.gif)

此动画为合成测试工程经实际剪辑引擎处理后的对比，说话人标签和字界预置；内容删除判断由 Codex 提供。本次没有运行实时语音识别或付费模型 API，不作为真实吸气检测准确率证据。

**背景与过场，两种配乐插入方式**

把素材拖到对应文字处，选择「背景」或「过场」：背景与人声叠加，可提前几秒进入；过场作为独立音乐段插入，后续人声顺延。插入后可查看音乐覆盖范围，单独调整音量、截取和淡入淡出。人声的音量与倍速不会同步作用于音乐。

![背景和过场配乐](docs/promo/04-music.gif)

拖入与类型选择为后期动作示意，参数调整来自真实网页操作；连续拖入流程尚待补录。

**从录音到节目材料**

导出剪后音频、文字稿、播客长文稿和简介时间戳。长文稿以剪后原话为基础，进一步改写可交给使用者自己的 Agent。

![导出节目材料入口](docs/promo/05-export.gif)

另外支持多人说话人标识、人声不变调倍速、历史剪辑自动保存及明亮／深夜模式。说话人标识不等于将混合录音分离成独立音轨。

## 本机运行

建议使用 Node.js 22 或更新版本、npm，以及较新的桌面浏览器。当前主要在 macOS 上验证；Windows 和其他环境需要另行验证。完整本机音频导出依赖 FFmpeg / ffprobe；声学校准另需 Python 3.12 和本机模型。

```sh
git clone https://github.com/averieh0202-maker/PodCut.git
cd PodCut
npm ci
npm start
```

打开 `http://127.0.0.1:5188/`。`npm start` 会检查并构建页面，同时提供完整本机 API，固定使用 5188；端口被占用时会明确报错。它运行期间需要保持终端开启。

macOS 日常使用可执行 `npm run service:install`，安装当前用户的登录启动服务。此后登录自动启动、异常退出自动重启，无需保持终端开启。用 `npm run service:status` 查看状态，`npm run service:restart` 重启，`npm run service:uninstall` 移除自动启动。源码开发继续使用 `npm run dev:opensource`。

先运行 `npm run doctor` 检查环境。在主页创建新剪辑，从「片段 → 导入音频」加载自己的录音，再配置语音服务进行转写。素材栏附带程序生成的演示配乐；开源包不附带 Edge 合成的演示朗读。此前本机已有的演示文件不受影响。

完整步骤见 [安装与使用指南](docs/getting-started.md)，数据存储说明见 [隐私与本机数据](docs/privacy.md)。

## 交给自己的 AI 完成初剪

可以在同一台电脑上，让有终端、文件访问权限的本地 AI 阅读仓库内的 [podcast-producer skill](skills/podcast-producer/SKILL.md)，调用现有转写、校准和剪辑工具，再打开网页人工精修。运行所需的语音识别和内容分析服务需使用者自行配置；本地 AI 对话不会自动替代这些 API。

可直接复制的任务指令、启动检查、命令行流程及当前限制见 [使用自己的 Agent](docs/using-your-agent.md)。精句、停顿阈值及配乐由使用者决定；结果保留源音频和可复原编辑。

## 配置自己的服务

```sh
cp .env.example .env.local
```

录音转写默认使用**火山引擎豆包语音「录音文件识别模型 2.0」标准版**（资源 ID：`volc.seedasr.auc`，`submit` + `query` 模式）。在 `.env.local` 填写自己的火山语音识别凭据；如果使用其他已开通的资源或调用模式，需相应修改配置。Agent 初剪的内容判断由网页绑定的兼容 Chat Completions 模型 API 或自行配置的 DeepSeek 完成，它不是录音转写模型。修改环境文件后重启服务。不要把服务端密钥加上 `VITE_` 前缀。

新录音转写会上传至所配置的语音服务；Agent 内容分析会把文字交给所选模型服务。相应 API 费用由使用者承担。对已经转写的工程进行手动剪辑和原话文字稿导出不需要模型 API。

如需完整的自动逐字校准，另行安装本机运行环境：

```sh
npm run setup:alignment
```

该命令会安装 Python 依赖并下载用于逐字校准的 **Qwen3-ForcedAligner-0.6B** 与 **iic/speech_timestamp_prediction-v1-16k-offline**；它们在本机运行，与火山引擎的录音转写模型分工不同。耗时、内存和磁盘需求尚未在全新机器上完整验证。仓库没有预装模型。

## 与原安装隔离

- 代码是独立的普通文件副本，不使用指向其他安装目录的软链接或硬链接。
- 服务器工作目录、API 配置和 `.podcast-drafts/` 均属于此副本。
- 固定的独立端口隔离浏览器来源；草稿、素材库 IndexedDB 和 OPFS 存储名称也使用准备副本专用名称。
- 第一次打开时，历史剪辑和私人素材库应为空。不会自动读取其他 PodCut 安装的数据。
- 后续修改此目录不会自动更新其他安装。
