# 系统学习 ML

这是一个用 Obsidian 组织的机器学习、深度学习和 AI 基础设施知识库。20 章从张量、Transformer 和强化学习基础，延伸到分布式训练、推理引擎、RL 训推系统、集群数据和工程可靠性。

## 开始阅读

在 Obsidian 中选择 `systemLearning/` 作为库目录，从[整体目录](systemLearning/整体目录.md)进入。GitHub 上可以直接浏览各章的 Markdown 文件。

| 入口 | 用途 |
|---|---|
| [整体目录](systemLearning/整体目录.md) | 按章节和小节浏览主题 |
| [路径地图](systemLearning/路径地图.md) | 按主题词查找笔记的目录和文件名 |
| [QA](systemLearning/QA.md) | 回看已回答的用户批注 |
| [AGENTS.md](AGENTS.md) | 笔记模板、索引维护及批注处理规则 |

## 阅读路径

| 目标 | 从这里开始 |
|---|---|
| 机器学习与模型基础 | 第 1–5 章，张量与自动微分 → Transformer → PyTorch → 强化学习与对齐 |
| 训推系统知识 | 第 6–12 章，训推分工 → 分布式 → 推理优化 → 调度、性能、显存与稳定性 |
| 框架源码与工程机制 | 第 13–20 章，GPU 与内核 → 训练和推理框架 → RL 训推 → 集群、多模态与可靠性 |

在 Obsidian 中，`Cmd/Ctrl + O` 快速打开笔记，`Cmd/Ctrl + Shift + F` 搜索全库。

## 补充笔记

先在路径地图里确认主题归属，优先扩充已有笔记。新增主题时同步登记整体目录和路径地图。在任意正文笔记中用 `【user】` 开头提问，答复落在对应笔记里，QA 记录答案的位置。
