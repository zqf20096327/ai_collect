# AegisAI · 基于大模型的网络安全渗透测试系统

> 大学生创新创业项目 · 自动化渗透测试平台（授权测试 / 教学演示用途）

AegisAI（神盾）是一个由大模型驱动的自动化渗透测试系统：智能体自主规划「**侦察 → 资产枚举 → 漏洞检测 → AI 分析与报告**」的完整测试流程，集成 Nmap 端口扫描、Web 指纹识别、敏感路径枚举、SQL 注入 / XSS / 弱口令 / 命令注入 / 路径穿越检测器与本地 CVE 知识库，并自动生成专业渗透测试报告。

内置**本地演练靶场**（127.0.0.1:9001），无需安装 DVWA 等外部靶机即可完整演示。

## ✨ 核心特性

| 特性 | 说明 |
|---|---|
| 🧠 大模型驱动智能体 | LLM 每一步自主决策「下一步调用什么工具」，输出推理过程；决策异常自动回退内置策略引擎 |
| 🔌 大模型可插拔 | 支持 DeepSeek / 智谱 GLM / 通义千问 / Kimi / OpenAI 及任意 OpenAI 兼容接口；**未配置 Key 时以离线策略引擎运行**（功能完整，可演示） |
| 🛠 工具链集成 | Nmap（自动检测，缺失时回退内置纯 Python 扫描器）、HTTP 指纹、目录枚举（含软 404 识别）、5 类 Web 漏洞检测器（全部带对照验证防误报） |
| 📚 本地 CVE 知识库 | 30+ 条「产品+版本」漏洞规则与暴露面加固提示，离线匹配，可按需扩充 |
| 🎯 内置演练靶场 | 一键启动的本地靶场（SQLi / XSS / 弱口令 / 命令注入※ / 路径穿越※ / 敏感文件 / 需登录的成员页），※为模拟实现，不执行真实命令、不读取真实文件 |
| 🔑 靶场凭据（选填） | 新建任务可填靶场账号密码：智能体先登录目标（自动兼容 CSRF 表单，适配 DVWA 类靶场）再检测，并可发现**登录后页面**的漏洞；凭据只在内存中使用，不落盘、接口不回显 |
| 📄 自动报告 | Markdown + 可打印 HTML 渗透测试报告（封面 / 执行摘要 / 风险统计 / 证据 / AI 分析 / 修复建议） |
| 📡 实时可视化 | WebSocket 推送智能体的每一步思考、工具调用与发现；深色安全运维风格 Web 界面 |
| 🔐 合规设计 | 创建任务必须勾选授权确认；扫描范围强制限定在授权 scope 内；只做检测验证，不投放破坏性利用载荷 |

## 🚀 快速开始

环境要求：Windows / macOS / Linux，Python 3.10+（开发验证用的是 3.12）。

```bash
# 1. 安装依赖（建议使用虚拟环境）
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt     # Windows
# .venv/bin/python -m pip install -r requirements.txt       # macOS / Linux

# 2. 一键启动（平台 :8000 + 本地靶场 :9001）
.venv/Scripts/python scripts/start_all.py

# 3. 浏览器打开
#    http://127.0.0.1:8000
#    新建任务 → 目标填 127.0.0.1:9001 → 勾选授权确认 → 启动智能体
```

命令行方式（无界面）：

```bash
.venv/Scripts/python cli.py scan -t 127.0.0.1:9001 --name 演示 --authorized
.venv/Scripts/python cli.py tools          # 查看可用检测工具
```

运行测试：

```bash
.venv/Scripts/python -m pytest tests -q
```

## 🧩 接入真实大模型（重要）

系统默认以**离线演示模式**运行（无需任何 Key，AI 分析由内置策略引擎完成，输出带 `[离线演示]` 标记）。
拿到 API Key 后，编辑 `.env` 即可切换为真实大模型驱动：

```ini
AEGIS_LLM_PROVIDER=deepseek          # deepseek / zhipu / qwen / kimi / openai / custom
AEGIS_LLM_API_KEY=sk-xxxxxxxx
```

重启后顶栏会显示「LLM：在线」，智能体的每一步决策、发现分析、执行摘要都由大模型生成。
推荐 [DeepSeek](https://platform.deepseek.com) 或智谱 `glm-4-flash`（有免费额度）。

## 📦 发给同学 / 换电脑运行

整个文件夹是**自包含、可移植**的——靶场就是项目的一部分（`range/`），在任何电脑上启动都会随平台一起在本机运行，不需要额外搭建。

**方式一（推荐，Windows）**：运行 `scripts/make_package.py` 生成分享包 zip 发给同学，对方解压后**双击 `启动.bat`** 即可（自动建虚拟环境装依赖、起平台+靶场并打开浏览器），只需电脑已装 Python 3.10+。

**方式二（手动）**：直接把项目文件夹压缩发送（**排除 `.venv/`、`data/`、`__pycache__/`**），对方按"快速开始"自行建环境。

两种玩法：
- 各自本机测：朋友在他电脑上扫 `127.0.0.1:9001`（他的本机靶场）；
- 局域网互测：你在 `.env` 里把 `AEGIS_RANGE_HOST=0.0.0.0` 并放行防火墙 9001 端口，朋友新建任务时目标填 `你的局域网IP:9001`——即可演示"跨主机渗透测试"（注意仅限信任的局域网）。

> `data/` 里的任务与报告是运行数据，不会（也不应）包含在分享包里；`.env` 默认离线演示模式，朋友无需任何 API Key。

## 🔐 合规与安全声明

- 本系统**仅用于已获书面授权**的安全测试与教学演示；对未授权目标进行渗透测试属于违法行为。
- 创建任务时必须勾选授权确认，所有扫描行为强制限定在授权范围（scope）内。
- 检测器只做「检测与验证」，不投放破坏性利用载荷；靶场中的命令执行与文件读取均为模拟实现。
- 测试产生的所有数据（任务、报告）保存在本地 `data/` 目录。
