# dsh-hippocampus

给 DeepSeek Harness（DSH）里的会话一份**会变淡但不会说谎**的长期记忆。

DSH 的会话本身没有跨会话记忆：上下文一压、窗口一关，前面聊过的东西就没了。
这个插件补上那一层——**自动记**，不用模型自觉调用；**按线索想**，而不是每轮把旧事全塞回去；**会变淡**，久远的东西降权，但原话不删。

---

## 它解决什么

常见的「记忆」做法是：存摘要，需要时把摘要塞进上下文。这个做法的毛病是——**摘要一改，原话就没了**。哪天摘要抽错了一条，你再也回不去看当时到底说了什么。

这个插件的取舍相反：

| | 存什么 | 回得去吗 |
|---|---|---|
| 常见做法 | 每轮压成摘要存库 | 不能，摘要即真相 |
| 本项目 | **只增不改的原始流**（每条带时间） | 能，索引坏了删掉重算 |

所有派生数据（索引、段落、显著度、预激活）都是**算出来的**，`stream.jsonl` 才是唯一事实。所以：

- 索引写坏了 → 删 `state.json` 重算，数据不受影响
- 摘要抽错了 → 不影响原话，重抽就行
- 想换排序规则 → 重算，不用迁移数据

---

## 它做三件事

**1. 自动记。** 每一轮、每次工具调用都落盘。工具调用也记——「我上次是这么查的」「这条命令报错了」是经历的一部分，不是噪声。

**2. 按线索想。** 每轮先看当前这段话，再从库里找相关的旧事，**最多浮 3 条**。不是「把所有相关都端上来」——那等于没筛选。

**3. 会变淡。** 久远的段在召回里降权（半衰期可配）。但**原始流一条不删**——变淡的是「想起来的机会」，不是「发生过的事实」。

## 安装

它是个 DSH 插件包。挂进 DSH 的 profile：

```bash
# Linux / macOS
ln -s /path/to/dsh-hippocampus ~/.dsh/profiles/<your-profile>/node_modules/dsh-hippocampus

# Windows（管理员 PowerShell）
New-Item -ItemType SymbolicLink `
  -Path "$env:USERPROFILE\.dsh\profiles\<your-profile>\node_modules\dsh-hippocampus" `
  -Target "D:\path\to\dsh-hippocampus"
```

然后**重启 DSH**。

重启后看日志 `~/.dsh/hippocampus/diag.log`，应该出现：

```
apply 跑完 · v0.2.x.x · code=xxxxxxxx
```

没有这一行 = 没挂上。

## 配置

第一次启动会在 `~/.dsh/hippocampus/config.json` 生成一份默认配置。最少只需要一项：

```json
{
  "workspaces": ["D:\\path\\to\\your-workspace"]
}
```

`workspaces` 里列的文件夹才会被记。**没列的文件夹，它一个字都不写**——宁可没记忆，也不要串线。

完整字段见 `config.example.json`。几个常用的：

| 字段 | 默认 | 是什么 |
|---|---|---|
| `workspaces` | `[]` | 要记的文件夹（空 = 哪都不生效） |
| `lines` | `[]` | 同一个文件夹里住着多个身份时，按会话分线，各自记忆互不可见 |
| `humanName` | `human` | 群聊场景里「人」的显示名，群消息靠它区分人和 bot |
| `primeMax` | `3` | 每轮最多浮几条旧事 |
| `halfLifeDays` | `30` | 变淡的半衰期 |

`lines` 那段有个坑要提前知道：**给一个文件夹补上 `line` 名，库目录名会跟着变**（目录名里带 `sha1(cwd + '::' + 线名)`）。改名之前先备份旧库，否则旧记忆会留在没人读的目录里。

## 数据在哪

全在本地，一个字节都不出网：

```
~/.dsh/hippocampus/
  config.json                 你的配置
  diag.log                    运行日志
  <工作区名>-<hash>/
    stream.jsonl              原始流（唯一事实，只增不改）
    state.json                派生索引（可删，下次启动重建）
    seqs.json                 事件序号账本（防重复写）
```

**这几样都是你的隐私，不要连仓库一起分发。**

---

## 限制（说在前面）

- **依赖 DSH。** 它不是独立程序，要 DSH 宿主注入才能跑。没有 DSH 装不起来。
- **没有向量检索。** 召回走 BM25 + 中文分词，换个说法就找不到了。这是有意的取舍——为了零依赖、离线、可解释。真需要语义检索时再上。
- **单机。** 库是本地的，不同步、不联网、没有服务端。
- **Windows 优先。** 路径和软链部分按 Windows 测的；其它平台没验过。
