## 📖 Abstract
<p align="justify">Layout-to-image (L2I) generation for remote sensing imagery requires realistic small objects aligned with prescribed oriented bounding boxes (OBBs). However, global box descriptions in prior L2I methods leave local geometry within image-token regions implicit. Coarse, uniform latent grids may also represent small objects with only one or a few image tokens. Together, these constraints hinder the generation of small objects with accurate shapes and orientations. To address these limitations, we present <b>GeoGrain</b>, a granularity-aware L2I framework for precise small-object control in remote sensing imagery. GeoGrain introduces (i) Granularity-Aware Geometry Encoding (GAGE), which constructs layout tokens from global OBB descriptions with local geometric conditions at image-token positions, and (ii) Granularity-Aware Token Expansion (GATE), which subdivides image-token grid cells overlapping the input OBBs, producing finer image tokens while retaining coarse tokens elsewhere. GAGE encodes local OBB geometry on the resulting mixed-resolution grid, aligning each layout token with its corresponding image token. Experiments on the oriented small-object detection datasets SODA&#8209;A and AI&#8209;TOD&#8209;R demonstrate state-of-the-art layout fidelity alongside high generation quality. On these datasets, GeoGrain improves AP over the strongest baseline by 18.6 and 6.3 points, respectively, reaching AP comparable to that measured on real images. Data augmentation with our generated images also improves downstream detection and outperforms augmentation with images from the baselines.</p>

## 🧩 Method Overview

<div align="center">
    <a href="assets/framework.jpg"><picture><source type="image/avif" srcset="assets/framework.avif"><img src="assets/framework.jpg" alt="Overview of GeoGrain" width="100%"></picture></a>
</div>

<p align="justify">GeoGrain builds on a pretrained text-to-image diffusion transformer, <a href="https://huggingface.co/black-forest-labs/FLUX.2-klein-base-4B">FLUX.2 [klein] 4B Base</a>, with a frozen image&ndash;&#8288;text branch and a trainable image&ndash;&#8288;layout branch.</p>

<ul>
<li><div align="justify"><b>GAGE (Granularity-Aware Geometry Encoding).</b> For every image-token cell that an OBB overlaps, a layout token combines the class label, the global OBB coordinates, the local intersection geometry inside the cell and the cell's position relative to the object; it shares its RoPE position with that image token.</div></li>
<li><div align="justify"><b>GATE (Granularity-Aware Token Expansion).</b> Grid cells that overlap an input OBB are subdivided into 2&times;2 fine tokens, while coarse tokens are kept elsewhere; fine and coarse tokens are denoised jointly.</div></li>
<li><div align="justify"><b>Masked flow-matching loss.</b> Training layouts hold at most <i>n</i> objects; the loss skips cells covered only by annotated objects left out of the layout, so the model does not learn to generate objects the layout does not specify.</div></li>
</ul>
