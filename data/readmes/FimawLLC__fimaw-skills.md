## Usage

```bash
# Skills are bundled inside FimawCode — open a workspace and they load automatically.
# Or clone this library standalone:
git clone https://github.com/FimawLLC/fimaw-skills.git
```

Each skill lives in its own directory with a `SKILL.md` (YAML front matter + guidance)
and optional `references/`, `scripts/`, or `assets/`.
