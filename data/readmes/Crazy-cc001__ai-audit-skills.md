# AI Audit Skills · 审计与财务 AI 技能库

> 把重复的对账、底稿、合规审核、PDF/Excel 批量处理，交给 AI Agent。
> 面向审计师、会计师事务所、代账会计、企业财务与内审。

**English**: A collection of AI-agent skills for audit and finance work — invoice/bank reconciliation, audit working papers, public-procurement compliance checks, and batch PDF/Excel extraction. Built for Claude Code and compatible agents. All examples are sanitized.

---

## 这些技能解决什么问题

审计和财务工作里，大量时间花在**规则明确、但极其耗人**的事情上：逐张发票对流水、对着回单敲数字、从账套导十年总账再填底稿、一页页翻 PDF 找投标人信息。

这些工作有一个共同点：**判断需要人，计算不需要人。**

这个仓库把「计算」交给脚本，把「判断」留给你和 AI：

- 脚本负责：解析、匹配、求和、校验、出表——同样输入必得同样输出；
- AI 负责：理解你的需求、判断业务归属、决定下一步、把异常交回给你；
- 你负责：拍板、复核、签字。

> 核心原则：**数字不靠感觉算。对不上就停，不猜业务原因。**

## 1. 发票 × 银行流水自动对账

**你原来怎么做**：把发票台账和银行流水并排放，VLOOKUP 一列列对，遇到红冲、部分回款、多笔小额合并就卡住。

**现在怎么做**：把销项发票、进项发票、银行流水三类数据放进目录，AI 按「XML 数电票 > 原生 PDF > 扫描 PDF-OCR」优先级解析，做四层匹配（金额容差、户名模糊、日期区间、多笔合并），输出六张 Excel 表和一份 Markdown 对账报告。

**输出**：
- 已匹配对账明细
- 未核销发票清单
- 无票银行流水（税务风险）
- 往来差额汇总
- 财税风险预警
- 解析异常单据

**适合**：代账会计月度全盘对账、企业财务应收应付核对。

## 2. 银行对账单 × 记账凭证核对

**你原来怎么做**：对着银行回单逐笔敲进 Excel，再和凭证比；数字对不上就开始猜「是不是重复付款」「是不是超付」。

**现在怎么做**：以**对账单**为准（不用回单拼凑），先做三重自校验——金额合计 = 表头发生额、逐笔余额链自洽、承前页 = 上月末余额；通过后再和凭证逐笔勾稽。**数字对不上就停，回原件复核，不猜业务原因。**

**输出**：逐笔核对表（xlsx）、差异清单、银行存款借/贷/净额与对账单的勾稽结论。

**适合**：审计抽凭、银行存款余额核对、总账会计月末对账。

---

## 3. 审计底稿自动编制

**你原来怎么做**：在财务软件里逐年切换账套，导出总账、明细账，再手工填十年期审定表；科目代码跨年一变，公式就错。

**现在怎么做**：从新纪元（挂接金蝶 K3 账套）读取明文数据，按「读取账套 → 提取年度数据 → 解析报表 → 核对勾稽 → 填充底稿 → 明细补全 → 差异标注」七步流水线，按你的底稿模板填审定表十年列、二级三级明细，并自动做账表核对。

**输出**：填好的审计底稿（审定表 + 明细表 + 账表核对 + 差异说明）。

**适合**：行业协会、民非组织等需要连续多年列示的审计项目；换客户时只改配置区的 5 个地方。

> 这个技能与新纪元/K3 和特定底稿模板绑定，换软件或换模板需要按 SKILL.md 的“通用性”一节调整。

## 4. 招采项目合规审核

**你原来怎么做**：翻招标文件、投标文件、评标报告，逐条对照法规；异常低价、时间节点、评分畸高畸低全靠眼睛看。

**现在怎么做**：按审核对象加载对应检查清单（招标文件、投标文件、评标报告、合同、招标代理），逐项对照法规；再用四个脚本做机器检查：

- `abnormal_price_check.py`：异常低价检测（支持房建/轨道交通/市政）
- `timeline_check.py`：9 项时间节点合规检查
- `scoring_check.py`：客观分一致性、主观分 Z-score 畸高畸低
- `bid_metadata_check.py`：投标文件创建者/修改者/MD5，检测同一人编制迹象

**输出**：结构化审核报告（严重问题 / 一般问题 / 合规结论 + 法规条文索引）。

**适合**：政府投资项目审计、巡审、招标代理机构检查。

> 内置法规以国家及安徽省、合肥市现行规定为主，其他地区请替换 `references/法规速查表.md`。

## 5. PDF 信息批量提取

**你原来怎么做**：一页页翻投标文件，找到《投标人基本情况表》，复制名称、地址、联系人、电话，粘到 Excel。

**现在怎么做**：按「关键词页定位 → 转 Word → 清洗表格 → 提取字段 → 汇总 Excel」四步流水线；找不到基本情况表时自动兜底，从唱标信息、法定代表人证明书、授权书里提取。

**输出**：投标人信息汇总 Excel（名称、注册地址、联系人、电话、法定代表人、技术负责人等）。

**适合**：招投标资格审查、合同要素提取、批量档案整理。

---

## 6. Excel 项目批量提取 + 查重

**你原来怎么做**：在抽查清单里按填充色一行行筛，记下项目编号，去源目录找文件夹、复制资料，再逐个提取投标人信息，最后手工查重。

**现在怎么做**：按机构、填充色、序号/编号区间筛选标记行 → 按编号匹配源目录文件夹并复制 → 逐项目跑 PDF 提取流水线 → 按「项目编号-项目名称」重命名汇总 → 单列查重（报告/标色/去重副本）。

**输出**：每个项目一份《投标人信息汇总表》 + 总汇总表 + 查重报告。

**适合**：招投标项目抽查、批量资料整理、投标人信息比对。

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/Crazy-cc001/ai-audit-skills.git
```

### 2. 安装到 Claude Code

**macOS / Linux / Git Bash**：

```bash
mkdir -p ~/.claude/skills
cp -r ai-audit-skills/skills/* ~/.claude/skills/
```

**Windows PowerShell**：

```powershell
Copy-Item -Recurse .\ai-audit-skills\skills\* "$env:USERPROFILE\.claude\skills\"
```

也可以只复制你需要的单个技能目录。

### 3. 在 Claude Code 里直接说需求

```
帮我把这个月的发票和银行流水对一下，输出六张表
核对这份银行对账单和记账凭证，先做三重自校验
按这个底稿模板，把 2016-2025 年的账套数据填进去
审核这个项目的招标文件、投标文件和评标报告
从这堆投标 PDF 里提取投标人名称、地址、联系人和电话
```

AI 会读取对应技能的 `SKILL.md`，按步骤调用 `scripts/` 下的本地脚本，最后把 Excel 和报告交给你。

## 它怎么工作

```
你（审计 / 财务）
   │  自然语言需求
   ▼
Claude Code / AI Agent
   │  读取 SKILL.md，按步骤调度
   ▼
本地 Python 脚本（解析 / 匹配 / 计算 / 校验）
   │
   ▼
Excel 报表 + Markdown 报告 + 待确认清单
```

每个技能都是一个独立目录：

```
skills/<skill-name>/
├─ SKILL.md          # 给 AI 看的操作手册：什么时候用、按什么步骤做、有哪些坑
├─ scripts/          # 确定性计算：解析、匹配、校验、出表
└─ references/       # 检查清单、法规、字段字典、配置
```

`SKILL.md` 不是写给程序看的 API 文档，而是写给 AI 的**作业指导书**——包含业务规则、判断边界、常见坑和输出格式。这是它和普通脚本仓库最大的区别。

## 安全与隐私

- **示例已脱敏**：仓库中不含真实客户名称、人名、银行账号、金额明细；路径统一替换为 `C:\path\to\...` 等占位符。
- **本地运行**：脚本在你的机器上处理文件，不主动上传数据。
- **不要把真实客户资料粘贴到不信任的在线服务**；使用前请遵守客户保密协议和所在机构的数据安全规定。
- 如果你要提交 Issue 或 PR，请先脱敏，不要贴真实底稿、发票、流水或企业名单。
