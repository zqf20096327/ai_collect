Data and Analytics roles have some of the strictest ATS filters in the industry. Job descriptions for Data Analyst roles contain dense technical keywords (SQL, Python, Tableau, Power BI, ETL pipelines) and the ATS filters resumes ruthlessly before a human ever reviews them.

This template is engineered specifically for the Data domain. The single-column LaTeX layout guarantees 100% ATS parseability, while the section structure is optimized to highlight the quantified impact (metrics, percentages, scale) that Data hiring managers look for.

### ⚡ The Data Resume Formula: What Actually Gets You Shortlisted

The #1 mistake Data candidates make is listing tools without quantified impact. ATS systems scan for keyword density, but human reviewers scan for numbers. This template's structure forces you to write in the only format that wins both:

**Wrong:** *"Used SQL to query databases and generate reports."*
**Right:** *"Engineered 12 SQL pipelines processing 4M+ daily rows, reducing reporting latency by 73%."*

The template sections are pre-ordered to put your most impressive technical proof at the top, where the 6-second recruiter scan always starts.
