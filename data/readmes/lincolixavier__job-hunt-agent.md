# job-hunt-agent

**Turn your AI coding agent into a careful, honest job-search assistant.**

It finds postings that match your rules, tailors a one-page CV for each, fills the application, tracks everything, and hands you anything that needs a human.

## Why

Job hunting with an AI agent works surprisingly well, until it doesn't: it applies to the same company twice, invents a skill, misses the "hybrid, 3 days a week" line at the bottom, asks for a salary below your floor, writes cover notes that scream "AI", or forgets what it did yesterday.

This repo is the structure that fixes that, distilled from a real search that ran 20+ batches and more than a hundred applications:

- **Your facts, once.** Your CV lives as data (`cv.toml`). Every tailored CV picks and reorders those facts. Nothing gets invented.
- **Your rules, enforced.** Hard rules (remote only, no on-call, salary floor, companies to skip) are checked by code before the agent spends time on a posting.
- **A memory that's a file.** Every posting found, skipped, applied, rejected or interviewing is one row in `tracker.csv`, with dated notes. Duplicates are refused.
- **You stay in charge.** The agent never sends a message without your yes, never touches passwords, IDs or CAPTCHAs, and hands you logins, videos and personal stories with everything else prepared.


## Quickstart

```bash
git clone https://github.com/lincolixavier/job-hunt-agent.git && cd job-hunt-agent
make setup && source .venv/bin/activate   # or just use bin/jobhunt, no install needed
jobhunt init                               # creates your private workspace in me/
cp ~/Downloads/my-cv.pdf me/base/
claude                                     # or any agent that reads AGENTS.md
> /setup
```

The setup workflow reads your CV, asks about your rules, salary and writing preferences, and builds a first CV for you to approve. Details: [docs/getting-started.md](docs/getting-started.md).

## What's inside

```text
AGENTS.md            instructions every agent reads (CLAUDE.md imports it)
workflows/           step-by-step playbooks: setup, hunt, apply, inbox, prep, outreach
.claude/commands/    /setup /hunt /apply /inbox /prep /outreach /status for Claude Code
src/jobhunt/         the jobhunt CLI: standard-library Python, no dependencies
docs/                guides, portal field notes, where to find postings, writing style
me/                  YOUR data (created by `jobhunt init`, gitignored)
```

### The `jobhunt` CLI

The agent handles judgment; the CLI handles everything that should never be guessed.

| Command | What it guarantees |
|---|---|
| `jobhunt screen <url>` | Deal-breakers (on-call, hybrid, relocation...) are flagged with the exact sentence, negations included. |
| `jobhunt track find <company>` | You never apply twice. |
| `jobhunt cv build <slug>` | A tailored CV from your facts, rendered to PDF, failing if it spills past one page. |
| `jobhunt ask --posted "90k-160k"` | The salary you type follows your policy and warns below your floor. |
| `jobhunt lint draft.txt --kind linkedin_note` | No banned phrases, no em dashes, within the character limit. |
| `jobhunt fetch <url>` | Full posting text from Ashby, Lever and Greenhouse APIs, saved before it disappears. |
| `jobhunt status` | A readable dashboard of every application, with stale ones flagged. |

Full reference: [docs/cli.md](docs/cli.md).

## Privacy

Your workspace (`me/`) is gitignored and stays on your machine. The CLI only makes network requests in `jobhunt fetch`, to public posting APIs. What your agent sends to its model provider is governed by that provider's settings.

## Responsible use

This is a tool for one person's careful search, not a spam cannon: no duplicate applications, no CAPTCHA solving, no messages without approval, no invented experience. Please read [docs/responsible-use.md](docs/responsible-use.md).
