# Awesome Medical Imaging Agents [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Agentic AI systems for medical image analysis, including radiology agents, pathology agents, ultrasound agents, surgical imaging agents, segmentation agents, and medical vision-language model agents.

This repository curates research papers, agent benchmarks, and open-source systems for medical imaging agents. It focuses on tool use, retrieval-augmented generation, multi-agent collaboration, planning, segmentation, report generation, clinical reasoning, safety, and evaluation across CT, MRI, chest X-ray, ultrasound, pathology, endoscopy, ophthalmology, PET, and other imaging modalities.

## Start Here

Selected systems, surveys, and benchmarks across imaging domains.

- [MedImageOSWorld](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-medimageosworld) - Benchmark for GUI agents operating CT, MRI, and ultrasound consoles and planning acquisitions (2026).
- [MedRAX: Medical Reasoning Agent for Chest X-ray](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-medrax) - Director-worker architecture where composable tool-using agents outperform single-model baselines on chest X-ray reasoning (Radiology, 2025; [Code](https://github.com/bowang-lab/MedRAX)).
- [RadAgent: A Tool-Using AI Agent for Stepwise Interpretation of Chest CT](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-radagent) - Generates chest CT reports through an explicit tool-calling workflow with inspectable intermediate reasoning traces (Radiology, 2026).
- [Agentic Systems in Radiology: Design, Applications, Evaluation, and Challenges](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-agentic-systems-in-radiology) - Best entry-point survey mapping agent design patterns, evaluation protocols, and open challenges across the full radiology pipeline (Survey · Radiology, 2025).
- [CPathAgent: An Agent-based Foundation Model for Interpretable High-Resolution Pathology Image Analysis](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-cpathagent) - Agentic pathology foundation model mimics pathologist diagnostic logic to deliver interpretable analysis of whole-slide images (Pathology, 2025).
- [Echo-alpha: Large Agentic Multimodal Reasoning Model for Ultrasound Interpretation](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-echo-alpha) - Demonstrates that large agentic reasoning models can jointly localize lesions and perform grounded multimodal clinical interpretation of ultrasound studies (Ultrasound, 2026).
- [EndoAgent: A Memory-Guided Reflective Agent for Intelligent Endoscopic Vision-to-Decision Reasoning](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-endoagent) - Memory-guided reflective agent for endoscopic vision-to-decision reasoning; representative model for specialty-specific imaging agent design (Endoscopy, 2025; [Code](https://github.com/Tyyds-ai/EndoAgent)).
- [VoxelPrompt: A Vision Agent for End-to-End Medical Image Analysis](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-voxelprompt) - Multi-stage vision agent for end-to-end volumetric medical image analysis covering segmentation, detection, and QA across CT, MRI, and PET (3D Imaging, 2024).
- [MedSAM-Agent: Empowering Interactive Medical Image Segmentation with Multi-turn Agentic Reinforcement Learning](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-medsam-agent) - Introduces multi-turn RL to train an interactive segmentation agent that decides which prompts to issue to SAM — the first RL-trained imaging segmentation agent (Segmentation, 2026; [Code](https://github.com/CUHK-AIM-Group/MedSAM-Agent)).
- [MMedAgent: Learning to Use Medical Tools with Multi-modal Agent](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-mmedagent) - First paper to train a medical agent that selects and calls specialist tools (segmentation, retrieval, calculators) on demand across seven imaging modalities (Multimodal, 2024; [Code](https://github.com/Wangyixinxin/MMedAgent)).
- [MedAgent-Pro: Towards Evidence-based Multi-modal Medical Diagnosis via Reasoning Agentic Workflow](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-medagent-pro) - Integrates imaging, labs, and clinical guidelines via explicit tool calling; demonstrates evidence-based multimodal clinical reasoning (Medical VLM, 2026; [Code](https://github.com/jinlab-imvr/MedAgent-Pro)).
- [AgentClinic: A Multimodal Benchmark for Tool-Using Clinical AI Agents](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-agentclinic) - The canonical multimodal benchmark for tool-using clinical AI agents with an open simulator across imaging, EHR, and lab modalities (Benchmark, 2026; [Code](https://github.com/SamuelSchmidgall/AgentClinic)).
- [ABRA: Agent Benchmark for Radiology Applications](https://github.com/Nanboy-Ronan/awesome-medical-imaging-agents#start-abra) - First benchmark where agents operate a real DICOM viewer (OHIF + Orthanc) via tool calls, testing end-to-end radiology agent workflows on live imaging software (Benchmark · Radiology, 2026).

## Scope

- Medical imaging agents for radiology, pathology, ultrasound, CT, MRI, chest X-ray, dermatology, endoscopy, PET, ophthalmology, and cardiac imaging.
- Agent workflows for tool use, retrieval-augmented generation, multi-agent collaboration, self-reflection, planning, report generation, quality control, and human-in-the-loop review.
- Research resources including peer-reviewed papers, arXiv preprints, agent benchmarks, reproducible code, and related open-source systems.
- Safety and evaluation work on hallucination detection, fairness, robustness, uncertainty, abstention, privacy, and clinically grounded evaluation.

## Radiology Agents (57)

Agents for chest X-ray, CT, MRI, DICOM workflows, radiotherapy planning, and radiology decision support.

- [CAG-WM: A Synthetic-Data-Driven Coronary World Model for Autonomous Guidewire Navigation](https://papers.miccai.org/miccai-2026/0138-Paper4072.html) - A world model trained on 100 synthetic angiography–3D coronary cases in a SOFA simulator learns vessel–guidewire dynamics and plans through internal multi-step rollouts for autonomous percutaneous coronary guidewire navigation; it exceeds 80% success on 20 multi-center clinical cases with the shortest total navigation time (about 2 minutes) (MICCAI 2026, 2026; [Code](https://github.com/CaoYue2004/CAG-WM)).
- [SeedPro: Place Brachytherapy Seeds Like Expert Clinicians via Hierarchical Reinforcement Agents](https://papers.miccai.org/miccai-2026/0930-Paper3635.html) - Hierarchical reinforcement-learning agents generate fine-grained preoperative brachytherapy seed-placement plans that favor fewer needle punctures; on internal and external datasets they reduce organ-at-risk exposure by 12–20% and puncture count by 25% relative to prior planners (MICCAI 2026, 2026; [Code](https://github.com/Haitao-Lee/SeedPro)).
- [MeVisQA: Medical Visual Question Answering via Visual Programming](https://papers.miccai.org/miccai-2026-sat/SAFER_007.html) - Applies visual programming to medical VQA, with generated code invoking vision modules so reasoning and execution stay separate and auditable for measurement, counting, multi-step, and multi-image questions; introduces the radiologist-workflow-inspired SliceVQA benchmark, where it nearly doubles the accuracy of recent medical LVLMs (MICCAI 2026 SAFER workshop, 2026; [Dataset](https://github.com/NdkArthur/SliceVQA)).
- [X-Ragent: Tool-Augmented Reinforcement Learning for Evidence-Grounded Chest X-Ray Reasoning](https://arxiv.org/abs/2610.16811) - Trains a Qwen3-VL-8B chest X-ray agent with agentic SFT and GRPO on Rad-CoT, a 7.7K-trajectory tool-augmented corpus, separating learned evidence seeking from validity-gated measurement so invalid quantitative tool outputs never enter the reasoning; reports the best results on three CXR benchmarks, including +8.6 points on held-out ChestAgentBench (arXiv, 2026).
- [MammoClaw: Towards Skill-Evolving Agent Harness for Breast Cancer Mammography Analysis](https://papers.miccai.org/miccai-2026-sat/Deep_Brea3th_010.html) - Training-free harness lets frozen MLLMs gather mammography evidence with ROI, paired-view, and contralateral-breast tools, and turns failed trajectories into reusable skills; on BI-RADS assessment and breast density estimation, tools alone did not reliably help while evolved skills improved tool use in some settings (MICCAI 2026 Deep-Brea3th workshop, 2026; [Project](https://krishnakanthnakka.github.io/mammoclaw)).
- [OA-MAP: Evidence-Grounded Multi-Agent Multimodal Framework for Interpretable Knee Osteoarthritis Progression](https://arxiv.org/abs/2610.12134) - A coordinator recruits MRI, X-ray, and clinical agents that select prediction tools and retrieve literature evidence, with uncertainty-informed clinician review that triggers recomputation of affected findings; fusion models reach AUROCs of 0.80 for structural and 0.68 for pain progression on 100 held-out FNIH participants (arXiv, 2026).
- [RadOnc-Agent: An LLM-Orchestrated Framework for AI Workflows Across the Radiotherapy Care Pathway](https://arxiv.org/abs/2610.06923) - An LLM controller coordinates 26 functions across four radiotherapy phases through schema-constrained tool calls and persistent patient context; evaluation measures workflow execution rather than clinical correctness or prospective benefit (arXiv, 2026).
- [Multi-Agent AI for Chest Radiography: A Sequential Segmentation and LLM-Driven Consultative Tool for Medical Training](https://www.medrxiv.org/content/10.64898/2026.05.29.26354432v1) - Vision agents localize anatomy and segment pathology, then ground a locally hosted LLaVA 7B tutor with prompt guardrails that block unanchored queries; the preprint reports no quantitative performance metrics (medRxiv, 2026).
- [When to Request and Whether to Trust: A Two-Decision Imaging Agent for Pleural Effusion Assessment](https://papers.miccai.org/miccai-2026-sat/MedAgent_033.html) - A learned policy requests lateral chest radiographs selectively, then checks image-pair compatibility before re-reading; counterfactual controls find no measurable mean benefit from matched lateral views over duplicated frontal images, and verification rejects some valid returns (MICCAI 2026 MedAgent workshop, 2026).
- [LongCXR-Agent: Query-Driven Tool Selection for Longitudinal Chest X-ray Reasoning](https://papers.miccai.org/miccai-2026-sat/MedAgent_024.html) - A query-driven agent preserves prior-current chest X-ray order, routes questions among four comparison types, and selectively invokes five specialized tools for disease transitions, severity, spatial evidence, and structural comparison; evaluated on 666 longitudinal QA episodes (MICCAI 2026 MedAgent workshop, 2026).
- [AutoProtocol: Agent-Driven Automation of CT and MRI Protocoling in Radiology](https://openreview.net/forum?id=UXJ4X0HCHi) - Retrieves similar cases from 4.4 million prior examinations so an LLM agent can recommend patient-specific CT and MRI protocols without task-specific fine-tuning (MIDL 2026 Short Paper, 2026).
- [FRAC-MAS: A Safe and Explainable Multi-Agent System for Fracture Diagnosis](https://arxiv.org/abs/2608.28662) - Stacks four vision models with conformal prediction to produce statistically grounded differential fracture diagnoses, then hands off to a multi-agent workflow that independently verifies results, retrieves clinical guidelines, and drafts patient-accessible reports; the verification agent flags 86.6% of cases as high-confidence needing no escalation, and user studies rate its reports as significantly more comprehensible than reports from Llama, MedGemma, and Gemini (arXiv, 2026).
- [A Modular Agent for Reliable and Auditable Spatial Relation Verification in CT Scans](https://arxiv.org/abs/2608.21140) - Decomposes binary spatial-relation verification in axial CT slices into language parsing, YOLO-based anatomical localization, and deterministic geometric verification instead of end-to-end VLM prediction, reaching 94.1% accuracy on the MIRP spatial QA benchmark and beating direct Qwen2-VL prompting by 42.5 points while keeping every intermediate step auditable (arXiv, 2026).
- [DentAgent: Evidence-Centric Multi-Agent Coordination for Multimodal Dental Reasoning](https://arxiv.org/abs/2608.18878) - An Orchestrator agent coordinates five modality-specialist agents over radiographs, intraoral photographs, and 3D dental data, tracking each agent's findings as structured evidence on a shared blackboard before generating traceable diagnoses, surpassing senior specialists by 17.3 points on multi-label diagnosis across four benchmarks (arXiv, 2026).
- [CT-PrepAgent: Bounded Policy and Controlled Execution for Adaptive CT Data Preparation](https://arxiv.org/abs/2608.01233) - Policy-driven CT data-preparation agent that profiles heterogeneous DICOM series and executes adaptive preprocessing through guarded, verified, and recoverable steps, lifting verified output yield from 61.7% to 70.0% on private data and improving downstream segmentation Dice across three public CT tasks (arXiv, 2026).
- [One-for-All Adaptive Radiotherapy Planning Agent: A Foundation Framework for Daily CBCT-guided Radiotherapy](https://arxiv.org/abs/2607.14870) - Foundation-model agent that autonomously performs complete online adaptive radiotherapy planning directly from daily cone-beam CT in under two minutes, chaining synthetic CT generation, multimodal alignment, and tumor/organ segmentation into a human-in-the-loop workflow across head-and-neck, lung, abdominal, and prostate cancers (arXiv, 2026).
- [Policy-Driven CT-Agent: Modeling Phase-Aware Diagnostic Control for Clinically Consistent CT Reasoning](https://arxiv.org/abs/2607.10748) - Policy-driven agent harmonizes heterogeneous CT phases into a unified evidence representation and iteratively requests additional contrast phases when diagnostic sufficiency is unmet, letting it flexibly follow different institutional, regional, or guideline-specific phase-selection protocols (arXiv, 2026).
- [A Vision-Language Framework for Comparative Reasoning in Radiology](https://arxiv.org/abs/2606.06407) - Entity-aware cross-image reasoning framework for reference-case retrieval and longitudinal comparison in radiology; introduces MedReCo-DB with 690K images from 160K patients across eight institutions and seven modalities (arXiv, 2026).
- [A Machine-to-Machine Knowledge-Guided LLM Agent for Generalizable Radiotherapy Treatment Planning](https://arxiv.org/abs/2606.00922) - Transfers DRL-derived treatment planning parameter knowledge to an LLM agent via in-context learning for autonomous, iterative radiotherapy planning without human intervention across prostate, liver, and complex anatomy cases (arXiv, 2026).
- [MedExpMem: Adapting Experience Memory for Differential Diagnosis](https://arxiv.org/abs/2605.22872) - Experience-memory framework that lets VLM-based diagnostic agents accumulate differential diagnosis expertise from prior failures and retrieve it for radiology cases across 11 subspecialties (MICCAI 2026, 2026).
- [A Discordance-Aware Multimodal Framework with Multi-Agent Clinical Reasoning](https://arxiv.org/abs/2604.16333) - Multimodal ensemble fuses ResNet18-derived knee MRI and X-ray embeddings with demographics and biomarkers, then a multi-agent clinical-reasoning layer interprets discordance between imaging-observed structural damage and patient-reported symptoms to assign osteoarthritis phenotypes and tailored management recommendations (arXiv, 2026).
- [Evo-MedAgent: Beyond One-Shot Diagnosis with Agents That Remember, Reflect, and Improve](https://arxiv.org/abs/2604.14475) - Self-evolving memory module that equips a chest X-ray agent with episodic, procedural, and tool-reliability memory stores for inter-case learning without retraining, lifting ChestAgentBench accuracy by up to 14 points (arXiv, 2026).
- [Agentic Automation of BT-RADS Scoring: End-to-End Multi-Agent System for Standardized Brain Tumor Follow-up Assessment](https://arxiv.org/abs/2603.21494) - Multi-agent system combining an extractor agent (clinical notes) and a scorer agent (BT-RADS decision logic + volumetric CNN segmentation) for standardized post-treatment glioma MRI response assessment (arXiv, 2026).
- [Agentic LLM Workflow for MR Spectroscopy Volume-of-Interest Placements in Brain Tumors](https://arxiv.org/abs/2603.13371) - LLM agent decomposes spectroscopy VOI placement into candidate generation and optimal selection via tool calls, enabling user-instruction-driven MRS acquisition planning for brain tumors (arXiv, 2026).
- [An Explainable Agentic AI Framework for Uncertainty-Aware and Abstention-Enabled Acute Ischemic Stroke Imaging Decisions](https://arxiv.org/abs/2601.01008) - Imaging agent that explains decisions and abstains under uncertainty for acute stroke workflows (arXiv, 2026).
- [CXReasonAgent: Evidence-Grounded Diagnostic Reasoning Agent for Chest X-rays](https://arxiv.org/abs/2602.23276) - Evidence-grounded chest X-ray agent that structures diagnostic reasoning around retrieved findings (arXiv, 2026).
- [DUCX: Decomposing Unfairness in Tool-Using Chest X-ray Agents](https://arxiv.org/abs/2603.00777) - Audits how unfairness arises across tool-selection and reasoning stages in CXR agents (arXiv, 2026).
- [Evidential Reasoning Advances Interpretable Real-World Disease Screening](https://arxiv.org/abs/2605.15171) - EviScreen retrieves region-level historical case evidence from dual knowledge banks to make medical image screening more interpretable (arXiv, 2026).
- [Experience-Guided Self-Adaptive Cascaded Agents for Breast Cancer Screening and Diagnosis with Reduced Biopsy Referrals](https://arxiv.org/abs/2602.23899) - Cascaded imaging agents adapt from prior cases to improve screening decisions while reducing unnecessary biopsies (arXiv, 2026).
- [GAZE: Grounded Agentic Zero-shot Evaluation on Rare Brain MRI](https://arxiv.org/abs/2605.00876) - Lets VLMs call DICOM viewer tools and PubMed-backed retrieval before generating reports for rare brain MRI cases (arXiv, 2026).

## Pathology Agents (Whole-Slide Imaging · Digital Pathology) (40)

Agents for whole-slide image analysis, digital pathology, pathology reports, and slide navigation.

- [PlanPath: Exploration-Guided Orchestration for Patient-Level Pathology Reasoning](https://arxiv.org/abs/2610.18664) - Turns a clinical question into an exploration plan, routes to the relevant slides among roughly 15 WSIs per patient, and moves from tissue- to cell-level analysis; on new renal and gastric cancer patient-level VQA datasets it beats the strongest baseline by 9.4% and 12.1% overall accuracy (arXiv, 2026; [Code](https://github.com/JSGe-AI/PlanPath_1)).
- [PathPilot: An Adaptive Question-Conditioned Multi-Magnification Navigation Agent for Whole-Slide Image Analysis](https://arxiv.org/abs/2610.16734) - Navigates across magnifications like a pathologist: CrossMagLoc learns per-magnification localization from pathologist viewing behavior to pick a starting region, then EviRegionSearch explores outward according to which question-relevant evidence is still missing; evaluated on question answering across five internal and external cohorts (arXiv, 2026).
- [MechAgent: Active Mechanism Falsification for Agentic Cross-Species Medical Reasoning](https://papers.miccai.org/miccai-2026-sat/MedAgent_042.html) - A committee of pathology, toxicology, translational, evidence-auditor, and adversarial agents deliberates over a typed hypothesis graph, selecting evidence information-theoretically and running latent interventions on a multimodal foundation model to test whether proposed biological mechanisms causally drive preclinical-to-clinical predictions (MICCAI 2026 MedAgent workshop, 2026).
- [An agentic framework for autonomous scientific discovery in cancer pathology](https://www.nature.com/articles/s41591-026-04357-y) - SPARK generates biological hypotheses, converts them into executable tissue-analysis tools, and verifies candidate biomarkers across histopathology and spatial biology cohorts; clinical utility still requires prospective validation (Nature Medicine, 2026; [Code](https://github.com/cpath-ukk/SPARK)).
- [TissueCodePilot: A Code-Action Agent for AI-Assisted Spatial Tissue Analysis](https://papers.miccai.org/miccai-2026/1062-Paper1741.html) - A coding agent plans and executes spatial tissue analyses from minimal natural-language prompts, evaluated on 1,500 image-question pairs across three tissue types; the project repository notes that code and data are not yet fully released (MICCAI 2026, 2026; [Project](https://github.com/hula-ai/TissueCodePilot)).
- [MorphoOrgaAgent: A Foundation-Model-Based Multi-Agent System for Autonomous Organoid Analysis](https://papers.miccai.org/miccai-2026-sat/MedAgent_039.html) - Agents interpret natural-language organoid analysis requests, combine Cellpose geometric prompts with SAM3 text prompts for instance segmentation, and generate measurements and reports; introduces the MorphoOrgaVQA evaluation benchmark (MICCAI 2026 MedAgent workshop, 2026).
- [Hepato-LLaVA: An Expert MLLM with Sparse Topo-Pack Attention for Hepatocellular Pathology Analysis on Whole Slide Images](https://arxiv.org/abs/2602.19424) - Introduces a sparse topo-pack attention mechanism and a 33K-pair expert-validated QA dataset to enable an expert multimodal LLM to interpret gigapixel hepatocellular carcinoma whole-slide pathology images (arXiv, 2026; [Code](https://github.com/PRIS-CV/Hepto-LLaVA)).
