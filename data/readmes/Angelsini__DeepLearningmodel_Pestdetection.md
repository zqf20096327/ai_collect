# Pest Detection using YOLOv5

An open-source deep learning project for pest detection using computer vision and YOLOv5.

## Features
- Pest detection from images
- YOLOv5 object detection
- IP102 dataset support
- Model training and evaluation

## Technologies
- Python
- YOLOv5
- PyTorch
- OpenCV

## Repository Contents
- pestrecognition.ipynb - Training and detection notebook
