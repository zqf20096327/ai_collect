## 这是什么

一套完整的抖音 AI 直播间，所有程序都在你自己的电脑上运行，大模型免费、离线：

- **弹幕现场回答**：本地大模型（Ollama + 通义千问 Qwen2.5，7B 或 14B）逐条作答，字幕上屏，微软语音配音，人物配合点头、挥手、大笑等动作
- **观众优先**：弹幕、礼物一进来，空场引导话术立刻让路，正在念的也当场掐断；礼物和 @主播的提问排在普通弹幕前面
- **礼物指挥主播**：小心心让他手速翻倍，大啤酒让他歇口气，嘉年华让项目一键上线
- **限时挑战和账本**：「挑战 AI 直播 2 小时赚 2000 块」横幅和倒计时，余额、花费、token 消耗面板
- **自动接入抖音**：用一个小号的 Cookie 读取直播间的真实弹幕和礼物
- **内容安全**：11 类敏感词库，观众弹幕和主播回复双向过滤；除抖音外不提其他平台名
- **一键换主播**：名字、性格人设、形象图、挑战时长和金额、账本速度，全在 `自定义/` 文件夹里改，不用碰代码
- **可选弹幕点歌**：接嗷呜点歌机（AwooMusicBot）+ 网易云音乐

![工作流程](教程图片/01-flow.png)

整条链路：观众在抖音发弹幕 → 「连接抖音直播间」读到弹幕 → 后端排队、过滤、让大模型写回复、配音 → 舞台页面显示人物和字幕 → OBS 采集舞台画面 → 直播伴侣推流回抖音。

## 开始前要准备什么

### 电脑

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11，64 位 |
| 显卡 | NVIDIA 显卡，**驱动更新到最新**。显存 12GB 及以上用 14B 模型（更聪明），8GB 用 7B（部署时自动选） |
| 硬盘 | D 盘或 E 盘留 **20GB** 以上（大模型 5～9GB，运行环境约 2.3GB） |
| 网络 | 第一次部署要下载约 10GB；直播时配音要联网 |

### 账号

- **主播号**：你用来开播的抖音号
- **小号**：另一个抖音号，只用来读取弹幕和礼物。**不要用主播号**，原因见[第 3 步](#第-3-步填写-env)

### 软件

| 软件 | 需要自己装吗 | 说明 |
|---|---|---|
| Node.js、Python、Ollama | **不用** | 第一次部署时自动下载官方免安装版，放进项目的 `runtime/` 文件夹，不往 C 盘装 |
| [OBS Studio](https://obsproject.com/zh-cn/download) | 要 | 用来采集舞台画面，安装时可以改到 D/E 盘 |
| 抖音直播伴侣 | 要 | 抖音官方的电脑开播软件，在抖音官网搜索「直播伴侣」下载 |

## 第一次使用：七步开播

![流程概览](教程图片/02-steps.png)

第一次大概需要一小时（主要是下载大模型）。以后每次直播只要几分钟，见[以后每次直播](#以后每次直播)。

### 第 1 步：下载项目

1. 点本页右上角绿色的 **Code** 按钮 → **Download ZIP**
2. 把压缩包解压到 D 盘或 E 盘，比如 `E:\AI直播\ai-live-room`
   - **不要**放在桌面或 C 盘
   - 路径里有中文没关系
3. 打开文件夹，应该能看到下图这些文件

会用 Git 的也可以：`git clone https://github.com/hanxiao203230222-hub/ai-live-room.git`

![文件夹里有什么](教程图片/03-folder.png)

日常只会用到三个 bat 文件（按图中 ①②③ 的顺序双击）和 `自定义` 文件夹。从 GitHub 下载的源码里还没有 `runtime` 文件夹，第 2 步会自动生成。

> 部署之后别再挪文件夹位置。挪了也没关系，再双击一次 `一键部署.bat` 就能修好。

### 第 2 步：一键部署

1. 双击 **`一键部署.bat`**，会弹出一个黑色窗口
2. 等它自动完成下面这些事（**中途别关窗口**）：
   - 下载免安装版 Node.js / Python / Ollama（约 1.6GB；电脑上已经装了的会跳过）
   - 安装程序依赖和抖音直连需要的 Python 环境
   - 生成 `.env` 配置文件，并按显存自动选 14B 或 7B 模型
   - 下载大模型（14B 约 9GB，7B 约 4.7GB），放在项目**旁边**的 `ollama-models` 文件夹
   - 代码自检
3. 看到绿色的 **「部署完成。」** 就成功了，黄字「还需要你手动做」下面是剩下的步骤（一般只剩填 `.env`）
4. 按任意键关闭窗口

![一键部署成功的样子](教程图片/04-deploy.png)

**这一步可能遇到的问题：**

| 现象 | 怎么办 |
|---|---|
| 下载中断、网络报错 | 再双击一次 `一键部署.bat`，已经下好的会跳过 |
| 提示「连不上 github.com，下载不了 Ollama」 | 过一会儿再试；或者先去 [ollama.com/download](https://ollama.com/download) 安装 Ollama，再双击 `一键部署.bat`（只会下载缺的） |
| 提示「托盘右键 Ollama → Quit，再运行一次部署」 | 你电脑上原本就有 Ollama 在运行。右下角托盘找到羊驼图标 → 右键 → Quit，再双击一次 `一键部署.bat` |
| 显存不够、选错了模型 | 看[常见问题](#常见问题)里的「直播时卡顿」 |

部署可以反复运行，不会覆盖你改过的 `.env` 和 `自定义` 文件夹。

### 第 3 步：填写 .env

> 只想先在电脑上试试、暂时不连抖音的话，这一步可以跳过，直接做第 4 步。

在项目文件夹里找到 `.env` 文件 → 右键 →「打开方式」→「记事本」。只需要改两行：

![用记事本填写 .env（示意，号码和 Cookie 是假的）](教程图片/05-env.png)

#### 3.1 填直播间号 `DOUYIN_LIVE_ID`

开播后，用电脑浏览器打开自己的直播间（或者在直播伴侣里复制直播间链接），地址最后那串数字就是直播间号：

![直播间号在哪（示意）](教程图片/06-roomid.png)

#### 3.2 填小号 Cookie `DOUYIN_COOKIE`

Cookie 用来读取礼物信息。不填也能收到弹幕，但收不到礼物。

1. 用 Chrome 或 Edge 打开 `https://live.douyin.com`，**用小号登录**
2. 按键盘 **F12** 打开开发者工具，点「网络 / Network」
3. 列表是空的就按 **F5** 刷新页面，然后随便点一条请求
4. 右侧「标头 → 请求标头」里找到 `cookie` 这一行，右键「复制值」
5. 粘贴到 `.env` 里 `DOUYIN_COOKIE=` 的后面

![获取小号 Cookie（示意，内容是假的）](教程图片/07-cookie.png)

改完按 **Ctrl+S** 保存，关闭记事本。

> ⚠️ **安全提醒**
> - **只用小号**：同一个 Cookie 长时间抓取可能被平台风控，用小号不会连累主播号
> - Cookie 等于账号的登录凭证：**不要发给任何人，不要截图外传**
> - 复制完别在网页上点「退出登录」，退出后这个 Cookie 就失效了
> - 等号两边不要加空格和引号

### 第 4 步：启动直播间并测试

1. 双击 **`启动直播间.bat`**，会出现一个黑色窗口，还可能多一个最小化的「Ollama」窗口
   - 黑色窗口就是直播间本体，**直播期间不要关**
   - Ollama 窗口是大模型服务，也不要关
2. 等窗口里出现「后端已启动」和「LLM 预热完成」。第一次启动要把大模型加载进显存，可能要一两分钟
3. 几秒后浏览器会自动打开**控制台** `http://localhost:5173/console.html`

![启动成功的样子](教程图片/08-startup.png)

控制台是给你自己用的后台，观众看不到：

![控制台](教程图片/09-console.png)

4. 检查顶部状态栏：「已连接」和「LLM：已接入」都正常就行。「抖音直连」现在是未启动（第 7 步之后才变绿），「嗷呜点歌机：未连接」不影响直播

![状态栏](教程图片/10-console-status.png)

5. 在「模拟弹幕」里点一个示例按钮，比如「三哥晚上好！」。几秒后右侧预览里会出现问答卡片，并且能听到主播说话
6. 在「模拟送礼」里点一个礼物，比如「大啤酒」。主播会感谢你，并去喝咖啡歇 15 秒
7. 测试完，在「直播挑战」里点一次 **「重置」**，清掉测试数据

> ⚠️ 正式直播时**不要再点**模拟弹幕和模拟送礼，观众会看到这些假互动；模拟送礼的金额也会算进挑战进度。

### 第 5 步：设置 OBS

画面的路线是：舞台页面 → OBS 浏览器源 → OBS 虚拟摄像机 → 直播伴侣。这一步只在第一次做，OBS 会记住设置。

1. 打开 OBS →「设置」→「视频」：**基础（画布）分辨率**和**输出（缩放）分辨率**都填 `1080x1920`，点确定
2. 「来源」面板点 **＋** → 选 **浏览器**，起个名字（比如「AI直播间」）→ 确定
3. 按下图填写：
   - URL：`http://localhost:5173/`
   - 宽度：`1080`，高度：`1920`
   - **「通过 OBS 控制音频」不要勾**：声音要从电脑扬声器放出来，直播伴侣才采得到

![OBS 浏览器源设置（示意）](教程图片/15-obs-browser.png)

4. 确定后，OBS 预览里应该能看到舞台。如果是白屏：确认「启动直播间」窗口开着，然后右键这个来源 →「刷新」
5. OBS 右下角「控制」面板点 **「启动虚拟摄像机」**。不用点「开始直播」，推流交给直播伴侣

![启动虚拟摄像机](教程图片/16-obs-vcam.png)

### 第 6 步：设置直播伴侣并开播

![直播伴侣设置（示意）](教程图片/17-douyin-companion.png)

1. 打开抖音直播伴侣，用**主播号**登录，选「常规模式」、**竖屏**
2. 「添加素材」→「摄像头」→ 设备选 **OBS Virtual Camera**
   - 不要选 WebcastMate VirtualCamera（那是直播伴侣自己的）
   - 画面有黑边：把分辨率改成自定义 1080×1920，再拖满画布
3. 底部声音设置：
   - **麦克风关掉**，开着会有回声
   - **电脑声音打开**，设备选你实际在用的耳机或音箱，不要选「默认」
4. 确认预览画面正常、主播说话时「电脑声音」的音量条在跳动
5. 点 **「开始直播」**

> 直播标题或简介里建议注明「AI 生成内容」。舞台画面底部已经自带一行「本直播间角色与回复由 AI 生成」。

### 第 7 步：连接抖音直播间

1. **开播之后**，双击 **`连接抖音直播间.bat`**
2. 回到控制台，顶部「抖音直连」**变绿**就说明连上了。从这时起，观众的真实弹幕和礼物会自动进来
3. 限时挑战会在连上直播间时自动开始第 1 轮

这个窗口直播期间也不要关。断线会自动重连；一直连不上就检查 `.env` 里的直播间号和 Cookie，以及是否真的已经开播。

### 下播

1. 直播伴侣点「结束直播」
2. 关掉「连接抖音直播间」和「启动直播间」两个黑色窗口
3. OBS 点「停止虚拟摄像机」，然后关闭 OBS

挑战进度会自动保存，下次启动接着算。

## 以后每次直播

第一次设置好之后，每次直播只需要：

1. 双击 **`启动直播间.bat`**，等控制台打开、「LLM：已接入」
2. 打开 OBS，点 **「启动虚拟摄像机」**
3. 打开直播伴侣，确认画面和「电脑声音」正常，点 **「开始直播」**
4. 双击 **`连接抖音直播间.bat`**，等控制台「抖音直连」变绿

右图只改了三处：`设置.json` 里的名字和挑战、`人设.md` 里的性格、`人物图/头像.png`。观众问「主播你叫什么名字呀」，她回答「我是元气小美啦，叫我小美就好」，这是大模型按新人设现场生成的。

| 想改什么 | 改哪里 |
|---|---|
| 主播名字、自称 | `自定义/设置.json` → `主播名字`、`自称` |
| 挑战每轮时长、目标金额、标题 | `自定义/设置.json` → `挑战` |
| 账本：每小时费用、token 消耗速度、余额 | `自定义/设置.json` → `账本` |
| 主播在直播里做的项目 | `自定义/设置.json` → `工作` |
| 性格、说话风格 | `自定义/人设.md`，用大白话写三五行 |
| 人物形象 | 透明背景的 PNG 半身像，命名为 `头像.png`，放进 `自定义/人物图/` |

改名字的例子（用记事本打开 `设置.json`，只改冒号后面的值）：

```json
"主播名字": "元气小美",
"自称": "小美",
"挑战": {
  "标题": "",
  "每轮时长分钟": 90,
  "目标金额元": 1000,
```

内置话术和提示词里的「热情三哥 / 三哥」会自动换成你设置的名字；挑战标题留空会自动生成「挑战AI直播90分钟赚1000块」。想先试试换形象，可以把 `教程图片/example-avatar.png` 复制到 `自定义/人物图/` 并改名为 `头像.png`。

每个字段的详细说明见 [自定义/使用说明.md](自定义/使用说明.md)。

## 常见问题

**主播不说话，或者回答来来回回都是那几句**
「Ollama」窗口被关了，或者大模型没下载完。关掉「启动直播间」重新双击；还不行就再运行一次 `一键部署.bat`，看最后的提示。

**刚启动时回复很慢，日志里有「LLM 调用失败：timeout」**
第一次启动要把大模型加载进显存，等日志出现「LLM 预热完成」就正常了。

**直播时卡顿**
OBS 和直播伴侣也要占显存。用记事本打开 `.env`，把 `LLM_MODEL=sangge-danmaku-14b` 改成 `LLM_MODEL=sangge-danmaku`（7B），保存后再运行一次 `一键部署.bat`（会下载 7B 模型），然后重启直播间。

**大模型一直很慢**
更新 NVIDIA 显卡驱动后重启电脑。

**观众听不到主播的声音**
按顺序查：OBS 浏览器源「通过 OBS 控制音频」**没有**勾；电脑本身能听到主播说话；直播伴侣「电脑声音」打开了，设备选的是你实际在用的耳机或音箱。

**观众听到回声**
直播伴侣的麦克风关掉；用手机看自己直播时，手机静音或戴耳机。

**OBS 白屏 / 直播伴侣黑屏**
OBS：确认「启动直播间」开着，右键浏览器源 →「刷新」。直播伴侣：确认 OBS 已经「启动虚拟摄像机」，摄像头选的是 OBS Virtual Camera。

**抖音直连连不上，或者礼物收到一两条就断**
确认已经开播、直播间号对、Cookie 是最新复制的。同一个 Cookie 长时间抓取可能被风控，先停几天或者换一个小号。

**提示端口被占用**
之前的直播间没关干净。关掉所有「启动直播间」窗口再重新打开。

**改了 `设置.json` 后启动报「格式有误」**
多半是少了或多了逗号，或者用了中文引号。对照上面的例子改回来。

更多问题见 [使用教程.md](使用教程.md#13-常见问题)。

## 开发者

```bash
npm install
npm run dev          # 后端 :4317 + 前端 :5173，改配置和提示词会自动重启
npm run typecheck    # 类型检查
npm run sim -- 3 20  # 每 3 秒发一条随机弹幕，共 20 条
npm run share        # 生成带免安装运行环境的分享版文件夹
```

| 页面 | 地址 |
|---|---|
| 竖屏推流页（1080×1920） | http://localhost:5173/ （`?mute=1` 静音，`?transparent=1` 透明背景） |
| 控制台 | http://localhost:5173/console.html |
| 后端 API + WebSocket | http://127.0.0.1:4317 （`/ws`，`POST /api/danmaku`，`POST /api/gift`） |

- 大模型默认走本机 Ollama 的 OpenAI 兼容接口，也可以在 `.env` 里换成 DeepSeek 等云端模型
- 提示词在 `config/prompts/`，敏感词库在 `config/sensitive/`，主配置在 `config/app.json`
- 详细的设计说明（意图识别、队列优先级、冷却、礼物、挑战、账本）见 [docs/开发文档.md](docs/开发文档.md)

```
├── server/          后端：弹幕队列、意图识别、大模型、TTS、礼物、挑战、账本、敏感词
├── src/stage/       竖屏舞台页（React）
├── src/console/     控制台页（React）
├── config/          app.json 主配置、prompts/ 提示词、sensitive/ 敏感词库
├── 自定义/          给使用者改的：设置.json、人设.md、人物图/
├── scripts/         部署、打包、下载运行环境、抖音直连桥（Python）、测试脚本
├── vendor/          DouyinLiveWebFetcher（抖音网页直播间抓取）
├── public/          静态资源，含占位形象
├── docs/            开发文档
└── 教程图片/        文档截图
```
