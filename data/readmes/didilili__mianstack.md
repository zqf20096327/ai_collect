**别再到处找了，面试备考的硬货，这一栈给你配齐！** 花费数月调研、整理、打磨，做出了自己心目中的「顶配题库」。资料收藏了一堆，临到面试还是不知道先看什么——这份题库，就是想帮你把最费时间的准备功课提前做好。

**面试官爱问什么，咱就重点练什么。** 面栈把真实面经里的提问与考点关联起来，让反复出现的问题有据可查，让备考重点更清楚。从技术基础到 AI 应用，从八股到项目实战，既能考前突击，也能深入学习。下一场面试，知道该练什么，更有底气接住一句「展开讲讲」。

📢 **免费开源，持续更新，内容与体验都是顶配。** 面试在变，面栈就继续跟上；新面经、新考点、新项目，持续添硬货。目标就一个：**打造「地表最强」程序员面试题库天花板！！**

## ✨ 面栈，强得有点超纲

- **🎯 把真实面经，做成你的面试备考外挂。** 同一道题，哪些公司问过、多少篇面经提及、原话怎么问，关联起来一起看。再按知识点、专题、题型和难度筛选，优先攻下反复出现的问题。**高频有依据，复习直接冲重点。** **[找高频考点 →](https://mianstack.com/question/)**

- **🏢 大厂题路定向突击，冲哪家就先摸透哪家。** 公司、岗位、校招社招、面试轮次分门别类，原帖里的招聘季、批次信息也一并整理。公司专页集中看面经、岗位与关联题目，**目标公司问过什么，先拿来练一遍。** **[按公司准备 →](https://mianstack.com/company/)**

- **💼 项目面硬货直接上桌，架构、选型、源码全安排。** 围绕 **20 个真实开源项目**，拆架构、看选型、找源码，配上简历示例和场景化答法。项目怎么介绍、方案为什么这么选、实现细节怎么追，都有具体项目可以对照。**项目面的底气，直接往源码里找。** **[进入项目拆解 →](https://mianstack.com/project/)**

- **📖 可能是你见过最舍得把答案讲透的题库。** **600+ 道参考答案**，结合官方文档、技术文章、优质题库与项目实现编写，参考资料随文标注。「核心回答」帮你抓住现场答法，原理、代码、图解和常见追问留给深入学习。先翻翻 **[Attention 怎么算](questions/Q-0036.md)**、**[B 树和 B+ 树有什么区别](questions/Q-0193.md)**，看看题解的成色。

- **🧾 大厂面试情报站，真面经持续上新。** 真实面经持续收录，原帖内容、来源链接及可见的作者、发布时间一起保留。关注近期考点，回看原始问法，**让备考跟着真实面试走。** **[看最新面经 →](https://mianstack.com/interview/)**

- **🔥 独家专题配热榜，考前突击上顶配。** **[面试有料](https://mianstack.com/topics/)** 按公司、项目和技术主题编排精华题单；**[面经热问榜](https://mianstack.com/#home-ranking-title)** 统计近 60 天发布的已收录面经，圈出反复出现的技术题；**[面前必看](https://mianstack.com/must-review/)** 先过八大方向的 60 道核心题。时间紧，就从这些重点下手。

- **🔓 这份题库，最狠的是免费还开源。** 网站资料免费阅读，题目与全部已有参考答案直接在本仓库开放。在线刷、下载看、提改进，甚至拿去做自己的复习工具，都有入口。**把顶配备考，做成人人都能用的标配。** **[直接读题库 →](INDEX.md)**

- **📌 收藏、复习、已掌握，你的备考有存档。** 题目、公司、面经随手收藏，给题目标记「待复习」「已掌握」，阅读历史和上次读到的题目也帮你记着。免注册，记录保存在当前浏览器，回来接着刷。**[我的复习 →](https://mianstack.com/study/)**

- **🤝 最强题库，一起添硬货。** 你刚遇到的新题，可能就是下一位求职者的重点题。分享面经、补充答案、指出错误、反馈体验，都欢迎；公开面经已有原帖，给个链接就能贡献。让我们一起，打造**全网最有价值**的程序员面试题库。**[参与共创 →](#contributing)**

- **🛠️ 教程、源码、神仙群友，直接给你配满队。** 配套 **[ai-agents-from-zero](https://github.com/didilili/ai-agents-from-zero)** 系统教程与完整实战源码，补原理、做项目、练面试，一路都有资料可跟。还有 **[「全宇宙最有爱的 AI Agent 社群」](#community)**，聊开发、聊面试、交流踩坑，也欢迎吹水吐槽。硬货一起学，弯路一起少走。

<summary><strong>数据复用与仓库目录</strong></summary>

题目、参考答案与面经原文使用 Markdown 保存，公开题集的原题与出处使用 JSON 保存。除了直接阅读，也可以用这些内容制作自己的检索、复习工具或阅读网站。读取方式见 **[数据使用说明](USAGE.md)**。

```text
mianstack/
├── questions/        # 面试题、考点与参考答案
├── assets/questions/ # 答案配图
├── interviews/       # 面经出处、公司岗位与原帖内容
├── collections/      # 公开题集里的原题与出处
├── indexes/          # 自动生成的题库目录
├── schema/           # 字段与引用规则
├── examples/         # 题目与面经文件示例
├── scripts/          # 内容检查与目录生成
├── tests/            # 内容检查脚本的测试
├── categories.json   # 知识方向与专题
├── aliases.json      # 旧题号对应的新题号
└── publishers.json   # 公开题集发布者
```

题号固定，不会重新排序或重复使用。网站中的项目档案、题目与来源的关联及专题编排由网站单独维护，不包含在本仓库的数据中。

字段与维护方式见[字段说明](schema/README.md)、[维护说明](MAINTAINING.md)和[变更记录](CHANGELOG.md)。

</details>
