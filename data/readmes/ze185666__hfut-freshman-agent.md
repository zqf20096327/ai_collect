# 合工大工科新生智能体

合肥工业大学工科新生 AI 助教 —— 基于扣子（Coze）Web SDK 的免登录嵌入式聊天页。

面向大一工科新生的高频痛点：高数 A 听不懂、电路分析不会做题、找不到学长笔记和真题课件。这个页面把已经搭好的 Agent 直接嵌进网页，打开就能问，不用注册、不用跳转。

## 功能

- **免登录直聊**：页面加载即挂载 Coze Web SDK，无需注册账号
- **全屏自适应**：SDK iframe 铺满视口，移动端可直接分享到班级群
- **启动兜底**：脚本被拦截、token 失效、网络异常三种情况都有提示和重试，不会一直转圈
- **轻量**：单文件 HTML，无构建、无依赖，扔到任意静态托管即可

## 快速开始

1. 克隆仓库
2. 打开 `index.html`，把第 69 行的占位符换成你自己的令牌：

```js
var TOKEN = 'sat_REPLACE_WITH_YOUR_TOKEN';
```

3. 用任意静态服务器打开（直接双击 `file://` 打开可能被 CORS 拦截）：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 获取令牌

在扣子平台创建 Agent 并发布为 Web SDK 应用后，可在应用详情页获取访问令牌。注意两点：

- 令牌需要同时具备 **读取项目信息（getMetadata）** 和 **运行（run）** 权限，否则页面会显示"无权访问"
- 令牌写在前端代码里等于公开，**只适合演示和课程作业**。正式上线应改为后端签发短期令牌

## 项目结构

```
.
├── index.html   # 单文件应用（样式 + SDK + 启动逻辑）
└── .coze        # 部署配置
```

## 设计说明

- 启动页用蓝紫渐变 Logo + 加载动画覆盖首屏，SDK 就绪后淡出，避免白屏
- 用 `MutationObserver` 监听 SDK 动态插入的 iframe，在其 `load` 后收起启动页，比固定延时更可靠
- 20 秒仍未拿到 iframe 则判定失败，给出"重新进入"按钮

## 背景

合肥工业大学集成电路学院大一课程作业（Vibe Coding 方向）。选题来自自己上课的真实问题：高数 A 的极限证明、电路分析的节点法，课堂上跟不上就只能自己啃。做这个页面的目的是把答案送到同学手边，点开就能用。
